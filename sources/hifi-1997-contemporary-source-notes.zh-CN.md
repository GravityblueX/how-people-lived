## 1. 一名电子厂职工：单位宿舍本身可以决定 Hi-Fi 是否“玩得起来”

### Locator

1997 年第 8 期，约 39 页：

**《富有胆味的晶体管合并机——评华韵 A-50 扩音机》**，署名“Hi-Fi钟”。

当前目录摘要明确出现第一人称：作者称自己是音响发烧友，主要玩胆机；白天在番禺一家电子厂工作，晚上住公司宿舍，并把宿舍面积较大、因此有较大地方听 Hi-Fi 直接联系起来。摘要还写到，他平时有空会去广州的电器城逛，与一家主要卖胆机的店主很熟，朋友买音响时也常找他商量。

### 这条材料能证明什么

这是目前 hobby-life-world 线非常理想的一条同期个人材料，因为它把几个通常被拆开的变量压在一个人身上：

```text
职业：电子厂职工
+ 居住：公司宿舍
+ 空间：宿舍较大
+ 休闲：有空听 Hi-Fi / 逛电器市场
+ 技能偏好：胆机
+ 零售关系：与专业店主熟悉
+ 同好角色：朋友购买时会向他咨询
```

因此可以直接支持一个很具体的机制：

**housing allocation / 居住安排不只是“住在哪里”，还可能决定某种兴趣有没有声学空间。**

对于一套需要音箱距离、听音位和一定音量的 hobby 来说，单位宿舍面积可能比“是否买得起一台机器”同样重要。

### 不能证明什么

- 不能把这名电子厂职工外推成 1997 年普通产业工人；
- 他本身在电子厂工作，可能比一般劳动者更容易接触电路、元件和器材知识；
- 摘要没有给工资、器材总价、宿舍平方米数；
- “朋友常找他商量”能证明局部口碑角色，不能证明他是正式俱乐部核心人物。

### 下一步

优先找完整页或扫描，以抽取：

- 作者具体器材；
- 单位宿舍结构；
- 是否自行维修/制作；
- 器材价格；
- 广州电器城具体名称；
- 是否提到家庭成员或邻里噪声。

## 2. “工薪族”的价格边界在 1997 年文本里已经被参与者自己说出来

### Locator

1997 年第 8 期，54—55 页：

**《令你心动的组合》**，署名“学明”。

目录摘要明确把“工薪族”和器材价格联系起来：作者先承认音响领域存在“一分钱一分货”的升级逻辑，但紧接着说明，对工薪族而言，天价器材属于可以听、却难以实际购买的对象，因此“超值”“价钱相宜”的器材才成为真正可进入的选择。

### 研究意义

这比研究者今天说“当年 Hi-Fi 很贵”更强，因为它是 **1997 年圈内文本自己在区分 aspiration 与 executability**：

```text
看得到 / 听得到高端系统
≠
家庭预算可以拥有
```

可以把它接到两个项目概念：

- **aspirational listening / 向往型试听**：借商店、展会、朋友系统短暂获得高端声音；
- **wage-compatible system / 工资兼容系统**：真正能进入家庭并长期维持的器材组合。

后续 price-to-wage ladder 不应只搜最高价机器，而要优先找文章里明确面向“工薪族”“入门”“超值”的组合价格。

### 边界

- “工薪族”是作者自己的市场/身份分类，不等于统计学收入组；
- 摘要没有收入分母；
- 推荐组合可能受媒体和商业生态影响，不能当成实际销量。

## 3. “惯常去海印看行情”：专业市场本身可以成为周末 hobby routine

### Locator

1997 年第 8 期，68—70 页：

**《我等你来，已经等了一年多啦！——访问二位法国 TRIANGLE（金三角）厂方人员》**，徐昶。

摘要中的第一人称回忆称，1995 年中旬某天，作者“惯常”去海印电器区看行情，并进入金海印电器广场二楼的一家大型音响店。

### 研究意义

这个“惯常”很重要。

它说明专业市场不是只有“决定购买后才去一次”的交易终点，也可以成为 hobby routine：

```text
没有明确购买计划
→ 周末 / 空闲去专业市场
→ 看新品与行情
→ 试听
→ 与店员 / 同好交流
→ 回家继续比较
```

也就是说，**retail space can become leisure infrastructure / 零售空间可以变成休闲基础设施**。

在 Web 搜索、视频测评和电商之前，“去市场看看”本身承担今天刷新品、看测评、比较价格的一部分功能。

### 边界

这是一名深度器材参与者/媒体作者的实践，不应外推为所有消费者；但可以证明该生活方式实际存在。

## 4. 1985 DIY 记忆在 1997 同期文本中的残留：爱好的代际链早于 Web

### Locator

1997 年第 8 期，50—51 页：

**《味胜醍醐的双束射四极管——829B(FU29)》**，金伟杰。

作者在 1997 年文本中回忆：1985 年夏，《无线电与电视》曾刊出使用 829B/FU29 的功率放大器电路，随后有人按图仿制；作者自己利用旧广播扩大机的外壳与铁台，花了一个多月制作和调试。

### 证据分类

- 对 **1997 年作者如何记忆 1985 DIY 路线**：A（同时代 1997 文本）。
- 对 1985 那篇文章的精确内容与实际传播规模：**C/B 候选**，必须追 1985 原刊复核。

### 研究意义

这提供了一条非常清楚的前互联网技术知识链：

```text
技术杂志刊电路
→ 读者按图制作
→ 旧设备外壳 / 现成元件再利用
→ 一个月级调试劳动
→ 周边同好听音 / 传播
```

它提醒 Hi-Fi 的经济门槛不能只写“进口整机价格”。DIY 路线可能以大量时间、技能、二手零件和失败风险替代现金。

后续应把 **money-to-skill substitution / 金钱—技能替代** 加入 hobby 比较。

## 5. “发烧友和他的 Hi-Fi 俱乐部”：圈内人当时已经在反思“谁算发烧友”

### Locator

1997 年第 8 期，约 71 页附近目录条目：

**《在音乐中寻知音——记一位发烧友和他的 Hi-Fi 俱乐部》**，肖遥。

摘要开头即写作者接触过不少发烧友，包括偏音乐和偏器材者，并直接提出“怎样才算是发烧友？”

### 研究意义

这能防止今天把“发烧友”当成一个稳定、客观、从来定义一致的人口分类。

至少到 1997 年，圈内文本自己已经在区分：

- 喜爱音乐；
- 热衷器材；
- 俱乐部参与；
- 身份自称与外部识别。

因此任何历史量化都不应把“购买中高端音响的人”“杂志读者”“俱乐部成员”“自称发烧友”混成同一分母。

## 6. 同一期本身就是一个“兴趣世界截面”

1997 年第 8 期目录同时出现：

- 国际音像博览会；
- 海外与国产器材评测；
- 发烧友第一人称；
- 胆机 DIY；
- 每月器材搭配；
- 北京音响城；
- 音像城和进口唱片；
- 武汉国际音响大展；
- Hi-Fi 俱乐部。

因此它可以作为一个 **source bundle / 同期来源包** 来研究：

```text
器材
+ 音乐载体
+ 商店
+ 展会
+ DIY
+ 个人身份
+ 俱乐部
+ 工薪预算语言
```

这些不是 Internet 以后才出现的组件。

Web 后来的变化应更精确地问：

- 原来按月出版的信息变成多快？
- 原来必须去海印/新街口才看到的行情，能否异地搜索？
- 原来编辑筛选的来稿，是否变成任何用户都能发帖？
- 原来店内/俱乐部口头声望，是否变成论坛账号的可见声望？
- 原来本地二手与熟人交换，是否变成全国可搜索 listing？

## 7. 对“普通人到底有多少种活法”的补充

这一组同期材料已经足够证明：至少在 1990s 中后期，中国城市里真实存在这样一种并不等同于职业或家庭身份的生活路径：

```text
白天上班
→ 晚上回宿舍/家听系统
→ 空闲去音响市场
→ 读专业刊物
→ 自己制作或调整器材
→ 帮朋友选机器
→ 去商店/俱乐部试听自己买不起的系统
→ 下一月继续
```

它不会出现在“学历—就业—婚姻—住房—生育”序列里，却真实占据同一个人的工资、住房和时间。

这也是 hobby life-world 轴要保存的东西：

> **一种人生不只有它必须完成的节点，也有它愿意持续返回的地方。**
