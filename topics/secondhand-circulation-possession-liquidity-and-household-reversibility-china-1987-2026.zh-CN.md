# 从卖旧货到“回血”：二手流通、财物退出与家庭可逆性（中国，1987–2026）

## 研究问题

这篇 note 不把二手交易写成消费潮流史，也不把“循环经济”当作天然进步叙事。它补的是普通生活矩阵里一个此前容易被忽略的问题：**一个人买进一件东西之后，还能不能比较低成本地把它卖掉、送走、换成现金或腾出空间？**

购买能力只描述了家庭资产流的一半。另一半是退出：

- 搬家时，家具能不能处理掉；
- 毕业时，书、电脑和生活用品是否只能丢弃或高成本带走；
- 初入职场时，能不能用二手物品压低“把出租屋变得可住”的门槛；
- 收入紧张时，闲置物品能不能变成一笔小额现金缓冲；
- 照护、返乡、换城市或缩小住房时，已经积累的物品会不会反过来成为移动阻力；
- 一个人从偶尔出售闲置，什么时候又会跨进持续倒卖、维修、收购等非正规劳动。

本文使用几个工作概念：

- **ownership exitability / 财物退出可执行性**：拥有之后，能否在需要时把物品从家庭库存中退出；
- **possession liquidity / 财物流动性**：物品能否在可接受时间、折价、运输和交易成本下重新变成现金；
- **household reversibility / 家庭库存可逆性**：建立一个家庭或房间时购入的物品，是否会把人永久锁在原地点和原生活阶段；
- **furnishing-threshold compression / 居家配置门槛压缩**：二手购买是否降低第一次独立居住、租房或异地落脚所需的前置成本。

必须先固定几条边界：

`有旧货市场 ≠ 每个人都方便卖旧货`

`网页上挂出 ≠ 有买家 ≠ 成交 ≠ 已收款`

`成交价 ≠ 原购买成本可恢复`

`二手更便宜 ≠ 使用成本一定更低`

`卖闲置 ≠ 从事二手经营`

`二手平台增长 ≠ 人们变得更贫困或更环保`

---

## 1. 前互联网基线：Internet 没有发明二手流通，问题首先是“卖到哪里去”

### 1.1 1987 北京：旧货很多，但卖出渠道本身就是基础设施

北京市政府 1987 年转发《关于解决卖旧货问题的请示》。文件记录，1985 年北京收售旧自行车 61,015 辆、旧电视机 13,902 台、旧手表 21,529 块、旧录音机 7,602 台；旧货销售额 4,424 万元，比 1975 年的 1,440 万元增长两倍。

更重要的不是规模，而是文件自己指出的摩擦：当时旧货主要由国营信托企业经营，**渠道单一、网点不足、分布不均，群众卖旧货很不方便**。政策提出增加集体、个体等渠道、开办旧货市场，并要求信托企业把坐店收购与社区定点收购、**电话预约收购、流动上门收购**结合起来。

来源：北京市人民政府办公厅，1987-04-30，A 级同时代制度材料：
<https://www.beijing.gov.cn/zhengce/zfwj/zfwj/bgtwj/201905/t20190523_73266.html>

这给二手生活史提供了一个很重要的前互联网基线：

```text
household owns unwanted object
→ knows there is a buyer/channel
→ can reach outlet or arrange pickup
→ item can be appraised
→ transport is executable
→ seller accepts price
→ object exits household
→ cash/space is recovered
```

其中任何一步失败，所谓“这东西还有价值”都不等于它对家庭具有可执行的流动性。

因此 Internet 到来以前也已经有 **addressability problem / 可寻址问题**。只不过地址不是搜索框里的个人卖家，而是信托商店、旧货市场、流动收购者、电话预约和熟人网络。

### 1.2 1998：旧货市场本身已经被制度化成一个服务栈

1998 年《旧货流通管理办法（试行）》把“旧货”定义为已经进入生产或生活消费、处于储备、使用或闲置状态但仍保留使用价值的物品；把旧货市场定义为具有信息、评估、结算、翻新、保管、运输等配套功能的交易场所。

来源：国内贸易部、公安部，1998-03-09，A：
<https://www.hengqin.gov.cn/lab/flfg/bmgz/content/post_3727256.html>

这说明旧货交易从来不只是“卖家遇到买家”。一个可运行的二手市场还需要：

`信息发现 + 成色判断 + 价格形成 + 身份/来源判断 + 支付 + 仓储 + 搬运 + 必要时翻新`

后来互联网真正改变的，主要是其中的信息发现、匹配、信用和支付层；大件家具、电器的搬运、检查和现实交付并没有因此消失。

### 这一阶段仍不知道的事

本轮没有取得足够的 1980s–1990s 普通家庭日记或同时代第一人称，去量化人们究竟更常把衣物、家具、家电送亲友、卖给流动收购者、带去信托商店，还是干脆长期堆放。**制度上存在旧货流通 ≠ 普通家庭的退出路线已经被完整复原。**

## 2. 2005–2012：扩张型未来里，财物第一次被大量压成“同城可搜索对象”

### 2.1 2005 赶集：发现在线，交付仍然在线下附近

2005 年《新京报》报道赶集网在北京出现，明确把模式概括为“线上二手货，线下就近交易”。平台把城市理解成一个大社区，普通用户可以免费发布信息，再在附近完成现实交易。

来源：新京报经新浪科技保存，2005-06-02，B：
<https://tech.sina.com.cn/i/2005-06-02/0941624627.shtml>

同年 58 同城上线；2005 年底的同期报道说，发布流程被简化，并加入结构化分类搜索和用户评价。2006 年 263 又把原有“跳蚤市场”升级为更广泛的分类信息业务，并强调分类信息高度依赖城市和地域。

来源：

- 赛迪网经新浪科技，2005-12-20，B：<https://tech.sina.com.cn/roll/2005-12-20/1121797097.shtml>
- 新浪科技，2006-05-24，B / 平台经营者同时性陈述：<https://tech.sina.com.cn/i/2006-05-24/1438953632.shtml>

这里真正新增的是 **personal-goods addressability / 个人旧物可寻址性**。一把椅子、一台显示器、一本教材，不必先进入专业旧货商店，普通人自己就能把它编码成：

`类别 + 标题 + 描述 + 价格 + 城市/区域 + 联系方式`

然后等待附近陌生人搜索到。

但它仍然是非常明显的混合链：

```text
online discovery
→ message/phone
→ negotiate
→ arrange place/time
→ inspect
→ cash/payment
→ carry item away
```

所以“分类网站出现”不能写成“二手交易已经完全电子化”。

### 2.2 2005：支付中介开始改变“先给钱还是先给货”的信任结构

2005 年同期报道把支付宝解释为一种信用中介：在买家确认收到货前暂时保管货款。这个机制并不限于二手商品，但它对陌生人 C2C 尤其关键，因为它把原来的：

`先汇款给陌生人 / 先发货给陌生人`

拆成：

`买方付款 → 平台暂存 → 卖方发货 → 买方确认 → 卖方收款`。

来源：人民网-江南时报经新浪财经，2005-02-03，B：
<https://finance.sina.com.cn/roll/20050203/04301343972.shtml>

这使交易半径可以从“最好能当面验货”进一步扩大到跨城快递，但新增的也不是无条件信任，而是 **platform-mediated conditional trust / 平台中介的条件性信任**。

### 2.3 2007：毕业生的物品退出，直接连接另一个年轻人的低成本进入

2007 年初的一篇同期报道记录：一名当年大学毕业、刚参加工作的刘先生，在网站跳蚤市场从一名即将毕业离校的大学生手里买到 15 英寸液晶显示器和品牌 MP3，总价约为新品的一半。他自己明确说，这种网上淘换很适合经济能力不强的初职青年和学生。

来源：齐鲁晚报经新浪，2007-01-01，B，含同时性第一人称：
<https://news.sina.com.cn/c/2007-01-01/032710905959s.shtml>

这里非常值得把卖家和买家放在同一条生命历程链上：

```text
毕业者：即将离校 → 物品成为移动负担 → 卖出
          ↓
初职者：收入有限 → 需要设备 → 以较低价格买入
```

同一件旧物连接了两种相反的过渡：**一个人在缩减上一阶段的库存，另一个人在降低下一阶段的进入成本。**

这可以称为 **transition matching / 过渡期匹配**。

### 2.4 2009：大量人“想卖但不知道怎么卖”——退出可执行性仍未自动成立

《中国青年报》2009 年通过腾讯网进行的 1,571 人调查不是全国代表性样本，但它提供了极好的机制证据：97.2% 受访者称有闲置物品，76.5% 想卖却不知道怎么卖，只有 19.5% 表示卖过。

同一报道里，北京通讯公司职员文小娟发现 40 多件几乎没穿的衣服，朋友帮她在网站“个人闲置”区贴照片，每件标 10–20 元；一天内卖掉 8 件，买家都上门自取、当面交易。她接受的价格很低，但仍因物品终于退出家中而高兴。

来源：中国青年报，2009-03-31，B，含同期第一人称：
<https://zqb.cyol.com/content/2009-03/31/content_2603231.htm>

这里可以把 **possession liquidity** 拆成至少三个维度：

- **time liquidity**：多久能卖掉；
- **price liquidity**：要折价到什么程度才有人接；
- **logistics liquidity**：对方能否自取、自己是否要打包寄送。

卖出并不代表原价值被恢复。文小娟的案例反而说明，普通家庭可能通过很大的折价换取**空间和时间上的快速退出**。

同一报道还有另一条非常重要的非正规劳动路线：一名从安徽来北京的旧家电经营者收购电视，简单维修清洁后再出售，主要顾客包括外来务工者和刚毕业学生。他把这种收入方式和普通打工比较，认为自由度更高。

这说明二手流通还存在一个不能混淆的边界：

`household liquidation → occasional resale → repair/resell → regular secondhand livelihood`

它们不是同一类劳动。

## 3. 2015–2019：拥堵型未来里，二手平台扩大选择，也把信任、验货和维权劳动推给个人

### 3.1 二手购买可以降低“拥有一个能用的生活”的门槛

2018 年《人民日报》记录一名在北京工作的“90 后”赵琳：原本要更换一条新首饰链需 1000 多元，她在二手平台找到同款、约八成新的链子，价格 300 元；之后又陆续购买二手双肩包、化妆镜台灯等。

来源：人民日报，2018-07-27，B，含同期第一人称：
<https://society.people.com.cn/n1/2018/0727/c1008-30173724.html>

这里并不是“买不起新品所以只能买旧”的单一路径。更准确的是：二手市场让一个人可以在**新品预算、二手预算、不买**之间重新组合。对租房者、学生、初职者尤其重要，因为需要一次性配置的东西很多，而每件物品的使用期限可能短于一个长期家庭。

### 3.2 但平台把“陌生物品”带进生活，也把证据劳动带给普通人

同年媒体调查记录了“到手刀”、调包、脱离平台交易、骚扰等问题。一名大学生回忆自己 2014 年第一次在平台出售闲置自行车时，因为缺少经验接受了不可靠的交换方案，最后损失物品和运输成本；另一名个人卖家则说，为了防纠纷，自己会从装箱到寄出全程拍摄保留证据。

来源：中国新闻网经人民网，2018-08-28，B，含同期/近同期个人陈述：
<https://capital.people.com.cn/n1/2018/0828/c405954-30255147.html>

于是成熟二手平台并没有把交易成本消掉，而是把它改写成：

`拍照描述 + 定价 + 回复 + 判断账号 + 打包 + 运费 + 留证 + 等确认 + 售后/争议处理`

可以称为 **resale administration labor / 转售行政劳动**。

对低价大件物品尤其如此：如果退货运费、搬运和时间成本接近商品本身价值，消费者即使发现问题也可能放弃维权。2009 年《中国青年报》已经记录过类似旧家电案例。二手“便宜”因此必须和**剩余寿命、检验能力、搬运成本、退换可执行性**一起算。

## 4. 2020–2022：偶发型未来里，家庭库存开始更像一个可反复买入—卖出的账户

2022 年《工人日报》记录在上海工作的“90 后”刘白。她在 2016 年大学毕业、有收入后开始购买衣物，也逐渐产生不再喜欢的闲置；经同学介绍，她使用二手平台“一键转卖”，不到一周以 29 元卖掉一件毛衣。她记得买方确认收货后货款进入账户这件事给自己带来的便利感。到 2022 年 2 月，她卖出一只 58 元的直板夹时，这已经是她通过平台卖出的第 363 件商品。

来源：工人日报经新华网，2022-02-14，B，含同期第一人称：
<https://www.news.cn/politics/2022-02/14/c_1128367326.htm>

这和 2009 年“想卖但不知道怎么卖”的状态已经不同。对一部分熟练用户，出售闲置从偶发事件变成了一个重复流程：

```text
buy
→ use
→ become idle
→ relist
→ ship
→ receive money
→ buy/use again
```

这可以称为 **reversible consumption inventory / 可逆消费库存**。购买不再总被理解为“东西从此永久进入家庭直到坏掉或丢弃”，而是“先拥有，之后如果不需要仍可能重新退出”。

但这绝不等于家庭物品已经像银行存款一样流动：

- 并非每件物品都有人接手；
- 实际成交价通常低于购买价；
- 拍照、沟通、打包和寄送都需要时间；
- 低价物品可能不值得出售；
- 平台规则、账号信用、快递和支付都成为新的依赖。

所以“闲置品是资产”只能写成**有条件的资产**。

### 不把疫情强行写成原因

2020–2022 处在疫情时期，但上述刘白的二手使用路径从 2016 年就开始。疫情可能影响消费、物流、收入或整理行为，但本轮没有足够证据证明她的转售习惯由疫情造成。因此这里只把这一阶段用作“普通生活连续性受到测试时，平台化转售已经存在”的时间背景，而不做因果跳跃。

## 5. 2023–2026：防守型未来里，二手流通开始成为“别把自己锁死”的一种家庭策略

### 5.1 2025：租房、换工作、换城市的人，可以把住房配置做得更轻

2025 年《中国青年报》记录关亚飞：大学毕业后换过几份工作、跨城市搬家四次，目前和朋友在北京五环外合租；她从高中起就在线出售闲置，毕业后家里越来越多东西来自二手市场，记者写到她住处近八成物品来自二手渠道，一台原价约 3000 元的洗衣机以 350 元买入。

来源：中国青年报经中新网，2025-10-02，B，第一人称：
<https://www.chinanews.com.cn/sh/2025/10-02/10493109.shtml>

这条材料把二手市场和迁移真正接起来。一个高流动租房者如果必须对每次搬家都购买全新家电、家具，再在离开时承受全部沉没成本，独立居住会更昂贵；如果相当一部分库存可以低价进入、以后再转售，家庭就获得一定的 **asset-light mobility / 轻资产移动性**。

这里的“轻”不是没有物品，而是**不把每一件物品都当成必须陪伴几十年的长期资产**。

### 5.2 2025：照护导致的迁移，会先变成一次“清算房间”的劳动

同年另一篇《中国青年报》第一人称更直接。28 岁姜敏在北京生活十年，母亲重病后决定回省会城市工作并把父母接到身边。离开的决定成形后，她把家里“没必要带走”的 100 多件物品陆续挂上二手平台；搬离出租屋时，大部分已经卖掉。她把这个过程形容成像在出售自己的过去。

来源：中国青年报经中国青年网，2025-12-27，B：
<https://txs.youth.cn/xw/202512/t20251227_16432749.htm>

这补出了一个此前迁移研究里容易遗漏的环节：

```text
care shock
→ reconsider city/job
→ decide to move
→ classify possessions: take / sell / give / discard
→ convert some objects to cash
→ reduce moving load
→ close old household
→ assemble next household
```

迁移不是人和行李箱瞬间换城市。一个住了十年的成年人，需要把十年积累的物质生活**解绑定**。

可以称为 **transition liquidation / 过渡期清算**。

### 5.3 “回血”不是财富神话，而是微型缓冲

2025 年同期青年消费报道已经把“出售闲置、赚钱回血”作为常见说法记录下来。对具体家庭而言，它的意义不应被夸大：卖几件衣服、相机、桌椅很少足以替代稳定收入或正式社会保障；但它可以让原本纯粹沉没的消费品重新产生一点现金和空间。

因此更准确的概念是 **micro-liquidity fallback / 微型流动性后备**，而不是“家庭资产证券化”。

## 6. 海外对照：Craigslist 显示，分类信息如何把“搬到一座城市”的几个前置任务压到同一个检索层

2004 年 Boulder County Business Report 对 Craigslist 的同期报道保存了一名 22 岁迁居者 Jessica Matzuk 的经历：她还住在弗吉尼亚、距离 Boulder 数千英里时，就通过 Craigslist 联系当地出租房源，最终找到合适房间；到当地后又通过 Craigslist 找到床，并继续用它查询活动、课程和演出。她把这种方式和报纸分类广告比较，强调网上信息免费、描述更详细、更容易搜索。

来源：Craigslist 保存的 2004-01-23 同期媒体转载，B：
<https://www.craigslist.org/about/press/simpletrick>

这提供了一个与中国 2005–2010 分类信息非常可比的机制：**arrival-stack compression / 到达前置栈压缩**。

过去搬到陌生城市以后才逐项解决的：

`房间 → 床/家具 → 工作/服务 → 社交活动`

可以在到达之前通过同一个城市分类信息层先发现一部分候选。

这不是中国特有，也不是 2010s 手机平台才出现的。共同变化来自**城市化人口移动 + 搜索型本地信息系统**；中国的具体形态则受到本地分类网站、门户频道、QQ/电话、当面交易、C2C 支付和快递体系共同塑造。

---

## 7. Internet 到底改变了什么？不是“旧货有了”，而是退出半径、匹配粒度和交易状态变了

可以把长期变化粗略写成：

```text
亲友转送 / 信托商店 / 旧货市场 / 流动收购
→ 电话预约与更密集的城市旧货网络
→ 门户跳蚤市场 / 分类网站：个人 listing 可搜索
→ C2C：账号 + 支付中介 + 快递扩大交易半径
→ 移动二手平台：拍照、定价、聊天、信用、物流、支付集成
→ 家庭形成“买入—使用—再卖出”的重复循环
```

真正新增的不是“人终于会买旧东西”，而是：

1. **seller addressability**：一个普通卖家和一件具体旧物更容易被陌生人搜到；
2. **market radius expansion**：交易半径从附近市场逐渐扩到同城、跨城；
3. **trust instrumentation**：评分、历史交易、平台支付、争议处理变成信任工具；
4. **inventory reversibility**：物品不再天然被假定为永久留在家庭；
5. **transition support**：毕业、初职、租房、搬家、照护返乡等人生过渡可以通过二手流通降低一部分物质摩擦。

## 8. 反例与风险：高可见性并不意味着高流动性

### 8.1 有 listing，没有成交

页面曝光、收藏、聊天和询价都不是成交。一个物品可以挂很久，最后仍然被扔掉或带走。

### 8.2 价格不是唯一成本

大件二手家电和家具还包含：

- 运输；
- 上楼；
- 安装；
- 清洁；
- 维修；
- 剩余寿命；
- 退货搬运。

因此低买价可能对应更高总成本。

### 8.3 交易安全不是平台自动解决的

2018 年大量报道中的调包、“到手刀”、脱离平台诈骗、骚扰等表明：信用工具只能降低部分风险。个人仍需要判断、保存证据和承担纠纷时间。

### 8.4 二手出售也可能变成另一份工作

当一个人为了卖几十件东西持续拍照、回复、打包、寄快递时，家庭清理已经有明显劳动量；如果进一步专门寻找货源、维修、转卖，则跨入非正规经营。研究时必须区分“减少家庭库存”和“靠买卖差价谋生”。

### 8.5 不把非自愿低价消费浪漫化

买二手可能来自审美、环保、兴趣，也可能只是预算约束；卖掉物品可能来自极简，也可能来自失业、照护、搬迁和空间压力。不能把所有路径都包装成“循环生活方式”。

## 9. 对四种未来时间感的修正

### 2005–2012：扩张型未来

新增的是“更多东西可见、更多陌生人可联系、更多低价设备可进入生活”。对毕业生和初职者尤其如此。与此同时，很多交易仍依赖电话、QQ、同城见面、现金和自己搬运。

### 2015–2019：拥堵型未来

物品选择更多、交易更容易，但家庭也积累更多闲置；平台化转售变成管理库存的一种办法，同时制造定价、聊天、打包、信用判断与维权劳动。

### 2020–2022：偶发型未来

成熟用户已经能把闲置出售作为重复性的家庭后台流程。它提供一点现金和空间后备，但物流、账号和平台规则本身也成为连续性依赖。

### 2023–2026：防守型未来

更值得注意的不是“年轻人都爱二手”，而是**不把一次消费永久锁死**：租房、换城、照护返乡、兴趣变化时，尽量保留退出路线。二手平台因此与“稳定”并不矛盾——它可以是一种通过降低沉没成本来维护可逆性的方式。

## 11. 尚未确定 / 下一步

1. **1980s–1990s 家庭层第一人称仍薄。** 应找旧货商店、信托业、流动收购、毕业生离校、搬家和旧家电市场的同期报刊、地方志与日记。
2. **真实成交时长和折价率缺少长期可比数据。** listing 数量不能替代售出率；挂牌价不能替代成交价。
3. **大件与小件应分开。** 一本书、一部手机、一台洗衣机、一张沙发的运输与退货成本完全不同。
4. **农村/县城与大城市差异不足。** 同城平台密度、快递、搬运和专业回收网络可能显著改变退出能力。
5. **平台消失会不会冻结旧 listing？** 这正是 companion old-Web note 的核心问题。
6. **回收、赠送、以旧换新与二手转售不能混成一个动作。** 它们对应不同现金、关系与物流结果。

## 本轮改变的理解

**普通人的选择空间，不只由“我买得起什么”决定，也由“以后不需要了，我能不能把它顺利退出生活”决定。**

当旧货只能靠少数门店、熟人或流动收购者处理时，一张桌子、一台电视、一屋书会更容易变成搬家的阻力和沉没成本；当同城分类、平台支付、快递和移动二手市场逐渐把这些物品变得可搜索、可议价、可交付之后，家庭库存获得了一点可逆性。

这并没有让物品变成现金等价物，也没有消灭诈骗、折价、搬运和交易劳动。它真正改变的是：**建立一个生活以后，再退出它、缩小它、搬走它、把其中一部分换回下一段生活所需现金的可能性，变得比过去更高。**
