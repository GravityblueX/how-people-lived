# 中国并非在 1994 年以前“完全没有网络”：CFido、拨号 BBS、离线阅读与异步远方（1986—2001）

> 本文不是一篇“中国互联网公司史”，也不是把少数计算机爱好者提前写成“全民网民”。它解决一个普通生活史的边界问题：**在中国全功能接入国际 Internet、商业 Internet 和家庭上网成为常态以前，已经有哪些数字通信可以被谁使用？这些系统怎样改变了少数真实使用者的学习、交友、兴趣、信息获取和对远方的想象？**
>
> 核心区分：`pre-Internet digital communication ≠ full-function Internet ≠ commercial public Internet ≠ household access ≠ mass adoption`。

## 1. 为什么要单独写这一层

现有互联网史很容易被压成一个日期：1994 年 4 月 20 日。

这个日期非常重要，但对普通生活史来说，它只回答一只钟：**中国什么时候实现与国际 Internet 的全功能连接？**

它不直接回答：

- 1994 年以前是否已经有人通过计算机网络发送跨国电子邮件；
- 1990 年代初是否已经存在不依赖 TCP/IP Internet 的民间数字通信网络；
- 哪些系统属于科研 / 机构使用，哪些属于业余爱好者；
- 普通个人何时可以向电信运营商购买 Internet 接入；
- 家庭何时真正负担得起电脑、调制解调器、电话费和上网费；
- 哪些人的“网络生活”先于自己的 Internet 账号出现。

因此，中国数字通信进入生活至少要保留多只不同的钟。

## 2. 1986—1996：不要把几种网络状态压成一条“联网 / 未联网”二元线

### 2.1 1986 / 1987 的“第一封电子邮件”本身就提醒我们先定义对象

中国科学院高能物理研究所的机构史记录，1986 年高能所通过长途电话线路与 CERN 之间建立电子邮件传输，并把 1986 年 8 月的国际邮件记为中国第一封电子邮件；CERNET 的互联网史材料则把 1987 年 CANET 以约 300 bps、经公用分组网实现的 store-and-forward 邮件作为“中国第一封 E-mail / 中国人使用 Internet 的开端”。

来源：

- 中国科学院高能物理研究所，网络发展史（机构历史，B）：<https://ihep.cas.cn/jg/yjbm/jszx/zxgk/wlfz/>
- CERNET, *Evolution of Internet in China*（机构历史整理，B）：<https://www.edu.cn/english/cernet/introduction/200603/t20060323_4285.shtml>

这里不应为了得到一个漂亮“第一”而强行消掉差异。更稳妥的写法是：

> **1980 年代后半，中国已经存在面向科研 / 学术用途的国际电子邮件与远程计算机通信；但这不等于中国已经实现全功能 Internet，也更不等于普通家庭已经能够上网。**

不同史料对“第一封电子邮件”的日期与技术路径存在口径差异，本项目保留这一争议。

### 2.2 1991：CFido 是另一种完全不同的“网络已经存在”

2024 年 *Isis* 的研究把 Chinese FidoNet（CFido）的活动期概括为 1991—1998，并指出它主要由计算机业余爱好者构成，是一个 dial-up BBS 网络，而不是大众 TCP/IP Internet。

高质量研究（B）：

- Wen-Ching Sung, Chen-Pang Yeang, Zhixiang Cheng, “Demarcating a Pure Land: CFido as a Cyberspace for Computer Amateurs in 1990s China,” *Isis* 115.2 (2024): <https://www.journals.uchicago.edu/doi/10.1086/730229>

CFido 当前仍在线的 legacy site 自述网络起源于 1991 年，并称后来覆盖 13 个省市、100 多个站台、经常上站者过万；这个规模数字来自网络自身的历史页面，**只能记录为“CFido 自身曾这样描述”，不能当成已经由独立人口统计验证的普及率。**

平台遗留页（历史内容由当前页面承载；不是本轮验证的历史 capture）：

- <https://cfido.com/>

### 2.3 1994：全功能 Internet 是另一只钟

CNNIC 的历史整理明确记录：1994 年 4 月 20 日，NCFC 通过 64K 国际专线与 Internet 实现全功能连接。

同一份时间线又记录：

- 1995 年 1 月，邮电部电信总局通过北京、上海国际专线，开始通过电话网、DDN、X.25 等方式向社会提供 Internet 接入；
- 1996 年 1 月，CHINANET 全国骨干网建成并正式开通，全国范围公用计算机互联网络开始提供服务；
- 1996 年 12 月，169 网等公众多媒体通信网开始全面启动。

来源（CNNIC 机构历史整理，B）：

- <https://www3.cnnic.cn/n4/2022/0401/c87-912.html>

1997 年第一次 CNNIC 统计报告后来记录全国上网用户约 62 万。这个数量级再次说明，**“国家已经全功能接入”与“普通人已经普遍上网”之间存在很长的社会扩散区间。**

来源：

- CNNIC `.CN` 大事记（B）：<https://www3.cnnic.cn/n4/2022/0830/c57-10124.html>

因此本项目以后固定保留：

```text
科研 / 邮件 / 专线数字通信已存在
≠ 中国已实现全功能 Internet
≠ 公用商业 Internet 已全国可买
≠ 普通家庭经济可及
≠ 大规模行为整合
```

## 3. 一个 CFido 用户到底需要什么：这是“民间网络”，不是“低门槛大众网络”

CFido 当前遗留的 StarStudio BBS 页面给出了一条异常具体的进入条件：

- 一台电脑；
- 一台调制解调器；
- 一条能够拨外线的电话；
- 通讯软件；
- 拨打具体 BBS 电话号码。

来源（当前 legacy page，承载历史操作说明）：

- <https://www.cfido.com/starstudio/star.htm>

这条清单很重要，因为它同时证明两件事。

第一，**1990 年代前半确实存在不依赖大众 Internet 的民间数字通信路径。**

第二，它的经济与技能入口明显很高。需要家中 / 单位可用电脑、modem、电话线、软件配置能力，还要承担电话资源与拨号时间。这种系统可以证明“当时有人这样活”，不能证明“普通中国家庭已经普遍这样活”。

这叫 **network existence / population executability gap**：

> 一个网络真实存在，和一个社会群体能否普遍执行它，是两个完全不同的问题。

## 4. 单线电话如何塑造一整套数字生活：连接稀缺，阅读被搬到离线

StarStudio 的遗留操作说明保存了一个今天很容易想不到的约束：大量 Fido BBS 是爱好者在家架设的单线系统；一条电话线同一时刻只能服务一个拨号用户，所以系统不鼓励用户长时间在线读信、写信。

它推荐 BlueWave 快信：

```text
短暂拨号上站
→ 把新信打包下载为 STUDIO.###
→ 挂断电话
→ 在自己电脑上离线读信、写回复
→ 回复被打包为 STUDIO.NEW
→ 下次短暂拨号
→ 上传信包
→ BBS 整理并供其他人读取 / 转发
```

页面直接把收益概括为节省电话费、节省上站时间，并让其他站友更容易拨进去。

来源：

- <https://www.cfido.com/starstudio/star.htm>

这补出一个新的普通技术生活机制：**scarcity-shaped interface / 稀缺塑造界面**。

现代 Web 常把“在线”当作默认连续状态；CFido 的实际使用却会主动把工作拆成：

```text
昂贵 / 稀缺的连接窗口
+
便宜 / 私人的离线阅读时间
```

这里 Internet 之前的数字生活不是“不够实时的现代网络”，而是一套围绕电话资源精确优化出来的生活方式。

### 4.1 “每天只有十几分钟”不是心理感受，而是系统级资源分配

StarStudio 用户级别页面还列出不同等级对应的日使用时间：新用户约 10 分钟、正式用户约 20 分钟、进阶用户约 30 分钟；升级还要求填写较完整注册资料、做自我介绍、学会 BlueWave。

这说明 **connection time was rationed / 连接时间被配给**。

一个人网络里的“今天”可能不是全天候在线，而是：

> 等线路空闲 → 拨通 → 在十几分钟内完成同步 → 挂断 → 余下的一天在离线状态继续参与网络。

因此增加 **burst-synchronized social life / 脉冲同步式社交生活**。

## 5. 不持续联网，也可以拥有跨城的“远方共同体”

StarStudio 当时列出的信区不仅有硬件、软件、网络、编程，还包括：

- 闲聊；
- 游戏；
- 文学；
- 音乐；
- 摄影；
- Hi-Fi；
- 体育；
- 医药保健；
- 美食；
- 跳蚤市场；
- 英语；
- 金融；
- 爱情 / 私密信箱等。

页面区分全国转发的 Echomail、本地 Localmail、私密 PVT 和跨网络 Netmail。

来源：

- <https://www.cfido.com/starstudio/star.htm>

这至少支持一个窄结论：

> **CFido 的实际设计已经允许一个人通过异步转信参与超出本地 BBS 的兴趣与日常讨论；数字社交并不需要两个人同时在线。**

这里形成 **persistent community without persistent connectivity / 无持续连接的持续共同体**。

它对“普通人怎么活”很重要：远方第一次可以不是“打一次长途电话时短暂出现”，而是以一批隔夜、隔日抵达的文本持续存在于自己的电脑里。

但仍须强调样本边界：这些人首先是能进入计算机通讯爱好者网络的人，而不是人口意义上的“普通中国人”。

## 6. 家庭不仅是用户所在地，还可能是网络基础设施的一部分

StarStudio 页面明确说很多 BBS 由爱好者在家中架设；CFido 首页也把站长贡献描述成使用自己的业余时间维护网络。

这意味着某些家庭出现一种很特别的基础设施关系：

```text
私人住房
+ 电脑
+ modem
+ 电话线
+ 电费 / 电话费
+ 站长的下班后劳动
→ 变成别人可以拨入的公共 / 半公共数字节点
```

这里加入 **domestic infrastructure volunteering / 家庭基础设施志愿化**。

它会带来一批普通生活史问题，当前证据还不能完整回答：

- 电话线被 BBS 占用时，家人如何打电话？
- 站长的家人是否承担设备噪声、电话费和夜间自动转信的影响？
- 多线站台的线路与设备成本从哪里来？
- 家庭住房条件是否决定能否成为站长？

这些问题比“哪个著名企业家当年是站长”更接近本仓库的核心。

## 7. 身份早于 Web profile：昵称、注册资料与本地站台身份同时存在

StarStudio 允许用户使用 ID，但升级页面又要求注册资料完整、正确，并明确提到中文名。也就是说：

```text
现实个人资料
→ 本地 BBS 注册
→ 一个可持续使用的 ID
→ 本地 / 全国信区发言
```

这是 **layered pre-Web identity / 分层的前 Web 身份**。

它不能被简单等同于后来平台的“实名认证”，因为我们尚未恢复：

- 各站是否都执行同样规则；
- 资料如何保存；
- 是否能跨站核验；
- 同一个人的多个站台 ID 如何关联；
- 谁能看到注册资料。

但它足以修正“线上身份始于 Web 账号 / SNS profile”的隐含假设。

## 8. 1997：CFido 与 Internet 并不是一夜之间替代，而是先叠在同一个人的生活里

### 8.1 《龙音》从 CFido 信件变成 Web 电子杂志

《龙音》第二期自标日期为 1997 年 5 月 9 日。当前保存的页面记载：杂志先借放在《计算机世界报》主页，随后站长为 CFido 申请 `cfido.com`，租用美国加州服务器空间；杂志同时保留纯文本和 HTML 两种版本，在 CFido 站台下载，也可通过 Internet URL 获取，并提供 Internet email 反馈地址。

当前 legacy page 承载的同期文本（A-content / 当前容器；未由本轮历史 capture 独立验证）：

- <https://www.cfido.com/deq.htm>

这形成 **protocol coexistence / 协议共存**：

```text
CFido Echomail 内容
→ 编辑电子杂志
→ 纯文本版本继续在 CFido 发行
→ HTML 版本进入 WWW
→ Internet email 收反馈
```

不是“Internet 到来，旧网第二天消失”，而是同一内容先跨两套基础设施流动。

### 8.2 1997 年第一人称：Internet 被体验成“眼界和能力突然扩张”，但这仍是高门槛个案

同一期《龙音》中，署名 White Spoon 的作者把文章日期写为 1997 年 4 月 20 日。他回忆前一年 8 月朋友送给自己一台 14,400 bps modem，半年多 Internet 使用让他感觉眼界、知识和电脑技术快速扩展；随后他发现网上很少能听到中国传统音乐，于是尝试制作符合通用 MIDI 标准的中国民族风格作品，希望让海外亲友和更远处的人能听到。

来源：

- <https://www.cfido.com/deq.htm>

这是一条非常珍贵的**同时代第一人称材料**，但其社会位置也很特殊：作者有 modem、Internet access、音乐专业训练和 MIDI 制作能力。

它能证明的是：

> 对至少一部分 1997 年的早期网络使用者，Internet 已经被体验成一种扩大知识边界、技能边界和文化传播半径的基础设施。

它不能证明 1997 年普通青年普遍拥有同样的未来感。

这可以作为后来“扩张型未来”的更早技术前史，但**不要把 1997 直接塞进 2005—2012 的时代类型。**

## 9. 从拨号网络走向 Web：技术不是线性替换，而是外围层不断迁移

当前 `cfido.com` 的遗留页面还留下了 OICQ、RealPlayer 网络直播、Internet 链接等后来的外围层；主页自述最后更新时间为 2001-10-17，并说网站保留约 2000 年时的样子。

来源：

- <https://cfido.com/>
- <https://cfido.com/oldindex.htm>

该自述只能证明当前网站**这样描述自己的保存状态**，不能把今天看到的页面直接当作 2000 年历史 capture。

但作为生活史，它支持一种更一般的变化模型：

```text
拨号 BBS / Echomail
→ BBS + Internet email
→ BBS 内容 + Web 主页 / HTML 杂志
→ Web + OICQ / 流媒体
```

这是 **network-layer succession without instant social replacement / 网络层继替而非瞬时社会替代**。

## 10. 一个可复核的物理证据：1997—1998 nodelist 不是抽象“全国网”

`cfido.com` 当前 nodelist 索引保留（或重新发布）了多份带日期的 nodelist 文件，例如 1997-08-22、1997-10-31 以及 1998 年连续的周度列表；其来源页指向后来公开的 GitHub 保存库。

- CFido nodelist index：<https://www.cfido.com/nodelist/list.html>
- 后来保存库：<https://github.com/lshw/cfido_nodelist>

例如 `NODELIST.304` 的文件头写明 1997-10-31，并列出 Region 65 / Mainland China 下北京、天津、沈阳、上海、广州、深圳、南京等多地节点与拨号号码。

这一材料的 provenance 是“后来保存的历史文件”，不是本轮从原始 1997 介质或 WARC 取得；所以它适合证明：

> **当时确实存在需要被机器读取的节点 / 电话路由表，CFido 的跨城连接不是后来回忆里才出现的抽象概念。**

但不能仅凭当前副本证明每个列出的节点在该日都正常可拨通。

## 11. 海外对照：FidoNet 的核心约束不是中国特有

1993 年 *Washington Post* 同期报道 FidoNet 时，写到全球节点已从 1990 年约 6,000 增长到 25,000 以上，并把它描述为由 BBS 爱好者分担长途电话与运行成本的合作网络；一些 BBS 免费，一些按较低年费提供文件、游戏和消息区。

同期媒体（B）：

- <https://www.washingtonpost.com/archive/business/1993/07/19/fidonet-enthusiasts-share-a-low-cost-way-to-communicate/eaf20b43-5c52-4663-82c4-c22c48ba5ca8/>

FidoNet 1995 年技术标准档案又保存了 FTS-0001、Echomail、nodelist 等规范条目：

- <https://www.stacken.kth.se/doc/fidonet/INDEX.HTM>

因此跨国共同机制至少包括：

- 公共电话网作为数据传输基础设施；
- 站长私人 / 业余劳动维持节点；
- store-and-forward 而非持续端到端连接；
- 连接与长途费用推动批量转信；
- 本地 BBS 与跨地域 message network 叠加；
- hobby / community knowledge 先于大众 Web。

中国更需要单独解释的是：

- 电脑、modem 和私人电话在 1990 年代初的经济可及性；
- 中文输入、编码、中文平台与软件生态；
- CFido 与 1994 后 Internet、163/169 等公共服务的重叠期；
- 城市 / 地区分布与用户社会构成。

因此不要把全球 FidoNet 的规模或使用习惯直接外推中国。

## 12. 它改变了“普通人怎么活”的哪一点理解

这条前史增加的不是“1990 年代又有一种网站”，而是至少五个生活机制：

### 12.1 asynchronous reach without continuous connection

不需要持续在线，也可以维持跨城讨论和远方关系。

### 12.2 scarcity-shaped interface

电话费、单线占用和有限上站分钟不是外围成本，而会直接决定软件和交流行为：先下载，离线读，下一次再上传。

### 12.3 domestic infrastructure volunteering

家庭电话线、电脑与夜间业余劳动可以临时变成一小块公共通信基础设施。

### 12.4 protocol coexistence

拨号 BBS、Echomail、Internet email、WWW 和 OICQ 可以连续几年叠在一个人的日常里，而不是整齐接班。

### 12.5 network existence / population executability gap

“有网络”与“普通人有网络”必须永远分开。

## 13. 核心矩阵更新

| 维度 | 本轮新增 | 当前证据边界 |
|---|---|---|
| 教育 / 学习 | 跨城技术经验、软件与兴趣知识异步流动 | 用户偏计算机爱好者，不能外推普通学生 |
| 就业 | 技术社群与职业网络可能重叠 | 本轮没有可靠普通求职结果链，不夸大 |
| 住房 | 家庭可成为 BBS 站台的物理机房 | 家庭协商、电话冲突证据仍薄 |
| 婚姻家庭 | 信区包含爱情、私人话题；站长生活嵌入家庭 | 不能由栏目存在推断真实关系结果 |
| 迁移 / 远方 | 异步跨城消息减少地理隔绝 | 用户门槛高，不等于 migrant workers 普遍可用 |
| 非正规 / 志愿劳动 | 站长用业余时间、设备和电话维护节点 | 具体成本结构需更多账目 / 第一人称 |
| 证件与记录 | 本地账号 + 注册资料 + ID 并存 | 跨站身份关联未知 |
| 通信方式 | 电话拨号、Echomail、Netmail、离线信包 | 线路成功率 / 实际延迟尚缺系统样本 |
| 信息获取 | 论坛主题横跨软件、新闻、兴趣与生活 | 代表性有限 |
| 社交关系 | 无持续联网的持续共同体 | offline meeting / long-term tie 证据待补 |
| 未来预期 | 1997 个案把 Internet 体验为知识与传播半径扩张 | 个案社会位置特殊，不外推 |
| 线上 / 线下身份 | 本地注册资料、handle、跨区发言分层 | 资料可见性 / 审核实现未知 |
| 平台消失与记忆 | nodelist、HTML 杂志、遗留站点保存部分旧网 | 原 BBS session、信包、私信和本地软件环境大量缺失 |

## 14. 反例与后见之明风险

### 反例 1：不能因为 CFido 存在，就说“1994 年前中国普通人已经上网”

这正是本文要阻止的错误。CFido 是民间数字网络，却要求电脑、modem、电话和技术能力；全功能 Internet、商业接入和家庭普及是另几只钟。

### 反例 2：不能因为早期 CFido 用户后来出现知名企业家，就把网络写成“创业预备班”

*Isis* 研究确实讨论了后来进入数字产业的人，但对生活史而言，更值得研究的是大量没有成为名人的普通站友如何读信、交友、学软件、占用电话线和安排晚上。

### 反例 3：不能把 store-and-forward 写成“落后的即时通信”

在昂贵、低速、单线的约束下，离线阅读是一种非常理性的工程与生活设计。

### 反例 4：不能把今天还在线的 `cfido.com` 当成已经验证的 1997/2000 页面

当前页面可以承载历史文本、旧代码和历史自述，但历史浏览器渲染、子资源、服务器响应和原始页面时间点仍需 archive capture 独立验证。

## 15. 已知 / 高概率 / 不知道

### 已知

- 1980 年代后半中国已经存在国际电子邮件 / 科研数字通信；
- 1991 起出现 CFido 这一拨号 BBS 网络；
- 1994-04-20 是全功能 Internet 连接的重要独立节点；
- 1995—1996 公用 Internet 服务开始向社会扩展；
- CFido 的遗留操作说明明确依赖电脑、modem、电话和通信软件；
- StarStudio 明确使用 BlueWave 离线信包以节省电话费与上站时间；
- 1997 年《龙音》明确同时通过 CFido 与 WWW / Internet email 分发。

### 高概率 / 合理推断

- 电话线和费用稀缺是 CFido 日常软件结构的重要塑形力量；
- Web 到来时，旧拨号网络与新 Internet 曾存在明显重叠，而非瞬时替换；
- 对能进入该网络的人，异步跨城交流已经能形成持续的技术 / 兴趣共同体。

### 仍不知道

- 1991—1998 各年份稳定活跃用户的可信分母；
- 用户的城市 / 农村、收入、年龄、性别和职业分布；
- 普通家庭如何协商电话线被 BBS 使用；
- 站长实际月度电话费、电费和硬件折旧；
- 一条 Echomail 从发送到远端普通用户实际读到的延迟分布；
- 多少线上关系转化为求职、合作、友谊、恋爱或线下互助；
- 原始 DOS BBS、BlueWave、中文终端在不同机器上的真实视觉 / 输入体验。

## 16. 下一步最值钱的证据

后续若继续这条线，优先寻找：

1. 1993—1998 同时代报刊中的 modem / 电话费 / BBS 使用价格；
2. 原始 CFido message packet、BlueWave packet、站台手册或安装介质；
3. 能确认年份的拨号 BBS 截图 / 录像 / 终端记录；
4. 普通站友而非后来知名人物的同期个人信件、日记或 BBS 发言；
5. 家庭电话线冲突、夜间上站、长途拨号费用等生活细节；
6. 中国 1995—1998 CFido 与 163 / 169 / 网吧 / 学校 Internet 的同人并行使用材料。

这条研究不会把 `old-web-archaeology` 的范围往 1991 年无限前推；Web 页面、浏览器、遗留站点和保存机制的 companion 另写入该仓库，CFido 的 1991—1994 网络生活前史保留在 `how-people-lived`。

## 17. 本轮判断

这是一个**实质新增**，不是对已有网吧专题的重复。

网吧专题补的是 `access without ownership`：Internet 已经成为公众服务后，没有私人电脑的人怎样租到接入。

CFido 前史补的是另一件事：

> **即使没有持续 Internet 连接，一个人也可以通过短暂的电话拨号、离线信包和自动转信，维持一个跨城市的数字身份与共同体。**

因此，它新增了新的通信转折机制、前 Internet 边界与历史可见性问题；研究饱和计数不增加。
