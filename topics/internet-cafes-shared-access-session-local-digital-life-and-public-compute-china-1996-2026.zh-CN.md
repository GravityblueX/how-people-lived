# 从“租一小时互联网”到“租一小时算力”：网吧、共享接入与会话型数字生活（中国，1996—2026）

> 本文研究的不是“网吧兴衰史”，而是一个普通生活问题：**当 Internet 已经存在、网站也已经存在，但家庭还没有电脑、固定线路、宽带或足够性能的终端时，一个人怎样真正进入数字生活？**
>
> 核心区分：`Internet exists ≠ ordinary household access ≠ personal device ownership ≠ person-level executability`。

## 1. 为什么把网吧放进普通生活史

中国 1994 年 4 月 20 日实现与国际 Internet 的全功能连接，是基础设施史上的明确节点；但这不能直接改写成“1994 年普通中国人开始上网”。中国科学院对该节点的回顾明确指向一条 64K 国际专线和科研网络的全功能连接；CNNIC 后来的历史整理记录，到 1998 年末全国上网计算机约 74.7 万台、上网用户约 210 万。两者之间至少还有商业服务、接入价格、终端设备、家庭拥有率、地理覆盖和使用技能等多只不同的钟。

来源：

- 中国科学院计算机网络信息中心，中国全功能接入国际互联网 30 周年材料（机构回顾，B）：<https://www.cnic.cas.cn/jdtw/zxyw/202404/t20240419_7124379.html>
- CNNIC《1997—1999 年互联网大事记》，其中整理第三次统计报告数字（机构历史整理，B）：<https://www3.cnnic.cn/n4/2022/0401/c87-913.html>

因此网吧最值得研究的不是“年轻人去哪里打游戏”，而是一种**access without ownership / 非所有权接入**：

> 一个人可以没有自己的电脑、没有自己的电话线、没有固定家庭宽带，却通过按小时租用一台联网机器，取得临时的数字能力。

这正好补上“正式接入国家 Internet”和“家庭普遍私人化接入”之间最容易被历史叙事压扁的一层。

## 2. 研究状态必须分层：国家接入、商业可得、共享可得、家庭可得、个人随身可得

研究中国 Internet 大众化时，至少分开：

1. **科研 / 机构连通**：科研网络、电子邮件、专线等已经运行，但服务对象有限；
2. **全功能国际 Internet 连接**：1994 年 4 月 20 日是明确技术与制度节点；
3. **商业 Internet 服务出现**：普通个人原则上可以付费购买服务，但成本、终端和线路仍可能很高；
4. **共享公共接入**：网吧、公众电脑屋、学校机房、图书馆、单位机房等让没有个人设备者临时使用；
5. **家庭私人接入**：家庭电脑、拨号、宽带进入家中；
6. **个人随身接入**：手机网络把“上网地点”与固定终端进一步拆开；
7. **高性能公共计算**：私人联网已经普遍后，共享场所仍可能因为高性能 GPU、外设、空间和社交而继续存在。

这里最重要的修正是：

```text
公共接入不是家庭宽带之前的“不完整互联网”；
它是一种有自己价格、隐私、时间、身份和空间约束的完整生活形态。
```

## 3. 1996—1998：上海网吧说明“公众可用”与“家庭拥有”可以同时很低

1998 年 8 月 26 日《中华读书报》同期报道上海“网吧”时写道：上海第一家网吧“威盖特”于 1996 年 5 月出现；到 1998 年，在上海信息港办公室审核登记的网吧 / 公众电脑屋约 400 家；早期上网费约 50 元/小时，报道时已降到约 14 元/小时。报道还给出一个很关键的同城对照：当时上海家庭计算机普及率约 8%，因特网用户超过 2 万户。

同期来源（B，地方媒体；数字是报道所见的地方管理与行业口径，不能外推全国）：

- <https://www.gmw.cn/01ds/1998-08/26/GB/213%5EDS3505.htm>

它支持一个很窄但重要的结论：

> **1990 年代末，一个城市可以同时出现数百个公众联网场所，而绝大多数家庭仍没有个人计算机。**

这就是 **access-layer lag / 接入层时差**。

网站、服务器、商业 ISP、网吧和家庭电脑并不是同一天“到来”。历史上真实的一个年轻人可能先在外面拥有 Internet，几年以后才在自己的房间里拥有 Internet。

### 3.1 “第一次上网”不等于“第一次拥有电脑”

在共享终端环境下，个人数字生活的入口可能是：

```text
走到店里
→ 付小时费
→ 分到一台机器
→ 学会浏览器 / 聊天工具
→ 临时登录账号
→ 时间到 / 钱用完
→ 离开
```

因此普通人的“first Internet encounter”需要另外问：

- 第一次是在学校、单位、网吧还是家里？
- 是否有别人指导？
- 是浏览网页、收邮件、聊天室还是游戏？
- 一次会话多少钱？
- 能否把文件带走？
- 下次回来还能不能恢复自己的状态？

## 4. 海外对照：1994 年伦敦 Cyberia 证明“公共入口”不是中国特有

英国 *Guardian* 在 1994 年 9 月报道伦敦 Cyberia 时，写到它至少有 6 台终端，使用 NCSA Mosaic，14.4 kbps 连接，预计收费约 £2.50/小时；*Independent* 同期报道又强调，Cyberia 的设计目标之一就是让技术经验很少的人也能接触 email、国际数据库和在线交友 / 公告信息。

同期来源（B）：

- Guardian, 1994-09-07: <https://www.theguardian.com/technology/1994/sep/08/internet>
- Independent, 1994-09-12: <https://www.independent.co.uk/life-style/cafe-with-a-mission-to-explain-cyberia-offers-chance-to-check-your-email-and-network-over-coffee-and-croissant-1448226.html>

这说明“公共 Internet 场所”首先是一个更一般的早期 Internet 问题：

> **当个人网络服务已经存在，但家用硬件、线路、技能和费用仍是门槛时，城市商业空间可以临时把设备、连接和技术帮助打包出租。**

中国后来出现的大规模网吧有自己的制度、游戏产业、城市化和人口结构背景，但“先租 access、后拥有 access”并非中国独有。

## 5. 2000s：个人身份开始脱离机器——账号可以跟人走，终端只是临时壳

共享机器有一个非常重要却常被“网站史”忽略的生活结构：机器不是你的，但账号逐渐是你的。

一个网吧用户可能在完全不同的机器上重复登录：

- QQ；
- 邮箱；
- 论坛；
- 游戏账号；
- 博客 / SNS；
- 下载站或网盘。

于是形成 **terminal-to-account decoupling / 终端—账号解耦**：

```text
今天坐 37 号机
明天坐 12 号机
下周换另一家网吧
→ 机器不停变化
→ QQ 号 / 邮箱 / 游戏身份仍然连续
```

这是一种很早的“云端个人连续性”：普通人未必拥有持续的本地硬件状态，却开始拥有跨终端持续的在线身份。

但这并不意味着个人数字生活完全脱离本地机器。浏览器缓存、下载文件、临时文档、截图、聊天记录、插件、游戏补丁和本地保存都可能依赖某一台机器或网吧的管理方式。

所以应把这类生活称为 **session-local digital life / 会话型数字生活**：

> 在线账号可能是长期的，本地执行环境却按小时出现、按小时消失。

## 6. “公共 Internet”并不等于匿名无门槛：2002—2008 的网吧成为凭证化入口

2002 年国务院令第 363 号《互联网上网服务营业场所管理条例》把网吧、电脑休闲室等定义为“通过计算机等装置向公众提供互联网上网服务的营业性场所”，并建立相应的审批与监管制度。

制度来源（A/机构法规范文本的当前官方公开版本）：

- <https://www.qingdao.gov.cn/zwgk/zdgk/fgwj/zcwj/zfgb/2002_21/202010/t20201025_1750085.shtml>

随后不同城市出现越来越具体的身份登记系统。2004 年天津同期报道说，用户需要凭身份证购买实名上网卡，再凭卡使用；2003 年底已在 400 余家网吧试运行。上海 2004 年报道则写到本地居民可用社保卡、外地人士用身份证、外籍人士用护照，管理系统覆盖 1350 家网吧、约 12 万台计算机。2008 年北京又出现首次入店拍照并扫描身份证、以后以身份证号查询登记信息的操作路径。

同期来源（B）：

- 天津，2004-04-02：<https://news.sohu.com/2004/04/02/34/news219713498.shtml>
- 上海，2004-11-25：<https://news.sohu.com/20041125/n223178578.shtml>
- 北京，2008-10-17：<https://news.sina.com.cn/c/2008-10-17/152816474573.shtml>

因此增加 **credentialed public access / 凭证化公共接入**：

```text
有一家网吧
≠ 我能立刻上网

还可能需要：
有效身份证件
+ 年龄条件
+ 本地登记 / 实名卡
+ 店内机器可用
+ 付费余额
+ 目标网站 / 客户端可访问
```

这对“数字机会可执行性”特别重要。

### 6.1 现实身份和线上身份是两层不同的身份系统

同一个人进入网吧时可以被本地系统记录为实名身份证身份，进入 QQ、论坛或游戏以后又使用昵称 / 账号。

因此不要把“实名进入机器”与“网站页面公开实名”混成一件事。

可以把状态拆成：

```text
现实人
→ 证件
→ 网吧登记记录
→ 具体机位 / 时段
→ 网络连接
→ QQ / 邮箱 / 论坛 / 游戏账号
→ 在线行为
```

历史档案往往只剩其中一层。

## 7. 2008：网吧仍是许多青少年的主要入口，尤其是农村青年，同时手机已经开始接管另一部分 access

CNNIC《2008—2009 中国青少年上网行为调查报告》记录：2008 年青少年网民过去半年在网吧上网的比例为 **57.5%**；农村青少年网民为 **65.4%**。同一份报告又说，当时已有近五成青少年网民使用过手机上网。

机构调查（A/B：机构统计报告；只代表“青少年网民”调查口径，不代表全国全部青少年）：

- <https://www.cnnic.cn/n4/2022/0401/c116-890.html>

2009 年报告又记录，青少年网民使用手机上网比例达到 **74%**，而网吧使用率从 2008 年的 57.5% 降到 **49.4%**；农村青少年手机上网比例为 74.5%。

- <https://www.cnnic.cn/n4/2022/0401/c116-907.html>

到 2010 年，CNNIC 继续观察到家庭、学校和手机入口增长，网吧比例进一步下降。

- <https://www3.cnnic.cn/n4/2022/0401/c116-841.html>

这组数字最值得留下的不是“网吧衰落”，而是一个**overlapping transition / 重叠式转型**：

```text
2008：共享 PC 仍很重要
同时：手机 Internet 已经快速上升
→ 两种接入形态在同一个人的生活中重叠
→ 不是某一天全国从网吧突然切换到手机
```

而且“手机上网”也不能反推“家里有个人电脑”。对于一部分人，真实路线完全可能是：

```text
需要大屏 / 游戏 / 下载 / 长时间聊天 → 网吧
随时看消息 / 短时浏览 → 手机
家里仍没有性能相当的 PC
```

## 8. 2008 外来工：公共网络空间可以成为“看外面世界”的夜间窗口

2008 年 4 月《海峡导报》对厦门翔安一处工业园周边“黑网吧”的调查报道说，当地工业园约有 7000 名外来工；记者采访到的许多年轻工人下班后会去上网，因为其他娱乐选择较少。一名被称为“小张”的外来工说，去网吧除了放松，也会看新闻、了解事情。

同期个人材料（B：记者当时访谈；地方、场景和样本高度有限，不代表全国外来工）：

- <https://news.sina.com.cn/s/2008-04-02/051613671211s.shtml>

这不能证明“网吧导致了 migrant future expansion”，但至少证明一种真实生活路径存在：

```text
工厂下班
→ 出租屋 / 村庄周边缺少其他娱乐空间
→ 按小时进入共享电脑空间
→ 聊天 / 游戏 / 看新闻
→ 临时扩大信息与社交半径
→ 再回到宿舍 / 出租屋
```

这是一种很典型的 **after-work access window / 下班后的接入窗口**。

对于住集体宿舍、城中村或租房的人来说，“家里没有电脑”并不等于“数字生活不存在”。数字生活可能被压缩在每天晚上两三个小时、某个街口的一排共享终端里。

## 9. 2009：新生代农民工的“城市生活”不只由汇款构成

*China Daily* 2009 年同期报道采访 18 岁的甘肃青年 Li Dong：他在苏州工业园工作，月收入 1500 元；晚饭后会去 Internet cafe 聊天或玩网游，周末逛街。他说外出的动机包括挣钱和获得生活经验。报道同时援引一项 2500 名“新生代”农民工调查，其中 54.2% 把“提升自己”列为主要外出原因，另有一部分人提到丰富生活或希望取得城市居留。

同期材料（B；媒体采访 + 被报道的调查，需保留来源口径）：

- <https://www.chinadaily.com.cn/business/2009-05/27/content_7947362.htm>

这个个案很适合修正一种旧的生活史模板：

> “农民工离乡 → 工厂劳动 → 把钱汇回家 → 返乡”

当然仍然是真实路径之一，但年轻人的异地生活还可以同时包含：

- 在城市取得生活经验；
- 消费；
- 同龄人社交；
- 网游 / 聊天；
- 看到新的信息和职业 / 城市生活方式；
- 在“留下、换城市、回家”之间不断重新估计。

因此网吧不仅是通信基础设施，也是**迁移后城市生活的临时私人空间**之一。

这里仍须避免浪漫化：网吧消费会占用工资和睡眠，也可能存在安全、监管和工作时间冲突；“能在城市晚上上网”并不等于取得稳定住房、职业上升或城市身份。

## 10. 会话型数字生活的代价之一：共享机器降低设备门槛，却提高隐私和状态连续性风险

公共终端把设备成本从“买一台电脑”改成“按小时付费”，但这不是无成本替代。

至少会出现：

- 前一个用户留下的浏览器状态；
- 自己忘记退出账号；
- 密码被本地恶意软件窃取；
- 下载文件留在本地磁盘；
- 网吧还原卡 / 重装后本地状态消失；
- 机器上的软件版本、输入法、插件与家中不同；
- 没有真正私密的屏幕和物理空间。

海外的公共终端安全案例说明这种风险不是抽象推演。2003 年 AP / CBS 报道，一名攻击者曾在纽约多家 Kinko's 公共终端偷偷安装键盘记录软件，截获 450 多组用户名与密码。

海外同期比较（B；不能据此推断中国网吧发生率）：

- <https://www.cbsnews.com/news/cybercafes-pose-security-problems/>

因此增加 **shared-machine privacy budget / 共享机器隐私预算**：

> 公共设备让一个人进入 Internet 的门槛更低，但她必须用更少的本地控制权、更弱的物理隐私和更高的凭证风险交换这种可及性。

## 11. 2010s：家庭宽带和智能手机没有让共享场所瞬间失去意义，而是让它换工作

2018 年人民网一篇回顾网吧转型的报道采访长沙经营者与长期网民。受访者回忆，2000 年网吧常被用于聊天、游戏和语音视频；随着智能手机、微博、微信等进入日常，单纯为了“聊天”去网吧的人明显减少。报道把行业转型概括为从简单设备 / 上网服务逐步转向游戏、社交和更完整的消费空间。

回顾性材料（C/B：2018 年采访回忆 1990s—2000s，适合研究记忆与长期变化，不用于单独确定早期精确技术细节）：

- <https://media.people.com.cn/n1/2018/1023/c40606-30356433.html>

这里出现 **function migration of access nodes / 接入节点的功能迁移**：

```text
早期：稀缺的是 Internet connection + PC
↓
家庭宽带后：稀缺更多变成高性能机器、游戏环境、同伴共处
↓
手机普及后：聊天 / 新闻不必再去网吧
但高性能 PC、多人“开黑”、整块不受家中约束的空间仍可被租用
```

因此不能用“家庭宽带普及”作为网吧历史的自动终点。

## 12. 2020—2022：疫情把共享基础设施的一个弱点暴露出来——它必须保持一个现实场所开放

2020 年疫情期间，文化和旅游部门对互联网上网服务营业场所实行暂停 / 有序恢复和限流等措施。2020 年 9 月 24 日，文化和旅游部新闻发布会称全国恢复营业的上网服务场所为 7.91 万家，复业率 67.79%。

同期机构来源（A/B）：

- 2020-05 恢复开放指南：<https://www.mct.gov.cn/whzx/whyw/202005/t20200514_853352.htm>
- 2020-09 复业数据：<https://www.mct.gov.cn/whzx/whyw/202009/t20200928_875589.htm>

这里不需要推断“所有依赖网吧的人都断网”。到 2020 年，家庭网络和智能手机已经覆盖大量用户。

真正能确认的是：**共享接入是一种 location-dependent infrastructure / 地点依赖型基础设施**。它的机器、空间和网络不能像手机一样跟着用户移动；当营业场所关闭，原本依赖它提供的高性能 PC、游戏环境或公共空间会一起暂时消失。

这与 2020—2022 的“偶发型未来”非常一致：

> 不是网站消失了，而是连接人和网站的现实入口可能暂时停止运行。

## 13. 2024—2026：当 Internet 不再稀缺以后，网吧可以重新成为“公共算力”

2024 年一篇同期采访中，一名 33 岁用户说自己大学前两年因为没有电脑常去网吧，后来有了电脑就很少去了；《黑神话：悟空》推出后，因为自己的电脑性能不够，他又回到网吧。

同期个人材料（B；媒体特稿，不代表总体用户）：

- <https://www.thepaper.cn/newsDetail_forward_28895652>

到 2026 年，另一篇同期报道采访常去网吧的“徐明”：他认为购买八九千元的电脑成本高且不保值，而网吧可以按需使用相当配置。报道同时引述行业协会数据称，2025 年上网服务经营主体和营收都出现回升。

同期材料（B/C；财经媒体平台上的行业特稿，行业数字应继续追溯协会白皮书，不把媒体转述当原始统计）：

- <https://m.thepaper.cn/newsDetail_forward_32633618>

这构成 **public-compute revival / 公共计算再兴**：

```text
1998：我没有电脑和 Internet → 租一台联网 PC
2026：我有手机、宽带、轻薄本 → 但没有高性能 GPU / 外设 → 再租一台高性能 PC
```

表面都是“去网吧”，但稀缺资源已经改变。

### 13.1 防守型未来中的固定成本回避

这一阶段不应简单解释成“年轻人更穷，所以回网吧”。现有材料不支持如此宽泛的因果命题。

但可以记录一种明确存在的选择逻辑：

> **如果一台高性能设备昂贵、折旧快、使用频率又不高，按小时租用可以把大额固定成本改成可中止的小额流量成本。**

这和 2023—2026 经常出现的“保留现金、减少沉没成本、提高可逆性”具有结构相似性，但这里只把它作为一个可观察的 micro-strategy，而不是整个社会情绪的代表。

## 14. 四种时代时间感：网吧材料告诉我们的不是“乐观—悲观”单线

### 14.1 2005—2012：扩张型未来

2008—2009 的材料里，可以看到：

- 外来工把上网当成了解“外面”的窗口；
- 新生代 migrant worker 会把“挣钱”与“生活经验 / 自我提升 / 城市生活”放在一起；
- 青少年 Internet 用户迅速增长；
- 手机和网吧同时扩大接入半径。

这里的扩张更多是：**世界可看见的部分变大了，生活路线不再只通过家乡熟人网络显现。**

但不能把这写成“每个人都相信会阶层上升”。

### 14.2 2015—2019：拥堵型未来

Internet 接入本身不再是很多城市青年最稀缺的问题，选择却变多了：游戏平台、社交平台、移动应用、硬件升级、工作和城市消费一起争夺时间和现金。

网吧开始从“Internet gateway”变成可选娱乐场所。

这意味着数字生活从“有没有”变成“我要把有限时间和钱放在哪个系统里”。

### 14.3 2020—2022：偶发型未来

公共场所可以因为公共卫生事件突然暂停。用户可能仍有手机 / 家庭网络，但某些线下数字能力和社交空间会消失。

这里的新经验是：

> **digital service exists ≠ access venue remains executable next week**。

### 14.4 2023—2026：防守型未来

至少有一类当代用户会把网吧重新理解成“按需租高性能环境”，而不是拥有一台迅速折旧的昂贵机器。

这种选择保留了：

- 现金；
- 居住空间；
- 退出自由；
- 不升级个人设备也能临时进入高性能应用的能力。

同时，它也可能意味着持续支付小时费、依赖营业场所与缺少完全私人化的数字环境。

## 15. 这条线怎样接回“普通人到底有多少种活法”

共享接入至少增加一种过去容易被家庭拥有率隐藏的人生：

> **没有私人终端，但并不在数字社会之外。**

一个 2008 年住工业区出租房的年轻工人，完全可能没有自己的 PC，却每晚拥有两个小时 Internet；一个 2024 年有手机、有宽带、有轻薄本的上班族，也可能没有能运行高规格游戏的机器，却临时购买三小时高性能计算。

所以技术生活史的分析单位不能只有“家庭拥有”：

```text
ownership
shared access
institutional access
rented access
mobile access
borrowed access
public compute
```

它们都会生成不同的生活节奏、隐私结构、费用模型和身份状态。

## 16. 与标准人生脚本和重点矩阵的连接

| 维度 | 本专题新增观察 |
|---|---|
| 教育 | 学校机房与网吧可能并列成为没有家庭电脑者的数字入口；本轮尚未充分恢复具体学生作业 / 求职流程 |
| 就业 | 外来工下班后的网络生活有同期个案；但“网吧普遍用于找工作”本轮证据不足，不写成结论 |
| 住房 | 宿舍、城中村、出租屋有没有电脑 / 宽带 / 可独处空间，会决定共享终端的价值 |
| 婚姻家庭 | 共享终端可维持异地联系，但本轮没有足够个人家庭通信材料单独量化 |
| 迁移 | 公共终端能降低移居城市后保持数字联系和获取信息的设备门槛 |
| 照护 | 本轮不是主轴；后续可查视频聊天 / 家庭紧急联系怎样从网吧过渡到手机 |
| 非正规劳动 | “黑网吧”说明合法经营记录与真实使用场所并不完全重合 |
| 长期中断 | 疫情可让共享接入节点暂停；设备 / 场所依赖因此成为脆弱点 |
| 证件与记录 | 2000s 城市实名卡、身份证扫描、照片登记把 Internet access 接到现实身份接口 |

| Internet 平台 | 平台账号比终端更可携带，形成 terminal-to-account decoupling |
| 信息获取 | 2008 外来工个案明确把看新闻、了解外部信息写入网吧用途 |
| 社交关系 | 网吧从 access point 转成多人游戏 / 同伴共处空间 |
| 未来预期 | 2009 migrant 材料出现生活经验、自我提升和城市可能性；当代则出现按需租设备以控制固定成本 |
| 线上 / 线下身份 | 身份证 / 实名卡与 QQ / 游戏昵称形成两层身份系统 |
| 平台消失与记忆保存 | 用户账号、网站、网吧本地机器、监管记录具有完全不同的保存寿命 |

## 17. 反例与边界

### 反例 1：Internet 普及并不必然让公共电脑空间死亡

韩国 PC bang 是很好的海外反例。*Guardian* 2002 年同期报道说，韩国宽带已经高度发展，但约 2.2 万家 PC bang 仍然作为便宜、快速、可与朋友共处的游戏空间存在。

- <https://www.theguardian.com/technology/2002/oct/17/onlinesupplement.newmedia>

这说明共享空间可以从“缺家庭 Internet 的补丁”变成独立的社会空间。

### 反例 2：网吧增长不自动等于数字包容

一个地方网吧多，并不能证明：

- 女性、老人、未成年人、残障者同样可及；
- 夜间出行安全相同；
- 每个人都承担得起小时费；
- 账号和文件具有足够隐私；
- 工作 / 教育任务适合在公共机器完成。

### 反例 3：手机替代共享 PC 也不是完整替代

手机可以替代聊天、新闻、轻量搜索，却不等于替代：

- 大屏多窗口；
- PC 游戏；
- 特定 Windows 软件；
- 高性能 GPU；
- 长时间键盘输入；
- 本地外设。

所以“移动 Internet 普及”只能说明一部分功能转移。

## 18. 后见之明风险

1. **不要把 1994 当普通家庭 Internet 元年。** 全功能连接是国家网络节点，不是家庭普及率。
2. **不要把 1998 上海报道外推全国。** 上海的网吧密度、收入、电脑拥有率和商业环境高度特殊。
3. **不要把“网吧使用率”写成“没有家用电脑的比例”。** 同一个人可以家里上网，也去网吧。
4. **不要把“去网吧”统一解释成游戏。** 同期材料包括聊天、新闻、语音视频等。
5. **不要把 migrant 个案浪漫化成数字赋权故事。** 工时、工资、住房、合法场所可及和职业上升仍是更硬的约束。
6. **不要把实名登记等同于网站实名。** 现实入口身份与应用账号是两层系统。
7. **不要把疫情场所关闭推断成“用户完全断网”。** 到 2020 年手机和家庭网络已很普遍；关闭直接证明的是共享空间 / 机器不可用。
8. **不要把 2024—2026 网吧回升写成“历史循环”。** 稀缺资源已经从 connection 转到 compute / peripherals / social space。

## 20. 尚未确定、下一轮可追

- 1996—2000 中国网吧用户的更大规模“第一次上网”第一人称样本；
- 1990s—2000s 网吧实际常见 OS、浏览器、QQ / OICQ 版本、还原卡 / 管理软件谱系；
- migrant worker 是否以及怎样在网吧找工作、查工资、打印简历，而不是只娱乐 / 聊天；
- 网吧与宿舍公共电话、寻呼机、手机之间的家庭通信替代关系；
- 网吧本地下载、软盘、U 盘、打印、扫描怎样形成“临时个人文件系统”；
- 女性和不同年龄群体在公共上网空间中的可及差异；
- 真实“网吧 → 求职 / 租房 / 购票 / 汇款 → 线下结果”的完整 transaction chain；
- 2024—2026 行业回升数字需要继续回到中国互联网上网服务行业协会原始白皮书核验。

## 21. 对“人怎么活着”的修正

这一专题改变的不是“网吧很重要”这句常识，而是研究单位：

> **一个人不需要拥有一项技术，也可能围绕它形成持续多年的生活。**

1990s 的 Internet 可以先存在于实验室，再存在于商业 ISP，再存在于街上的共享电脑，最后才存在于更多家庭和每个人的口袋里。对于某个具体普通人来说，这几层的顺序可能完全不同。

更进一步，公共接入并没有因为私人化接入而彻底失去意义。它可以换一种工作：

```text
租 connection
→ 租 PC
→ 租游戏与社交空间
→ 租高性能 GPU / 外设 / 整块时间
```

因此技术普及不只是“越来越多人买到了同一件东西”。

它也可能意味着：**同一座城市不断出现新的地方，让你不必买下那件东西，也能临时成为一个拥有那种能力的人。**
