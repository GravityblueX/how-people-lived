# 从付费声讯查分到 Web 与推送：信息时差、人生节点与查询接口（中国，1994–2026）

> 研究问题：当一个决定升学、录取或资格的人生结果已经在机构后台形成时，普通人**何时、通过什么接口、花多少钱、凭什么身份、以多大确定性**真正知道它？电话声讯、学校通知、纸质成绩单、Web、短信、App 和微信并不是一条简单的替代链；它们长期重叠，并把“等待结果”变成一种有费用、拥堵、认证、时间窗和权威层级的日常实践。

本专题与 `old-web-archaeology` 的 companion 相互参照：

- `EXAM_RESULT_VOICE_HOTLINE_WEB_QUERY_SMS_AND_OFFICIAL_NOTIFICATION_STATE_GAPS_1997_2015.md`

本文件主要研究普通生活和生命历程；中文旧 Web 的页面、表单、后端和 archive state 由 companion 处理。

## 1. 为什么“结果已经有了”仍然不等于“我知道了”

一个考试结果至少有几只不同的钟：

```text
阅卷/审核完成
→ 机构生成个人结果
→ 确定公开时点
→ 某个查询渠道装载数据
→ 渠道真正开放
→ 本人有可执行的接入方式
→ 成功完成认证/输入
→ 得到显示或语音结果
→ 结果能否被复核
→ 正式成绩单/录取通知等法定或行政文书到达
→ 本人据此做下一步选择
```

因此：

```text
institution has a result
≠ channel is open
≠ person can reach the channel
≠ query succeeds
≠ displayed result is final/official notice
≠ person knows the next life-course outcome
```

这套区分适用于高考、中考、自学考试、职业资格、录取和其他高 stakes result。

本专题把其中最重要的生活变量称为：

**information-latency budget / 信息时差预算**。

一个人不只是在等待“结果”，还在承受：

- 等多久；
- 是否能比学校纸质通知更早知道；
- 早知道是否要付费；
- 电话线/服务器是否拥堵；
- 家里是否有可用电话、手机或联网终端；
- 是否有准考证号、身份证号、查询卡、动态口令等认证材料；
- 这个结果只是参考显示，还是正式行政状态。

## 2. 1990s 前半：Internet 尚未大众化，但电话网已经能成为“数据库入口”

### 2.1 不要把“没有大众 Web”写成“没有交互数字信息”

《舟山市志（1989—2005）》的在线基本 HTML 版本记录：舟山 1994 年 8 月开通首个自动信息服务台“168”，起初提供股市行情等三十多个栏目；1997 年 7 月开始提供高考成绩查询；1998 年又开通与全省联网、并与 168 连接的 160 人工信息台。此后栏目扩展到其他考试、旅游餐饮、出入境咨询、驾驶员计分、公积金和船期等。

Source (institutional local gazetteer, current HTML representation):
- 浙江省地方志，《舟山市志（1989—2005）》上卷，Page 571：
  https://dfz.zj.gov.cn/zlyz/ossfs/h5/ZS-Z-330900-2005-001-0301/files/basic-html/page571.html

Evidence grade: **B/A-adjacent institutional retrospective compilation**（地方志为后编机构材料，所记对象和统计属于历史行政记录，但不是 1994 当日原始系统文档）。

这条证据的重要性不是证明“中国 1994 年人人都用 168”，而是证明一种常被 Web 史忽略的层已经存在：

> **电话网络 + DTMF/自动语音 + 后台数据库，本身就可以组成面向公众的交互信息服务。**

它不是 Internet，也不要求用户拥有电脑。

### 2.2 电话普及、168 可达与实际使用必须分开

地方志同时显示舟山城乡程控电话和公用电话在 1990s 仍处于扩张过程。因此“168 服务已开通”只说明该区域的电话系统能够提供这种能力，不能自动推导：

- 每个家庭有固定电话；
- 每位农村考生都能独立拨号；
- 每部电话都允许拨打收费信息台；
- 查分费用对所有家庭都很轻；
- 高考查分是当时 168 的主要用途。

这里必须保持仓库一贯的 adoption ladder：**service exists → reachable → affordable → used → normalized**。

## 3. 2002–2004：同一个分数可以同时穿过电话、短信、Web、EMS 与学校

### 3.1 四川 2002：Web 查询并不天然免费

2002 年四川的同期报道保存了一套非常清楚的多渠道查分：移动短信按条收费，电信提供语音热线；同时“新推出”的网上查询需要先去电信营业厅购买一张 30 元查询卡，再登录指定网站输入卡上的账号密码。查询卡一张对应一个考生，可反复查询。

Source:
- 四川在线，《四川省24日起查高考分 移动电信开通查询“通道”》，2002-07-22：
  https://news.sohu.com/09/70/news202247009.shtml

Evidence grade: **B — 同期地方媒体。**

这一材料直接否定一个容易出现的线性故事：

> `Web = 免费；电话 = 收费；所以 Web 一出现收费声讯就自然消失。`

2002 年的现实完全可能是：

```text
想最快知道
→ 在短信、声讯或 Web 中选一种
→ Web 仍需先去实体营业厅买查询卡
→ 再回到能联网的电脑完成查询
```

因此新机制不是“Web 免费化”，而是 **channel-cost recombination / 渠道成本重组**：钱、交通、终端、账号和时间被重新分配。

### 3.2 辽宁 2003：固定电话、手机、短信和 Internet 同时存在

辽宁省招考办 2003 年的同期说明把成绩查询明确拆成固定电话/移动电话语音信箱、短信订制和 Internet 网站三类；正常行政渠道仍逐级下发成绩。网站能提供更详细信息，但并未替代其他渠道。

Source:
- 中国教育在线，《辽宁6月29日零时起可查2003年高考分数》，2003-06-25：
  https://gaokao.eol.cn/news/200603/t20060323_77156.shtml

Evidence grade: **B — 同期招生信息转述。**

这应该被理解为 **parallel-channel transition / 平行渠道过渡**，而不是媒介更替。

### 3.3 湖北 2004：在线、168、EMS 与纸质成绩单同一天交错

2004 年湖北的同期报道写得非常具体：考生当天可以登录两个网站或通过 168 查询；申请特快专递的人由速递局发送成绩；纸质成绩单同时向各地招考办发放。

Source:
- 《楚天金报》/新浪教育，《湖北省高考评卷结束 今日下午可查成绩》，2004-06-25：
  https://edu.sina.com.cn/l/2004-06-25/73908.html

Evidence grade: **B — 同期媒体。**

因此，一个普通家庭的“查分”可以是多个钟同时运行：

```text
网页/168先知道一个数字
→ 等 EMS 或学校纸单
→ 若认为异常，再去县区招办申请复查
```

查询快并不等于整个人生节点已经完全在线化。

## 4. 2005–2012 的“扩张型未来”里，早一点知道结果甚至可以买到

这一时期不能简单写成“大家乐观”，但成绩查询提供了一个非常具体的时代结构：教育机会变得更加可计算、可检索，而**信息抵达速度本身**可以成为收费服务。

### 4.1 2007 南京：付费买的不是分数，而是“比学校早 24 小时知道”

《中国青年报》2007 年采访南京考生计璐。她为了第一时间知道高考成绩，连续拨 168 三次；前两次进入系统却未成功得到分数，也已经开始计费，第三次才查到，合计约五六元。报道还说，因为线路忙，亲友会一起拨打；江苏当年学校/当地招办的免费成绩约在声讯开通 24 小时后可得到。

Source:
- 中国青年报，《部分省市仍继续高考查分收费》，2007-08-20：
  https://news.sina.com.cn/c/2007-08-20/034913698832.shtml

Evidence grade: **B + contemporary first-person quotation**。

这条材料形成一个新的生活史概念：

**latency-priced information / 按信息时差定价。**

严格说，考生不是为“本来不知道的成绩”永久买单，因为第二天可以免费从学校知道；她是在为：

> **现在就知道，而不是明天知道。**

这和今天为了快递加急、即时行情或提前选座付费有类似的经济结构，但高考分数的情绪与生命历程权重显著更高。

### 4.2 高峰同时发布会把亲属变成并行查询资源

同一报道记录“亲戚朋友都帮着打电话”。这里不是简单的家庭情绪，而是一个可建模的执行策略：

```text
大量考生同一时点查询
→ 线路容量不足
→ 单人反复拨号成功率低
→ 家庭/亲友把多部电话并行化
→ 谁先接通谁先获得结果
```

本专题称为：

**parallel-channel household coordination / 家庭并行查询协调。**

家庭不只是安慰者，也临时变成一个小型高可用查询集群。

### 4.3 反例：168 并不总是收费，Web 也不总是最快

2006 年湖北正式停止 168 收费查分，改为成绩信息单和两个网站第一时间免费提供；河北同年把 168 改为免信息费，并保留网站和正式通知渠道；山东也把 168、网站、成绩单改为三种免费方式。

Sources:
- 新华网/新浪，《湖北停止使用168声讯台收费查询高考成绩》，2006-04-02：
  https://news.sina.com.cn/e/2006-04-02/16108593731s.shtml
- 学信网转《燕赵都市报》，《河北：2006年高考成绩查询168不再收信息费》，2006-06-15：
  https://gaokao.chsi.com.cn/gkxx/heb/200606/20060615/513197.html
- 青岛新闻网/新浪，《山东高考成绩25日前公布 3种方式查询全部免费》，2006-06-14：
  https://news.sina.com.cn/c/2006-06-14/14159202969s.shtml

Evidence grade: **A/B institutional-media chain.**

所以不能写：

> “168 = 收费剥削，Web = 免费进步”。

正确的单位是**具体年份、地区、考试和渠道政策**。

## 5. 2008–2009：声讯不仅“告诉你结果”，甚至可以承担志愿输入

### 5.1 上海 2008：168 是招生事务输入接口，而不仅是播报器

上海大学 2008 年成人高考录取通知保留了一条非常强的机构证据：考生可通过 168 声讯查询本人录取情况；符合条件的未录取考生还可以通过声讯电话补填志愿；正式录取通知书则要到 12 月中旬寄出。

Source:
- 上海大学继续教育学院，《2008年上海大学成人高考招生录取本科/专升本分数线》，创建时间 2008-11-18：
  https://cce.shu.edu.cn/info/1464/9274.htm

Evidence grade: **A — 同期大学官方网页。**

同年上海春季招生，学信网转“上海招考热线”消息称，填报志愿继续采用拨打 168 教育声讯电话的方式。

Source:
- 上海招考热线/学信网，《上海：2008年普通高校春季入学招生录取工作顺利结束》，2008-01-28：
  https://gaokao.chsi.com.cn/gkxx/sh/200801/20080128/3766513.html

Evidence grade: **A/B institutional republishing.**

这说明“声讯台”不应被缩成一个语音版公告栏。它可以参与真正改变下一状态的 transaction：

```text
candidate state
→ telephone authentication/input
→ preference submission
→ admissions backend receives choice
→ later admission outcome
```

因此本专题增加：

**voice transaction interface / 语音事务接口**。

### 5.2 上海大学普通高招还出现 Web + 声讯并行填专业志愿

2008 年上海大学本科招生信息中，考生可以选择拨打 168 声讯电话，也可以登录填报志愿网站，填写 10 个以上专业志愿信息。

Source:
- 学信网，《必看：2008年上海各校高考优惠招生政策盘点》，2008-04-29：
  https://gaokao.chsi.com.cn/gkxx/ss/200804/20080429/6140857.html

Evidence grade: **B — 同期媒体/招生信息汇编。**

这里最重要的不是比较哪一种“先进”，而是看到同一机构为了不同家庭的终端条件提供并行入口。

## 6. 2009：网页已经成熟，但“全体同时刷新”的日常仍然会制造拥堵和时间门

### 6.1 上海：Web 和 168 同时在 18:30 开放，网页提前变慢

2009 年上海中考成绩 18:30 起可通过网站与 168 查询；报道者 16:30 登录时已经感觉网站明显变慢，正式开放前后出现拥堵。168 查询不收信息服务费。

Source:
- China Daily 转同期报道，《09上海中考昨起开始查分 分数普遍高于学生预估》，2009-07-07：
  https://www.chinadaily.com.cn/china/2009-07/07/content_8392576.htm

Evidence grade: **B — 同期媒体。**

这里出现的是 **publication-time coupling / 发布时点耦合**：

普通 Web 通常按需要到访；高 stakes result 却把几十万人的行为压到一个预先公布的分钟附近。即使网络已经“随时在线”，制度仍制造一个极端同步的流量峰。

### 6.2 大连：自动信箱甚至只开 90 分钟

2009 年大连中考有一条非常狭窄的电话查询窗口：早上 6:30–8:00，拨 168 自动信箱、输入 9 位准考证号，90 分钟后自动关闭；纸质成绩单则在当天稍晚、凭准考证和毕业证到指定地点领取。

Source:
- 半岛晨报/新浪教育，《辽宁省15日早6点半开始查询09年中考成绩》，2009-07-14：
  https://edu.sina.com.cn/zhongkao/2009-07-14/1443209902.shtml

Evidence grade: **B — 同期媒体。**

因此又有一层：

**temporal gate / 时间门。**

“服务存在”不等于一天中任何时刻都可执行。一个家庭的早晨会被制度规定的 90 分钟重新排程。

### 6.3 2009 全国快照：没有一种“全国统一的查分媒介”

湖南省教育厅现存 2009 年全国高考查分方式汇总显示，各地同时存在考试院网站、县区招办、成绩单、短信、168 声讯、118114 等组合；部分 168/短信已经免费，另一些地区仍采用不同收费与认证方式。

Source:
- 湖南省教育厅，《2009年高考全国各地成绩查询时间及查询方式汇总》，页面标注发布时间 2009-06-18：
  https://jyt.hunan.gov.cn/sjyt/xxgk/gzdt/tpxw/201701/t20170121_3954970.html

Evidence grade: **A/B institutional republishing of contemporaneous compilation.**

因此本专题拒绝使用一句“2009 年中国人上网查高考成绩”概括全国。

## 7. 2015–2019：接口摩擦下降，但等待对象从“分数什么时候来”转向“这个分数意味着什么”

2019 年上海市教育考试院的官方通知显示：6 月 23 日 20:00 起可在网站输入准考证号与身份证后六位查询，次日起 EMS 仍把成绩通知单投递到报名时填写的通讯地址；成绩复核也已有明确的在线申请窗口。

Source:
- 上海市教育考试院，《2019年上海市普通高校招生统一文化考试成绩即将公布》，2019-06-20：
  https://www.shmeea.edu.cn/page/08000/20190620/12967.html

Evidence grade: **A — 同期官方。**

陕西 2019 年则公布四个免费查询平台，包含考试院网站、门户网站、微信和微博等。

Source:
- 西安日报/China Daily，《陕西省招办：四平台可查询高考成绩》，2019-06-11：
  https://shx.chinadaily.com.cn/a/201906/11/WS5cff6725a31011d294daaf8d.html

Evidence grade: **B — 同期媒体引用官方。**

这些证据支持一种谨慎判断：

> 到 2019 年，在不少城市/省份，“拿到数字本身”的金钱与终端摩擦已经显著低于 2000s 初；但人生不确定性没有消失，而是更多转移到位次、分数线、志愿、专业、城市和录取结果的解释链。

这不是证明 2019 年所有年轻人更“拥堵”，而是一个 **waiting-object migration / 等待对象迁移**：

```text
早期：我什么时候才能知道分数？
后来：分数已经马上知道，但它到底够不够、怎么填、最后录到哪里？
```

## 8. 2020–2022：偶发型未来提醒人们，日历本身也可能变

本专题暂不为了凑四阶段强行声称疫情“改变了查分心理”。更安全的连接是仓库已有 pandemic synthesis：2020–2022 的关键经验之一，是学校、考试、毕业、招聘等原本理所当然的日历都可能改期或改变执行方式。

对于 result interface，应该继续追问：

- 考试是否按原日期举行；
- 成绩发布时间是否变动；
- 线下成绩单/复核是否改为远程；
- 家庭是否能稳定获得设备和网络；
- “结果接口正常”是否掩盖了下一步录取、入学、迁移的不确定。

这一段本轮没有找到足够强、能新增机制的一手第一人称材料，故保持为 **under-evidenced**，不把后来“疫情一代”叙事倒灌进 2020 当时人的体验。

## 9. 2023–2026：数字化并不保证旧渠道死亡——168 的基础设施余生

### 9.1 甘肃 2023：电信 16887801 与 Web、微信并列为官方高考查分入口

2023 年甘肃省教育考试院公告明确列出：考生可以拨移动 125809、电信 **16887801**、联通 1161148；也可以用省考试院网站、阳光高考平台和多个官方微信公众号查询。Web 查询需要考生号和身份证号。

Source:
- 甘肃省教育考试院（甘肃政务服务转载），《2023年甘肃省普通高校招生全国统一考试成绩查询公告》，2023-06-25：
  https://zwfw.gansu.gov.cn/yuzhong/zwzx/zxfb/art/2023/art_71ad2ab568e3425d9af98c054c587664.html

Evidence grade: **A — 同期官方公告。**

这条证据非常重要，因为它直接反驳：

> “智能手机普及以后，168 这类语音系统必然已经完全退出制度接口。”

至少在甘肃 2023 年高考查分中，电话热线仍是正式可选入口。

本专题称为：

**infrastructural afterlife / 基础设施余生。**

旧系统可以失去主流文化可见性，却仍作为冗余、习惯、运营合同或兼容性入口继续工作。

### 9.2 从 pull 到 push：等待姿势改变了

2024 年广东省教育考试院宣布，11:30 起直接向报名系统绑定手机号**推送**高考成绩，12:00 起再开放微信/百度等小程序自行查询。

Source:
- 羊城晚报/央广网，《2024广东高考成绩25日11时30分起公布》，2024-06-24：
  https://www.cnr.cn/gd/gstjgd/20240624/t20240624_526761111.shtml

Evidence grade: **B/A-adjacent — 同期媒体引用省考试院公告。**

因此出现一个长期行为转换：

```text
拨号/刷新：人反复去问系统“有了吗？”
→
短信/绑定手机推送：系统在规定时点主动找到人
```

这可称为 **pull-to-push waiting transition / 从拉取等待到推送等待**。

它减少的是“不断主动查询”的劳动，却不自动减少分数之后的志愿和录取不确定性。

## 10. 海外对照：法国 Minitel 说明“Internet 以前的数字公共接口”并非中国特例

### 10.1 1989 Paris-II：Minitel 已经进入大学入学事务

1989 年《Le Monde》同期报道，Paris-II 为避免大学报名时的排队，让申请人先通过 Minitel `3615 UP2` 获得代码；高考（baccalauréat）结果出来当天，再通过 Minitel 获得领取报名材料的预约时间。但报道同时指出，技术消除了部分现场排队，并没有消除学校容量不足本身。

Source:
- *Le Monde*, “Le casse-tête des inscriptions universitaires — Du bac aux facs”, 1989-06-17：
  https://www.lemonde.fr/archives/article/1989/06/17/le-casse-tete-des-inscriptions-universitaires-du-bac-aux-facs_4145423_1819218.html

Evidence grade: **B — 同期全国报刊。**

这与中国后来的声讯/Web 招生接口形成一个非常有用的跨国对照：

> **数字接口可以消除“去哪排队”和部分信息延迟，却不能消除名额稀缺。**

### 10.2 1998–1999 法国教育部：Minitel 显示结果，但行政文书仍可能是正式状态

法国教育部 1998 年关于教师跨地区调动的公报明确规定：Minitel `EDUTELPLUS` 上显示的结果只有 indicative value，不能替代具有正式行政效力的调出/调入决定。候选人可以凭个人 NUMEN 识别号查询。

Source:
- Ministère de l’Éducation nationale, BO n°32, 1998-09-03：
  https://www.education.gouv.fr/bo/1998/32/perso.htm

Evidence grade: **A — 同期官方。**

这一海外对象给本专题增加了另一个通用状态：

**displayed-result / authoritative-state gap — 显示结果 / 权威状态缺口。**

这不是某一国 Web 的 bug，而是制度信息系统普遍可能存在的层级。

### 10.3 相似与差异

共同变化：

- 电话/视频文字终端可以在 Web 以前提供远程数据库访问；
- 结果发布会制造同步高峰；
- 远程界面能减少排队，但不消除名额、资格或录取容量约束；
- 显示状态和正式文书可能并存；
- 按连接时长计费的信息服务在多个国家都有历史基础。

不能直接类比的地方：

- Minitel 的设备分发、计费制度和全国服务生态与中国 160/168 不同；
- 中国固定电话、城乡公话、移动电话和家庭 PC 的普及路径不同；
- 中国高考分省招录和地区查询政策高度异质；
- 不应把法国 Minitel 的普及程度倒推成中国 168 的家庭可达性。

## 11. 这条历史真正改变了什么普通生活？

### 11.1 “等待”不是空白时间，而是基础设施状态

过去的考试结果常被叙述为一个日期：

> 7 月 24 日公布成绩。

但普通人的实际一天可能是：

```text
早上知道今晚九点声讯开放
→ 把准考证号放在电话旁
→ 亲友各自准备拨号
→ 开放时线路忙
→ 反复拨打并计费
→ 某个人先听到数字
→ 家里重新计算志愿
→ 第二天再等学校/纸质成绩单
```

“公布日期”因此只是 institutional date，不是 lived time。

### 11.2 信息接入方式可以影响一个家庭怎样组织高 stakes moment

重要变量包括：

| 维度 | 可能状态 |
|---|---|
| 终端 | 固话、公话、手机、网吧/家庭 PC、学校终端 |
| 费用 | 免费、通话费、按分钟信息费、短信费、查询卡 |
| 时间 | 第一时间、比学校早一天、固定 90 分钟窗口、长期可查 |
| 认证 | 准考证号、身份证后几位、查询卡、动态口令、NUMEN |
| 权威性 | 参考显示、正式成绩单、复核结果、录取通知书 |
| 家庭劳动 | 单人查询、亲友并行拨号、代查、代收 EMS |
| 失败方式 | 忙音、输入错、服务器拥堵、账号/卡不可用、错误测试数据 |

这张表让“查分”从一个网页按钮恢复成一个完整 ordinary-life transaction。

## 12. 对四种时代时间感的谨慎更新

### 2005–2012：扩张型未来

新增证据不证明“所有学生乐观”，但显示：

- 更多渠道可以更快获得制度结果；
- 甚至愿意为“早几个小时/一天知道”付费；
- 查询结果立刻连接下一步志愿、专业和城市选择；
- Web、短信、声讯并行扩大了可执行入口。

这是一种很具体的 expansion：**未来分支变得更快可见**。

### 2015–2019：拥堵型未来

至少在成熟数字地区，“知道分数”的接口成本已明显下降，但一个分数之后要协调的位次、专业、城市、住房、就业预期等没有因此减少。

所以可以提出但尚不能广泛量化的假说：

> **信息延迟下降，同时决策变量增加。**

这比“2019 年的人更焦虑”更可检验。

### 2020–2022：偶发型未来

本轮不新增强结论。应继续寻找同期个人材料，验证考试/成绩/复核日历改变是否让人把“系统会按时工作”本身当成不确定变量。

### 2023–2026：防守型未来

不能因为今天强调稳定、退路和缓冲，就把查分接口也写成悲观。相反，查询本身已经可以免费、即时、多渠道甚至主动推送；**防守性更多可能发生在结果后的选择和风险管理**。

同时 2023 甘肃保留声讯热线说明：系统韧性有时不是“全部换成最新渠道”，而是允许旧、新入口并存。

## 13. 反例与后见之明风险

### 反例 1：电话声讯并不等于“落后”

当家庭 PC 和 Internet 还不普遍时，固定电话或公话可能比 Web 更容易执行。不能用 2026 的手机体验嘲笑 2002 的声讯。

### 反例 2：Web 不自动等于免费

四川 2002 的网上高考查询需要购买 30 元查询卡。

### 反例 3：168 不自动等于收费

2006 后很多地区取消信息费；2009 上海中考的 168 查询已不收信息服务费；2023 甘肃仍保留 168 入口。

### 反例 4：知道分数不等于知道录取

成绩、分数线、位次、志愿、投档、录取和正式通知是不同状态。

### 反例 5：数字显示不一定是法定最终状态

法国教育部的 Minitel 公报明确留下了这个区别；中国材料也常同时保留正式成绩单/录取通知书。

### 后见之明风险

不要把今天的“查分网站”概念倒投到 1990s：当时一个交互式公共数据库入口完全可以首先存在于电话和语音系统里。

## 15. 已知 / 可推断 / 尚不知道

### 已知

- 1994 年舟山已有自动 168 信息服务，1997 年当地 168 提供高考成绩查询；
- 2002–2004 多地成绩查询已是语音、短信、Web、EMS/学校并行；
- Web 查询可能收费或需实体购买查询卡；
- 2006 前后多个省份开始取消高考声讯信息费；
- 2007 同期个案证明家庭会为更早知道成绩反复付费拨号；
- 2008 上海招生事务中，声讯电话可不仅查询，还参与填报志愿；
- 2009 不同地区存在同步开放、网络拥堵、限时声讯等不同执行状态；
- 2019 上海 Web 查询与 EMS 正式通知仍并存；
- 2023 甘肃官方高考查询仍保留电信 16887801；
- 2024 广东已有绑定手机号主动推送成绩；
- 1980s–1990s 法国 Minitel 已进入考试、大学注册和行政结果查询。

### 可合理推断

- “提前知道”曾经是一种可定价的生活资源；
- 电话/网页拥堵会使家庭把多个终端和亲友组织成并行查询；
- Internet 普及后，制度等待没有消失，只是从渠道可达性逐步迁移到排序、录取和后续决策；
- 旧接口可以在新接口成熟后保留很长的制度余生。

### 尚不知道

- 1990s 全国范围 160/168 的家庭实际使用率、城乡分布和真实平均资费；
- 各省第一年把高考成绩接入 168/160 的精确时间表；
- 168 IVR 的原始提示语、后台 schema、认证字段和峰值线路容量；
- 2000s 用户究竟更常从家中固话、公话、单位电话还是其他地点拨查分热线；
- 声讯、短信、Web 在各省的真实查询次数和重复查询分布；
- 2015–2019 “信息延迟下降但决策变量增加”的主观体验是否能被大量同时代日记/论坛材料支持；
- 2020–2022 疫情期间，考试与成绩发布日历变化在个人材料中怎样被写成对未来可靠性的认识；
- 2023 甘肃 16887801 的实际使用量，以及保留它的具体运营/无障碍/冗余理由。
