# 从家务服务公司到平台阿姨：家庭作为工作场所、照护转移与家政劳动的生活史（中国，1983–2026）

## 为什么这个对象值得单独研究

家政服务不是“消费升级”的附属细节。它同时连接至少两条普通人的生命线：

1. 一个家庭因为工作、育儿、养老、疾病或家务时间不足，需要把一部分照护劳动交给家庭外的人；
2. 另一个人把自己的时间、技能、迁移和身体劳动卖给这个家庭，以维持自己和自己的家庭。

因此，家政服务最适合用来检查一个经常被隐藏的机制：

> **一个家庭获得了可持续的工作与照护，不代表照护劳动消失；它可能只是被转移到另一个人的生命历程里。**

这份研究包把家政放进 `how-people-lived` 的家庭生命历程、迁移、住房、非正规劳动、照护、证件/记录与数字平台矩阵，不把“保姆”“阿姨”“月嫂”“钟点工”当成稳定不变的职业类别。

---

## 证据边界

本轮区分：

- **A：原始/同时代制度或报刊证据**：当年报刊、政府文件、当时平台/服务说明；
- **B：同期媒体观察与采访**：可以证明有人这样工作/找人，但不自动代表全国；
- **C：后来回忆/档案重述**：适合补前史，不能单独锁定全国普及程度；
- **D：研究者机制归纳**：以下加粗的机制名称属于分析术语，不伪装成历史行动者自己的概念。

不能从“北京出现家务服务公司”跳到“80年代中国城市家庭普遍雇保姆”，也不能从“2014 年有在线平台”跳到“家政匹配已经平台化完成”。

## 1. Internet 以前：家庭照护已经是劳动与组织问题

### 1983，北京：家务服务被组织化

北京日报后来基于旧报纸整理的资料显示，1983 年由市妇联、朝阳区妇联主办的朝阳家务服务公司成立，首批招收 55 名家庭服务员；当时登记需求包括幼儿无人照看、老人住院陪护、幼儿园接送以及家务负担影响上班等。不到两个月登记用户已超过 700 户。同期《人民日报》1986 年的报道则记载，北京市三八家务服务总公司自 1983 年底成立后两年多，为约 1.5 万户介绍了约 1.18 万名保姆。

这里最重要的不是机构“第一”的称号，而是它揭示了一个前 Web 的匹配系统：

`家庭提出需求 → 妇联/服务公司登记 → 招募/培训服务员 → 介绍见面 → 家庭内服务`

家庭中的照护缺口早已需要信息匹配、信誉与组织中介；Internet 后来的确改变匹配成本，但没有创造这个需求。

证据：

- C/A-archive compilation：北京日报“温故”，引用 1983–1984 年原报：https://xinwen.bjd.com.cn/content/s6983c4ece4b0687a2890c698.html
- A（同时代报刊）：《人民日报》1986-03-31：https://cn.govopendata.com/renminribao/1986/3/31/4/

### 1997–1998，武汉：下岗女性与城市家庭需求被接在一起

1998 年《人民日报》报道武汉市妇联 1997 年启动“巾帼家政服务行动”，最初针对中年下岗女工；试点街道先逐户调查哪些家庭需要服务、哪些女性愿意做家政，服务队成立当天上午已有二十多户家庭签约钟点工。

这说明家政既可以是家庭的照护基础设施，也可以是劳动市场冲击后的就业吸收器。

**机制 1：household-as-workplace / 家庭即工作场所**

与工厂、办公室不同，工作地点是雇主的卧室、厨房、儿童房和老人床边。工资之外，住不住家、吃什么、什么时候能睡、是否被尊重、能不能拿手机、是否有私人空间，都成为就业条件。

证据：A/B（同期报刊数字版）：https://cn.govopendata.com/renminribao/1998/12/5/7/

## 2. 2005–2012：扩张型未来里，家政也是一种“让别人的未来可执行”的劳动

### 2005：网页价格不等于真实可成交价格

北京现代商报 2005 年记者查阅多家家政公司网站时，网页仍标普通家政服务员月薪 600–800 元；记者打电话后得到的却是“涨价了，具体价格要雇主和服务员自己商量”。

这构成一个很干净的生活史边界：

> **browser-visible price ≠ executable household arrangement**

网页能降低找信息的成本，但工资、工作内容、住家与否、休息和实际开始日期仍要在电话与线下面谈中重做一次。

证据：B（同期报道）：https://finance.sina.com.cn/roll/20050113/00001289970.shtml

### 2007：Web 可以只是电话网络的目录

2007 年北京家政服务协会与社区服务中心开通 134 条家政求职热线。报道明确说，市民可登录北京家政网 `www.jiazhengbj.org` 或北京市社区服务信息网 `www.bjcs.gov.cn` 查询热线号码；上一年春节已有 2900 多名京籍家政员通过热线找到工作。

真实路径更像：

`Web 找号码 → 打热线 → 服务机构/社区节点 → 候选人 → 面谈 → 上户`

而不是“在网站上一键找到保姆”。

证据：B（同期报道）：https://news.sina.com.cn/c/2007-01-01/023510905731s.shtml

### 2008–2011：“拼保姆”把照护切成时段

2008 年济南、2009 年成都、2011 年南充都有同期报道记录“拼保姆/合租保姆”：几个相邻家庭共同购买一个人的不同时间段。2009 年成都案例中，一名住家保姆原本每月 800 元，两个邻近家庭各再支付 300 元购买清洁/做饭时间，使原雇主成本下降、家政员总收入升到 1200 元；报道同时指出，多个家庭都需要晚饭等同一时间段时会发生冲突。

**机制 2：care-slot fractionalization / 照护时段分割**

Internet/forum 可以帮助找到“正好缺周一、周三下午”的另一户人家，但它不能消灭地理移动和同一小时只能在一户人家的事实。

证据：

- B：2008 济南：https://news.sina.com.cn/c/2008-12-09/111514852819s.shtml
- B：2009 成都：https://finance.sina.com.cn/roll/20090310/06452718576.shtml
- B：2011 南充：https://news.sina.com.cn/o/2011-02-14/075021949741.shtml

### 2008：照护转移悖论在春节暴露出来

2008 年吉林一名外来保姆面对雇主加薪仍坚持回家过年，理由是已经一年没见孩子，不愿赚“年节钱”。

**机制 3：care-transfer paradox / 照护转移悖论**

一个城市家庭购买家政劳动后，可以让父母继续工作、老人继续在家生活或婴儿得到照护；但提供这些劳动的人也有自己的孩子、父母、春节和照护义务。雇主家庭的“有人在场”，有时建立在劳动者自己家庭的“不在场”之上。

证据：B + contemporaneous self-report：https://news.sina.com.cn/c/2008-02-03/080813376537s.shtml

### 2009：高薪不等于职业身份获得承认

成都一名 40 多岁的高薪“管家”要求媒体使用化名，因为不愿亲友知道自己真正从事家政；她还说，在雇主家中，访客更容易把她看成亲戚或公司管理人员。报道同时指出公司将岗位称作“管家”而非“保姆”。

**机制 4：role-title / social-identity dissociation / 岗位称谓—社会身份分离**

收入、技能和职业体面并不会同步变化。一个人可以在劳动市场里成为高价服务者，却在亲属/熟人网络里隐藏职业。

证据：B + contemporaneous self-report：https://news.ifeng.com/society/2/200906/0608_344_1192789.shtml

### 2008–2009 的危机反例

金融危机一方面压缩部分家庭购买住家保姆的预算，推动“拼保姆”等更细碎的安排；另一方面也有白领/大学毕业生在失业或求职困难时临时进入家政。

因此不能把 2005–2012 的“扩张型未来”写成所有人都沿职业阶梯向上。更准确的是：总体机会空间扩张的同时，家政也可以作为危机时的 fallback occupation，而一些家庭则把照护从全职购买改成碎片化购买。

## 3. 2013–2015：从“信息上网”到“匹配上网”，但工作仍在门内发生

2014 年上海的同期报道描述“云家政”家庭生活服务平台：用户可以在线搜索和匹配家政员、在线购买服务，家政员仍要上门面试，家庭认可后才能正式工作；雇主之后可评价，平台跟踪服务质量。平台还聚合线下门店和家政员资料。

真实状态机是：

`在线搜索/资料 → 预约 → 上门面试 → 家庭接受 → 真正进入住宅 → 服务 → 评价/续约/换人`

所以：

> **online match ≠ household relationship**

Internet 可以把候选人数据库、评价和订单做成控制面，但喂饭、抱孩子、给老人翻身、夜间起床、做饭、清洁以及人与人之间的信任都无法在页面里完成。

证据：B（2014 同期报道）：https://finance.ifeng.com/a/20140415/12127522_0.shtml

## 4. 2018–2019：拥堵型未来——技能升级、证件增多，但劳动关系仍难被制度看见

### 培训合格，不等于能进入培训补贴制度

2018 年《人民日报》采访 45 岁河南籍陈同兰：她此前在工地做不稳定零工，2014 年在济南偶然进入家政公司，学习失能老人照护，约 20 天、180 课时后持证上岗。

同一报道又记录一个制度接口问题：济南针对非本地户籍农民工的培训补贴要求签劳动合同，而家政行业大量实际安排是家庭服务/居家合同，服务对象是家庭，难以满足这一形式条件。一家公司一年培训三千多人，但只有一千多名本地户籍人员拿到补贴。

**机制 5：employment-form legibility gap / 用工形式可识别性缺口**

一个人可以稳定地每天劳动，却因为“谁是雇主、签的是劳动合同还是服务协议”而在培训、社保和劳动法接口中呈现成另一种人。

证据：A/B（人民日报同期采访）：https://politics.people.com.cn/n1/2018/0803/c1001-30204234.html

### 2019：“金牌”技能可以扩张收入，也可以吞掉生活时间

2019 年新京报/中新网采访月嫂徐丽华。她从育儿嫂转为月嫂，收入从早期几百元增长到接近 2 万元/月，热门档期需要提前数月预约；但其工作是住家、24 小时待命，长期每天睡眠不足五小时。

她有三个孩子，自己每个孩子只带到一岁便交给婆婆；过去六年仅在老家过过一次春节。她把继续工作的原因明确连接到三个孩子的学费和未来，希望再工作八年、多攒钱。

这是一条非常清楚的 2019 同时代未来：

- 对职业：技能升级、收入增长、订单可预期；
- 对家庭：继续积累教育资金；
- 对时间：职业成功以睡眠与家庭共同在场为代价。

**机制 6：care-labor temporal capture / 照护劳动的时间占领**

与普通“上班时间”不同，住家月嫂的劳动边界会进入夜晚、睡眠和私人设备使用；劳动场所与居住空间重合。

证据：B + contemporaneous first-person：https://www.chinanews.com.cn/m/sh/2019/03-20/8785039.shtml

### 证书越来越重要，但证书本身不自动建立信任

同一 2019 报道中，月嫂会携带多种证书见雇主，但不同公司评级标准并不一致，雇主仍可能要求二次体检或怀疑证件真伪。

因此应区分：

`有证 → 证书可验证 → 证书代表同一技能标准 → 雇主相信 → 实际服务可靠`

它们不是同一个状态。

## 5. 2020–2022：偶发型未来——“有订单”仍可能进不了门

2020 年 3 月上海的同期报道记录家政员石红玲上户时随身携带身份证、复工证、健康证、随申码和 14 天行动轨迹。即使这些材料齐全，不同小区门岗仍可能采用不同规则；一次她材料齐全仍被拒绝，另一次雇主必须绕到另一扇门接她，之后因过于麻烦暂停继续预约。

这构成一个非常明确的状态链：

`平台/公司有单 → 阿姨人在上海 → 健康条件满足 → 证件齐全 → 小区允许进入 → 雇主配合接人 → 真正上户 → 服务开始`

**机制 7：household-entry executability / 家庭进入可执行性**

疫情期间，“工作存在”与“身体能抵达工作场所”突然再次分开。数字平台、健康码和工作群没有消灭住宅门岗这一最后的物理接口。

证据：B + contemporaneous self-report：https://news.sina.cn/gn/2020-03-20/detail-iimxyqwa1935609.d.html

这也是“偶发型未来”的典型结构：劳动者可以准备证件、算隔离成本、保持技能，却无法提前确定下一户住宅是否真正允许自己进去。

## 6. 2023–2026：防守型未来——平台、社保、住房与现金到手之间的重新取舍

### 平台没有完全取代线下公司和熟人

互联网家政平台“阿姨来了”发布的 2023 年平台样本调查中，受访家政员找工作渠道里，线下家政公司约 51%，熟人介绍约 35%，互联网平台约 13%。这不是全国代表性抽样，不能外推全国，但至少是一个强反例：即使平台已经成熟，关系网络和线下中介仍然是重要入口。

同一平台样本里，40 岁以上在岗人员占很高比例，报告将其与子女长大后家庭负担下降、其他行业年龄门槛、生活技能适配和收入吸引力联系起来。

**机制 8：midlife care-skill conversion / 中年照护技能转化**

人的职业入口不只发生在 20 多岁。孩子长大、家庭照护负担下降之后，40–50 岁女性也可能把长期家庭经验重新转化为有偿劳动。

证据（平台样本，需标明 selection bias）：https://news.bjd.com.cn/2024/03/20/10725966.shtml

### 2025：制度终于来了，但有人的缴费地平线已经错过

2025 年关于上海员工制家政的同期采访中，一名 52 岁、在沪从业二十多年的安徽家政员说，如果自己刚入行时就有真正的员工制，她现在可能已经满足养老金缴费年限；但到了 52 岁才重新开始计算，她认为吸引力已经变低，并更愿意直接面对雇主、避免公司抽成。

另一名福建家政员已有老家退休金。她从住家育儿转为白班后，工作不再提供住宿，于是不得不重新解决上海居住问题；她加入一家老乡开的家政公司，主要理由之一正是公司能提供宿舍。

这里出现两个此前家庭史容易漏掉的变量：

**机制 9：social-insurance horizon mismatch / 社保时间地平线错位**

制度在某年变得“可用”，并不意味着对所有年龄段劳动者都有同样价值。缴费年限和预期返乡时间会改变制度选择。

**机制 10：housing-as-employment infrastructure / 住房即就业基础设施**

住家家政把住房与工作绑定；转为白班意味着劳动者突然必须在高租金城市单独购买自己的居住空间。公司宿舍因此不是福利边角，而可能直接决定一个人能否留在这座城市接单。

证据：B + contemporaneous interviews：https://finance.sina.com.cn/jjxw/2025-06-13/doc-inezxpey0330801.shtml

### 春节仍会把两套家庭日历撞在一起

2025 年上海一名 58 岁家政员过去两年因照顾瘫痪老人而错峰返乡，但这一年因为儿子婚后第一个春节，坚持拒绝雇主高薪、回家团聚。与此同时，需要春节值班的雇主家庭仍要寻找替代照护。

这说明平台化以后，最硬的资源仍然是人的时间：

`雇主家庭春节照护刚需 ↔ 家政员自己的家庭仪式与照护义务`

证据：B + contemporaneous first-person：https://mzj.sh.gov.cn/lnb-xw/20250123/f7fabc1139964df58b00b0a8fdb8752e.html

## 7. 海外对照：1994 年美国，Internet 以前同样需要“如何与住家照护者一起生活”的知识系统

1994 年《华盛顿邮报》报道 Vanessa Sandom 在寻找住家 nanny 时发现，自己缺少的不只是候选人名单，还包括“怎样招聘、怎样管理、怎样与一个住在家里的劳动者共同生活”的知识，于是创办纸质 newsletter `Nanny News`，通过 nanny agencies 与订阅分发。

报道中的一名 21 岁住家 nanny 也谈到，由于与雇主家庭共同居住，工作与下班的边界很难完全分开；雇主则强调需要主动讨论彼此边界。

这说明两个机制不是中国特有：

- 家庭作为工作场所会模糊劳动/私人边界；
- 在 Web 以前，机构、电话、纸质通讯、推荐与个人网络已经可以形成家政劳动的信息基础设施。

证据：B（1994 同期报道）：https://www.washingtonpost.com/archive/lifestyle/1994/08/12/you/11058b9b-81aa-4480-90a2-3feb7a20e429/

跨国差异则需要继续研究：中国这一时期家政劳动与大规模农村—城市迁移、下岗再就业、祖辈照护、户籍/社保和一线城市住房成本的耦合尤其强，不能用美国 nanny/au pair 模型直接套用。

## 8. 对四种未来感的修正

### 2005–2012：扩张型未来，但扩张依赖别人提供照护时间

一部分城市家庭可以把更多时间投入职业与消费，一部分家政员则把迁移和技能升级看作增加收入的路径。问题不是“谁更现代”，而是两条未来经常依赖同一份被重新分配的照护时间。

### 2015–2019：拥堵型未来进入家庭内部

证书、培训、月嫂等级、平台评价增加；高技能家政员可以获得更高收入，但工作、住房、睡眠、自己的孩子与养老缴费同时进入计算。未来不是单一“涨工资”，而是更多接口一起需要维持。

### 2020–2022：偶发型未来把物理接入重新变成不确定条件

有订单、有证件、有平台账号也可能进不了小区。家庭能否复工与家政员能否“上户”直接耦合。

### 2023–2026：防守型未来不是“退出劳动市场”，而是重新优化保障与可持续性

中年劳动者会比较：现金到手、公司抽成、社保还来不来得及、住家还是白班、宿舍有没有、离雇主多远、春节是否回家。所谓稳定越来越像一组可持续条件，而不是一个永久单位身份。

## 9. 重点矩阵更新

| 维度 | 本轮新增 |
|---|---|
| 教育/技能 | 家政培训、月嫂技能、证书与技能等级 |
| 就业 | 中介制、住家、白班、钟点、共享时段、员工制尝试 |
| 住房 | 住家工作绑定住房；白班化后需要自购城市住宿；公司宿舍可决定可就业性 |
| 婚姻家庭 | 雇主家庭劳动参与依赖外部照护；家政员自己家庭承受长期离场 |
| 迁移 | 外地家政员进入大城市，春节/疫情/养老预期又推动返乡 |
| 照护 | 照护没有消失，而是在家庭、祖辈、机构、家政员之间重新分配 |
| 非正规劳动 | 家庭服务合同、中介挂靠、私单与口碑接活长期共存 |
| 长期中断 | 生育、春节、疫情、小区封闭、雇主更换都可中断工作链 |
| 证件/记录 | 身份证、健康证、技能证、平台评价、健康码、社保记录各自解决不同问题 |
| 通信/Internet | Web 从目录→论坛求助→数据库匹配→预约评价；电话/面谈持续重要 |
| 社交关系 | 熟人介绍与口碑没有被平台消灭 |
| 未来预期 | 孩子教育资金、技能涨薪、退休缴费年限、返乡、城市住房共同进入计划 |
| 线上/线下身份 | 平台昵称/等级/证书与线下“保姆/管家”职业认同可能不一致 |
| 历史可见性 | 网页容易保存招聘/介绍，真正发生在住宅内部的劳动、私聊、口碑与冲突最难保存 |

## 10. 反例与后见之明风险

1. **不要把家政写成女性就业“解放”的单线故事。** 它可以带来现金收入和技能升级，也可能带来超长工时、住家边界模糊和自己家庭照护不足。
2. **不要把雇家政写成中产炫耀。** 对双职工家庭、失能老人家庭、产后家庭而言，它可以是工作能否继续的基础设施。
3. **不要把平台写成中介终结者。** 2023 平台样本自身仍显示线下公司和熟人介绍占重要位置。
4. **不要把有证写成专业性已解决。** 证书的发证主体、标准、真伪、雇主是否认可都需要单独验证。
5. **不要把高工资写成职业地位同步提高。** 2009 与 2025 都还有隐藏职业身份的材料。
6. **不要把疫情写成行业“停摆”的统一经验。** 住家旧客户、留城人员、钟点工、不同小区规则差异极大。
7. **不要把某个平台年鉴外推为全国劳动者结构。** 平台自身用户有明显 selection bias。

## 11. 仍不知道什么

- 1980s–1990s 不同城市、阶层、户籍家庭实际使用家政的普及率；
- 1990s 家政公司、报纸分类广告、电话热线、街道/妇联介绍各占多大比例；
- 家政员自己的孩子由谁照护，以及这一照护链的全国分布；
- 2005–2012 家政网站的真实访问量与成功匹配率；
- 平台评分是否长期改善劳动者议价能力，还是主要增强雇主筛选；
- 中介制、服务协议、劳动合同在各城市各工种中的真实比例；
- 住家住房的隐含价值如何进入工资比较；
- 40–50 岁进入家政是否普遍发生在子女教育负担下降之后，需要更强的生命史/面板证据；
- 2023–2026 “防守型未来”中，社保、住房、现金流与返乡选择如何一起决定实际职业持续时间。

## 本轮最重要的理解变化

> **家政服务不是“一个家庭少做了家务”，而是社会把照护时间重新接线。**
>
> 一个母亲能够继续上班，可能因为另一个母亲住进她家照顾孩子；一个老人能够留在自己的房间，可能因为一个外地中年女性把自己的住房、春节和退休安排都绑到这份工作上。Internet 后来让双方更容易找到彼此，却没有把这份劳动变成虚拟事务。网页能保存候选人、价格和评价，真正让生活继续下去的那部分——凌晨起床、接孩子、喂饭、翻身、在两个家庭之间选择春节去哪边——始终发生在屏幕之外。
