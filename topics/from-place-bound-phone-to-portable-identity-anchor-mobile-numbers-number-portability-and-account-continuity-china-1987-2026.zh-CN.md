# 从“换号只是通知朋友”到“手机号不能轻易丢”：移动号码、携号转网与数字身份连续性（中国，1987—2026）

> 研究切口：一个电话号码什么时候从“拨这个号可以找到我”，逐渐变成“这个号还是我许多数字生活状态能够继续工作的条件”？
>
> 本文不写手机产业史，也不把手机号误写成正式法律身份证。它研究的是 **personal address continuity / 人的可寻址连续性**、**number portability / 号码可携带性** 和 **account continuity / 账号连续性** 怎样叠加，最后让“换一个手机号”从一次通信变更变成一次需要迁移关系、支付、账号、安全凭据和制度记录的小型人生工程。

## 一句话结论

**移动电话先把“找到一个人”从家庭/单位地址中解耦出来；Web 与移动互联网随后又把这个号码写进越来越多账号、支付和身份验证状态；携号转网则试图让号码本身从运营商中解耦。到这一步，手机号已经不只是通信工具，而是一种跨平台的个人连续性基础设施。**

但以下状态必须始终拆开：

```text
一个人正在使用某号码
  ≠ 这个号码依法登记在此人名下
  ≠ 这个号码从未被别人使用过
  ≠ 所有朋友/单位都知道这个号码
  ≠ 所有互联网账号都绑定这个号码
  ≠ 能收到短信就一定是原账号所有者
  ≠ 携号转网成功后所有第三方服务都会无缝工作
  ≠ 注销号码后所有历史绑定都会自动消失
```

本文把这种逐渐累积的结构称为：

> **phone-number identity accretion / 手机号的身份增生**

而换号时必须逐项搬迁这些联系和权限所形成的负担，称为：

> **identity switching cost / 身份切换成本**

## 1. 为什么这是 life-horizons 问题，而不是一篇“手机发展史”

仓库已经研究迁移、远距离家庭、校友重连、就业、居住证、护照和各种数字事务。手机号把这些线串起来，因为它常常是一个人跨城市、跨工作、跨住房以后仍然保持不变的少数私人标识之一。

固定电话更接近：

```text
place / household / unit -> telephone number
```

移动电话逐渐允许：

```text
person -> mobile number -> reachable while moving
```

而 Web/App 时代又继续叠加：

```text
mobile number
  -> contact address
  -> SMS notification endpoint
  -> account binding
  -> password recovery
  -> payment/account security
  -> real-name subscriber record
  -> login / authentication factor
  -> health/service contact field
  -> carrier-portable identity anchor
```

于是一个普通人的“未来可逆性”会出现新的条件：

- 可以换工作，但是否要通知所有客户？
- 可以换城市，但联系方式能否不变？
- 可以换运营商，但银行、微信、支付宝、网站绑定会不会受影响？
- 可以注销旧号，但旧号以后被重新放给别人时，历史账号有没有真正解绑？
- 丢失或停用号码以后，过去十几年积累的账号还拿不拿得回来？

这就是为什么号码连续性属于 ordinary life infrastructure，而不仅是电信行业竞争。

## 2. Internet 以前与大众 Internet 早期：号码首先解决“人在移动，怎样还能找到”

中国移动电话业务从 1980 年代后期起步。它最初昂贵、稀少，不能倒写成普通家庭基础设施。

到 2000 年第一季度，信息产业部统计显示移动电话用户已超过 5000 万，移动通信业务量第一次超过固定电话业务量；同期报道把价格和入网门槛持续下降列为进入更多家庭的重要条件。

- 2000-05-23，《北京晨报》经新浪：<https://news.sina.com.cn/china/2000-05-23/91712.html>

2001 年 7 月移动电话用户达到约 1.2 亿；2002 年中移动用户约 1.76 亿，固定电话约 1.99 亿，无线寻呼仍有约 2507.5 万用户；到 2005 年，移动用户约 3.93 亿，已经超过固定电话约 3.50 亿。

- 人民日报 2001-08-24 历史版面：<https://cn.govopendata.com/renminribao/2001/8/24/6/>
- 工信部保存的 2002 年 6 月通信月报：<https://www.miit.gov.cn/gxsj/tjfx/txy/art/2020/art_9918596d71124956b23b556ea6c370b4.html>
- 国家统计局“十五”通信业总结：<https://www.stats.gov.cn/zt_18555/ztfx/15cj/202303/t20230301_1920491.html>

这些数字只能证明基础设施快速普及，不能证明每个人都拥有手机，也不能说明所有群体使用方式相同。

### 真正的新生活能力：person-address continuity

固定电话和单位电话把联系方式牢牢绑在地点上。移动号码则逐渐允许一个工人、学生、销售人员或迁移者离开原住房以后仍然保持同一个可呼叫地址。

这不是 Internet 发明的，但它后来成为 Internet 账号体系最重要的输入之一。

可以把早期变化写成：

```text
以前：知道“他住哪里 / 单位哪里” -> 找到电话 -> 找到人
后来：知道“他的手机号” -> 即使他换宿舍、换租房、出差、迁移，也仍可能找到人
```

这降低的是 **social relocation cost / 社会关系随迁成本**。

## 3. 一个重要反例：2004 年，很多人仍然真的会为了资费换号码

如果从 2026 年倒看，很容易觉得“手机号从一开始就不能换”。同期证据并不支持这种写法。

2004 年哈尔滨日报与当地市场调查公司的一项调查中，58.3% 的受访者说曾调换过手机号码，47.3% 表示愿意因为资费而换运营商并换号。

- 2004-09-01，《哈尔滨日报》经搜狐：<https://news.sohu.com/20040901/n221828125.shtml>

证据等级：**B（同期地方媒体 + 调查）**。

限制：

- 这是哈尔滨地方样本，不是全国概率调查；
- 报道没有足够方法信息，不能用 58.3% 外推全国人口；
- 但它足以作为强反例，证明 2004 年“保持号码连续性”还没有普遍压倒资费选择。

因此后面的历史问题不应该是：

> “什么时候人们终于能换号码？”

而应该是：

> **“什么时候一个号码背后的关系与账号负载重到让换号越来越昂贵？”**

## 4. 2005—2007：手机号开始从“联系地址”变成 Web 账号的安全与控制入口

这是旧网与生活史真正交叉的地方。

### 4.1 2005：游戏账号已经把手机当密码恢复通道

2005 年《热血江湖》相关同期报道介绍新增“手机密码保护”功能：用户可以绑定手机，用短信找回账号密码；网页查询还可以通过手机号和会员信息查看相关绑定状态。

- 2005-09-05，新浪游戏：<https://games.sina.com.cn/o/n/2005-09-05/1603124246.shtml>

证据等级：**B（同期操作/产品报道）**。

这时的关键变化不是“手机可以上网”，而是：

```text
mobile number possession
-> can receive SMS
-> can recover / change Web-account credential
```

手机号第一次开始承担 **account-control endpoint / 账号控制端点**。

### 4.2 QQ：一个通信地址开始控制另一个通信身份

2005—2007 的 QQ 生态也能看到相似变化。同期资料将 QQ 账号区分为是否绑定手机；手机绑定可以参与短信服务、密码找回等操作。2006 年关于 QQ 被盗的报道甚至记录了账号可能被盗号者绑定到自己的手机、原用户随后需要通过申诉材料解除控制的情形。

- 2006-09-20，京华时报经搜狐：<https://news.sohu.com/20060920/n245445345.shtml>
- 2007-11-16，中新网：<https://www.chinanews.com.cn/sh/news/2007/11-16/1079503.shtml>

2007 年后一则案例中，当事人说自己的付费 QQ 已使用五六年，许多重要工作客户都通过它联系；即使此前绑定手机，账号仍然被盗，手机自助找回也没有顺利解决。

证据等级：**B（同期媒体 + 当事人引语）**。

这说明两件事同时成立：

1. 数字账号本身已成为现实工作关系的入口；
2. 手机绑定降低部分恢复成本，但并不意味着“绑定 = 永不丢失”。

因此：

> **phone-bound ≠ securely recoverable**。

## 5. 2005–2012 的扩张型未来：号码越来越像“跟人走”的基础地址，但还没有成为绝对不可替换的身份

这一阶段最容易被后见之明写成“手机彻底改变人生”。更准确的说法是：

- 手机数量高速扩张；
- 一个号码可以跟着人离开固定地点；
- 短信和 Web 账号开始互相绑定；
- 真实工作联系人、QQ、游戏账号和支付逐渐积累在号码周围；
- 但人们仍然会因为资费、套餐、运营商或城市生活需要换号。

所以“扩张型未来”在这一格并不是所有人都想长期绑定一个号码，而是：

> **我可以不断增加新的联系、工作和账号，同时仍认为换卡、换号、换运营商是可承受的生活动作。**

换号负担正在变大，但尚未稳定成今天这种“要先盘点几十个 App”的小型迁移工程。

## 6. 2010—2013：实名制把号码与法律订户关系绑得更紧，但“登记”仍不等于“实际使用者”

2010 年起，预付费新入网用户被要求登记真实身份。同期报道特别值得注意的是，当时大量预付费卡仍通过报刊亭、街边零售点等渠道销售，因此“规则启动”与“每一次实际销售都完成身份核验”之间存在明显执行距离。

- 2010-08-20，中国教育和科研计算机网转载政策说明：<https://www.edu.cn/wisafety_9958/20100820/t20100820_512090.shtml>

2013 年更严格的实名登记规则实施时，同期报道又区分了“实名登记”和“身份真实性核验”等状态，并讨论零售渠道如何逐步接入身份验证。

- 2013-09-02，中新网：<https://www.chinanews.com.cn/sh/2013/09-02/5231311.shtml>

这里必须长期保留三种角色：

```text
registered subscriber / 法律登记人
actual everyday user / 日常实际使用者
account operator / 操作某个互联网账号的人
```

它们经常重合，但历史研究不能假定永远重合。例如家庭成员代办卡、单位卡、早期非实名预付费卡、转送旧卡等，都可能让关系暂时分叉。

所以：

> **real-name registration ≠ perfect one-person-one-number identity mapping**。

## 7. 2014：二次放号第一次清楚暴露“电信号码生命周期”和“互联网账号生命周期”并不同步

2014 年北京青年报/人民网的一则同期报道记录，新用户拿到一个运营商重新放出的手机号后，持续收到原使用者的银行卡通知，并发现部分淘宝/支付宝账号仍与号码保持关联；短信验证甚至可能让新持号者进入旧账号流程。

- 2014-09-15，人民网：<https://society.people.com.cn/n/2014/0915/c1008-25661203.html>

证据等级：**B（同期媒体调查）**。

这是一个极关键的状态缺口：

```text
carrier:
OLD_USER cancels number
-> number quarantined / recycled
-> NEW_USER obtains number

internet platform:
OLD_ACCOUNT still bound to same digits
-> SMS goes to whoever currently controls the number
```

也就是说：

> **telecom identity reset ≠ platform identity reset**。

这产生 **identity residue / 身份残留**。

手机号开始像一个被多个互不完全协调的数据库共同引用的外键；运营商把号码重新分配，并不会自动触发银行、购物网站、社交平台和游戏逐个解除旧绑定。

## 8. 2015–2019 的拥堵型未来：一个稳定号码开始承载太多生活状态，换号本身变成“项目”

这一阶段有非常好的同期第一人称材料。

### 8.1 2018：从“通知通讯录”到“我到底绑定过多少 App”

新华社/人民网 2018 年关于“新人遭遇旧账”的调查访问了刚毕业、到新城市生活的用户。受访者小敏换到新号码后，很快开始收到前任号主的信用卡账单等信息。报道概括了一个时代差异：早期换号最主要的麻烦是通知通讯录，而 App 时代以后，用户往往已经记不清一个号码到底绑定过多少第三方服务。

- 2018-11-12，人民网：<https://society.people.com.cn/n1/2018/1112/c1008-30396405.html>

这里出现：

> **binding-graph opacity / 绑定图谱不可见性**

用户知道自己“有一个手机号”，却未必有一张完整清单知道哪些系统把它当作：

- 登录名；
- 密码恢复地址；
- 二次验证因子；
- 支付通知；
- 联系地址；
- 实名账户字段。

### 8.2 2018—2019：换号的真正成本是“重新配置自己”

2019 年人民网关于携号转网的同期报道访问北京用户吴丹。她回顾自己 2018 年因为运营商体验问题换号，真正痛苦的并不是买一张新 SIM，而是随后大量繁琐的号码变更和通知操作，耗费了明显时间和精力。

- 2019-04-03，人民网：<https://finance.people.com.cn/n1/2019/0403/c1004-31012251.html>

证据等级：**B（2019 同期报道 + 2018 近同期个人经历）**。

这个案例把“拥堵型未来”变得非常具体：

> **生活项目变多以后，保持一个稳定的号码，本身就是减少未来协调负担。**

工作联系人、金融账户、社交关系、购物、出行、政务和账号恢复同时存在时，换号就像小型搬家：新的房间其实已经有了，麻烦的是把所有地址都改过来。

## 9. 2019 携号转网：号码第一次全国性地从运营商组织身份中拆出来

2019 年 11 月 27 日，全国“携号转网”正式提供服务。工信部相关启动材料说明，为此完成了 1800 余项系统建设改造、网内网间联测超过 103 万项、三家企业累计投资超过 30 亿元，并建设 31 个省级区域的实时交互联动系统。

- 2019-11-27，新华社经中央网信办：<https://www.cac.gov.cn/2019-11/27/c_1576389972372088.htm>

同一材料还列出此前十年试点：

- 2009 海南开始准备试点；
- 2010-11-22 天津、海南第一批试点；
- 2014 海南双向携转；
- 2014 江西、湖北、云南加入；
- 2019 全国铺开。

这里真正改变的不是“号码归个人所有”这种法律表述，而是：

```text
person + number + carrier A
-> keep number
-> carrier B
```

第一次在全国范围内成为正式可执行路线。

这可以叫：

> **carrier-independent address continuity / 与运营商解耦的可寻址连续性**

### 但携号转网并不携带整个数字人生

同一官方材料恰好提供了反例。试运行期间，有用户在携转后遇到上网、充值或部分应用服务异常。

所以必须区分：

```text
number ported
!= old contract eliminated
!= handset compatibility guaranteed
!= all carrier-specific benefits retained
!= all third-party apps recognize new carrier state
!= bank/platform bindings migrated
```

> **carrier portability ≠ application portability**。

这也是为什么携号转网降低的是一类 switching cost，不是把所有切换成本归零。

## 10. 海外对照：美国 1996—2003 证明“号码可携带”首先也是反锁定，而不是 Internet 功能

美国 1996 年《电信法》后的 FCC number portability 规则明确把号码可携带定义为用户更换运营商时仍可保留原号码，并指出如果不能保留号码，消费者选择服务商的自由就会被明显削弱。

- FCC 1996 First Report and Order：<https://docs.fcc.gov/public/attachments/FCC-96-286A1.pdf>
- Federal Register 1996-07-25：<https://www.govinfo.gov/content/pkg/FR-1996-07-25/pdf/96-18477.pdf>

到 2003 年美国移动号码携带正式落地前，《华盛顿邮报》非常直接地写道：用户想换运营商的理由很多，但一直有一个强理由不换——号码保不住；对承包商和其他把手机号长期写在业务联系人里的劳动者来说，号码本身已经成为职业身份的一部分。

- 2003-11-04，Washington Post：<https://www.washingtonpost.com/archive/lifestyle/2003/11/04/for-cell-users-safety-in-numbers/3725673c-287e-463d-b8aa-0f3e13064ca3/>

这个海外对照说明：

- “号码形成切换成本”并不是中国特有；
- 在 App 大规模出现以前，职业联系人和社会关系本身就足以使号码有很高价值；
- 中国后来的特殊复杂性之一，是一个超大规模移动市场上，手机号又进一步与实名制、短信验证和大量超级 App 账号体系叠加。

因此不能把 2019 中国携号转网只写成“追赶某项通信政策”，也不能把手机号锁定完全归因于微信/支付宝。

## 11. 2020–2022 的偶发型未来：一个旧号码甚至可以短期决定“普通流程能不能继续跑”

2020 年北京健康宝提供了非常清楚的状态案例。11 月有用户反馈，返京行程核验时，系统要求核验此前在微信端和支付宝端绑定过的两个手机号；其中一个号码已经作废，导致健康宝无法正常完成核验。官方说明因此提醒，换绑手机号需要提前操作，解绑后的号码在一定时间窗口内仍可能参与行程核验。

- 2020-11-25，北京青年报经人民网：<https://bj.people.com.cn/n2/2020/1125/c14540-34435865.html>

这不是用来评价防疫制度，而是一个事务史事实：

> **old phone number can remain temporally relevant after the user considers it abandoned / 用户认为旧号已作废，并不等于所有制度立即忘记它。**

这里出现：

> **binding-memory latency / 绑定记忆延迟**

数据库为了某种核验逻辑，可能故意保留一个号码一段时间。于是“我今天换号”与“所有制度今天都承认新号”之间存在时间差。

2022 年中国信通院推出手机号“一键解绑/一键查询”服务时，其目标已经明确是让在网用户查询手机号注册的互联网账号，并解除**当前用户获得该号码之前**遗留的部分互联网账号绑定；报道还特别说明，当前持号期间本人绑定的账号不在同一处理范围内。

- 2022-06-08，人民网：<https://finance.people.com.cn/n1/2022/0608/c1004-32441591.html>

这表明“二次号码”问题已经从用户逐个平台申诉，开始被当作一个跨运营商—互联网平台的基础设施问题处理。

偶发型未来在这一格不只是“人更焦虑”，而是：

> **当越来越多普通流程突然要求远程认证时，一个失效、丢失或残留绑定的号码，会从生活麻烦放大成流程阻断点。**

---

## 12. 2023–2026 的防守型未来：防守的不只是号码本身，而是账号可恢复性

### 12.1 “二次号码焕新”：运营商开始替用户清理别的平台记忆

2025 年，工信部指导推广“二次号码焕新”。黑龙江通信管理局的说明非常清楚：运营商把回收号码重新投放后，新用户可能因为前任号主绑定第三方 App 而无法注册、登录或正常使用；服务通过信通院码号服务平台与互联网企业协作，帮助清除**开户之前**的历史绑定。

- 2025-05-16，黑龙江省通信管理局：<https://hljca.miit.gov.cn/xwdt/gzdt/art/2025/art_68d9615319fd4df4b6be6d261e094062.html>
- 2025-05-21，黑龙江联通/通信管理局：<https://hljca.miit.gov.cn/xwdt/xydt/art/2025/art_464977113e424c4b910723b4e12d07dd.html>

这里最重要的不是“一键”，而是数据拓扑：

```text
carrier knows:
when NEW_USER obtained number

platform knows:
which account is bound to number

refresh service tries to establish:
binding created before current ownership
-> remove / repair

binding created during current ownership
-> do not automatically remove
```

这实际上在重建一种过去不存在的 **temporal ownership boundary / 号码持有时间边界**。

### 12.2 规模说明“身份残留”已经成为常规治理对象，但不能直接等于受害人数

工信部 2025 年第三季度通告称，“二次号码焕新”已覆盖 230 余款主流应用，处理解绑申请超过 2.6 亿次，累计服务用户超过 430 万人。

- 2025-10-28，工信部：<https://www.miit.gov.cn/zwgk/zcwj/wjfb/tg/art/2025/art_30a89a6098804ec1944aeabe6a999b9e.html>

2026 年第一季度，覆盖扩大到 249 款常用应用，服务用户超过 912 万，申请解绑应用超过 5.6 亿次；第二季度又扩大到 258 款、服务用户超过 1435 万、申请解绑超过 8.5 亿次。

- 2026-04-30 工信部第一季度通告：<https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2026/art_983eaf483b80451c8b49d6b34e1ebe08.html>
- 2026-08-13 工信部第二季度通告：<https://wap.miit.gov.cn/zwgk/zcwj/wjfb/tg/art/2026/art_440c2ded2ba54f0387b4cca50acf8147.html>

这些数字表示服务调用/解绑申请规模，不等于“中国有同样数量的人遭遇了严重账号盗用”，也不能从“申请数”反推每个应用一定存在错误绑定。

### 防守型未来的新变量：recoverability buffer

到这时，一个稳定手机号的意义已经不仅是“别人能打给我”。普通人的防守动作可能包括：

- 换号前逐项解绑银行、支付、社交、邮箱与常用 App；
- 保留一个已经用了很多年的号码，即使别家运营商套餐更好；
- 通过携号转网换服务商而不换号码；
- 新办号码后先清理前任号主留下的绑定；
- 确认重要账号还有邮箱、密码、设备密钥或其他恢复通道，避免把全部恢复能力押在一个号码上。

这可以叫：

> **recoverability buffer / 可恢复性缓冲**

防守的不是“我永远不换生活”，而是：

> **即使手机丢了、运营商变了、号码被回收了，我过去十几年积累的数字生活不要跟着一起消失。**

## 13. 一个特别重要的反例：号码连续性提高，并不代表号码就是可靠的永久身份证

手机号非常适合作为身份辅助，却天然有一个与身份证不同的属性：**会回收再利用。**

因此：

```text
same digits at t1
!= same person at t2
```

这使“手机号 = 人”始终只是一个需要时间条件的工程近似。

二次放号案例说明，任何历史研究或系统设计都不能把号码当永久个人 ID。至少应该同时记录：

- 号码；
- 运营商/号段状态；
- 当前持有人起始时间；
- 历史绑定建立时间；
- 实名登记状态；
- 平台是否重新验证账号主体。

否则，新的号码持有人可能意外继承旧人的“数字影子”。

## 14. 对四种未来时间感的修正

| 时期 | 号码与普通生活 | 更精确的时间感解释 |
|---|---|---|
| 2005–2012 扩张型未来 | 手机高速普及，号码跟人移动；短信绑定和密码恢复开始进入 Web 账号 | 新关系、新账号、新工作不断增加；换号仍常见，但号码开始累积未来价值 |
| 2015–2019 拥堵型未来 | App、银行、支付、社交和工作联系人共同压在号码上；2019 全国携号转网 | “换运营商”不应该迫使我重新配置整个人生；稳定号码成为减少协调负担的基础设施 |
| 2020–2022 偶发型未来 | 远程认证和健康码等临时高强度事务让旧号/绑定错误成为流程阻断点；2022 出现跨平台一键解绑 | 普通流程可能突然依赖一个以前只是“联系方式”的字段；身份维护失误的后果被放大 |
| 2023–2026 防守型未来 | 二次号码焕新、批量解绑、跨平台清理历史绑定 | 防守从“保住号码”变成“保住恢复路径并清掉过去错误地挂在这个号码上的别人” |

这个表不是在说每一代人的心理都一致。它描述的是**同一个号码在不同时期承载的基础设施负荷**怎样变化。

## 15. 这改变了哪些“普通人有多少种活法”的判断

### 15.1 迁移可以不再意味着社会地址重置

一个人从家乡去深圳、北京、杭州读书或工作，不必每次迁移都重新发明“怎样找到我”。移动号码让一部分社会关系从地点中解耦。

### 15.2 换工作/城市与换通信服务可以拆开

携号转网把“运营商选择”和“个人联系地址”部分拆开；这和居住证、社保、护照专题中反复出现的 **portability / 可携带性** 属于同一类现代生活变化：

> 人在换机构时，不必把自己过去积累的状态全部清零。

### 15.3 数字身份也形成了路径依赖

一个用了十年的号码越成功地承担联系、支付、登录和恢复，它就越难退出。

这是一种很少被生活史写出的 **successful-infrastructure trap / 成功基础设施黏着**：

> 正因为一个号码太好用，它才逐渐成为不能随便替换的东西。

### 15.4 “号码归零”与“人生归零”之间需要制度缓冲

二次号码焕新本质上是在承认：电信运营商有权/有必要循环号码资源，但互联网平台不能假设同一串数字永远属于同一个人。

这是一种跨行业的身份时间协调问题。

## 16. 历史可见性：最容易留下的是帮助页，最容易消失的是那张真实绑定图

这一题对旧 Web 保存特别不友好。

容易存活：

- “如何绑定手机”的新闻/帮助页；
- 资费、功能说明；
- 携号转网政策；
- 公开网站的短信找回说明；
- 运营商公告。

容易消失：

- 某个具体用户在 2007 年到底绑了哪个号码；
- SMS 是否真的送达；
- 密码找回失败页面；
- 用户换号后忘记了哪些平台；
- 运营商号码回收/冷冻/二次放号的具体内部时点；
- 平台账号与号码的私有绑定表；
- 携转后某个第三方 App 为什么判断失败；
- 客服人工修复记录。

因此 surviving Web 会系统性高估“功能存在”，低估“身份连续性失败”。

> **help page survives better than failed identity state / 帮助页比失败的身份状态更容易留下。**

任何将来做个人数字生活史的研究，都不能仅凭“当时网站有手机绑定功能”写成“普通人已经稳定拥有账号恢复能力”。

## 17. 证据等级与后见之明风险

### A：官方/原始制度与统计

- 工信部/国家统计局通信用户统计；
- 2019 携号转网官方启动与流程；
- 2025–2026 工信部“二次号码焕新”服务统计；
- FCC 1996 number portability order。

### B：同期媒体、操作报道、用户案例

- 2004 哈尔滨换号调查；
- 2005 游戏账号手机密码保护；
- 2006–2007 QQ 绑定/盗号案例；
- 2014 二次号码与支付账号案例；
- 2018–2019 换号体验；
- 2020 健康宝换绑问题。

### C：回顾性材料

本稿尽量不依赖多年后的怀旧回忆。若后续补入“第一部手机/第一次换号”等口述史，必须单独标 C，不能用来确定当年网页功能或精确实施日期。

### 主要后见之明风险

1. **把 2026 的手机号重要性倒灌到 2000。** 2004 地方调查已经证明很多人愿意换号。
2. **把手机普及写成全国同步。** 城乡、收入、年龄、地区差异巨大。
3. **把实名制写成“手机号就是身份证”。** 号码会回收；登记人与使用者可能分叉；平台绑定有自己的生命周期。
4. **把携号转网写成所有账号自动迁移。** 官方试运行材料恰恰记录携转后的应用服务问题。
5. **把二次号码解绑申请数写成受害者数。** 服务请求/解绑条目不等于严重损失人数。
6. **把健康码案例泛化成所有疫情数字系统。** 本稿只用它证明特定时期“旧手机号仍可保持事务相关性”。

后续若继续深化，优先找：

- 1990 年代寻呼号 → 第一批 GSM 号码的个人连续性经验；
- 2000–2005 农民工、销售、个体经营者是否把手机号当作跨城市工作地址；

## 20. 本轮新增机制

本轮相对于已有仓库覆盖，新增的不是另一篇通信史，而是以下可复用机制：

1. **personal address continuity / 人的可寻址连续性**；
2. **phone-number identity accretion / 手机号身份增生**；
3. **identity switching cost / 身份切换成本**；
4. **carrier-independent address continuity / 与运营商解耦的号码连续性**；
5. **identity residue / 二次号码身份残留**；
6. **binding-memory latency / 换号后的绑定记忆延迟**；
7. **recoverability buffer / 数字身份可恢复性缓冲**；
8. **successful-infrastructure trap / 成功基础设施黏着**。

因此本轮构成实质新增，阶段饱和计数应重置为 **0**。

## 结论：电话号码后来变成了“一个可以随身带走的过去”

固定电话时代，电话号码更像一个地点。搬家、离开单位、毕业，都可能让过去的人更难再找到你。

移动电话最初改变的是这一点：号码开始跟着身体走。

Web 和 App 又改变第二层：越来越多账号开始记住这串号码，用它发验证码、找回密码、确认付款和通知风险。于是过去十几年认识的人、注册的服务和积累的工作关系，都在这串数字周围留下连接。

2019 年携号转网让人可以换运营商而保留号码；2020 年以后又越来越清楚地暴露出另一面——**号码能跟着你走，但别人的旧账号也可能跟着同一个被回收的号码走到你这里。**

所以手机号的历史不是从“通信”简单升级成“身份”。更准确地说，它逐渐成为一个连接许多不同身份系统的公共接口，而普通人开始为保持这个接口连续、可恢复、不过期、不串号，承担新的日常维护劳动。

这让“普通人到底有多少种活法”多了一个很小却重要的条件：

> **你当然可以搬走、换工作、换运营商、重开生活；真正珍贵的是，重开以后，过去真正属于你的那些关系与账号，不必全部重新从零开始。**
