# 从坐班地点到可携带工作：远程办公、SOHO 与工作边界（中国，2000–2026；含前史与海外对照）

> 研究问题：一份工作究竟在多大程度上必须与一个固定地点绑定？当通勤可以被通信替代以后，普通人获得的是空间选择权，还是把办公室的义务搬进了住宅和休息时间？

## 结论先行

本专题补充一个此前生命历程矩阵没有独立建模的变量：**workplace-location decoupling / 工作地点解绑**。

它不是“Internet 出现以后大家都能在家上班”，而是一条需要逐层成立的状态链：

```text
工作内容理论上可远程执行
→ 雇主/客户允许不在固定办公室完成
→ 本人有可工作的住所或第三空间
→ 设备、电话/网络、软件与身份认证可用
→ 企业邮件/内部网/文件/审批可达
→ 同事与客户能协同
→ 输出被真正接收并纳入工作流
→ 工资、合同、绩效、晋升与福利仍连续
→ 本人还能维护工作与生活边界
```

因此：

- `work done at home ≠ telecommuting employee`；
- `SOHO/freelance ≠ employer-approved remote employment`；
- `remote-capable job ≠ employer permits remote work`；
- `VPN/mail reachable ≠ every required workflow reachable`；
- `commute removed ≠ saved time belongs to worker`；
- `can work anywhere ≠ wants to work everywhere`。

本专题使用三个相邻但不能混为一谈的生活状态：

1. **home-based work / 居家劳动**：生产发生在住所，可能完全不依赖数字通信；
2. **SOHO / 自由职业或小型居家办公室**：本人通常直接面对客户、项目和收入波动；
3. **telecommuting / remote employment / 电子通勤或远程雇佣**：劳动者仍处于雇佣关系和组织管理中，只是工作地点与雇主提供的固定办公室部分解绑；
4. **hybrid / mobile / nomadic work / 混合、移动或游牧工作**：同一份工作可以在办公室、家、共享空间和旅途中切换。

这一区分很重要。2008 年的毕业生同时做文案、网店、自由撰稿与家教，与 2009 年仍按上司要求、用电子邮件向编辑部交稿的“电子通勤族”，不是同一种就业关系。

## 1. Internet 以前就有人不在雇主办公室工作

远程工作的历史不能从 Web 开始，更不能从 2020 年开始。

美国 BLS 使用 NLSY79 长期队列重新分析 1988–2022 年工作地点时发现，1988 年受雇者已经报告约 2.0% 的总工作时间在家完成；到 2018 年仍只有 3.6%，2020 年才突然升至 8.7%。这组数字不是“中国的直接对照”，也不能证明 1988 年每一小时在家工作都通过数据网络完成，但至少说明**工作地点与单位地点部分分离，早于大众 Web**。[BLS, 2026](https://www.bls.gov/opub/mlr/2026/article/from-typewriters-to-telecommuting-insights-from-the-national-longitudinal-survey-of-youth-1979-on-four-decades-of-remote-work.htm)

1995 年南加州 350 家雇主和 700 名通勤者调查进一步显示，20 人以上企业中约 15% 有某种 telecommuting，最大的障碍之一恰恰不是“Internet 有没有发明”，而是**岗位是否适合、管理者是否接受、设备由谁提供**。[Valk & Hellot, 1997](https://journals.sagepub.com/doi/10.3141/1606-11)

1998 年美国一项 2000 户电话调查也很适合给“Internet 决定论”降温：它估计约 1110 万 remote workers / telecommuters，但其中只有约 35% 使用 Internet；电话、语音信箱、传真和其他通信仍然重要。[Work Study, 1999](https://www.emerald.com/ijppm/article/doi/10.1108/ws.1999.07948caf.004/389305/Telecommuting-is-here)

所以更准确的前史是：

```text
家庭生产 / 自由职业 / 外勤
+ 电话、邮政、传真
+ 家用电脑与调制解调器
+ 企业远程接入
→ Internet 后协调半径和数据可携带性继续扩大
```

而不是：

```text
Web 出现 → 人第一次可以不进办公室工作
```

### 中国边界：不要把科研联网写成普通家庭远程办公

中国在 1994 年以前已有科研邮件、专线和其他前 Internet 数字通信，这些历史应保留在互联网前史里；但本轮没有得到足够证据证明 1994 年以前**普通雇员**已经形成可见规模的制度化电子通勤，因此不把少量科研连通外推为大众工作方式。

反过来，也不能写成“1994 年以前只有办公室”。自由撰稿、个体经营、家庭生产等在住所完成工作的形式当然更早存在，只是它们不能自动归入现代 remote employment。

到 1995 年，大众家庭的数字工作条件仍非常有限：新华社经《南华早报》报道，当时中国城市家庭电脑拥有率不足 0.5%，486 兼容机价格约 6000–10000 元，而上一年度城镇人均收入约 3179 元。[SCMP/Xinhua, 1995](https://www.scmp.com/article/138895/pcs-too-costly-most-china)

到 1999 年底，CNNIC 报告的 Internet 用户已为 890 万，其中拨号用户 666 万、专线用户 109 万，说明基础设施正在快速扩张，但仍不能从“已有数百万网民”跳到“普通工作已经地点自由”。[CNNIC data reported by Sina, 2000](https://tech.sina.com.cn/news/internet/2000-01-18/15793.shtml)

## 2. 2000：SOHO 已经是一种可以被公开想象的工作脚本，但不是大众默认

2000 年《生活时报》已经把 SOHO 作为一种城市工作方式讨论，并且做了一个很有价值的区分：

- 自由撰稿、律师、设计等人主要通过结果交付维持工作；
- 另一些会计、技术人员则仍在公司允许下居家办公，公司为其配联网、专用电话、传真等设施，并继续通过电话或网络掌握工作状态。

这说明中国公众语境里在 2000 年已经同时存在“自由职业”和“雇主批准的居家工作”两种不同状态。[《生活时报》，2000-10-25](https://www.gmw.cn/01shsb/2000-10/25/GB/10%5E1507%5E0%5ESH5-2509.htm)

但媒体把某种生活方式写成“新选择”，只证明**可见性**，不证明普及率。2000 年的 SOHO 叙事应该被放在家庭电脑、电话、拨号接入、职业类型和雇主制度的实际门槛里理解。

这里出现第一个新机制：**worksite portability / 工作地点可携带性**。

一份工作如果从“必须去某个地址”变成“只要能安全访问所需信息并交付结果”，迁居、通勤距离、照护安排和生活城市之间就可能出现新的组合；但这种可携带性首先集中在文字、设计、软件、咨询、销售、编辑等信息型工作，而不会同步扩展到制造、餐饮、护理、建筑、物流等必须处理实体现场的岗位。

## 3. 2003 SARS：一次早期、可观察的“应急远程办公实验”

2003 年 6 月新浪《电子商务》保存了一份非常细的同期工作日记录。神州数码市场部员工周永先此前虽然知道公司已有移动办公系统，却几乎没有实际使用；公司开始在家办公后，她第一次尝试 SOHO：

1. 用公司统一办理的联通 165 账号拨号上网；
2. 一开始无法打开公司网上办公系统 NOOTS；
3. 打内部 IT 服务电话 7888；
4. 按技术人员指导从网上下载工具软件后才进入系统；
5. 在内部通讯录向记者发送稿件；
6. 发现有人没收到后又用电话确认、重新发送；
7. 领导继续通过 NOOTS 派新任务；
8. 电话、消息和文件修改贯穿一整天。

同期报道还把公司移动办公基础设施拆成三层：动态工位与随人电话号码；通过拨号进入企业网、访问邮件和内部网站；以及覆盖异地分支的 VPN。疫情期间咨询热线一度被大量系统配置问题“打爆”，约一周后才明显下降。[新浪科技，2003-06-09](https://tech.sina.com.cn/it/m/2003-06-09/1846196226.shtml)

这条材料非常重要，因为它直接否定了今天最容易投射回去的模型：

```text
在家 + 有 Internet = 可以工作
```

真实状态更像：

```text
家里有电脑
→ 有拨号账号
→ 能进入企业网
→ 客户端/工具正确安装
→ IT 支持可达
→ 内部通讯录、邮件、文件可用
→ 外部收件人真正收到
```

因此新增 **remote-work executability / 远程工作可执行性**：远程工作不是地点标签，而是一条依赖家庭设备、网络、组织授权、技术支持和协作对象共同成立的执行链。

而且公司当时明确把它理解为特殊时期的保障，而不是永久替代固定办公。同期负责人认为远程沟通仍不如现场方便，长期在外也可能削弱归属感。于是还要区分：

`emergency remote continuity ≠ permanent remote-work norm`。

## 4. 2005–2012：扩张型未来里，“不坐班”既可以是自主选择，也可以是过渡状态

### 4.1 2008 上海：住宅不一定是合格的工作场所

2008 年《新闻晨报》采访了几名上海 SOHO 工作者。30 岁自由撰稿人李先生原先在家专门腾出一个房间办公，孩子出生后噪声和家庭干扰使工作困难，于是与另外 4 名 SOHO 工作者合租办公室；报道记录该空间具备电话、传真、宽带、打印机和办公桌椅，每人分摊约 400 元月租。[新闻晨报/新浪，2008-01-30](https://news.sina.com.cn/c/2008-01-30/023014856800.shtml)

24 岁设计工作者王小姐则通过电子邮件承接并交付业务，但长期居家以后主动寻找共同办公空间，理由是缺少交流；25 岁软件开发者钱先生也因自我管理困难转向合租办公室。

这不是“远程办公失败”的故事，而是新增了一个关键变量：**workspace adequacy / 工作空间充分性**。

```text
住房存在 ≠ 有独立工作空间
有工作空间 ≠ 安静
安静 ≠ 有社交/客户会面条件
有宽带 ≠ 有打印、传真、会议、保密和 IT 支持
```

于是出现 **workspace rebundling / 工作空间再打包**：

`企业办公室 → 家庭拆包 → 多个自由工作者重新共享电话/传真/宽带/打印/社交空间`。

后来所谓 coworking 并不是凭空出现；2008 年这组材料已经展示了“家庭不足—重新共同办公”的生活需求。

### 4.2 2008 毕业生：弹性工作不是稳定工作的单向替代

同年《信息时报》经中新网保存了一组“隐性就业”毕业生材料。2008 届毕业生“小菲”没有签高校就业协议，同时做文案、网络商铺、自由撰稿和家教；另一名大四学生彭倩慧则说，先用格子铺给毕业后的不确定期找一个“落脚”方式，以后可能考公务员、也可能当教师，“看未来的就业形势”。记者同时记录，这些“曲线就业”受访者普遍仍希望未来找到常规、稳定单位。[中新网，2008-12-18](https://www.chinanews.com.cn/edu/qzjy/news/2008/12-18/1493597.shtml)

这对“2008 年年轻人已经向往彻底自由职业”的后见之明是一个重要反例。

扩张型未来里的真实状态可以同时包含：

- “我不想坐班，希望靠技能自己安排时间”；
- “我暂时找不到合适单位，用零工桥接”；
- “我现在喜欢自由，但仍把稳定就业当未来目标”；
- “没有劳动合同以后，档案、保险和争议处理要自己维护”。

所以新增 **employment-form optionality / 就业形态可选性**，但也增加 **institutional unbundling burden / 制度解绑负担**：自由职业者得到地点和时间自由的同时，原来由单位打包的合同、保险、档案和风险管理可能重新落回个人。

### 4.3 2009 H1N1：第二次疫情再次把远程能力当作 fallback

2009 年新华社报道上海一名 27 岁杂志编辑王原琪在甲型 H1N1 流感期间申请回家工作。她仍须按时按量完成上司布置的任务，通过电子邮件与上司和同事沟通；其二十多人编辑部中已有 8 人在家办公。报道明确把这种“电子通勤族”与 SOHO 区分：前者仍受雇主约束，有工作时间，只是依靠电话、传真、网络等远程通信替代一部分物理通勤。[新华网/搜狐，2009-12-04](https://news.sohu.com/20091204/n268682236.shtml)

2003 SARS 与 2009 H1N1 因而构成一条疫情前史：

**危机并没有创造远程工作技术；它会迫使组织把平时作为备用能力的远程接入真正投入使用。**

## 5. 2015–2019：办公地点变成可以按天重新组合的资源

2019 年《中国青年报》报道自由职业者王逸兴没有固定办公室：咖啡馆太拥挤，家里又过于放松，于是按天购买共享办公空间，用于工作、见客户和开会。另一位创业者杨昭先后试过家、社区图书馆、咖啡馆和按月众创空间，最后选择可按天使用的共享工位；现场有插座、网络、打印设备、电话间、储物柜，并能通过手机查看位置、预约、支付和开门。[中国青年报，2019-03-05](https://zqb.cyol.com/html/2019-03/05/nw.D110000zgqnb_20190305_2-11.htm)

这里真正变化的是 **workplace as a service / 工作场所服务化**：

办公室不再只有“雇主给我一张固定工位”与“我自己在家”两种状态，还可以变成：

`今天需要安静 → 买一天工位`

`今天见客户 → 买会议室`

`今天在另一城区 → 选最近节点`

这提高了 **spatial optionality / 空间可选性**，但并没有消除空间本身。恰恰相反，资料显示人在获得数字可携带工作以后，会重新购买安静、社交、会议、打印、隐私和稳定网络这些原来办公室免费打包的功能。

2019 的“拥堵型未来”因而不是简单“大家都想逃离办公室”，而是**固定办公室、家庭、咖啡馆、图书馆、共享办公之间开始形成组合式路线**。

## 6. 2020–2022：偶发型未来把备用能力推成大规模连续性基础设施

2020 年初的一份艾媒调查记录了非常典型的应急状态。在已开始工作的受访者中，47.0%采取居家办公；居家办公者里 60.1%并非独居。41.1%受访居家办公者说日均工作时长延长，24.2%缩短；34.7%认为效率提高，26.3%认为下降；76.8%表示所在企业尝试了新的在线办公软件。微信、电话、QQ 是最常用的沟通工具。[艾媒咨询，2020-02-10](https://www.sohu.com/a/371916792_533924)

这些数据来自商业调查，不能外推为全国劳动者比例，但它们足以否定两种单向叙事：

- `居家办公 = 所有人都更高效`；
- `省下通勤 = 所有人都获得同等自由时间`。

这里新增 **commute-time dividend allocation / 通勤时间红利分配**：

```text
通勤时间消失
→ 可能变成睡眠 / 家庭 / 自己的时间
→ 也可能被会议、消息、延迟下班和更长在线时长重新吸收
```

所以“远程工作节约时间”必须继续追问：**节约出来的时间最终归谁。**

同一危机也证明了 **remote-work continuity state / 远程工作连续性状态**：当实体办公室暂时不可进入时，某些行业仍能维持劳动合同、收入和项目流转；对必须处理实体人/物/场所的岗位则不存在同等 fallback。

### 海外长期序列：2020 是跃迁，不是起点

BLS 的同一 NLSY79 队列显示，在有至少一些居家工作时间的受雇者中，居家工作占比从 1988 年的 11.2% 到 2018 年仅增至 13.5%，2020 年突然升到 25.3%，2022 年回落至 21.7%；全职 telework 占比也从 2018 年约 3.9% 跃到 2020 年 15.3%，随后回落，而部分混合办公类别继续增长。[BLS, 2026](https://www.bls.gov/opub/mlr/2026/article/from-typewriters-to-telecommuting-insights-from-the-national-longitudinal-survey-of-youth-1979-on-four-decades-of-remote-work.htm)

跨国共同机制因此不是“疫情发明远程工作”，而是：

`少量、职业选择性的长期能力 → 外生危机扩大使用 → 复工后部分回撤 → 某些混合状态留下`。

## 7. 2023–2026：防守型未来里，真正有价值的可能是“可以远程”，而不是“永远远程”

### 7.1 数字游民把“换地方”与“换工作”进一步拆开

2023 年《中国青年报》记录 28 岁向玲娇在深圳、成都、重庆、杭州、上海、长春等地移动，但线上工作节奏继续；报道中的程序员高磊结束近十年北京生活回天津后，通过灵活用工平台承接外地任务。另一位受访者也明确说，随时拿手机、电脑工作的代价是工作与生活很难完全分开。[中国青年报/新华网，2023-03-23](https://www.news.cn/2023-03/23/c_1129456154.htm)

这些都是高度选择性的案例，不能写成青年普遍趋势，但它们证明了一个新的可执行状态：**mobility without job exit / 不退出工作也能迁移**。

过去改变居住城市常常意味着：

`辞职 → 搬家 → 在新城市找工作`

在少数可远程岗位中则可能变成：

`保留客户/雇佣关系 → 搬家或旅居 → 远程保持工作`

这为迁移增加了可逆性，但仍受职业技能、合同、收入、网络、时区和雇主政策约束。

### 7.2 防守的另一面：把工作重新关回边界里

2026 年《中国青年报》一项 1335 人问卷中，77.5%受访者感到生活与工作边界模糊；52.5%说下班后仍会回应工作消息，44.5%在非工作时段收到工作微信、电话或邮件。一名受访者休假旅行时仍随身带电脑，因为老板临时来电后会立即“原地办公”；一名 23 岁实习生说周末、晚间消息让“实时待机”成为常态。[中国青年报，2026-03-26](https://zqb.cyol.com/pc/content/202603/26/content_423922.html)

这组问卷同样不是全国概率样本，因此不宜把百分比外推为劳动人口比例；但第一人称与样本内部结构共同说明：

**workplace-location decoupling 可以增加空间自由，也可以制造 reachability capture / 可达性捕获。**

当“在哪里都能工作”变成“在哪里都应该回应工作”，技术提供的自由会反转成义务。

所以防守型未来里的远程工作，不宜只问“我要不要永久 WFH”，更应该问：

- 我是否拥有在通勤过长、照护、轻微疾病、灾害或迁移时临时远程的权利？
- 我能否在需要面对面协作时回到物理空间？
- 我的下班是否有真正的 offline state？
- 雇主是否把设备、网络、空间和电费成本无声转移给家庭？
- 远程以后绩效、晋升、培训与非正式关系是否仍然可见？

这形成 **remote optionality / 远程可选性**，而不是把“全远程”本身当终点。

## 8. 新增生活机制

### 8.1 workplace-location decoupling — 工作地点解绑

工作关系与固定办公地址不再完全重合。

### 8.2 remote-work executability — 远程工作可执行性

真正可远程需要岗位、政策、家庭空间、设备、网络、认证、内部系统、协作和交付共同成立。

### 8.3 workspace adequacy — 工作空间充分性

“有家”与“家能办公”之间存在独立缺口。

### 8.4 workspace rebundling — 工作空间再打包

办公室功能拆到家庭以后，打印、会议、社交、网络、安静和隐私又可能被共享办公重新组合。

### 8.5 commute-time dividend allocation — 通勤时间红利分配

减少通勤不等于私人时间增加；节约时间可能被雇主、家庭或本人重新分配。

### 8.6 remote-work continuity state — 远程工作连续性状态

危机中，remote-capable employment 可以成为维持工作关系的 fallback，而不是一种永久身份。

### 8.7 mobility without job exit — 不退出工作也能迁移

少数数字岗位允许居住地点变化而劳动关系继续，是迁移可逆性的新来源。

### 8.8 reachability capture — 可达性捕获

空间解绑如果没有时间边界，可能把“随时随地可工作”变成“随时随地应工作”。

### 8.9 remote optionality — 远程可选性

防守型未来可能更重视保留远程 fallback、混合切换和离线边界，而不是永久全远程。

## 10. 跨国比较：共同的不是 Internet，而是“哪类工作能从地点抽离”

美国 2001 年 GAO 对 telecommuting 的定义就是在 employer-provided location 之外工作；当时列出的主要障碍包括岗位/员工是否适合、敏感数据安全与远程监控，以及对利润的影响。[GAO-01-926, 2001](https://www.gao.gov/products/gao-01-926)

这与 2003 年神州数码的具体困难惊人相似：并不是“有网络即可”，而是远程接入、企业权限、客户端配置、IT 支持、组织管理和协作必须共同成立。

因此可比较的共同机制包括：

- 信息型岗位比现场型岗位更容易地点解绑；
- 企业信任/管理制度和家庭设备同样重要；
- Internet 扩大远程工作的协调半径，而不是创造所有 home-based work；
- 疫情会让备用能力突然变成大规模必要能力；
- 大规模实验之后常出现全远程回撤和混合状态；
- 家庭空间、社会互动和边界管理会重新成为稀缺资源。

中国特定的历史节奏则需要继续放在家用 PC/电话/宽带普及、企业网/OA/VPN、城市住房空间和单位制度变化里，而不能直接套用美国 telecommuting 比例。

## 13. 反例与后见之明风险

1. **不要把 SOHO 当成 remote employee。** 2008 年很多 SOHO 个案没有固定雇主或劳动合同。
2. **不要把 2003/2009 应急远程写成常态。** 同期资料明确把它视为特殊状态或雇主默许。
3. **不要把 2020 远程暴增写成线性技术成熟。** 它首先是外生危机导致的使用跃迁。
4. **不要把“省通勤”直接换算成“多休息”。** 2020 样本中不少人的总工作时长反而增加。
5. **不要把数字游民浪漫化。** 这是技能、职业、收入和自律高度选择性的路径，而且材料本身也保存孤独、工作生活混合等成本。
6. **不要把在家工作当成性别/照护自动友好。** 家庭空间和照护劳动可能同时占用同一时间与房间，需要另找分布证据。
7. **不要把“远程可用”当成“岗位公平”。** 现场工作岗位没有同等地点选择权。
8. **不要把消息可达写成劳动自由。** 通信可携带性也会把单位时间延伸进休息时间。

## 14. What we know

- 中国至少在 2000 年公开媒体里已经能清楚描述 SOHO 与雇主批准的居家办公。
- 2003 SARS 与 2009 H1N1 都留下了雇员因疫情进入远程状态的同期材料，证明 2020 不是起点。
- 2003 个案显示企业远程工作依赖拨号/宽带、企业网、VPN、客户端配置、内部帮助台和组织授权。
- 2008 SOHO 个案显示住所本身可能不是合格工作场所，并出现了合租办公室这种重新打包。
- 2008 毕业生材料显示弹性工作既可能是自主路线，也可能只是等待稳定工作的过渡状态。
- 2019 共享办公已经把工位、会议、网络和办公设备做成按天购买、移动选择的服务。
- 2020 大规模应急居家办公同时产生连续性收益和工时/效率/家庭空间问题。
- 2023–2026 的材料同时展示空间流动性与“随时待机”的边界成本。
- 海外证据证明 telecommuting / work-at-home time 早于大众 Web，而 Internet 主要扩大了协调、数据和地址可携带性。

## 15. What we can reasonably infer

- 工作地点解绑降低了某些信息型工作的**通勤与迁居绑定**，但同时把一部分办公空间、网络、设备、安静和自我管理成本转移给家庭。
- 疫情是很好的“系统故障测试”：它揭示哪些岗位已经具备远程连续性，哪些仍必须依赖现场。
- 共享办公和数字游民社区的兴起说明“地点解绑”并没有让物理工作空间消失，而是让它从雇主固定配置变成可重新选择和购买的基础设施。
- 防守型未来对 remote work 的价值，可能越来越表现为“保留一个 fallback 和地点切换权”，而不是追求永久全远程。

## 16. What we do not yet know

- 1990s 中国普通雇员通过电话/传真/调制解调器长期在家工作的规模与行业分布；
- 2000–2005 中国企业远程接入在非 IT 行业的真实采用率；
- 2003 神州数码 NOOTS 的原始客户端、认证协议、浏览器/OS要求与历史帮助文档；
- 2008–2012 SOHO 个案中收入波动、社保与长期职业结果的分布；
- 2015–2019 企业正式 hybrid policy 的规模，而不只是自由职业/共享办公案例；
- 远程工作的性别、住房面积、育儿、合租与城市层级差异；
- 远程状态对晋升、培训、非正式信息和职业网络的长期影响；
- 2023–2026 中国全职远程、混合、现场工作的可比代表性统计。

## 17. 它改变了我们对“人怎么活着”的哪一点理解

过去可以把工作地点理解成职业的一部分：进这家单位，就去这个厂、这栋楼、这张桌子；搬得太远，通常要改变通勤或改变工作。

通信基础设施把其中一些工作拆开以后，一个人获得了新的组合：可以保留工作而暂时不去办公室，可以在另一座城市继续接项目，也可以在家庭、共享空间和办公室之间切换。

但真正增加的不是抽象的“自由”，而是一个新的选择维度：

> **一份工作有多大比例必须把你的身体固定在某个地点；剩下可以移动的部分，又有多少真正由你决定移动到哪里、什么时候开始、什么时候停止。**
