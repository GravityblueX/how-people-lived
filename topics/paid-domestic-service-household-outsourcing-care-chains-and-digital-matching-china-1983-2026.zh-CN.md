# 从“家里总得有人做”到“能不能找到合适的人”：有偿家政、家庭劳动外包与照护链，中国 1983–2026

## 研究问题

标准人生脚本经常默认一个家庭在工作、结婚、生育、照护老人以后仍然能够“正常运转”，但很少继续追问：

> **做饭、清洁、接送孩子、照顾婴儿、陪护老人和病人这些必须完成的劳动，究竟由谁来做？**

一个双职工家庭可以依赖祖辈；也可以让一方退出劳动市场；可以把孩子送托；可以雇钟点工、住家保姆、月嫂、育儿嫂或护理员；可以在几个方案之间混用；也可能因为任何方案都接不上而被迫改变工作、居住或生育安排。

而对家政劳动者而言，同一套系统又是另一条人生路径：

- 农村妇女离开原家庭进入城市家庭；
- 下岗或失业者进入家政作为再就业；
- 有人把它当过渡工作；
- 有人通过育婴、养老、月嫂等技能形成长期职业；
- 有人以住家劳动换取城市收入，却把自己的孩子留在故乡；
- 有人通过手机、微信和移动支付继续远程参与自己的家庭。

本专题把这组问题称为：

- **domestic-service addressability / 家政服务可寻址性**：一个家庭知道去哪里找一个能做具体任务的人；
- **care-outsourcing executability / 照护外包可执行性**：从“想请人”到真的有人按时入户并完成工作，中间是否可执行；
- **household-labor substitution / 家庭劳动替代**：市场服务能否替代一部分亲属、配偶或本人的无偿劳动；
- **match-to-household funnel / 匹配—入户漏斗**：广告、网页、平台上的候选人怎样变成现实中真正进入家庭的人；
- **service continuity / 服务连续性**：家庭能否在春节、疾病、离职、跳单、疫情或搬家时维持照护；
- **care-migration chain / 照护迁移链**：一个家庭为了维持自己的照护，可能依赖另一个离开自己家庭的劳动者；
- **proxy digitality / 代理数字化**：服务已经通过 QQ、网站、视频等数字媒介展示，但真正操作电脑、填写信息、回复雇主的人仍可能是中介；
- **trust credentialization / 信任凭证化**：身份证明、健康证、技能证、评价、背景核查和二维码逐渐替代一部分熟人担保；
- **availability seasonality / 可用性的节令性**：春节等共同家庭时间会让城市照护供给突然收缩，因为服务者也有自己的家庭。

这不是“保姆史”，而是一个普通家庭能不能保持运转，以及谁为这种运转支付时间、迁移和亲属分离成本的生活史问题。

## 一、先固定几条边界

### 1. `家政公司存在 ≠ 家庭今天就能找到人`

至少还要经过：

```text
需求出现
→ 知道中介/热线/网站/平台
→ 描述任务、时间、住家与否、照护对象
→ 看见候选人
→ 候选人愿意接
→ 双方能联系
→ 面试/核验
→ 工资与休息谈妥
→ 身体到达家庭
→ 试工/磨合
→ 持续服务
```

2006 年广州已经有雇主把长期、包食宿、独立房间等条件贴到家政网站上，大半个月以后仍然没有找到保姆；所以“发布成功”绝不能等同于“家庭照护已经补位”。

### 2. `找到人 ≠ 找到合适的人`

家政劳动进入的是私人住宅，常涉及：

- 婴儿；
- 失能老人；
- 卧床病人；
- 现金和私人物品；
- 饮食和卫生；
- 长时间共处；
- 住家时甚至共享家庭空间。

技能、性格、隐私、作息、语言、做饭习惯、照护理念和信任都可能决定一段匹配能否持续。

### 3. `雇主选择劳动者 ≠ 劳动者没有选择权`

家政是双向匹配：

- 工资够不够；
- 是否住家；
- 是否允许休息；
- 老人/病人的照护强度；
- 雇主是否尊重人；
- 地点远不远；
- 春节能不能回家；
- 是否愿意做短单。

2008 年上海一名刚来的家政工甚至当天辞掉条件不差的别墅住家工作，因为觉得环境太冷清，希望换到更热闹的地方。这个个案不能代表整个行业，但足以证明“有职位”与“劳动者愿意留下”不是同一状态。

来源：
- 第一财经日报/新浪，2008-02-19：https://news.sina.com.cn/s/2008-02-19/030014965237.shtml

证据等级：**B，同期调查报道中的第一人称。**

### 4. `网上匹配 ≠ 劳动关系已经平台化`

一个网站可以只有：

- 供求信息；
- 电话号码；
- 视频面试；
- 中介登记；
- 培训信息。

劳动者仍可能直接受雇于家庭，中介只收介绍费；也可能由公司派单；也可能形成员工制。

因此必须分开：

```text
listing platform
≠ matching intermediary
≠ dispatch platform
≠ employing firm
≠ household employer
```

### 5. `家政让雇主家庭更可运行 ≠ 家政劳动者自己的照护问题消失`

一个人在上海照顾别人的孩子，完全可能把自己的孩子留在安徽；一个人留北京照护两个幼儿，可能意味着春节不能回山西。

这不是一个边角问题，而是本专题最重要的 **care chain**：

> **一个家庭获得的照护时间，可能来自另一个家庭暂时失去的现场照护时间。**

### 6. `数字沟通缓解异地母职 ≠ 数字沟通替代现场照护`

微信可以让家政女工：

- 语音提醒孩子起床；
- 和老师联系；
- 远程了解学习；
- 发红包；
- 维持夫妻和亲子联系。

但它不能替母亲：

- 做一顿饭；
- 在孩子生病时 physically 到场；
- 参加所有学校事务；
- 消除长期分居。

2019 年关于安徽无为家政女工的研究自己也明确提醒不要陷入“技术迷思”。

来源：
- 陈青文、王宇，《家政女工的微信使用与异地母职实践研究》，《今传媒》2019 年第 10 期，人民网转载：https://media.people.com.cn/n1/2019/1125/c430788-31473451.html

证据等级：**B，同行/期刊研究；其中包含同期问卷与深访第一人称。**

## 二、Internet 以前：先出现的是“家庭劳动社会化”的组织接口，而不是网页

### 1983–1984 北京：双职工家庭的时间问题先催生组织化家务服务

北京日报 2026 年整理旧报时重新展示了 1983–1984 年的原报材料：1983 年由北京市妇联、朝阳区妇联推动的朝阳家务服务公司成立，首批招收 55 名家庭服务员；不到两个月登记需求超过 700 户，随后又到密云招聘 145 人。

旧报中的用户需求非常具体：

- 父母都工作，孩子没人照顾；
- 老人住院需要陪护；
- 孩子要接送；
- 家务已经影响女性继续上班。

来源：
- 北京日报“温故”整理，引用 1983-12-22、1984-02-20、1984-03-16《北京日报》原版：https://xinwen.bjd.com.cn/content/s6983c4ece4b0687a2890c698.html

证据等级：**C/B：2026 年后来的档案整理，内部明确定位原报日期、标题与版面。尚未在本轮直接取得 1983/1984 原版数字文件，因此不升级为 A。**

这里真正重要的不是“第一家”头衔，而是当时已经出现一个很现代的家庭执行问题：

```text
所有成年人白天都有固定工作
+ 托育/陪护不足
+ 家务不会因为上班而消失
→ 必须从亲属以外寻找劳动时间
```

所以有偿家政不是单纯“富裕消费”。至少在这些登记家庭里，它也可能是**让家庭成员继续上班的时间基础设施**。

### 1980s 的另一条线：组织中介替代部分陌生人风险

同一组 1984 旧报材料记录有用户把组织化家务服务与自己私下找保姆相比较，认为公司至少能提供更明确的身份和介绍关系。

这可以概括为早期 **trust intermediation / 信任中介化**：

```text
熟人/街头/私人介绍
→ 有组织的登记与派介
→ 后来的证件、培训、平台评价与数字信用
```

这条变化比 Web 早十多年。

## 三、1990s：家政同时成为城市家庭的时间补丁和迁移女性的劳动路线

2007 年《新民晚报》对一名上海家政工赵阿姨的同期采访保存了一条回溯链：她 1993 年为还债离开安徽，先去北京，1995 年到上海，年底通过老乡介绍进入第一户雇主家；她回忆当时住家、包吃包住月薪 350 元，后来转做钟点工，并在多个家庭之间排班。

来源：
- 新民晚报/新浪，2007-07-31：https://baby.sina.com.cn/news/2007-07-31/083428142.shtml

证据等级：
- 对 2007 年当前劳动状态：**B，同期报道**；
- 对 1993–1997 经历：**C，十多年后的个人回忆**。

这条材料说明，在 Web 大众化以前，一条普通路径已经是：

```text
农村家庭现金需求
→ 女性跨省迁移
→ 老乡/中介介绍
→ 住家服务
→ 积累城市经验
→ 转为钟点、多雇主排班
```

家政因此同时影响两个家庭：

1. 城市家庭得到一段额外照护/家务时间；
2. 劳动者原家庭得到现金收入，却失去她的现场劳动和陪伴。

这个“双家庭账本”以后在手机和微信时代变得更可见，但不是那时才产生。

## 四、2005–2012：扩张型未来——Web 扩大了匹配半径，但身体、信任和春节仍留在线下

### 2005：需求开始可以被公开描述成结构化任务

2005 年上海报道已经出现“中国家政服务网”上的求职/雇佣帖子。有家庭公开寻找男家政人员，原因包括：

- 失能男性老人需要扶抱和擦身；
- 家里缺少能做重体力活的人；
- 希望把驾驶、维修、清洁等技能组合到一个服务角色里。

来源：
- 新闻晨报/新浪，2005-01-04：https://edu.sina.com.cn/j/2005-01-04/96680.html

证据等级：**B，同期报道，证明 Web 发帖这种供需表达确实存在；本轮未恢复原帖 DOM。**

这里的变化是 **task addressability**：家庭不只是说“要保姆”，而能公开描述“要照顾哪种人、要什么性别/技能、为什么”。

但这仍然不证明帖子最后找到人。

### 2006 杭州：所谓“视频找保姆”里，真正操作电脑的可能还是中介

青年时报记者实际去家政市场体验“QQ 视频找保姆”，发现：

- 网上和雇主打字聊天的是介绍所工作人员；
- 家政工本人常站在门口等待；
- 一名求职者直言自己识字不多，更不会用电脑；
- 她认为工作人员代传话太麻烦，还是直接见雇主更放心；
- 一些雇主也不愿仅凭网上交流决定。

来源：
- 青年时报/新浪，2006-02-10：https://news.sina.com.cn/s/2006-02-10/10508171869s.shtml

证据等级：**B，记者同期操作/现场报道 + 当事人第一人称。**

这给数字史增加一个非常重要的概念：

## **proxy digitality / 代理数字化**

页面已经在线，劳动者却未必成为“数字用户”。实际状态可能是：

```text
雇主用 QQ
→ 中介工作人员读/打字
→ 口头转述给家政工
→ 家政工口头回答
→ 中介再次打字
→ 最终仍安排面对面见面
```

因此：

> **`worker represented online ≠ worker personally online`。**

如果只看网页和“视频招聘”新闻标题，很容易把数字能力错误地分配给实际劳动者。

### 2006 广州：一条网页 listing 也填不满春节的人力缺口

2006 年 1 月，一名广州雇主已经在“广州家政服务网”发帖，给出：

- 长期聘用；
- 包食宿；
- 独立房间。

大半个月以后仍然没有找到人，同时她又线下跑了三家家政公司，也都无人可派；报道还观察到首页上大量“急找保姆”需求长期没有解决。

来源：
- 信息时报/新浪，2006-01-24：https://news.sina.com.cn/c/2006-01-24/11378068776s.shtml

证据等级：**B，同期调查。**

所以：

```text
listing visibility ↑
```

并不推出：

```text
worker supply ↑
```

尤其春节前，真正稀缺的不是信息，而是**愿意把自己的家庭团聚时间让给另一户家庭的人**。

### 2007 北京：Web 与电话热线并行，而不是网页取代电话

2007 年，北京家政服务协会和北京市社区服务中心开通 134 条家政求职热线，面向本地失业人员。同期报道明确给出两个 historical host：

- `www.jiazhengbj.org`
- `www.bjcs.gov.cn`

网站的作用是**查询热线列表**；真正求职仍通过电话和线下中介网络完成。报道还称此前一年春节有 2900 多名北京本地家政员通过热线找到工作。

来源：
- 北京晨报/新浪，2007-01-01：https://news.sina.com.cn/c/2007-01-01/023510905731s.shtml
- 北京日报/新浪，2006-12-30：https://news.sina.com.cn/s/2006-12-30/064010895476s.shtml

证据等级：**B，同期媒体；host 与用途可定位。**

因此 2000s 更准确的基础设施是：

```text
Web 目录
+ 电话热线
+ 家政公司门店
+ 老乡/熟人
+ 社区服务中心
```

而不是“进入网站 → 一键雇佣”。

### 2008：经济冲击会同时改变雇主需求和劳动者的未来判断

#### 雇主侧

2008 年末北京有白领把每月 4 次小时工缩减到 1 次大扫除。同期家政公司称小时工雇用量下降明显，而老人照护需求相对更刚性。

来源：
- 北京晨报/新浪，2008-12-26：https://news.sina.com.cn/c/2008-12-26/231916928591.shtml

证据等级：**B，同期报道。**

这说明家庭劳动外包也有弹性层次：

```text
可自己补做的清洁
≠ 婴幼儿照护
≠ 卧床老人连续护理
```

经济下行时，前者更容易被重新内包回家庭。

#### 劳动者侧：一个很强的 2008 未来想象样本

2008 年 12 月，一名来自安徽的家政求职者杨彩娥到上海后发现需求骤降。报道把她的犹豫写得非常直接：

> 是继续留在城市寻找可能的将来，还是回家守土地？

来源：
- 劳动报/新浪城市，2008-12-08：https://vic.sina.com.cn/20081208/10588436.shtml

证据等级：**B，同期报道中的第一人称/现场观察。**

这条材料很适合加入“扩张型未来”的反证：

> 2005–2012 并不是所有人的未来都单向扩张。宏观危机可以瞬间把一条已经形成的迁移—服务路线重新变成“留城还是返乡”的二选一。

### 2008：劳动者也在主动选择生活，不只是接受更高工资

上海一名春节后新到的年轻家政工小段，20 分钟内被一户住别墅的小夫妻选中，月薪 1800 元、有独立房间和卫生间，但她当天就辞了，理由是别墅区太冷清，宁愿累一点也想在更热闹的地方生活。

来源：
- 第一财经日报/新浪，2008-02-19：https://news.sina.com.cn/s/2008-02-19/030014965237.shtml

证据等级：**B，同期第一人称。**

这条材料阻止我们把家政劳动者写成只对工资单一响应的人。

### 2010 宜昌：网站、视频、培训与证件开始组合成一条跨城输送链

湖北日报 2010 年记录宜昌工会家政体系：

- 建培训基地；
- 建家政服务网站；
- 定期发布供需；
- 外地家政公司、客户和服务人员可通过网络视频沟通；
- 学员报名需身份证、无犯罪记录证明、家属签字；
- 体检、培训、考试以后取得证书；
- 大批人员再被推荐到京沪粤等城市。

来源：
- 湖北日报/新浪，2010-04-06：https://news.sina.com.cn/o/2010-04-06/055017327959s.shtml

证据等级：**B，同期机构运作报道。**

这已经接近一个早期的 **digital labor corridor / 数字劳务走廊**：

```text
县市招募
→ 身份/健康/培训
→ Web 发布
→ 视频沟通
→ 跨城雇主/公司
→ 身体迁移
→ 入户服务
```

但真正完成服务的仍然是人跨城移动，而不是视频本身。

## 五、信任的数字化：从熟人担保到监控、证件和可查询记录

### 2006 的极端例子：“电子保姆”把信任问题变成持续监控

上海一家家政公司 2006 年在网站宣传“电子保姆”，在雇主家安装摄像头，通过手机查看现场视频，并支持报警、历史录像等功能。

来源：
- 中国新闻网/新浪，2006-01-14：https://news.sina.com.cn/o/2006-01-14/09437980806s.shtml

证据等级：**B，同期报道；能证明公司这样宣传和服务存在，不能证明普及率。**

这个例子很重要，因为它说明数字化信任并不总是“更平等的透明”：

```text
陌生人进入家庭
→ 雇主不信任
→ 监控技术进入住宅
→ 家政工承受持续可视化
→ 隐私和尊严冲突
```

因此不能把“更多信息”自动写成“更好的劳动关系”。

### 2007：职业标准开始把互联网使用本身列入较高等级能力

2007 年北京家政服务地方标准按技能和工作内容分级，高等级服务人员被期待掌握更多护理、文化和现代生活技能。

这里需要注意：标准能证明**制度希望如何定义专业化**，不能证明绝大多数从业者马上完成这种升级。

---

## 六、2015–2019：拥堵型未来——候选人更多、平台更多，但信任、连续性和双向匹配成为稀缺品

### 2018 春节：真正稀缺的是“能连续照护的人”

2018 年北京一名女性的父亲瘫痪在床，长期家政工已经两年多没有回家，春节要请假两周。雇主理解她要回家，但替班短期护工很难找到，且价格明显上涨。

来源：
- 北京青年报/人民网，2018-02-07：https://society.people.com.cn/n1/2018/0207/c1008-29809583.html

证据等级：**B，同期第一人称 + 市场调查。**

同一篇报道还记录：

- 很多家政工更愿意接长期单；
- 春节短单不稳定；
- 58 同城上有公司宣传“一万名保姆过年不回家”，记者打电话后得到的实际驻京人数约 5000，且需要提前预约。

这里至少有三条边界：

```text
online advertisement ≠ verified worker inventory
advertised inventory ≠ immediately bookable worker
worker available in city ≠ worker willing to accept this short care job
```

这也是 old-Web/平台史很容易遗漏的 **inventory truth gap**。

### 2018：家庭需要的不只是“一个人”，而是可相信的专业照护

随着育儿、养老等任务进入家政，家庭会比较：

- 婴幼儿经验；
- 老人护理能力；
- 做饭和卫生；
- 证件和培训；
- 过去雇主评价；
- 是否稳定。

新华社 2018 年围绕“放心阿姨难找”的调查显示，即使线上家政企业快速增加，信息不对称、技能和信任仍然是核心问题。

因此可概括成：

> **match abundance ↑ 不等于 trusted match abundance ↑。**

### 2019：家政劳动让一个家庭获得现场照护，同时制造另一个家庭的“异地母职”

2019 年发表于《今传媒》的研究调查 92 名安徽无为县家政女工并深访 10 人。样本多在上海、北京、合肥、芜湖工作，许多人已经从业 5–10 年以上。

其中非常重要的同期第一人称包括：

- 35 岁的春梅在上海做家政 6 年，两个儿子留在老家由姑姑照顾；她每天用语音提醒孩子加衣、起床、周末做饭；
- 41 岁的艳平通过微信与儿子的老师沟通高中学习状态；
- 40 岁的叶子从工厂高强度工作转去做家政，通过微信红包与 15 岁儿子维持日常互动。

来源：
- 陈青文、王宇，2019：https://media.people.com.cn/n1/2019/1125/c430788-31473451.html

证据等级：**B，期刊研究；引文是研究时点的同期第一人称。**

这里出现一条以前 Life Horizons 很少明确画出的照护链：

```text
A 家庭：双职工/婴幼儿/老人需要现场照护
↓ 支付工资
家政女工跨城迁移
↓
B 家庭：孩子由姑姑/祖辈等留守照顾
↑
家政女工用微信、语音、红包远程参与
```

所以通信基础设施确实降低了家政迁移的家庭关系成本，但**没有把两端家庭合并成一个空间**。

### 2019：家政职业化也意味着劳动者开始计算技能投资

同一阶段，培训、职业技能和细分工种越来越直接影响薪酬与订单。这里不能把“职业化”只写成雇主获得质量保证；它也可能给劳动者：

- 更高价格；
- 更可迁移的技能；
- 更明确的职业身份。

但证岗不匹配、培训成本、劳动合同缺失和社保不足仍然存在，所以 `certificate ≠ stable employment relation`。

---

## 七、2020–2022：偶发型未来——家政成为一种“必须身体到场”的基础设施，因此线上化无法完全兜底

### 2020：平台、电话和在线面试都还在，但小区门口可以让整个服务链断掉

疫情期间上海等地出现非常清楚的状态：

```text
家政工已经返城
→ 隔离结束
→ 公司已经复工
→ 雇主仍有需求
→ 但小区不允许家政人员进入
→ 服务无法执行
```

中国青年报 2020 年记录一名来自湖北宜昌的育婴师：解封后准备回上海工作，一个多月仍接不到入户订单；有时临时出现一个工作，四五个人争两个岗位，甚至需要抓阄。

来源：
- 中国青年报/人民网，2020-05-12：https://it.people.com.cn/n1/2020/0512/c1009-31705329.html

证据等级：**B，同期第一人称 + 记者调查。**

这给数字生活史提供了一个很强的反例：

> **`match remotely ≠ care remotely`。**

家政、护理、保洁和接送的终端动作具有强烈的 physical presence requirement。

### 2020：线上面试、签约和“直播带人”快速增长，但只是把匹配环节线上化

2020 年行业开始大量使用：

- 线上培训；
- 视频面试；
- 线上签约；
- 线上付款；
- 直播展示家政员。

来源：
- 国际商报/人民网，2020-06-24：https://xiaofei.people.com.cn/n1/2020/0624/c425315-31757675.html

证据等级：**B，同期行业报道。**

这不能被写成“疫情让家政服务变成线上服务”。更准确是：

```text
discovery/matching/admin moved online
while
cleaning/feeding/lifting/care remained embodied
```

### 2021：春节是否返乡成为家庭连续性与劳动者亲属生活之间的直接权衡

2021 年上海有来自贵州的家政人员选择春节留沪，一方面响应减少流动，另一方面也为了多挣工钱；家中亲属表示理解。协会摸底显示，当年选择留沪的比例明显高于以往，并建立替补机制服务“一老一小”。

来源：
- 东方网/人民网，2021-01-12：https://sh.people.com.cn/n2/2021/0112/c134768-34524263.html

证据等级：**B，同期第一人称 + 行业调查。**

这里把春节“保姆荒”从一种价格现象推进成了**两个家庭时间表的冲突**：

- 雇主家庭最需要连续照护的时候；
- 也是服务者最想回自己家庭的时候。

## 八、2023–2026：防守型未来——家庭开始提前储备照护、劳动者开始用数字平台与凭证降低不确定性

### 2024：双职工 + 祖辈不可用，家政不再只是“省事”，而是家庭运行的一个候选基础层

2024 年福州一名母亲说，双胞胎即将上小学，自己和丈夫都在大学城上班，双方父母身体都不好，无法帮忙带孩子，因此需要寻找合适的家政服务。

来源：
- 福建日报/人民网，2024-07-18：https://fj.people.com.cn/n2/2024/0718/c181466-40915918.html

证据等级：**B，同期第一人称。**

这条材料非常适合修正“请阿姨=消费升级”的单一解释。

在这个家庭里，问题更接近：

```text
父母都工作
+ 两个孩子进入小学
+ 祖辈身体条件不足
→ 下午接送/家务/照护时间出现结构缺口
```

家政是用市场劳动补这个缺口的一种方法，但不是唯一方法。

### 2024–2025：照护开始进入“提前预订”式未来计划

2024 年北京报道中，有家庭担心优秀育儿嫂跳槽，愿意把月薪提高到接近 1 万元；市场人员提醒月嫂/育儿嫂若不提前数月预约，临近预产期很难找到合适人。

来源：
- 北京日报/中新网，2024-04-01：https://www.chinanews.com.cn/sh/2024/04-01/10190979.shtml

2025 年上海一名怀二胎的女性因为预产期是 1 月 21 日、正好撞春节，提前数月确定月嫂并和对方协商春节不返乡。

来源：
- 新民网/人民网，2025-01-07：https://sh.people.com.cn/n2/2025/0107/c134768-41100208.html

证据等级：**B，同期第一人称。**

这可以定义为 **care reservation horizon / 照护预订视野**：

> 怀孕、生产、开学、老人出院等未来事件，不再只需要准备钱和物品，还要提前锁定一个未来某天必须 physically available 的人。

这非常符合“防守型未来”的时间感：不是相信到时候市场自然会有人，而是提前几个月购买连续性的确定性。

### 2025：数字平台让农村家政劳动者从“等熟人带活”变成可派单的工作队列

2025 年青海互助县一名农村女性李琴英回忆，8 年前做保洁时主要靠熟人介绍，客源和收入不稳定；现在她通过县里的家政数字平台查看当天订单、参与派单，平时一天十余单，节假日可更多。

来源：
- 中国新闻网，2025-06-12：https://www.chinanews.com.cn/sh/2025/06-12/10431062.shtml

证据等级：**B，同期第一人称；关于“8 年前”的部分为 C 型个人回忆。**

这条变化与早期 2006 的“中介替阿姨在 QQ 上打字”相比非常明显：

```text
2006 proxy digitality
→ 2025 worker/dispatcher sees digital order queue
```

但也不能自动推出所有家政工都直接控制订单；很多平台仍由机构派单，劳动关系和抽成规则必须另查。

### 2025：信任逐渐变成可扫码、可查询、可追溯的“数字凭证包”

上海 2025 年已经有约 18 万名备案家政服务人员持上门服务证，居民可通过政务 App 查询机构信用评级、年龄、户籍、工作年限、服务证编号等信息。

来源：
- 解放日报/人民网，2025-01-27：https://sh.people.com.cn/n2/2025/0127/c138654-41122317.html

安徽淮北的同期案例则把健康证、技能证、评价等聚合到“一人一卡一码”体系，雇主用手机扫码核验。

来源：
- 人民网安徽，2025-09-18：https://ah.people.com.cn/n2/2025/0918/c358351-41355588.html

证据等级：**A/B：政府/主流媒体对当前公共系统与用户体验的描述。**

这里需要固定另一个硬边界：

```text
credential visible
≠ all facts verified forever
≠ worker definitely suitable for this household
≠ service quality guaranteed
≠ labor rights guaranteed
```

凭证可以压低陌生人交易的验证成本，但无法替代家庭磨合和真实劳动关系。

### 2024–2025：职业稳定以后，照护链也可能部分“回流”到劳动者自己的家庭

2024 年《人民日报》记录一名家政服务员与员工制企业签劳动合同、按月发工资、缴社保以后，把两个孩子从江西老家接到广州共同生活。她把这种变化概括为“工作稳了，心就安了”。

来源：
- 人民日报/人民网，2024-08-09：https://society.people.com.cn/n1/2024/0809/c1008-40295394.html

证据等级：**B，同期第一人称 + 企业/制度报道。**

这条材料很重要，因为它提示：

> **care migration chain 并非只能永久维持“我照顾别人的孩子、我的孩子留在老家”的结构。**

劳动合同、社保、稳定收入和城市居住条件可能改变劳动者能否把自己的家庭重新聚合到工作城市。

## 九、跨国对照：Internet 并没有发明“陌生家庭 + 陌生照护者”的匹配

### 1988 法国 Minitel：在 Web 以前，远程终端已经可以缩短工作匹配的检索路径

1988 年法国临时就业行业组织 UNETT 已经在 Minitel 上提供服务，让临时工和用人企业按行业与地区筛选劳务机构。

来源：
- Le Monde, 1988-06-16：https://www.lemonde.fr/archives/article/1988/06/16/l-union-nationale-des-entreprises-de-travail-temporaire-unett_4097705_1819218.html

证据等级：**A/B：同期新闻，明确描述当时服务。**

它不是家政专站，所以不能证明法国保姆当时都通过 Minitel 找工作；它能证明的是：

> **“终端搜索劳务中介”这套机制早于 Web。**

### 1992–1995 美国华盛顿地区 au pair 个案：报纸 + 中介 + 跨国迁移也能组成照护链

1995 年《华盛顿邮报》报道一起违法 au pair 中介案时，明确记录该经营者一边在北爱尔兰报纸刊登招募年轻女性的广告，一边在华盛顿地区报纸向忙碌家庭宣传住家儿童照护，并把双方匹配起来。

来源：
- Washington Post, 1995-01-15：https://www.washingtonpost.com/archive/local/1995/01/16/md-au-pair-provider-pleads-guilty/a338122a-54e8-4e52-807b-cd025763d361/

证据等级：**B，同期司法新闻。**

注意：这是一个违反移民法的个案，只能用于证明“报纸广告 + 中介 + 跨国照护匹配”实际存在，不能拿来代表正常 au pair 制度。

### 2001/2007 美国：Web 把家庭照护变成双边可搜索市场，但并没有替家庭作最终选择

Sittercity 2001 年开始提供家庭与保姆/照护者的在线匹配；Care.com 2007 年上线后把儿童、老年、家务等照护需求放在同一个数字市场。Care.com 后来的官方回顾明确说，其创办动机之一就是家庭依赖电话簿找照护太困难；同时其平台规则又强调最终雇佣、背景核验和适配仍由用户负责。

来源：
- Care.com 官方十周年回顾：https://www.care.com/c/carecom-at-10-where-weve-been-and-where-w/
- Care.com 2012 公开说明：https://www.prnewswire.com/news-releases/carecom-the-largest-online-marketplace-for-finding-care-in-the-us-announces-uk-expansion-148499945.html
- Sittercity 当前历史说明：https://www.sittercity.com/about-us

证据等级：**B/C：公司自述可证明其自身对历史和产品的表述，不能单独用于判断行业普及率。**

跨国共同机制因此更像：

```text
kin / neighbor / newspaper / phone / agency
→ searchable listings / profiles
→ background checks / reviews / messages
→ later platform scheduling / payment
```

而不是“中国从熟人走到平台、欧美一开始就市场化”这种简单差异。

更值得比较的是：

- 哪些家庭任务被市场化；
- 谁承担家务外包费用；
- 服务者是否跨地区/跨国迁移；
- 劳动关系是否正规；
- 背景核验谁负责；
- 家政劳动者自己的孩子和老人由谁照护。

## 十、四种未来时间感下，家政意味着什么

| 时段 | 家庭侧 | 劳动者侧 | 数字/通信侧 | 主要稀缺 |
|---|---|---|---|---|
| 2005–2012 扩张型 | 更多双职工、育儿/养老需求可通过市场补位 | 跨城家政是增收、再就业或过渡路线 | 网站、QQ、视频、热线扩大发现范围 | 人是否真的愿意来、春节供给、信任、技能 |
| 2015–2019 拥堵型 | 选择渠道更多，但“好阿姨难找”、稳定性变成问题 | 技能化、细分化，也承担远离自己家庭的成本 | App/平台、评价、微信降低信息与家庭联系成本 | trusted match、连续服务、双向适配 |
| 2020–2022 偶发型 | 家庭突然发现“阿姨进不了小区”就可能打断照护 | 返城、健康码、社区准入决定是否能工作 | 面试/签约可以线上，最终服务仍需入户 | physical access、流动许可、订单恢复 |
| 2023–2026 防守型 | 对预产期、开学、老人照护提前数月预约，保留替补 | 更看重技能、证件、稳定派单与劳动保障 | 数字订单、二维码凭证、政务信用、线上预约 | continuous care、可验证信任、稳定劳动关系 |

这四段不是价值判断，也不是每个人都同样经历。

## 十一、它改变了“普通人有多少种活法”的哪些部分

### 1. 双职工家庭不再只有“必须有一个亲属在家”这一种组织形式

如果市场照护可得，家庭可能形成：

```text
父母都工作
+ 托育/学校
+ 钟点家政
+ 月嫂/育儿嫂某一阶段介入
+ 祖辈偶尔支援
```

这比“一个人永久退出工作”多了一种组合方式。

但只有在价格、质量、供给和连续性可承受时，这种路线才是真实选项。

### 2. 祖辈照护从“默认基础设施”变成可以被部分替代的家庭接口

家政服务可以在祖辈：

- 身体不好；
- 不在同城；
- 不愿承担全日照护；
- 教养方式冲突；

时补位。

这会改变三代同住、迁居和父母退休后的责任，但不能由几个个案推出“祖辈照护已经退出”。

### 3. 有偿家政让“住得离父母远”更可执行，同时把风险转给市场

当年轻家庭不再必须依赖父母每天接送/做饭，城市选择可能更独立；但新的风险变成：

- 服务涨价；
- 临时离职；
- 春节断供；
- 信任失败；
- 护理能力不足。

### 4. 家政也是女性迁移与非正规劳动的重要生活路径

这条路线不能只从雇主视角写成“服务升级”。对劳动者来说，它涉及：

- 现金收入；
- 住家/非住家；
- 城市迁移；
- 自己孩子的照护；
- 社保；
- 职业尊严；
- 技能升级；
- 是否能把家庭接来城市。

### 5. “家务外包”并不等于家务消失

家庭只是把一部分劳动：

```text
unpaid household labor
→ paid service labor
```

劳动仍然存在，只是承担者、工资和可见性发生变化。

### 6. Internet 最大的早期改变不是“一键找到保姆”，而是让陌生人的需求和劳动变得更可寻址

2005–2010 的实际链条更像：

```text
网页/QQ/视频看到彼此
→ 电话/中介继续协调
→ 身份和技能线下核验
→ 现实见面
→ 身体入户
→ 漫长磨合
```

到移动平台以后，前半段越来越短，但后半段依然无法完全数字化。

## 十二、重点矩阵映射

| 矩阵 | 本专题新增理解 |
|---|---|
| 教育 | 家政培训、育婴/养老技能能成为成年再学习与增收路线 |
| 就业 | 家政既可能长期职业，也可能是失业后的缓冲/转轨岗位 |
| 住房 | 住家工把工作地与住宿捆绑；雇主住房也必须能容纳服务者 |
| 婚姻家庭 | 家务和照护可外包以后，家庭内部责任可以重新组合 |
| 迁移 | 农村/小城劳动者跨城进入另一家庭；收入和照护形成双向链 |
| 照护 | 婴幼儿、老人、病人照护可部分市场化，但 continuity 仍稀缺 |
| 非正规劳动 | 大量中介/撮合关系不等于正规劳动合同 |
| 长期中断 | 家政可成为失业/家庭中断后的 re-entry，也可能造成自己的母职空间中断 |
| 证件与记录 | 身份证、健康证、技能证、上门服务证、二维码逐渐形成 credential stack |
| 通信方式 | 电话→热线→QQ/视频→微信→平台订单，改变匹配与异地家庭联系 |
| 互联网平台 | listing、video、dispatch、rating、credit query 不能混为同一 transaction |
| 信息获取 | 家庭可公开描述任务，劳动者可看到订单，但 inventory 不等于可用供给 |
| 社交关系 | 老乡/熟人仍长期与平台并存；worker 与 employer 都依赖口碑 |
| 未来预期 | 预产期、开学、春节、老人出院开始需要提前锁定未来照护容量 |
| 线上/线下身份 | online profile 可能由中介代操作；后来出现可扫码可核验身份 |
| 平台消失与记忆保存 | 招聘页容易保存，真实入户、磨合、辞退和照护结果最难保存 |

## 十三、证据类型与后见之明风险

### A/B/C/D 约定

- **A**：原始制度文本、原始平台文档、同期可定位原始材料；
- **B**：同期新闻、同期学术研究、记者现场操作；
- **C**：后来对早年经历的回忆；
- **D**：本专题的机制概括与推断。

### 主要后见之明风险

1. **不要把 1983 家务服务公司写成今天平台家政的“必然起点”。**
   - 它只是组织化家庭服务的一条历史线路。
2. **不要把 2006 QQ/视频写成家政工已经普遍数字化。**
   - 同期现场证据恰恰显示中介代操作。
3. **不要把网站帖子数量写成实际成交量。**
4. **不要把雇主“有需求”写成劳动者必须接受。**
5. **不要把职业证书写成劳动合同或服务质量的同义词。**
6. **不要把微信缓解异地母职写成解决留守问题。**
7. **不要把疫情期间线上化写成家政可以远程完成。**
8. **不要把 2025 数字派单个案推广到所有农村家政工。**
9. **不要把“市场规模增长”当成普通家庭一定使用家政。**
10. **不要把家政职业化浪漫化成天然向上流动。**

## 十四、反例与反证

### 反例 1：更高工资也留不住某些劳动者

2008 上海小段放弃别墅住家岗位，说明 worker preference 不只由钱决定。

### 反例 2：有网页也没人

2006 广州雇主网上发帖、线下跑中介，仍在春节前找不到人。

### 反例 3：平台宣传库存可能夸大可用性

2018 春节一家公司网页宣传“一万名保姆留京”，记者电话核实时得到的实际驻京数量更低，且仍需预订。

### 反例 4：数字化可以增加监控，而不是只增加自主性

2006 “电子保姆”把信任难题转化为对家政工的实时视频监控。

### 反例 5：疫情证明线上匹配不能替代身体进入住宅

阿姨已经返城、平台可联系，也可能因为小区准入而无法工作。

### 反例 6：家政服务并非对所有消费同样刚性

2008 经济压力下，一些白领首先减少小时清洁，却继续存在老人护理等需求。

## 十五、我们还不知道什么

1. 1983–1990s 北京、上海等地组织化家务服务的家庭使用率和收入分层；
2. 1995 前后不同城市家庭究竟通过熟人、中介、劳务市场、报纸各占多少；
3. 2005–2010 家政网站的真实注册用户、帖子到成交 conversion rate；
4. `www.jiazhengbj.org`、`www.bjcs.gov.cn` 等历史页面的 DOM、charset、表单与登录方式；
5. 早期“网络视频面试”具体依赖 QQ、网页控件还是专门客户端的比例；
6. 家政工本人拥有电脑/手机、由中介代操作、由家人代操作三者的实际分布；
7. 平台评价和背景核验到底减少了多少匹配失败；
8. 春节保供中，额外工资究竟多大程度补偿了劳动者放弃返乡的家庭成本；
9. 双职工家庭使用家政后，女性无偿劳动是否真的减少，还是只减少其中一部分；
10. 员工制家政能否稳定改变家政工把孩子接到工作城市的概率；
11. 不同城市、收入层、独居老人和有孩家庭的家政可负担性；
12. 2023–2026 “平台派单”与“熟人/微信群/中介门店”实际份额。

## 十七、本轮改变了什么结论

以前可以说：

> “城市家庭在收入提高以后开始购买家政服务。”

现在更准确的说法是：

> **有偿家政是一种把家庭内部必须完成的时间劳动重新分配给陌生人的基础设施。它可以让双职工、独居老人、有幼儿或病人的家庭继续运转，也可以让一个失业者、农村妇女或中年劳动者获得新的现金路线；但这两种自由常常通过同一条照护链连接——一个人进入别人的家维持它的连续性，同时必须重新安排自己的孩子、父母、春节和未来。Internet 最先改变的是双方如何彼此被看见，随后才是证件、评价、视频、派单和支付；真正最难数字化的始终是最后一步：一个可信、愿意、时间对得上的人，能不能在需要的那一天真的走进这扇门，并留下来把生活接住。**
