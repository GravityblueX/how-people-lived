# 从“我想帮忙”到“我真的上岗”：志愿服务可寻址性、公共角色与被记录的公益劳动（中国，1993–2026）

## 研究问题

这篇 note 补普通生活矩阵里一个此前没有单独建模的维度：**一个普通人的生活并不只有受教育、挣钱、组建家庭和照护亲属；她也可能周期性进入一种非职业、非亲属的公共服务角色。**

真正要研究的不是“一个社会有没有志愿者”，而是：

```text
某个真实需要存在
→ 普通人知道这个需要
→ 找到可信的组织 / 项目 / 招募入口
→ 判断自己是否适合
→ 报名
→ 报名被系统或组织接受
→ 通过筛选 / 面试 / 测试
→ 完成培训
→ 时间、地点、交通和家庭责任允许
→ 被分配到具体岗位
→ 实际到场
→ 真正完成任务
→ 服务对象得到实际帮助
→ 服务被核验、记录
→ 这段经历是否继续改变学习、就业、迁移或人生目标
```

本文使用几个工作概念：

- **service addressability / 志愿服务可寻址性**：想帮忙的人能否知道“哪里缺人、缺什么人、什么时候缺人”；
- **service executability / 志愿服务可执行性**：报名以后，筛选、培训、交通、时间和家庭责任是否允许本人真正上岗；
- **temporary civic role / 临时公共角色**：一个人不改变职业身份，也能在某些日子承担非亲属、非市场的公共服务任务；
- **contribution optionality / 贡献可选性**：成年生活是否存在工作与家庭之外、可以反复进入和退出的社会贡献路径；
- **service-time budget / 志愿时间预算**：无报酬服务同样占用通勤、学习、休息、照护和有偿劳动时间；
- **life-course bridge / 生命历程桥梁**：一段志愿服务可能成为毕业与就业、城市与基层、专业学习与职业选择之间的过渡路线；
- **recorded altruism / 被记录的公益劳动**：志愿行为被转换为账号、编号、项目、时长、星级、证书或综合素质记录；
- **record-service gap / 记录—服务缺口**：系统里存在“多少小时”，并不自动证明这些小时对应真实、合格、有价值的服务。

先固定边界：

`有志愿活动 ≠ 普通人知道怎样加入`

`报名成功 ≠ 被录用`

`被录用 ≠ 实际到场`

`实际到场 ≠ 完成了有意义的任务`

`服务时长被记录 ≠ 服务质量被验证`

`志愿服务能带来履历价值 ≠ 所有人参加都以履历为目的`

`互联网扩大招募半径 ≠ Internet 发明了志愿服务`

## 1. Internet 以前：志愿服务早已存在，但“谁需要谁”主要由组织路由

### 1.1 1993–1994：青年志愿者行动的起点本身不是 Web 项目

1994 年 10 月《人民日报》的同期专题把全国青年志愿者行动的起点追到 1993 年 12 月 19 日：两万余名铁路青年职工沿京广线开展服务。同期第一人称尤其重要，因为它保存的不是后来总结出来的“志愿精神”，而是参与者当时怎样理解这件事。

北方交通大学学生梁芳回新疆探亲时，在列车上送水、扫地；第二天，同车不少大学生也加入。北京师范大学学生暑期去山西支教、调查希望工程；医务人员为了参加服务，要安排休息日和孩子照护。

来源：

- 《人民日报》，1994-10-07，第9版，“志愿者，你在想什么？”，A（同期报刊文本）：<https://cn.govopendata.com/renminribao/1994/10/7/9/>

这说明在中国尚未完成全功能 Internet 接入的时期，普通人已经可以进入志愿服务，但入口主要是：

```text
学校 / 单位 / 团组织 / 协会
→ 得知项目
→ 集体报名或被组织动员
→ 集中前往
→ 在明确地点服务
```

不能把 1994 前写成“没有网络，所以普通人无法找到非亲属服务对象”；更准确的是：**寻址主要依赖学校、单位、地方组织和既有社会网络，而不是公开可搜索的项目目录。**

### 1.2 “一助一”：前互联网的长期非亲属照护并不只是一次性活动

1994 年 3 月，“一助一”长期服务计划明确提出，由一个志愿者或一支服务队，为一个人或一个家庭持续提供医疗保健、生活服务、家教、科技服务、助耕助收等经常性服务，服务时间一般不少于 3–5 年。

来源：

- 《人民日报》，1994-03-07，第4版，A：<https://cn.govopendata.com/renminribao/1994/3/7/4/>
- 唐山地方实践的同期报道，《人民日报》，1994-04-19，第3版，A：<https://cn.govopendata.com/renminribao/1994/04/19/3/>

这里很容易产生后见之明误差。今天看到“长期服务”，不能想象成一个 App 自动把独居老人和附近志愿者匹配起来。真正的地址链更可能是：

```text
地方组织知道困难家庭
→ 组织把对象分配给志愿者 / 服务队
→ 双方建立重复接触
→ 组织维持一定连续性
```

Internet 后来改变的是**需求与志愿者可被公开描述、检索和跨组织流转的程度**，不是第一次创造“陌生人长期帮助陌生人”。

## 2. 2005–2012 的扩张型未来：志愿需求开始成为 Web 可报名对象

### 2.1 2006 北京奥运招募：Web、热线、纸表同时存在

2006 年 8 月北京奥运会、残奥会志愿者招募启动，北京地区网络报名系统和咨询热线 12308 同时开通；在北京生活和工作的普通人既可以登录所在区县的网络系统报名，也可以去街道、乡镇团委填写纸质报名表。

来源：

- 新京报 / 新浪，2006-08-29，B：<https://news.sina.com.cn/c/2006-08-29/00459871729s.shtml>
- 北京奥运会官方网站历史内容 / 新浪，2006-08-28，A/B：<https://sports.sina.com.cn/o/2006-08-28/16062424298.shtml>

这一点很重要：

> **Web 扩大入口，但成熟招募并不是“所有人只能上网”。**

至少同时存在：

`online form + telephone consultation + university recruitment point + street/town paper form`

这与很多后来数字公共服务的历史一样：数字入口先叠加在旧入口上，而不是一夜替代。

### 2.2 报名是漏斗入口，不是“已经做志愿者”

奥运招募留下了一组非常干净的状态漏斗。2008 年 3 月底，赛会志愿者申请人数达到 1,125,799 人；最终北京奥运会实际录用赛会志愿者 74,615 人，京外赛区另有 7,600 人。

来源：

- 新华社 / 新浪，2008-04-02，B：<https://2008.sina.com.cn/dt/other/2008-04-02/174763407.shtml>
- 法制日报 / 中国新闻网，2008-08-14，B：<https://www.chinanews.com.cn/olympic/news/2008/08-14/1347326.shtml>

与此同时，招募流程并不是“填完表就上岗”，而包括材料审核、测试、面试、岗位分配、背景审查、岗前培训和录用通知。

来源：

- 北京奥运会官方网站 / 搜狐，2007-03-27，A/B：<https://2008.sohu.com/20070327/n249015045_3.shtml>
- 北京奥运会官方网站 / 搜狐，2007-10-18，A/B：<https://news.sohu.com/20071018/n252727527.shtml>

因此以后研究任何志愿平台，都必须固定：

```text
page view
≠ application
≠ accepted application
≠ selected volunteer
≠ assigned volunteer
≠ trained volunteer
≠ actually served
```

### 2.3 扩张不等于低成本：有些志愿者要自己承担吃住和机会成本

2007 年江苏奥运志愿者选拔报道记录，数万人报名竞争约 100 个最终名额，而服务期间吃住等费用由个人承担。高三学生甚至在面试等待区继续做数学题。

来源：

- 《扬子晚报》/ 新浪，2007-12-31，B：<https://news.sina.com.cn/s/2007-12-31/015313171762s.shtml>

这使“志愿者很多”不能被直接解释成“服务很容易进入”。真正的 service executability 仍受到：

- 交通；
- 住宿；
- 学业；
- 工作；
- 家庭责任；
- 身体条件；
- 专业技能；
- 可连续投入的时间

共同限制。

### 2.4 2008 第一人称：志愿服务甚至可以主动打断“标准毕业脚本”

2008 年汶川地震后，西部计划增招一批毕业生开展一年灾后重建服务。同期《中国青年报》记录，一些人已经联系好工作，有人已准备读研或出国，却改道参加一年服务；研究生秦豹所在单位最终为他办理停薪留职。

来源：

- 中国青年报 / 新浪，2008-07-14，B，contemporary first-person：<https://news.sina.com.cn/o/2008-07-14/060214159279s.shtml>
- 中国青年报，2008-06-05，A/B：<https://zqb.cyol.com/content/2008-06/05/content_2212316.htm>

这不是要浪漫化“放弃工作”。相反，它说明志愿服务在少数人身上可以成为一种**holding state / life-course bridge**：

```text
毕业
→ 原定工作 / 读研 / 出国路线
→ 暂时挂起
→ 1 年志愿服务
→ 再决定就业、升学或是否留在当地
```

2008 年关于西部计划的报道还显示，服务期满后是否“扎根”受到编制和待遇等现实条件限制；因此“服务改变人生”必须和就业制度接口一起研究。

来源：

- 中广网，2008-01-07，B：<https://edu.cnr.cn/jyztc/jyzc/20080130/t20080107_504672891.html>

## 3. Web 不只招募人，也开始把“志愿者本人”变成持续记录的账号

### 3.1 2007：中国志愿者网已经把申报与评审部分搬到 Web

2007 年团中央有关志愿者评选文件明确要求在中国志愿者网 `www.zgzyz.org.cn` 开设专题和网上申报系统；网上申报截止后，数据按属地反馈到省级组织，后续还包括资格审查、实地考察和初评。

来源：

- 中国共青团，2007-12，A：<https://www.gqt.org.cn/documents/zqbf/200712/t20071204_53573.htm>

这提供一个很早的状态边界：

`网上提交 ≠ 资格已经确认 ≠ 现实经历已经核验`

Web 在这里是**材料入口和路由层**，不是完整事实验证器。

### 3.2 2011–2012：“志愿北京”把服务经历、时间和唯一编号合并成个人长期记录

2011 年底，北京宣布将“志愿北京”作为全市统一志愿服务综合信息平台。志愿者填写二十余项信息、实名注册后拥有唯一编号；个人基本信息和志愿服务时间被设计为长期保存。2012 年上线后的报道继续说明，注册者可网上申请团体、项目和培训，审核后由平台记录服务经历和时间。

来源：

- 北京日报 / 新浪，2011-12-19，B：<https://news.sina.com.cn/c/2011-12-19/031823653117.shtml>
- 中国互联网协会转载报道，2012-03-07，B：<https://www.isc.org.cn/article/19308.html>

这一步意味着服务从：

`某次活动里有人来帮过忙`

逐渐变成：

`某个持续存在的数字主体累积了 X 个项目、Y 小时、Z 项技能`

本文把这种变化称为 **recorded altruism / 被记录的公益劳动**。

它增加了可携带性和可见性，也会增加新的问题：谁记录？怎样验证？漏记怎么办？错记怎么办？一个小时到底表示“签到存在”，还是“完成了合格服务”？

## 4. 2015–2019 的拥堵型未来：当公益劳动变成可计算记录，意义与凭据开始摩擦

### 4.1 2015：学生志愿服务正式进入档案、实践学分和星级认证

教育部 2015 年《学生志愿服务管理暂行办法》明确要求学校建立学生志愿服务记录档案，将记录归入综合素质档案；高校将志愿服务纳入实践学分管理，并按累计时间进行星级认证。

来源：

- 教育部，2015-03-18，A：<https://www.moe.gov.cn/srcsite/A12/s7060/201503/t20150318_189379.html>

这里出现一个结构变化：

> **志愿服务既是一段现实关系，也开始成为教育制度可读取的 credential-like record。**

这不意味着学生从此“都为了学分才服务”，但它意味着服务动机与记录价值可以同时存在，也可能发生冲突。

### 4.2 2019 第一人称：真正稀缺的已经不是“有没有项目”，而是合适项目、交通时间、连续性和可信记录

2019 年《中国青年报》对 2000 名受访者的在线调查不能代表全国大学生，但其中的机制材料很有价值：

- 64.0% 曾通过学校/学院组织参加；
- 50.4% 曾通过志愿者官网申请；
- 55.3% 认为申请渠道繁琐；
- 39.4% 提到交通往来时间太长；
- 38.2% 提到资料档案管理不善。

同期第一人称还记录：

- 博物馆志愿者韩悦提到，学校综合测评对一定志愿时长有加分，博物馆会出具证明，但“有很多小时”并不代表每小时都在认真工作；
- 组织者连珊珊遇到志愿者活动当天早晨临时说不来；
- 一些服务对象机构不愿接受只来一次的大学生，因为培训和连续关系本身需要成本；
- 有学生为了满足时长要求，甚至报名与自己能力或心理条件不匹配的项目。

来源：

- 中国青年报，2019-08-15，B，contemporary first-person + online survey：<https://zqb.cyol.com/html/2019-08/15/nw.D110000zgqnb_20190815_1-08.htm>

于是“拥堵型未来”里的志愿问题不是：

`有没有机会？`

而更像：

`这么多机会里，哪一个离我近、我会做、时间对得上、组织愿意长期接纳我，而且这段劳动能被真实而不是机械地记录？`

这补出 **matching quality / 匹配质量** 和 **continuity cost / 连续性成本**。

## 5. 2020–2022 的偶发型未来：数字招募成为应急人力路由，但报名与实际上岗差距巨大

### 5.1 2020：预招募 93.7 万，实际上岗 48 万多

疫情早期，全国青年志愿体系通过线上平台、公告和群聊快速招募。中国青年报 2020 年 2 月报道：截至 2 月 10 日，各级组织预招募青年志愿者 93.7 万名，实际上岗 48 万多名；吉林一则预招募公告发布后 15 分钟内有 3000 多人在线报名。

来源：

- 中国青年报 / 中国青年网，2020-02-13，B：<https://news.youth.cn/jsxw/202002/t20200213_12194935.htm>

广东则在 1 月 30 日通过“i志愿”等平台招募储备 14,680 人，实际上岗约 10,518 人，并按专业医护、便民服务、秩序维护、心理疏导等不同类型组织队伍。

来源：

- 中国青年报 / 中国青年网，2020-01-30，B：<https://news.youth.cn/jsxw/202001/t20200130_12180869.htm>

这是一组极其清楚的状态证据：

`digital mobilization capacity ≠ deployable human capacity`

危机里真正稀缺的不是点击“我要报名”的人，而是：

- 本地可达；
- 健康风险可控；
- 能接受排班；
- 技能匹配；
- 组织有能力培训、发物资、分配、监督

的实际人员。

### 5.2 志愿服务也有家庭风险预算

同一时期的志愿者报道提醒我们，不应把无偿服务浪漫化成“没有成本”。志愿者可能同时是家庭主要收入者、有贷款、孩子或老人需要照顾；服务时间和健康风险都会回到家庭。

所以疫情阶段新增的不是“人人都变得无私”，而是 **care / income / civic-role conflict**：

```text
社会需要我
vs.
家里也需要我
vs.
工作收入不能无限中断
```

这与 1994 年医务人员为参加志愿服务先安排孩子照护，其实属于同一条长期机制。

### 5.3 2022 第一人称：志愿角色已经能和专业学习反复叠加

2022 年，首都医科大学学生董汉卿回顾自己从 16 岁开始持续志愿服务，累计超过 800 小时；疫情期间做热线、疫苗点、流调通知等工作。他明确说，尽量不耽误学业，志愿服务太忙时再补网课；同时把“做自己尊重的人”作为个人目标之一。

来源：

- 中国青年报 / 中国青年网，2022-05-06，B，contemporary first-person：<https://news.youth.cn/jsxw/202205/t20220506_13670644.htm>

这里出现一种以前 Life Horizons 矩阵里没有单独写出的成人/青年目标：

> **未来不一定只是在“我要做什么职业”上定义，也可能包括“我想成为一个怎样参与他人生活的人”。**

但这仍然是个案，不能外推成一代人的共同价值。

## 6. 2023–2026 的防守型未来：从“更多报名”转向“更可信的匹配、更可持续的关系”

### 6.1 2025：屏幕可以把一个遥远问题变成现实可执行任务

2025 年《中国青年报》记录，大学生吴梦琦先通过直播看到甘肃民勤的治沙场景，次年看到当地公益组织的志愿者招募后，跨越约 1500 公里实际参加种植梭梭树。

来源：

- 中国青年报 / 中国青年网，2025-03-29，B，contemporary first-person：<https://gy.youth.cn/gywz/202503/t20250329_15911658.htm>

这可称为 **screen-to-place bridge / 屏幕—地点桥梁**：

```text
远方问题被看见
→ 持续关注
→ 招募对象出现
→ 本人判断可参加
→ 交通成本可承担
→ 身体抵达
→ 实际服务
```

Internet 在这里不是“让人在线点一个赞”，而是把一个此前没有日常地址的远方问题，转换成一个有招募令、有时间、有地点的现实任务。

### 6.2 2025 春运：161 人报名，经过筛选、培训、测试，92 人上岗

安徽蚌埠 2025 年春运志愿服务中，161 名返乡大学生报名，经过选拔、培训、结业测试，最终 92 人进入服务岗位；其中有学生已是第三次参加。

来源：

- 中国青年报，2025-01-15，B：<https://news.cyol.com/gb/articles/2025-01/15/content_998l0xTaGb.html>

这再次证明，即使数字报名已经非常成熟，也不能把“报名人数”直接当“实际服务人数”。

### 6.3 2026：线上帮助本身也可以成为真正连续的服务，而不只是招募入口

2026 年山西“伙伴计划”材料记录，大学生志愿者通过线上一对一方式为多地中小学生提供长期学业辅导；另有跨千公里到当地授课、之后继续书信陪伴的混合关系。

来源：

- 中国青年报 / 中国青年网，2026-05-02，B：<https://qnzz.youth.cn/qckc/202605/t20260502_16639734.htm>

这说明 Internet 对志愿服务的影响至少有两种不同层次：

1. `online discovery / coordination → offline service`
2. `online medium itself = service site`

不能把二者混成“线上公益”。

### 6.4 被记录的公益劳动也会产生可交易、可造假的影子

当学校、平台和组织越来越依赖“小时数、证书、星级”表达公益劳动时，记录本身会获得外部价值。2025–2026 的调查已经出现付费购买所谓志愿时长、定制证书、虚假打卡等现象。

来源：

- 中国公益研究院转央广网访谈，2025-06-25，B：<https://www.chinadevelopmentbrief.org.cn/news/detail/66228.html>
- 《中国教育报》，2025-12-22，B：<https://paper.jyb.cn/zgjyb/h5/html5/2025-12/22/content_144741_19151157.htm>
- 《人民日报》，2026-03-30，B：<https://leaders.people.com.cn/n1/2026/0330/c58278-40691263.html>

这里必须避免一个简单道德化结论。问题不只是“有人作弊”，还包括一种制度设计风险：

```text
真实贡献
→ 被压缩成时长 / 证书
→ 时长成为升学、综评、评奖的代理指标
→ 代理指标获得交换价值
→ 人开始优化指标，而不一定优化真实服务
```

因此：

`recordability ↑` 可能同时带来 `legibility ↑` 和 `gaming surface ↑`。

## 7. 海外对照：Internet 同样不是从零发明志愿匹配

### 7.1 美国 1950s–1990s：Volunteer Service Bureau / Clearinghouse 已经做招募、评估和转介

美国 Hampton Roads 的机构史记录，1957 年当地就建立 Volunteer Service Bureau；1962 年其任务已包括志愿者招募、评估和向非营利组织转介，1970s 又发展为 Voluntary Action Center。

来源：

- VOLUNTEER Hampton Roads institutional history，C / institutional retrospective：<https://www.volunteerhr.org/ourhistory>

1991 年《华盛顿邮报》同时代报道则更具体：D.C. Volunteer Clearinghouse 保存近 700 个需要志愿者的机构档案，按“青少年辅导”“老年服务”“团体项目”等主题分类；clearinghouse 负责提供需求信息和要求，但并不替机构完成筛选和安置。

来源：

- The Washington Post，1991-02-21，A/B contemporary press：<https://www.washingtonpost.com/archive/local/1991/02/21/workers-and-opportunities-abound/d1e0cf6b-63bb-4f6d-876d-88dc49d36262/>

这和中国 1990s 的组织化路由形成一个很好的跨国共同点：

> **Internet 前已经存在“需求目录 + 中介转介 + 机构再筛选”的志愿匹配。**

### 7.2 1998 VolunteerMatch：Web 扩大的是发现半径，不是替组织完成服务

VolunteerMatch 1998 年上线。2000 年《Chronicle of Philanthropy》报道，1999 年最后三个月平台让 5.5 万多名潜在志愿者与需要帮助的非营利机构建立联系；志愿机会 listings 从 1998 年 12 月的 6,397 个增至 1999 年 12 月的 22,368 个。

来源：

- Chronicle of Philanthropy，2000-06-01，B：<https://www.philanthropy.com/news/volunteer-matching-program-still-extending-its-reach/>

必须注意原文用的是 matches / put potential volunteers in touch，而不是“完成了 5.5 万次服务”。所以海外比较同样支持：

`online match ≠ screening ≠ attendance ≠ task completion`

共同变化是**需求的可搜索性和候选人的发现半径**，而不是“Web 自动生产可靠志愿劳动”。

## 8. 它改变了“普通人怎么活”的哪一点？

### 8.1 一个人可以暂时拥有工作和家庭以外的公共身份

传统生命历程研究很容易只记录：

`学生 → 劳动者 → 配偶 / 父母 → 退休者`

志愿服务说明一个人还可以周期性成为：

- 博物馆讲解者；
- 社区协助者；
- 赛事志愿者；
- 支教者；
- 紧急运输者；
- 线上陪伴者；
- 环境修复参与者。

这些角色可能只存在一天，也可能持续三五年；有的和职业完全无关，有的反过来改变职业与迁移选择。

所以“普通人有多少种活法”还应加一个问题：

> **工作和家庭之外，这个人有多少种不以工资和亲属义务为前提、却能真实进入公共生活的角色？**

### 8.2 数字化把“想帮忙”从道德意愿变成可路由任务

前互联网时代并不缺善意，也不缺组织。但公开 Web、搜索、统一平台和移动入口增加了：

- 需求可见性；
- 项目时间和地点可检索性；
- 技能标签；
- 大规模候选人募集；
- 跨地域招募；
- 个人历史记录；
- 服务后的持续联系。

真正变化的是：

`善意存在`
开始更容易变成
`一个可以被安排到具体时空里的任务`。

### 8.3 但志愿服务越制度化，越需要防止把真实关系压缩成一个数字

一个高质量服务可能依赖：

- 连续出现；
- 训练；
- 专业边界；
- 服务对象信任；
- 组织协调；
- 交通和补贴；
- 风险保障；
- 对“不适合的人”说不。

这些都不能被一个“100 小时”完整表达。

因此数字化成熟后的关键问题，可能不是继续提高注册人数，而是：

> **系统能不能区分“有账号的人”“报名的人”“实际上岗的人”“长期可靠的人”和“真正产生帮助的人”？**

## 10. 后见之明风险

1. **不要把 1994 前写成“没有数字平台所以没有公益匹配”。** 学校、单位、协会、街道和报刊本来就在做路由。
2. **不要把 2008 奥运志愿者热情外推成所有青年都想做志愿服务。** 大型赛事本身是高选择性事件。
3. **不要把报名数当实际服务数。** 本题最重要的就是 funnel。
4. **不要把志愿服务浪漫化成没有成本的善意。** 食宿、交通、机会成本、家庭责任和健康风险都是真实约束。
5. **不要把学生志愿服务一律解释成“为了学分”。** 记录价值与内在动机可以并存。
6. **不要把“小时多”当作“帮助多”。** 某些服务需要连续性、技能和关系质量。
7. **不要把疫情志愿服务当作普通年份的代表。** 应急动员是压力测试，不是日常状态。
8. **不要把线上服务视为天然低成本。** 稳定设备、排班、关系维护、隐私和服务质量同样需要组织。
9. **不要从宣传性典型报道推断总体效果。** 典型人物适合研究“这种人生可能存在”，不适合估计普遍程度。

## 11. 尚未确定

- 1980s–early 1990s 中国普通城市居民通过报刊、街道、单位寻找志愿机会的完整日常路径，还缺微观材料。
- 1990s 早期青年志愿项目中，个人是主动寻找项目，还是多数由组织直接动员，分布如何，尚不清楚。
- 2000–2005 中文 Web 上最早稳定的公开志愿机会目录、论坛招募和个人报名页面，需要进一步做 old-Web capture 调查。
- `zgzyz.org.cn`、2006 奥运 18 个区县报名系统、早期 `bv2008.cn` 的历史 DOM、charset、form action、cookie/session 与 submit response，本轮仍未达到 verified historical transaction capture 门槛。
- “志愿时长”在不同高校具体怎样进入综测、评奖、毕业要求，差异很大，不应拿少数学校规则外推全国。
- 记录系统里 no-show、退岗、中途退出、被组织拒绝、服务质量不合格等负状态的保存比例未知。
- 长期志愿服务是否真正扩大非亲属支持网络、改变职业选择或降低孤立感，需要更系统的生命史资料。

## 12. 对核心矩阵的新增

| 矩阵维度 | 本题新增 |
|---|---|
| 教育 | 志愿服务可成为实践学习，同时也可被学分化、档案化 |
| 就业 | 一些长期项目形成毕业—就业之间的 holding state；经历也可能进入履历 |
| 迁移 | 西部计划、灾后服务、跨地域公益把短期/长期迁移变成可组织路径 |
| 照护 | 出现对非亲属对象的持续照护与陪伴责任 |
| 非正规劳动 | 志愿服务不能与无薪实习、免费劳工、正式社会工作混为一谈 |
| 长期中断 | 服务可主动推迟工作、读研或迁移，也可能成为重返社会角色的桥梁 |
| 证件与记录 | 实名账号、唯一编号、时长、星级、证书形成新的社会记录 |
| 通信方式 | 学校/单位/电话 → Web 招募 → 群聊/平台/移动端 |
| 互联网平台 | 项目、技能、时间、地点和人员被结构化匹配 |
| 信息获取 | 遥远社会问题可以通过直播、新闻和平台变成可执行招募 |
| 社交关系 | 形成工作与家庭之外的弱连接、项目关系和持续陪伴 |
| 未来预期 | “我要成为什么职业的人”之外，出现“我要成为什么样的公共参与者” |
| 线上/线下身份 | 账号与服务记录可跨项目累积，但数字记录不等于现场事实 |
| 平台消失与记忆 | 招募页面易保存，真实排班、到场、对象反馈和质量难保存 |

## 13. 与 old-web-archaeology 的交叉

旧网侧 companion note：

- <https://github.com/tmzncty/old-web-archaeology/blob/main/VOLUNTEER_RECRUITMENT_REGISTRATION_AND_SERVICE_RECORD_STATE_GAPS_2005_2015.md>

how-people-lived 关心的是：普通人的公共角色怎样变得可发现、可执行、可持续，以及怎样进入生命历程。

old-web-archaeology 应继续只问约 1995–2015 中文 Web：

- 旧招募页到底是什么页面对象；
- 区县分散报名系统如何跳转；
- 表单是否真的提交；
- 实名字段如何处理；
- 项目状态如何更新；
- 服务时长如何写入；
- 哪些页面和状态被 archive 保存；
- 哪些关键现实状态天然落在私有/线下黑区。

两边共同必须守住：

> **可见的招募壳层，不等于真实服务已经发生。**
