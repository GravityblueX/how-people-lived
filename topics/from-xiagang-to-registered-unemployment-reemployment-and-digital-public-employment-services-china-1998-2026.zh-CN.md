# 从“下岗”到“失业登记”：工作中断、制度托管、再就业与数字公共就业服务（中国，1998—2026）

> 本专题研究的不是抽象“失业率”，而是普通人在一份工作停止以后，**到底被制度叫作什么、靠什么生活、从哪里找下一份工作，以及这种中断怎样被记录下来**。

与 [《职场空窗、制度托管与重新进入》](career-gaps-holding-states-reentry-and-discontinuous-life-courses-china-1997-2026.zh-CN.md) 的分工如下：既有专题主要研究非连续履历、空窗解释劳动与重新进入摩擦；本文集中研究 **“下岗 / 失业 / 内退 / 登记失业 / 再就业”这些行政状态本身，以及公共就业服务从企业再就业服务中心、劳动力市场、电话和共享终端逐渐进入 Web / App / 全国统一平台的过程**。

本专题也是一个重要的后见之明校正：

> **“没有正在上班”从来不是一个天然统一的社会状态。**

同样暂时没有正常工资工作的人，在不同年份可能仍与原企业保持劳动关系、由再就业服务中心托管；也可能已经解除劳动关系并登记失业；可能办理内部退养；可能一边打零工一边找工作；也可能主动裸辞、备考、创业、照护或“慢就业”。这些路径的收入、社会保险、公共服务资格、统计可见性和未来感完全不同。

---

## 一、核心模型：employment-interruption state machine / 工作中断状态机

研究工作中断时，至少分开以下状态：

```text
实际是否每天工作
≠ 是否有工资收入
≠ 是否仍与原单位保持劳动关系
≠ 是否进入某种托管/内退状态
≠ 是否完成失业登记
≠ 是否参加过失业保险
≠ 是否符合失业保险待遇条件
≠ 是否真正领取待遇
≠ 是否被公共就业服务系统识别
≠ 是否正在找工作
≠ 是否已经开始新的稳定工作
```

这组区别能够解释一个看似奇怪的历史现象：1990 年代末可以同时存在大量“下岗职工”和“城镇登记失业人员”。两者不是简单重复统计。

本文把这种差异称作 **administrative-state plurality / 工作中断的多重行政状态**。

# 二、1998：离开岗位，并不一定立刻离开企业

1998 年深圳市关于国有企业下岗员工与登记失业员工的正式文件，为“下岗”这一中间状态留下了非常清楚的结构。

再就业服务中心的任务包括：

- 向下岗员工发放基本生活费；
- 代缴养老、失业和医疗保险费用；
- 培训、就业指导和帮助再就业。

进入市、区再就业服务中心托管的下岗员工，托管期限原则上不超过 3 年。深圳当时还规定，托管期间基本生活费按年度递减。

Source:
- 深圳市人民政府公报，1998-06-15，《关于认真做好我市国有企业下岗员工及失业员工基本生活保障和再就业工作的意见》：
  https://www.sz.gov.cn/zfgb/1998/gb143/content/post_10123116.html
- 深圳市人民政府办公厅，1998-07-15，《关于建立再就业服务机构有关问题的通知》：
  https://www.sz.gov.cn/zfgb/1998/gb145/content/post_10124194.html

Evidence grade: **A，正式同时期政府文件。**

### holding-state buffer / 托管型缓冲

这意味着一个人的生活可以出现：

```text
原岗位已停止
→ 正常工资劳动已停止
→ 仍与企业保持某种劳动关系
→ 进入再就业服务中心
→ 领取基本生活费 + 社会保险继续衔接
→ 培训 / 找工作
→ 再就业，或托管期满后转入另一状态
```

所以“下岗”不能简单翻译成今天直觉里的 `unemployed`。

它是一种 **holding state**：

> 人已经从原来的工作日常里掉出来，但尚没有立刻从原企业和旧福利接口里完全退出。

### 为什么这改变普通人的一天？

如果一个 40 多岁的国企职工突然没有原岗位，最现实的问题不是抽象“就业率下降”，而是：

- 下个月还有没有基本生活费；
- 医疗和养老保险谁继续缴；
- 我是否每天还需要去原厂 / 服务中心办理事务；
- 我的身份还是“本厂职工”，还是已经成了社会上的失业者；
- 去新的私营企业工作会不会使旧身份终止；
- 3 年以后如果仍没找到稳定工作，会变成什么状态。

这些问题决定了“失去一份工作”究竟是突然坠落，还是被一个有限期制度缓冲。

# 三、统计也证明：“下岗”和“登记失业”不能合成一个分母

2001 年劳动和社会保障事业发展统计公报记录：

- 年末国有企业下岗职工 515 万人；
- 全国城镇登记失业率 3.6%；
- 当年 227 万国有企业下岗职工实现再就业；
- 457 万失业人员和下岗职工参加再就业培训；
- 从再就业服务中心转出的 308 万下岗职工中，142 万人解除或终止劳动合同，占 46.1%。

同一份公报又记录，2001 年已有 469 万失业人员在全年某一时期享受失业保险待遇，年末领取失业保险金人数 312 万。

Source:
- 劳动和社会保障部、国家统计局，《2001年度劳动和社会保障事业发展统计公报》，2002-06-10：
  https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913248.html

Evidence grade: **A，官方同期年度统计公报。**

这些数字不能简单相加来推算“没有工作的人”，因为它们描述的是不同制度对象、存量/流量和时点。

这正好暴露出一个生活史原则：

> **administrative denominator ≠ lived population。**

未来研究不能拿“城镇登记失业率”替代当时所有人的真实工作中断经验；同样也不能拿“下岗职工人数”代表所有没有稳定工作的城市劳动者。

# 四、2001—2005：“下岗”这个托管状态开始被正式拆除

辽宁 2001 年的并轨方案把制度状态转换写得非常明确：

- 从 2001 年起，计划 3 年内关闭国有企业再就业服务中心；
- 下岗职工全部出中心；
- 从 2001 年 1 月 1 日起，新的企业减员不再进入再就业服务中心；
- 企业依法解除劳动关系以后，符合条件者衔接失业保险和劳动力市场。

Source:
- 辽宁省人民政府，辽政发〔2001〕25号，2001-07-06，《关于印发辽宁省国有企业下岗职工基本生活保障向失业保险并轨实施意见的通知》：
  https://www.ln.gov.cn/web/zwgkx/zfwj/szfwj/6D69769EF6384624B98CF5E8A65A12F1/index.shtml

Evidence grade: **A，正式同时期省级制度文本。**

2002 年国家统计局也记录，在并轨推进的同时，城镇单位“内部退养”人数继续增加，达到 510.5 万人。

Source:
- 国家统计局，2003-04-08，《2002年我国城镇就业呈现六大特点》：
  https://www.stats.gov.cn/sj/zxfb/202303/t20230301_1920041.html

Evidence grade: **A，官方同期统计分析。**

### status relabeling is a life-course event / 状态重命名本身也是生命事件

这不是词语换了而已。

```text
下岗 + 保留劳动关系 + 再就业服务中心
```

逐步变成：

```text
解除/终止劳动关系
→ 失业保险（若符合参保和其他条件）
→ 公共劳动力市场 / 再就业服务
```

对于一个真实的人，这会改变：

- 旧企业还承担多少生活保障；
- 谁继续缴社会保险；
- 自己是否必须进入公开劳动力市场；
- 下一份工作的单位性质能否与原来完全不同；
- “我是哪家厂的人”还是否是一个稳定社会身份。

### 一条真实路径：从“铁饭碗”想象到街边小生意

新华社 2004 年采访 41 岁的柴国伟。他 1988 年中专毕业后进入沈阳第六毛纺织厂，做了十多年。2001 年企业改制时，他仍曾把这份工作想象成可以做一辈子的工作。解除劳动关系以后，他先在家待了一段时间，后来和同样经历工作中断的妻子在家附近开面饼店。

报道把他的个人路径放在辽宁并轨与大量劳动者转向非国有经济就业的背景中。

Source:
- 新华社，2004-02-01，经新浪保存，《辽宁百万下岗职工转移到非公经济领域就业》：
  https://news.sina.com.cn/c/2004-02-01/12061687527s.shtml

Evidence grade: **B，近同时期新华社个案采访。**

这个人不能代表所有下岗职工，但可以证明一种真实可行的生命路线存在：

```text
长期国企就业
→ 关系解除
→ 在家停顿
→ 家庭共同转向小规模自营劳动
```

这里“重新就业”不必等于重新找到一个和旧国企一样的单位。

# 五、2003：《再就业优惠证》把“可被扶持的失业”变成一套证件状态

2003 年广东《再就业优惠证》管理办法，把“谁是政策能够识别的下岗失业者”定义得非常具体。

发放对象包括：

- 国有企业下岗职工；
- 国有企业失业人员；
- 国企关闭破产需要安置人员；
- 享受城市最低生活保障且失业一年以上的其他城镇失业人员。

同时明确排除了已经办理内部退养、在一定时间点前已经稳定再就业或已经从事个体经营等人员。

申请者还要根据自己究竟属于哪种状态，提交不同证明：下岗职工证、企业未解除劳动关系证明、失业证、社会保险手册、低保证明等。

更重要的是，该证的发放、使用、年审和注销要进入全省劳动力市场信息系统和“下岗失业人员再就业扶持管理系统”。

Source:
- 广东省劳动和社会保障厅 / 深圳市劳动局，2003-07-03 保存文本，《广东省〈再就业优惠证〉管理办法》：
  https://www.sz.gov.cn/zfgb/2003/gb350/content/post_4976320.html

Evidence grade: **A，正式同期制度文本。**

### recognition boundary / 制度承认边界

这带来一个特别重要的区别：

```text
现实里没有稳定工作
≠ 被认定为“下岗失业人员”
≠ 有资格领取《再就业优惠证》
≠ 已经真正享受到某项税费减免 / 岗位补贴
```

一个人生活里非常真实的“没工作”，如果没有落进特定行政分类，就可能没有同样的政策接口。

这就是 **recognition boundary / 制度承认边界**。

它同时解释了为什么普通生活史不能只看公开政策清单：政策能够帮助的是**制度先识别出来的人**。

# 六、2003：Internet 进入公共再就业服务，但“能上网”本身仍是一个条件

2003 年 1 月，全国首届下岗失业青年网上招聘大会在“中国青年创业网”进行，历史 locator 为：

```text
http://www.chinajc.com/
```

新华社同期报道记录：

- 网上“招聘大厅”约有 165.9 万人次点击；
- 1874 家企业提供 41,376 个岗位；
- 7,209 人在网上形成“初步就业意向”；
- 主办方还利用团组织的工作阵地，为下岗失业青年“登陆网站”创造必要条件。

山西青年王志刚在报道中说，自己过去在 Internet 和人才市场找工作时常遇到学历门槛，这次专场给出的服务业、一线岗位更适合自己；报道说他通过该网站找到北京一家建筑公司的保安岗位。

Source:
- 新华社，2003-01-27，经新浪保存，《下岗失业青年网上招聘大会帮七千人找到新岗位》：
  https://news.sina.com.cn/s/2003-01-27/203340616s.shtml

Evidence grade: **B，同期新华社报道；包含平台观察和一个同时期个人自述。**

### 一个非常重要的证据修正

报道标题把事件概括成“帮七千人找到新岗位”，但正文使用的统计口径是 **“7209 人达成初步就业意向”**。

因此研究中必须写：

```text
online preliminary intent ≠ job offer ≠ actual start ≠ sustained employment
```

不能把平台漏斗中间的一步，改写成最终人生结果。

### public access without home Internet / 没有家庭 Internet 也可以被数字公共服务覆盖

“为下岗失业青年登陆网站创造必要条件”这一句尤其重要。

它说明 2003 年公共就业服务的数字化不应被写成：

```text
每个人家里有电脑
→ 自己上网找工作
```

真实路径还可能是：

```text
没有私人电脑 / 宽带
→ 团组织、劳动力市场、学校、社区或其他公共终端
→ 登录就业网站
→ 搜职位 / 填信息
```

这与本仓已有的网吧、公共终端研究一起构成 **access-point substitution / 接入点替代**：

> 数字服务可以比家庭设备拥有率更早进入普通人的生活，因为机构可以暂时代替私人终端。

# 七、同一年，12333 又说明“Web 化”从来没有独占公共服务入口

2003 年劳动和社会保障部正式启用全国统一公益电话号码 `12333`，要求各地逐步把原有电话咨询系统整合到这个号码，并明确不收信息服务费，只按通信标准收费。

Source:
- 劳动和社会保障部，劳社部函〔2003〕84号，2003-05-27，《关于开展劳动保障电话咨询服务的通知》：
  https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zhgl/rlzyshbzxxh/202010/t20201031_394105.html

Evidence grade: **A，正式同期部门文件。**

所以 2000s 的公共就业/社保信息系统不应被画成：

```text
窗口 → Web → App
```

更接近：

```text
窗口 / 街道劳动保障站
+ 电话 12333
+ 劳动力市场信息网
+ 专项招聘网站
+ 纸质证件
```

多条渠道长期并行。

本文把它称作 **interface pluralism / 制度接口多轨并存**。

# 八、2001—2015：后台先联网，个人前台再逐渐 Web 化

2001 年官方统计已经记录：100 个劳动力市场现代化试点城市中，有 64 个实现市区内实时联网；2002 年这一数字上升到 90 个城市。

Sources:
- 2001 年劳动和社会保障事业发展统计公报：
  https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913248.html
- 2002 年劳动和社会保障事业发展统计公报：
  https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913251.html

Evidence grade: **A，官方同期年度统计公报。**

这再次提醒我们：

> **networked backend ≠ home Web access。**

劳动部门、职业介绍所、市区劳动力市场之间实时联网，可以先改变岗位流动和公共服务能力；普通劳动者本人却仍可能是在柜台、电话或公共终端前完成最后一步。

到 2015 年，全国高校毕业生就业网络联盟招聘周已经同时使用：

- `www.ncss.org.cn`
- `www.chrm.gov.cn`
- `www.chinajob.gov.cn`
- `www.cjob.gov.cn`

Source:
- 教育部办公厅、人社部办公厅，2015-03-11，《关于联合举办2015年全国高校毕业生就业网络联盟招聘周活动有关事项的通知》：
  https://www.moe.gov.cn/srcsite/A15/s3265/201503/t20150311_189363.html

Evidence grade: **A，正式同期通知。**

因此到 old-Web 时代末端，公共招聘 Web 已经从单次专项活动逐步变成多平台、常态化公共就业基础设施的一部分。

但“职位已经发布到全国平台”仍然只证明机会可见，不能证明一个具体失业者拥有适合的学历、技能、城市、时间、设备或面试机会。

# 九、2015—2019：工作中断也开始具有“主动选择”的一面

本专题不能把 1998 年的下岗经验直接延长到 2019 年。

2019 年《工人日报》采访多名经历过“裸辞”的年轻人。27 岁互联网从业者“肖肖”已经有工作，却因为团队长期晚下班、自己难以接受工作氛围而在没有先找好下一份工作的情况下辞职。

报道还记录，当时知乎“裸辞是一种怎样的体验”已有数百个回答和超过百万浏览，说明这种经验至少已经成为可公开讨论的职业路径。

Source:
- 《工人日报》，2019-12-01，经中新网保存，《那些“裸辞”的年轻人：996会辞职 太闲了也会辞职》：
  https://www.chinanews.com.cn/sh/2019/12-01/9021658.shtml

Evidence grade: **B，同期新闻采访；个案不代表全部劳动者。**

### interruption optionality / 中断选择权

这不是说 2019 年“失业变得自由”。恰恰相反，主动离开一份工作往往需要：

- 储蓄；
- 家庭支持；
- 可迁移技能；
- 对下一份工作的信心；
- 可承担一段没有固定收入的时间。

但至少出现了一种与 1998 年典型下岗完全不同的可观察路线：

```text
有工作
→ 因工作时间 / 发展 / fit 主动退出
→ 无下一单位的中断期
→ 再搜索
```

同样是“此刻没有雇主”，历史意义却完全不同。

因此不要把所有非就业时间都统一叫作“失业困境”，也不要把主动空窗浪漫化成人人可负担的自由。

# 十、2020—2022：一次外部冲击把“失业登记能不能远程办”变成现实基础设施问题

2020 年 3 月 31 日，人社部开通失业登记全国统一服务平台。

符合条件的劳动者可以：

- 通过 `12333.gov.cn` 或“掌上12333”在线登记；
- 也可使用地方网站、客户端、微信等；
- 也保留公共就业服务机构现场办理。

当时的全国平台采用填写登记表 + 本人书面承诺的方式，不再要求额外提交其他材料，由后台信息比对和必要调查核实。

Source:

### pandemic contingency → administrative remoteability

2020 年的变化不能简单解释成“疫情发明了网上失业服务”。数字公共就业服务早已存在多年。

更准确的变化是：

> **当正常窗口、迁移和面对面办事本身变得不可靠以后，能否在另一个地点完成登记、申领和进度查询，从便利功能变成了制度连续性的必要条件。**

这和本仓已有的“偶发型未来”一致：风险不再只是“我会不会失业”，还包括“原本应该正常运行的办事过程会不会临时停摆”。

# 十一、2023—2026：中断可以是缓冲，但也会变成新的履历负担

2023 年一名网络与新媒体专业应届毕业生“张雪”向时代周报记者说，自己投了至少 50 份简历，只得到四五次面试且没有后续，于是决定暂时“慢就业”，休息并重新思考适合做什么。

Source:
- 时代周报，2023-06-27，经澎湃号保存，《青年失业率突破20%，00后切换成“慢就业”模式》：
  https://www.thepaper.cn/newsDetail_forward_23639776

Evidence grade: **B，同时期第一人称新闻材料；报告中的平台调查样本不能外推所有毕业生。**

2024 年《中国青年报》又访问多名存在较长职场空窗的人。95 后缪蔡蔡 2022 年从互联网公司离职，经历创业尝试、伴侣换城市等因素，两年后重新求职时，已经遇到面试官把“空窗期太长”作为风险；另一名 2021 届毕业生先放弃不满意的工作、连续两年考研未成，到 2024 年 3 月在北京投出上百份简历，回复不足 10 个。

Source:
- 《中国青年报》，2024-04-16，《别把“职场空窗期”当“真空期”》：
  https://zqb.cyol.com/html/2024-04/16/nw.D110000zgqnb_20240416_2-07.htm

Evidence grade: **B，同时期采访 + 调查；个案用于证明路径存在，不用于估计全国频率。**

### buffer / stigma inversion / 缓冲—污名反转

在“防守型未来”里，工作中断可能同时承担两种相反功能：

1. **对本人**：为了恢复、备考、创业试验、迁移、等待更合适工作而保存选择权；
2. **对招聘系统**：变成必须解释、可能降低信任的履历缺口。

因此：

```text
life-course buffer
≠ employer-readable positive signal
```

这是一种新的时间政治，但不是简单的“今天的人更悲观”。更准确地说：

> 人们更愿意把“不要立刻锁定一条路线”当成一种可考虑的策略，而市场又可能要求他们为这段没有机构背书的时间付出额外解释成本。

# 十二、2026：失业状态进一步变成跨系统可联动的数据对象

2025 年底形成、2026 年公开的人社部“登记失业人员就业帮扶一件事”意见，计划把：

- 失业登记；
- 失业保险待遇申请；
- 就业服务；
- 培训意愿登记与信息推送；
- 就业创业扶持政策；
- 就业援助；
- 失业登记注销；
- 就业登记

做成联动流程，并要求经办、服务和政策落实数据进入省级和全国就业信息资源库。

Source:
- 人社部办公厅，人社厅发〔2025〕61号，成文 2025-12-31，公开 2026-01-08：
  https://www.mohrss.gov.cn/wap/zc/zcwj/202604/t20260401_571697.html

Evidence grade: **A，正式制度文本。**

### registry continuity / 登记库连续性

这里出现了一条长达近三十年的结构变化：

```text
1998：企业 / 再就业服务中心知道你是谁
→ 2003：纸证 + 地方劳动力市场信息系统识别你
→ 2020：个人可以在线提交全国统一失业登记
→ 2026：登记、待遇、服务、培训、援助、注销进一步联动
```

数字化减少了一部分重复证明和跨窗口搬运，但也意味着一个人的“失业—求职—服务—再就业”状态越来越能够被数据库连续描述。

这有利于服务，也产生新的历史可见性偏差：

> **被系统连续记录的人生，比没有登记、做零工、间歇劳动、家庭照护和不走公共服务的人生更容易在未来留下档案。**

# 十三、海外对照：美国公共就业服务也不是从“线下”一步跳进家庭 Web

## 1. 1996：America's Job Bank 已经进入 Internet 公共劳动力交换

美国劳工部 1996 年 11 月的 Employment Service Program Letter 记录：

- America's Job Bank 已提供 Internet job search；
- 雇主可以通过 Internet 直接录入岗位，但仍要经过州就业安全机构验证；
- 自 1995 年 11 月以来已有雇主使用 Internet direct-entry；
- 州机构之间还通过 Internet FTP 交换岗位文件；
- 同时仍保留 PC、mainframe 和触摸屏 ALEX 自助终端。

Source:
- U.S. Department of Labor, Employment Service Program Letter No. 03-97, issued 1996-11-01:
  https://www.dol.gov/sites/dolgov/files/ETA/advisories/ESPL/1997/ESPL03-97.html

Evidence grade: **A，同期美国劳工部正式技术/业务文件。**

因此即使在美国，公共就业数字化也更像：

```text
local employment office
+ kiosk / touch screen
+ state job bank
+ Internet search
+ employer direct entry
+ backend file exchange
```

而不是“一有 Web，所有求职者就在家自己完成”。

## 2. 1996—1997：失业保险也先出现电话 / 电子远程申领

美国劳工部 1996、1997 年连续发布文件，讨论各州通过电话和其他电子方式受理 unemployment insurance claims 的法律、数据和程序问题。

Sources:
- U.S. DOL, Unemployment Insurance Program Letter No. 05-97, 1996-12-02:
  https://www.dol.gov/agencies/eta/advisories/unemployment-insurance-program-letter-no-05-97
- U.S. DOL, Unemployment Insurance Program Letter No. 37-97, 1997-07-28:
  https://www.dol.gov/agencies/eta/advisories/unemployment-insurance-program-letter-no-37-97

Evidence grade: **A。**

### 跨国共同机制与中国差异

共同机制：

- 公共就业服务先把岗位和人员状态做成数据库对象；
- 电话、公共终端、Web 会长期并行；
- 远程 claim/application 会把“前台地点”与“后台权威状态”拆开；
- `online intent/application ≠ actual employment/benefit`。

中国特有或需要单独解释的部分：

- 1990s 末“下岗”作为保留企业劳动关系的制度性中间状态；
- 国企再就业服务中心；
- 《再就业优惠证》等特定身份凭证；
- 并轨过程中从企业保障向失业保险、公共就业服务转移；
- 户籍、地方劳动力市场和地方实施规则造成的可执行差异。

所以不能因为两国都出现“网上找工作”，就把两条工作中断制度史写成同一种经历。

# 十四、与四种未来时间感的关系

这些阶段是启发式比较，不是每个人都共有的时代情绪。

## 2005–2012：扩张型未来内部的“重新接轨”

对很多经历国企就业中断的人而言，这段时期未必是乐观扩张，而是把自己接入另一种劳动市场。

但社会层面新的服务业、私营就业、网上招聘、创业培训和公共劳动力市场确实增加了新的“下一步”接口。

因此同一时代可以同时存在：

- 年轻毕业生把未来理解成越来越多的行业/城市选择；
- 一名中年下岗职工把未来理解成“还能不能重新找到一个能维持家庭的岗位”。

**同一年存在不止一种未来。**

## 2015–2019：拥堵型未来与主动空窗

更多工作机会可搜索、换工作更普通以后，一部分人已经能主动退出不合适的岗位。

但选择增多也带来搜索劳动、收入缓冲和职业连续性压力。

## 2020–2022：偶发型未来

风险不仅是“岗位不好”，而是普通招聘、办事、流动本身都可能临时失常。

全国统一的线上失业登记、待遇申领成为一种远程连续性基础设施。

## 2023–2026：防守型未来

“慢就业”“空窗”“考证/考试”“先休息再找”“先留一点选择”可以成为实际策略；同时，空窗越长又可能越难重新进入招聘漏斗。

防守不是统一退出社会竞争，而是更强调：

- 现金和家庭缓冲；
- 不要太早封死下一条路线；
- 保留能重新进入工作或制度服务的接口。

# 十六、后见之明风险

1. **不要把“下岗”直接翻译成今天意义的普通 unemployment。**
   1998—2001 的制度含义必须保留劳动关系和再就业服务中心。

2. **不要把城镇登记失业率当成所有真实无工作人口。**
   登记口径本身就是研究对象。

3. **不要把“再就业”自动理解为恢复原行业、原工资和原社会地位。**
   新岗位可能是服务业、小生意、公益岗、私营企业或其他完全不同工作。

4. **不要把 2003 网上招聘会的 7,209 个“初步就业意向”写成 7,209 人稳定就业。**

5. **不要把 Internet 服务存在写成家庭 Internet 普及。**
   公共终端和组织提供的接入点可以先一步进入生活。

6. **不要把 2019 裸辞材料投射回 1998。**
   主动工作中断和制度性下岗不能混成同一种“自由选择”。

7. **不要把 2023–2026 的慢就业全部浪漫化为自我探索。**
   有些人是在低回复率和岗位不匹配后被动延长搜索；也有人确实主动保留选择。

# 十七、目前我们知道 / 可以合理推断 / 仍不知道什么

## 已经知道

- 1998 年再就业服务中心确实可以把“离开岗位”和“解除劳动关系”拆成两个时点；
- 2001—2005 前后，部分地区明确推进从“下岗中心托管”向失业保险和劳动力市场并轨；
- 2003 年《再就业优惠证》把扶持资格连接到实名证件、劳动关系证明和地方信息系统；
- 2003 年已经出现面向下岗失业青年的全国网上招聘活动，同时主办组织提供公共上网条件；
- 12333 自 2003 年起成为全国统一劳动保障电话咨询入口；
- 2020 年全国统一失业登记和失业待遇网上申领显著加强；
- 2023–2024 的同时期第一人称材料中，可以同时观察到慢就业、主动空窗和重新进入摩擦。

## 可以合理推断

- 从再就业服务中心到登记失业，不只是保障渠道变化，也改变了一个人的社会身份和找工作方式；
- 公共就业数字化先改变后台和机构联网，再逐步把更多步骤推到个人终端；
- 工作中断越依赖行政登记和平台记录，其状态越容易被制度看见；家庭照护、零工和未登记间歇劳动则更容易成为历史盲区。

## 仍不知道

- 1998—2003 不同城市下岗职工每天实际怎样使用再就业服务中心：去中心频率、真实培训内容、排队与交通时间；
- 普通家庭在 2003 网上招聘大会中使用家庭电脑、网吧、单位/团组织终端的真实比例；
- 7,209 个初步就业意向中，有多少最终到岗、做了多久、收入变化如何；
- 再就业优惠证后台系统的具体客户端、数据库、联网方式和基层录入劳动；
- 2005–2015 公共就业网站对中年失业者、农民工、非正式劳动者的实际使用率；
- 失业登记、商业招聘平台履历、社会保险记录和个人真实收入时间线之间到底有多大错位；
- 2023–2026 慢就业/空窗的群体分布、家庭现金缓冲以及不同学历/城市/职业的重新进入概率。

这些是后续真正值得追的缺口。

# 十八、这一轮改变了“人怎么活着”的哪一点理解

过去容易把工作史画成：

```text
有工作 → 失业 → 再就业
```

这轮证据更接近：

```text
有原岗位
→ 岗位停止但关系还在
→ 再就业中心托管
→ 解除关系 / 内退 / 重新就业 / 自营
→ 登记失业（或没有登记）
→ 保险 / 培训 / 公共招聘 / 家庭缓冲
→ 新工作 / 零工 / 再次中断
```

二十多年以后，又会出现：

```text
主动离职
→ 空窗 / 备考 / 创业 / 迁移 / 慢就业
→ 平台求职
→ 因 gap 再承担解释劳动
→ 重新进入
```

所以真正的新认识是：

> **“一份工作结束以后的人”不是一种人。**
>
> 有人仍属于原来的厂，有人已经进入失业保险，有人被放进内部退养，有人去摆摊，有人借公共电脑上网找保安工作，有人二十年后主动裸辞，有人毕业后决定先慢一点找。制度给每一种中断起的名字、允许它持续多久、提供什么钱和什么入口，会把同样一段“没有正常上班的时间”变成完全不同的人生。
