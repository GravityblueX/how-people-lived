# 从爱好者网络到“搭子”：兴趣可寻址、活动型陪伴与共同在场（中国，1980—2026）

> 研究问题：一个人想看戏、打球、逛公园、读书、带娃、旅行或练英语，但原有亲属、同学、同事、伴侣恰好不愿意、没时间或不在同城时，她还有没有办法找到“只和我一起做这件事的人”？
>
> 结论先行：互联网没有发明“因为共同兴趣而结识陌生人”，也没有让线上关系自动变成现实友谊。它更重要的变化之一，是扩大了 **interest-based addressability / 兴趣可寻址性**：人不必先知道另一个人的姓名、住址、单位或朋友关系，就可以先按“喜欢什么、想做什么、何时有空、是否同城”找到潜在同伴。随后出现的论坛、同城活动页、QQ群/微信群、SNS 与社交平台，又逐步把“发现同好”推进到“约时间—到现场—共同做一件事”。到 2020s，“搭子”把这种结构进一步显性化：一份深关系不必包办吃饭、旅行、运动、学习和娱乐，陪伴可以按活动拆分。

本题与仓内 `stranger-life-script-visibility`、`alumni-recontactability`、`dating/matchmaking`、`leisure`、`opening-hours-temporal-executability` 等专题相邻，但研究对象不同：这里追踪的是**陌生人怎样因为具体活动被找到、协调并进入同一物理或同步在线场景**，以及这种连接为什么可能只持续一顿饭、一场球、一趟旅行，而不转化为长期朋友。

## 1. 先拆状态：知道“有人也喜欢”不等于真的有人陪你去

至少要区分：

```text
有某种兴趣/活动需要
→ 知道可能有同好
→ 有渠道找到同好
→ 找到同城/可到达者
→ 时间、预算、节奏大致匹配
→ 建立初步联系
→ 对方回应
→ 约定活动
→ 双方实际到场 / 同步上线
→ 活动真实发生
→ 体验可接受
→ 关系结束 / 继续做同类活动 / 转成朋友
```

因此固定以下边界：

- `同好存在 ≠ 本人知道他们存在`；
- `同一个群 ≠ 现实认识`；
- `活动页存在 ≠ 活动真实举行`；
- `“感兴趣” ≠ “要参加” ≠ 实际到场`；
- `约好见面 ≠ 双方到场`；
- `共同做过一件事 ≠ 成为朋友`；
- `线上关系 ≠ 必须转线下`；
- `平台扩大发现半径 ≠ 消除距离、时间、费用与安全约束`。

这里把从“我想做一件事”到“另一个合适的人真实与我一起做成”称为 **copresence executability / 共同在场可执行性**。

另一个核心变量是 **interest-based addressability / 兴趣可寻址性**：过去寻找某人，常以姓名、单位、学校、住址或共同熟人为索引；兴趣网络允许反过来用“话剧、汉服、亲子、羽毛球、摄影、某一本书、某个城市活动”作为索引，再从中找到人。

## 2. 前互联网基线：兴趣网络早已存在，只是发现和协调半径不同

### 2.1 不能把“同好社交”写成 Web 发明

中国前互联网时期已经有协会、文化宫、学校社团、报刊读者网络、邮政通信、集邮交换、业余无线电等把陌生人按兴趣连接起来的渠道。这里不试图用一个爱好代表全国普通人，只建立“机制在 Web 前已存在”的最低基线。

一个较清楚的回顾性案例是广州业余无线电。2011 年广州无线电运动发展史采访称，广州无线电运动协会 1981 年成立，最初从一个业余电台和几十名爱好者发展；受访者胡玉田回忆，他通过无线电结识世界各地的朋友，并长期保存 QSL 通联卡和邮票。[新浪体育转广州日报，2011-11-26](https://sports.sina.cn/sa/2011-11-26/detail-ikknscsh8957740.d.html)

证据等级：**C（后来的机构史/个人回忆）**。它能证明参与者后来如何记忆“无线电—同好—跨地联系”这条链，不能单独证明 1980s 普通城市青年普遍拥有这种能力，更不能把集体业余台的存在写成普通家庭已有个人数字通信。

这一前史的重要意义是：

```text
共同兴趣
+ 社团/广播/报刊/邮政/电台等索引与通信渠道
→ 陌生人也能建立联系
```

互联网真正扩大的是检索速度、候选数量、更新频率和跨圈流动，而不是从零创造“同好”。

### 2.2 前互联网兴趣社交常更依赖固定组织与物理节点

文化宫、协会、学校、邮局、报刊栏目、固定活动日、线下交换市场等，本身既是发现同好的地方，也是实际见面的地方。它的优点是活动边界较明确、组织者和地点较可见；限制则包括地理覆盖、固定开放时间、加入门槛、信息更新慢，以及人在迁居以后需要重新找到当地入口。

因此长期变化不宜写成：

`没有兴趣社交 → Internet 有兴趣社交`

而更接近：

`本地组织 / 报刊 / 邮政 / 无线电等兴趣网络`
`→ BBS / 论坛按主题聚集陌生人`
`→ 同城活动页把兴趣与地点、时间重新连接`
`→ 群聊 / SNS 维持多个流动兴趣圈`
`→ 平台按具体活动临时匹配“搭子”`

这不是线性替代：旧组织、学校社团、线下俱乐部一直存在，网络更多是在它们之间增加新的发现与协调层。

## 3. 2005—2012：扩张型未来——“网上认识的人”开始变成可以一起过周末的人

### 3.1 2008：刚进入职场以后，工作关系并不能自动替代同龄朋友

2008 年 1 月，《新快报》报道 21CN“广州人广州事”论坛上的一场“80 后”故事接龙。发起者、版主“BB噶烧卖”当时刚毕业参加工作不久；他对记者解释，同事平时都很忙，很难结交新朋友，发帖的另一个目的就是认识更多同龄人。报道说，近 300 名网友参与接龙，其中一些跟帖者后来彼此认识，并“定期还会出来聚会”。[新快报/新浪，2008-01-11](https://news.sina.com.cn/c/2008-01-11/012413236036s.shtml)

证据等级：**B（同期媒体采访 + 平台可观察事实）**。报道能证明这批受访者将论坛使用和现实聚会连接起来，不能推出“80 后普遍靠论坛交朋友”，也没有留下可核验的原帖 transaction capture。

这个材料补了一种标准人生脚本之外的小断裂：

```text
毕业
→ 原班级/宿舍社交密度下降
→ 新单位同事不一定成为朋友
→ 论坛按年龄/城市/兴趣重新聚人
→ 一部分线上弱关系进入现实聚会
```

这可以称为 **post-institution social recomposition / 离开学校后的社交再组合**。学校和单位都曾经替人自动提供大量“每天会碰见的人”，但工作以后，原有制度性同伴并不必然满足周末与兴趣生活。

### 3.2 2008：“同一人生阶段”本身也可以成为兴趣/需要索引

同年 3 月，《新闻晨报》报道 40 多名“80 后”白领妈妈通过线上网络组织，在上海长风公园带宝宝聚会。IT 从业者朱小姐说，她 2006 年怀孕时在论坛认识了一批预产期相近的年轻妈妈，因为都在猪年 8 月前后生产，群体被称为“8月猪妈帮”。报道将工作繁忙、育儿经验不足、难得结伴出游作为她们组织线下活动的背景。[新闻晨报/新浪，2008-03-17](https://news.sina.com.cn/s/2008-03-17/031013582659s.shtml)

这说明网络索引并不只按“爱好”，还可以按一个非常具体的 **life-stage compatibility / 生命阶段兼容性**：同样刚生孩子、同样周末有空、宝宝年龄相近的人，比“认识很多人”更重要。

因此活动型社交不是纯娱乐问题，它会穿过照护、迁移、工作和家庭：

`我有朋友`

并不等于

`我有一个此刻能和我带同龄孩子出门的人`。

### 3.3 2009：豆瓣同城把“同好”进一步做成地点 + 时间 + 类型可检索对象

豆瓣自己的 2009 年产品博客提供了比怀旧回忆更强的同时代平台证据。3 月 4 日的产品说明称，“同城”已经上线一年，新首页将强化“一周热门”，并允许按时间和内容类型交叉筛选，类型包括“音乐演出”“生活聚会”等；平台还计划为已结束活动提供“精彩回顾”，保留照片和讨论。[豆瓣官方博客，2009-03-04](https://blog.douban.com/douban/2009/03/04/376/)

7 月，官方又宣布“同城活动地图”：发起人填写地点后，系统可尝试生成地图，参与者可以在活动页查看位置；平台直接把这一功能描述为帮助用户“更方便地参加同城活动”。[豆瓣官方 2009 年归档](https://blog.douban.com/douban/2009/)

证据等级：**A（平台同期官方产品文档）**，但它只证明平台设计和平台自己的功能主张，不证明每场活动都真实发生。

这里出现一个关键变化：

```text
“我喜欢什么”
+
“我今天/本周什么时候有空”
+
“我在哪座城市、能去哪里”
→ 可以被同一个界面联合检索
```

这比单纯论坛讨论多了一层 **coordination infrastructure / 协调基础设施**。兴趣开始不仅生成文字社区，也生成可以进入城市空间的事件列表。

### 3.4 2009：“99人书库”显示网络兴趣群可以组织持续的线下公共活动

2009 年《南方都市报》报道，豆瓣用户从当年 6 月开始策划“99人书库”，试图由 99 人各提供一个主题的 100 本书，并围绕书库组织纪录片、展览、沙龙、诗歌、设计和音乐等免费活动。报道给出的平台数字是：到 9 月，深圳站已有 524 人“参与”、1627 人“感兴趣”，全国有 4980 人“感兴趣”；这些是报道转述的平台状态，不等于实际到场人数。受访者 Nini 说自己参加过纪录片放映，也期待下一场摄影展。[南方都市报/新浪，2009-11-23](https://news.sina.com.cn/c/2009-11-23/041916650641s.shtml)

这条材料的价值不在于证明豆瓣“多流行”，而是显示一条可执行路径：

`线上发现同好 → 共同筹集资源 → 发布活动 → 有人实际到场 → 下一次活动继续`

兴趣网络因此能生产短期的 **micro-public infrastructure / 微型公共基础设施**：一间临时书库、一场放映、一张活动桌，而不只是聊天。

## 4. 海外前史比较：The WELL 说明“线上/线下”从来不是自动替代关系

美国 The WELL 是一个很好的 1980s 对照，因为它既早于 Web，也保留了较丰富的同期材料。

1990 年《San Diego Reader》记者以参与者身份描述：The WELL 办公室每月举行聚会，订户会组织周日 brunch，并安排 `f2f`（face-to-face）见面，一些关系发展成现实友谊；但作者本人反而明确喜欢一种“不必转成身体共同在场”的线上亲密感。[San Diego Reader，1990-03-01](https://www.sandiegoreader.com/news/1990/mar/01/members-keyboard/)

1997 年 Wired 回顾 The WELL 早期历史时又记录，办公室聚会自 1986 年 9 月开始，很快成为每月传统；参与者认为线下见面会反过来加强线上亲近。一个从得州远程登录的成员甚至回忆，在他专门前往湾区参加一次聚会之前，自己的帖子常感到被忽略。[Wired，1997-05](https://www.wired.com/1997/05/ff-well/)

这组海外材料给出三个重要反例：

1. `online community` 不必拒绝线下；线上和线下可以互相增强；
2. `online access` 也不一定消除地理不平等，现实见面仍可能改变一个人在群体中的位置；
3. 并不是每个人都希望网络关系“升级”为现实朋友，有人正是看重它不承担日常关系义务。

因此中国 2008—2010 出现的论坛聚会、同城活动不应写成“中国互联网特有”，它更像一个跨国的网络社会机制；中国特有的部分，需要进一步放在本地平台、移动通信、住房/城市交通和既有单位/学校关系结构中解释。

## 5. 2015—2019：拥堵型未来——圈子变多了，但城市里的时间并没有变多

### 5.1 2018：兴趣圈成为“多套并行关系”而不是唯一社区

2018 年《中国青年报》对 1982 名 18—35 岁受访者的问卷中，91.0%表示有自己的兴趣圈；调查样本并不能直接代表全国青年，但它保留了当时人怎样描述这些圈子的具体用途。中科院研究生李瑶到北京后喜欢上话剧，经网友推荐加入几个话剧群；一次把闲置票转给网友并线下见面后，又被拉入转票群和其他话剧群。她说这些群让买票、转票、获得演出信息和认识新朋友更方便。北京一名汉服爱好者则通过学校社团和跨高校微信群参与线下活动。[中国青年报，2018-05-17](https://zqb.cyol.com/html/2018-05/17/nw.D110000zgqnb_20180517_1-07.htm)

同一调查里，受访者加入兴趣圈的原因包括获取资讯、学习，也包括“生活枯燥，一个人太孤独”（37.9%）和寻找志趣相投的朋友（28.6%）；专家同时指出，当代兴趣圈更细、更流动，人可以在多个圈之间来回切换。报道也保存了反面评价：17.6%受访者认为兴趣圈占用太多时间、影响学习，10.7%担忧过度小众化引发争议。[同上](https://zqb.cyol.com/html/2018-05/17/nw.D110000zgqnb_20180517_1-07.htm)

这里出现 **social portfolio / 社交组合**：

```text
同学 / 同事
+ 话剧群
+ 学术群
+ 美食群
+ 汉服社
+ 考试群
```

这些关系可以相互重叠，但不必合并成一个“朋友圈”。人的社交生活开始更容易按功能并行维护。

### 5.2 “圈子更多”并不意味着现实见面更容易

大城市工作的时刻、交通距离、照护和生活琐事仍然构成 **coordination tax / 协调税**。这也是为什么“能加入十个群”与“今晚真的有人能陪我去看戏”是两个不同状态。

因此拥堵型未来里的新矛盾可以写成：

`候选关系数量 ↑`

但同时

`深关系共同空闲时段 ↓ / 城市移动成本仍在`

于是人更可能保留多个兴趣圈和活动入口，用它们在具体时刻补充原有朋友不能承担的活动，而不是简单用“网友”替换老朋友。

## 6. 2020—2022：偶发型未来——当共同地点突然关闭，陪伴能否暂时转成同步在线

2020 年 3 月《中国青年报》关于“云生活”的同期调查提供了一个很清楚的压力测试。23 岁的程芸芸刚工作不久，疫情期间一直一个人做饭、吃饭，觉得无聊，于是经常和朋友“云做饭”“云聚会”，一边聊天一边吃饭；她说这让独居生活更充实、没那么孤单，也加深了朋友感情。该次 3004 人问卷里有 20.8%称体验过“云聚会”。[中国青年报，2020-03-26](https://zqb.cyol.com/html/2020-03/26/nw.D110000zgqnb_20200326_2-03.htm)

这里不能写成“线上聚会等于线下聚会”。真正新增的是 **copresence substitution / 共同在场替代**：

```text
原有关系仍在
+ 物理共同地点暂时不可达
→ 同步视频/语音/在线活动维持部分陪伴
```

它是一条 fallback，而不是完整替代。身体共同在场、一起走路、共享餐桌、临时帮助和空间感都不能被一通视频完全复制。

但这次压力测试证明，互联网的社交功能不只用于“认识新人”；它也可以在现实连接突然断开时，临时保持既有关系的同步节律。

## 7. 2023—2026：防守型未来——“搭子”把陪伴拆成可替换的活动模块

2023 年《中国青年报》关于“搭子”的同期采访特别适合做状态区分。问卷对 1335 名受访青年调查，72.6%表示生活里有“搭子”；该比例只代表这一调查样本，不应外推全国。更重要的是受访者的具体做法。[中国新闻网转载中国青年报，2023-06-01](https://www.chinanews.com.cn/sh/2023/06-01/10017395.shtml)

北京研究生苏泽霖原来每周和室友逛公园，室友后来没空，她就在社交账号发帖，寻找年龄相近、会拍照、时间合适的女性同伴，最后找到两名“搭子”，有空时每周出去一次。她还另有一起练英文演讲的学习搭子。受访者刘雨萌明确把同城、位置距离、空闲时间和安全当成筛选条件；彭涛则讲到一次电影搭子见面后发现对方抽烟，活动结束后就没有再联系。[同上](https://www.chinanews.com.cn/sh/2023/06-01/10017395.shtml)

这已经不只是“兴趣圈”，而是 **activity-specific companionship / 活动专用陪伴**：

```text
逛公园 → A
练英语 → B
打球 → C
旅行 → D
吃饭 → E
```

一个长期朋友、伴侣或室友不再需要承担全部活动需求。我把这个变化称为 **companionship unbundling / 陪伴拆包**。

### 7.1 为什么它适合“防守型未来”而不是简单的“更开放”

这套关系的一个价值，是降低进入和退出成本。报道中的受访者直接把“搭子”描述为浅层社交：不主动维系就可能自然断掉；有人说打球搭子平时几乎不聊天，“纯打球”。[同上](https://www.chinanews.com.cn/sh/2023/06-01/10017395.shtml)

这不是一定要被解释成“年轻人不再会交朋友”。另一种更窄的解释是：在工作节奏快、朋友分散、共同空闲不稳定时，人开始明确区分：

- **深关系**：需要长期信任、照护、危机托付；
- **活动关系**：只需要某一项兴趣、地点、时间和边界匹配。

报道中的专家也给出重要反例：如果住院、全麻、需要把身份信息或银行信息交给别人，“搭子”不能自动承担这种深信任职责。[同上](https://www.chinanews.com.cn/sh/2023/06-01/10017395.shtml)

因此好的生活不是“把所有朋友都降级成搭子”，而是拥有 **social fallback diversity / 社交后备多样性**：深关系仍存在，同时某个具体活动不必因为深关系今天没空就完全取消。

### 7.2 新风险：弱关系执行需要自己的安全与边界机制

陌生人活动匹配扩大选择，也把陌生人风险带进现实共同空间。地点是否公开、身份如何判断、消费分摊、隐私披露、是否单独见面、如何结束关系，都成为新的维护劳动。

因此：

`更多候选人 ≠ 更多安全可执行的关系`

真正关键的是：

`发现成本下降 + 筛选成本可承受 + 退出权明确 + 线下安全条件存在`。

## 8. 这一条历史线改变了“互联网让人更孤独 / 更社交”的二元问题

“互联网到底让人更孤独还是更社交”过于粗糙，因为它把至少四种不同作用混在一起：

1. **discovery / 发现**：找到原本不知道存在的人；
2. **coordination / 协调**：确定时间、地点、费用、路线；
3. **copresence / 共同在场**：实际一起出现在现场或同步在线；
4. **relationship persistence / 关系持续**：活动以后是否继续联系。

互联网可能大幅改善前两项，却对第三项仍受城市交通和时间限制，对第四项更没有自动保证。

所以：

`discoverability ↑`

完全可以同时存在：

`deep friendship formation unchanged / difficult`

甚至：

`relationship maintenance burden ↑`

这一拆分也解释了为什么 1990 的 WELL、2008 的论坛聚会、2009 的豆瓣同城、2018 的兴趣圈和 2023 的“搭子”看起来相似又不完全相同：它们都在解决“我怎样找到合适的人”，但对关系持续时间和义务的期待越来越可以分层。

## 9. 时代时间感比较

### 2005—2012：扩张型未来

网络把学校、单位以外的人第一次大规模变得可发现；周末、演出、育儿、读书等活动可以由线上社区导向现实城市。未来感更像“外面还有很多我没认识的人、没去过的活动”。

### 2015—2019：拥堵型未来

圈子和信息越来越丰富，但时间、通勤和注意力成为瓶颈。人可以同时属于很多圈，却未必能稳定维持每个圈；“多个轻关系 + 少数深关系”更适配碎片化生活。

### 2020—2022：偶发型未来

共同地点突然不可达，原有线下活动被迫中断，同步在线成为部分陪伴的 continuity layer。它揭示“有网络关系”与“能共享城市空间”从来不是同一回事。

### 2023—2026：防守型未来

“搭子”把关系期待写得更窄：先确认这件事能不能一起做，再决定要不要发展关系。选择性更强、退出更轻，也更需要安全边界。它不必是悲观；更像在不确定时间表下，降低每一项活动必须依赖单一深关系的风险。

## 10. 重点矩阵：这条机制怎样穿过普通生活

| 维度 | 本题新增观察 |
|---|---|
| 教育 | 学习群、考研群、英语练习搭子把“一个人学习”变成可寻找临时同伴的路线；但群存在不等于学习完成。 |
| 就业 | 离开学校进入单位后，工作同事未必能替代原同学社交；兴趣网络可补 post-institution social gap。 |
| 住房 | 独居/合租者可以从住宅外寻找活动陪伴；住宅里没人不再等于周末必然一个人。 |
| 婚姻家庭 | 伴侣不必承担全部兴趣活动；新手父母还能按宝宝年龄/育儿阶段找同类家庭。 |
| 迁移 | 新到一座城市的人可先按活动重新建立弱关系入口，而不必等待单位/学校自然形成朋友圈。 |
| 照护 | 育儿同伴可以共享经验与活动；但活动搭子不能自动承担疾病、住院等深照护责任。 |
| 非正规劳动 | 活动组织、票务转让、摄影、教练等可能与兴趣圈交叉；本轮未证明其规模。 |
| 长期中断 | 失业、毕业、迁居、疫情等导致旧关系场景中断时，兴趣网络可以成为重新进入社会节律的一条弱连接。 |
| 证件与记录 | 本轮没有发现证件是核心门槛；大型/商业活动可能另有实名票务，需要与 rail/ticketing 等专题交叉。 |
| 通信方式 | 邮政/无线电/论坛/群聊/SNS 的共同作用是把同好变得可联系，但速度、半径和同步性不同。 |
| 互联网平台 | 论坛先聚话题；同城活动页进一步绑定时间、地点与 RSVP；社交平台又能按帖子临时找搭子。 |
| 信息获取 | “哪儿有演出/活动”与“谁愿意一起去”逐步在同一平台完成。 |
| 社交关系 | 从制度性同伴扩展到兴趣弱关系，再到活动专用陪伴；弱关系可结束，也可能转成朋友。 |
| 未来预期 | 扩张期强调“还有很多人和活动可发现”；防守期更强调节奏、距离、安全、退出与备用同伴。 |
| 线上/线下身份 | 在线昵称/帖子可以成为线下第一次见面的入口，但线上熟悉感不能替代现实安全判断。 |
| 平台消失与记忆保存 | 活动公告、照片和“感兴趣/要参加”更容易留下；实际到场、临时取消、私聊、转电话/QQ、活动后关系最容易消失。 |

## 11. 证据强度、反例与后见之明风险

### 已较强支持

- 2008 年中文论坛确有“线上互动 → 一部分用户线下聚会”的同期采访证据；
- 2008 年年轻母亲确有按育儿阶段在网上结识并组织公园活动的同期案例；
- 豆瓣官方 2009 年文档明确把同城活动做成时间、类型、地点可检索对象；
- 2018 年同期青年材料显示兴趣圈可以同时承担资讯、票务、学习和认识新人的功能；
- 2020 年物理共处受限时，同步在线聚会被部分受访者当成陪伴 fallback；
- 2023 年“搭子”材料明确显示同一人可以按不同活动维护不同伙伴，并保持浅关系边界。

### 反例必须长期保留

- The WELL 1990 年的作者明确喜欢不必转线下的网络关系，因此 `online relationship → offline` 不是“成熟度升级”；
- 2018 年兴趣圈也会耗费时间、产生圈层冲突；
- 2023 年电影搭子可以只见一次就结束；
- 深关系照护不能由活动搭子自动替代；
- 大量活动页与 RSVP 状态本身不能证明实际到场。

### 后见之明风险

- 不把 2008 年论坛聚会叫作“早期搭子”，除非当时人自己这样说；
- 不把“80 后”“90 后”人格化，重点写他们在某年龄遇到的平台和城市时间条件；
- 不把 2023 年“搭子”倒投回 1980s 爱好者协会；两者机制可比较，社会语义不同；
- 不把一个平台的产品设计写成全国普通人的行为；
- 不把“线上认识”直接写成“现实友谊增加”。

## 12. 尚未确定与下一步

1. 需要真正的 2005—2010 中文论坛/BBS 原帖 archive capture，确认当年聚会帖、活动报名、分页、时间戳和回复状态；同期新闻只能保留行为轮廓。
2. 需要更多 2007—2010 第一人称博客/论坛材料，尤其是“约了但没成”“去了以后不合适”“活动取消”这类负状态，避免成功聚会的保存偏差。
3. 需要更好的 1990s 中国电脑爱好者/BBS、业余无线电 packet radio、大学网络与线下聚会材料，判断数字兴趣网络何时从单位/高校小圈子外溢。
4. 需要区分本地大型城市和小城市/县城：候选同好数量增加以后，交通与活动供给是否仍限制共同在场。
5. 需要研究女性、未成年人、残障者等在陌生人线下活动中的安全与可达性，不把“能发帖”直接写成“能去”。
6. 需要追踪平台死亡：一个旧活动页消失以后，照片、参与者列表和之后形成的关系由谁保存、谁有权重新公开。

## 13. 这改变了我们对“人怎么活着”的哪一点理解

过去问“一个人有没有朋友”太粗。

日常生活真正经常遇到的是更小的问题：

> 今天想看一场戏、打一场球、带孩子去公园、去陌生城市旅行、练一小时口语，原来最亲近的人恰好不想去或没时间——这件事是不是就只能取消？

互联网时代新增的一项选择，不只是“认识更多人”，而是把人际关系的一部分从固定社会位置中拆出来：**你可以先按一件具体的事寻找另一个合适的人，再决定这段关系究竟只持续两小时，还是值得继续。**

这扩大了生活菜单，但没有废除深关系。它真正增加的是：一项活动不再必须等待同一个朋友、同一个伴侣、同一个同事永远与你兴趣一致、时间一致，普通人可以拥有更多条通向共同在场的备用路线。
