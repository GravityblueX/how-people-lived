# 从 36 张胶卷到无限快门，再到主动找回“慢拍”：摄影、可支配生活与影像记忆（中国，1980s—2026）

> 研究问题：普通人什么时候开始不仅“有一台相机”，而是把摄影变成会持续占用钱、周末、旅行、器材、学习和记忆整理的兴趣生活？胶片、数码相机、摄影论坛、手机与今天的复古相机，分别改变了什么？
>
> 本题是 `INDEX-hobby-life-worlds.md` 的第二个深描案例。它不把专业摄影师、新闻摄影、普通家庭留影和深度摄影爱好者混成同一人口，也不把“手机人人能拍”直接写成“人人都是摄影发烧友”。
>
> old-Web companion：[`tmzncty/old-web-archaeology/docs/PHOTOGRAPHY_FORUM_IMAGE_EXIF_CLASSIFIED_AND_ARCHIVE_STATE_GAPS_2000_2015.md`](https://github.com/tmzncty/old-web-archaeology/blob/main/docs/PHOTOGRAPHY_FORUM_IMAGE_EXIF_CLASSIFIED_AND_ARCHIVE_STATE_GAPS_2000_2015.md)

## 1. 先拆状态：拍过照片 ≠ 摄影成为生活世界

至少区分：

```text
家庭/单位里有人有相机
→ 偶尔拍纪念照
→ 自己主动带相机出门
→ 学习曝光、构图、胶片/后期
→ 重复购买胶卷、冲印、存储或器材
→ 为拍摄专门安排时间/路线
→ 进入影友、论坛、比赛或作品交流
→ 形成稳定的器材、作品、知识与归档习惯
→ 摄影成为自我描述的一部分
```

固定边界：

- `相机销售量 ≠ 摄影爱好者人数`；
- `拍照频率高 ≠ 深度摄影 hobby`；
- `手机每天拍照 ≠ 相机兴趣已经消失`；
- `论坛发片 ≠ 原图仍存活`；
- `EXIF 显示某机型 ≠ 发帖者长期拥有该器材`；
- `数码取消胶卷成本 ≠ 摄影总成本下降为零`；
- `胶片复兴 ≠ 全社会重新回到胶片时代`。

本题把一种摄影实践能否真正持续，称为 **photography executability / 摄影可执行性**。

## 2. 胶片时代的核心不是“老相机”，而是每一次按快门都有物质后续

传统 135 胶卷常见 24 张或 36 张一卷。拍下一张之后，画面不能立刻在机背确认；一卷拍完以后，还要经历冲洗、扩印/放大、取片、整理底片与相纸等环节。

因此胶片摄影天然包含至少三种今天容易被忘掉的预算。

### 2.1 exposure budget / 快门预算

每按一次快门，都会消耗有限胶片，并把未来的冲洗/扩印成本增加一点。

这不意味着每个胶片摄影者都会“珍惜每一张”，也不意味着数码以后摄影自动变认真；但它说明一次曝光具有可感知的边际成本。

### 2.2 feedback latency / 反馈时延

```text
拍摄
→ 不能立即知道最终结果
→ 胶卷拍完
→ 冲洗/扩印
→ 才能系统检查曝光、对焦与构图
```

学习摄影因而常跨越数天甚至更久。失败不是立即删掉重来，而可能在一卷之后才被看见。

### 2.3 physical archive burden / 实体档案负担

底片、相纸、相册、纸袋、日期笔记和冲印店包装本身就是档案系统。它的优点是无需账号和云服务也能长期存在；缺点是占空间、怕潮湿霉变、容易散失，而且检索能力很弱。

1994 年 3 月 22 日《人民日报》一组新闻摄影明确注明使用乐凯 BR 系列彩色胶片拍摄。这不是爱好者普及率证据，但可作为 1990s 胶片材料链仍属现实摄影基础设施的同时代锚点。

- 《人民日报》1994-03-22 第4版：<https://cn.govopendata.com/renminribao/1994/3/22/4/>

证据等级：**A/B（同时代报纸文本复录）**。

## 3. 1980s—1990s：相机进入更多家庭，不等于摄影 hobby 已无门槛

2018 年中新社/新京报整理海鸥相机史时称，海鸥方面把 1985—1995 年视为国产相机“黄金十年”，并回忆傻瓜相机在 1980s—1990s 进入许多普通家庭。

- 中新网，《相机记录“光阴的故事”》，2018-08-10：<https://www.chinanews.com.cn/sh/2018/08-10/8595976.shtml>

证据等级：**C/B（后来产业回顾 + 厂商口述）**。它能说明后来行业如何描述家庭相机扩散，不能单独推出某一年的家庭拥有率，也不能把“有傻瓜机”写成“深度摄影”。

更可靠的最低结论是：到 1990s，摄影兴趣已经有一整套前 Web 基础设施可以依赖：

- 相机与胶卷商店；
- 冲印店；
- 《大众摄影》《中国摄影》等专业/大众摄影刊物；
- 摄影协会、文化馆、单位和学校社团；
- 比赛与展览；
- 熟人、老师和本地影友；
- 邮寄投稿与读者来信。

《中国摄影家》创刊 30 周年回顾称，1980s 摄影活动和摄影组织增加，摄影报刊也有明显扩展；此材料同样属于后来机构史，只作为入口线索。

- 中国摄影家杂志，2018-08-28：<https://www.sohu.com/a/250527584_771892>

### 3.1 数码相机在 1998 年仍不能被倒写成普通家庭默认设备

1999 年《生活时报》同期报道估计：1997 年国内数码相机销量约 1.7 万台；1998 年市场原先曾乐观预计 5 万台，但实际可能只有其约一半。

- 《生活时报》，《数码相机风光未现》，1999-01-15：<https://www.gmw.cn/01shsb/1999-01/15/GB/860%5ESH14-132.htm>

证据等级：**B（同期市场报道）**。

它不能给出胶片相机拥有率，却足以守住一个重要边界：

```text
1998 中国已经可以买到数码相机
≠
1998 普通摄影爱好者已经整体进入数码摄影
```

胶片、冲印店与纸质摄影知识网络仍然是大量实践的现实环境。

## 4. 2000—2004：中文 Web 把“器材—作品—经验—二手”第一次长期放在同一个可搜索空间

色影无忌现存的官方历史页面称网站创立于 2000 年。其 2003 年新年致辞回顾 2002 年时说，网站迎来第 3 万名注册用户，曾出现千人同时在线，访问量为 2001 年四倍；同年还恢复“器材点评”、开办电子网刊、增加图片论坛组图功能。

- 色影无忌，`2003new-year.htm`：<https://www.xitek.com/commonfile/2003new-year.htm>

证据等级：**A-like publisher-retained historical page / 出版方当前仍保留的历史页**。它不是本轮验证过的 2002/2003 WARC，因此只能证明今天可定位到一份带有该历史日期/文本的官方遗留页，不能据此复原当年 DOM 与浏览器体验。

这一阶段真正改变 hobby 的，不只是“网上也能看照片”。摄影 Web 开始把原先分散在杂志、商店、影友家、二手市场和比赛中的多个状态放到相邻页面：

```text
看器材资料
→ 搜真实用户经验
→ 上传作品
→ 看别人批评
→ 搜镜头/胶卷/冲洗经验
→ 去二手区找机器
→ email / 电话继续交易
→ 再回论坛发片
```

### 4.1 二手市场让昂贵兴趣更可逆

色影无忌现存的《无忌二手交换论坛规则》标注日期为 **2001-10-05**，明确说设立论坛是为了让影友“互通有无”、盘活积压资金；要求出售者写成色、序列号、价格、说明，鼓励图片，并建议有购买意向后用 E-mail 和电话私下联系，鼓励当面交易。

- <https://www.xitek.com/commonfile/exchange.htm>

证据等级：**A-like publisher-retained historical rule page**。

这使 **secondhand reversibility / 二手可逆性** 成为摄影兴趣能否深入的重要变量：

```text
买错镜头 / 想升级
如果旧器材只能长期压在家里
→ 每次尝试都是较难逆转的大额支出

如果存在全国可发现的二手买家
→ 旧器材更容易变回现金
→ 升级 / 换系统 / 试错成本下降
```

2003 年蜂鸟论坛一条仍在线的二手帖中，卖家后来回帖称自己的 Sony F707 已在另一个网站以 4400 元成交。这个 current live legacy page 可以证明当时论坛用户确实把多个网站当作同一二手市场的一部分，但不能独立证明支付、交货与验收每一步。

- 蜂鸟论坛，2003-10-12：<https://bbs.fengniao.com/forum/80236.html>

### 4.2 2004：一个新手已经可以“先泡论坛，再买二手胶片单反”

2004 年蜂鸟论坛帖子《写给入门的新鸟——关于购买二手器材》中，作者自述自己也是入门者，在长期关注蜂鸟与无忌后，决定买传统单反 Nikon F80，并通过二手交易论坛看到天津网友的出售帖。

- 蜂鸟论坛，2004-09-24：<https://bbs.fengniao.com/forum/194668.html>

证据等级：**B/A-like（当前平台遗留页面承载同时代第一人称）**。

这个个案不能代表所有新手，却足够证明一种新路径已经可执行：

```text
没有本地熟人带路
→ 长期阅读全国论坛
→ 建立器材判断
→ 跨城市发现二手商品
→ 再通过现实交易获得第一套系统
```

Internet 在这里减少的不是“按快门”的劳动，而是 **entry knowledge + market radius / 入门知识与市场半径**。

## 5. 2005—2012：扩张型未来——无限快门与“器材注意力跑步机”一起出现

### 5.1 数码相机真正消掉的是“每张都要再花胶卷钱”，不是摄影成本本身

2009 年初的年度市场盘点称，2008 年中国数码相机市场规模约 880 万台，同比增长约 16.6%。

- 新浪数码/中关村在线，2009-01-20：<https://tech.sina.com.cn/digi/dc/2009-01-20/07042765180.shtml>

证据等级：**B（同期行业报道）**。

随着存储卡可反复擦写、照片可立即回看，摄影发生一个结构变化：

```text
胶片：每按一次快门增加材料成本 + 延迟反馈
数码：一次购买设备/存储以后，单张边际成本趋近于零 + 即时反馈
```

这可以称为 **capture abundance / 捕捉丰裕**。

但“无限快门”带来新的劳动：

- 拍摄数量暴增；
- 导入电脑；
- 筛选；
- 文件夹命名；
- RAW/JPEG 处理；
- 硬盘备份；
- 上传论坛；
- 后来又要迁移硬盘与格式。

也就是 **curation debt / 整理债务**：拍摄越来越便宜，选择、保存和找回越来越贵。

### 5.2 2008 第一人称：Internet 让资料更多，也可能让兴趣从“拍照片”滑向“等新器材”

蜂鸟论坛 2008 年帖子《清理旧照，感慨万千，要想解毒，请看此篇！！》留下非常强的同时代第一人称。

作者回忆读书时没钱买摄影书，于是把学校附近书店里摄影相关书籍大量站着读；当时主要想着怎样拍好照片。几年后电脑联网，他不再像过去那样买书，却开始天天关注器材论坛和 5D2、50D、D90 等尚未发布/刚传闻的新机器消息，并反省自己越来越把注意力放在升级器材上。

- 蜂鸟论坛，2008-08-27：<https://bbs.fengniao.com/forum/952944.html>

证据等级：**B/A-like（当前 live legacy page 承载 2008 同期第一人称）**。

这给兴趣互联网史增加一个非常重要的反例：

```text
information abundance
≠
practice attention automatically improves
```

Internet 降低知识稀缺的同时，也制造 **gear-attention treadmill / 器材注意力跑步机**：

```text
新机传闻 → 参数比较 → 论坛争论 → 发布 → 评测 → 降价 → 下一代传闻
```

一个爱好者的有限晚上可以从“读书、拍摄、冲印/后期”转移到“追新品信息”。这不是摄影特有，PC DIY、Hi-Fi、耳机、骑行和模型都可能出现同类机制。

### 5.3 同期反例：Internet 也能让没钱买书的人第一次拥有持续可问的同行网络

同一批论坛材料里又不能只写“论坛让人器材党化”。2008 年色影无忌一个镜头讨论帖中，用户称自己新买了一只二手腾龙 28-75/2.8，因为评测资料不多而开帖，请大家共同讨论、学习；帖子后来形成大量回复与样片。

- 色影无忌，2008-05-22：<https://forum.xitek.com/thread-528435-1-1.html>

所以 Web 同时存在两种相反效果：

- 降低学习/提问门槛；
- 增加消费与升级注意力。

不能预先决定哪一个对某个人更重要。

## 6. 摄影与“未来想象”：它不直接改写婚育脚本，却能制造另一条个人时间线

摄影这个案例提醒 Life Horizons：不是所有未来都表现为“几年后我要买房/结婚/考证”。

兴趣也会产生长期项目：

```text
今年先买入门机
→ 明年学后期
→ 有空去一次远途拍摄
→ 工作以后换镜头
→ 有孩子以后开始长期拍娃
→ 中年重新旅行
→ 退休以后有整块白天拍鸟 / 扫街
```

这些计划可能从来不会写进正式简历，却能跨过几十年。

### 6.1 摄影器材也可以被人生阶段重新解释

同一个相机在不同阶段可能是：

- 学生时期昂贵梦想；
- 第一份工资后的奖励；
- 旅行工具；
- 婚后家庭记录工具；
- 有孩子以后拍娃设备；
- 中年重新获得个人周末的入口；
- 退休后需要连续时间的新生活中心。

因此 hobby horizon 与 adulthood horizon 不应完全分开。

## 7. 2015—2019：拥堵型未来——手机没有简单“杀死摄影”，而是把设备选择变成组合

2019 年摄影论坛已经能看到同一个影友/同一组长期拍摄中混用手机和多种相机。一个 ZOL 摄影论坛帖子记录 2019 年 5—10 月的拍摄，EXIF/页面字段同时出现 OPPO R9s、Sony NEX-6、Sony A7、Fujifilm X-E2 等设备。

- ZOL 摄影论坛：<https://bbs.zol.com.cn/dcbbs/d31_51366.html>

证据等级：**B/A-like current live legacy page with contemporaneous image metadata**。

这里更合理的变化不是：

`相机 → 手机取代`

而是：

```text
手机：一直在身边、快速记录、快速分享
+
相机：特定画质、镜头、操作和仪式
→ device portfolio / 设备组合
```

另一个 2019 年年终回顾帖里，一名学校教师按月份整理全年校园影像，使用 Canon 70D、1D Mark IV 等较老机型；页面签名写“做喜爱的事情，充实生活乐趣”。

- ZOL 摄影论坛，2019-12：<https://bbs.zol.com.cn/dcbbs/d298_40492.html>

这类材料很适合反驳“摄影 hobby = 每年追新机”：旧机器、工作场景和长期记录完全可以共同维持一套稳定兴趣。

### 7.1 2019 论坛本身也已经进入移动时代

摄影论坛里开始大量出现手机 EXIF、手机摄影版、App 和跨设备发帖。也就是说老 Web 没有简单消失，而是在 2010s 后被移动端重新包裹。

这对 old-Web 研究意味着：

```text
论坛品牌仍活着
≠
用户仍以 2005 年那种桌面浏览器方式进入论坛
```

平台连续性与使用环境连续性必须分开。

## 8. 2020—2022：偶发型未来——当移动半径骤缩，摄影仍能继续，但对象被迫迁回家庭内部

2020 年 3 月，色影无忌与合作方发起“宅家的幸福时光”摄影月赛，明确引导参与者在居家时期拍摄饭菜、孩子、父母、全家福等家庭场景，并要求通过网站专区或论坛上传数字作品，不接受邮寄实物照片。

- 色影无忌，2020-03-20：<https://vision.xitek.com/news/202003/20-344444.html>

证据等级：**A/B（同期平台活动页）**。

这不是总体摄影行为调查，但它构成一个很清楚的 continuity stress test：

```text
相机/手机还在
论坛/上传还在
后期软件还在

但
远途旅行 / 街拍 / 线下聚会 / 摄影活动场地
可能突然不可执行
```

于是 hobby 并未必消失，而是发生 **subject-space contraction / 题材空间收缩**：摄影从旅行、城市与活动现场被迫转回窗户、房间、家人和日常物品。

2022 年中国青年报关于疫情后上海青年生活方式的同期采访还观察到，一些年轻人开始把过去随手消耗的时间用于培养兴趣，让平淡生活更有意义。

- 中国青年报，2022-08-16：<https://zqb.cyol.com/html/2022-08/16/nw.D110000zgqnb_20220816_4-07.htm>

这不是摄影专门样本，因此只作为更宽的兴趣时间背景，不用来推断摄影人数变化。

## 9. 2023—2026：防守型未来里出现一个看似反常的变化——主动买回“有限、慢、不能立即修正”

### 9.1 2024：有人愿意重新支付非常明确的“每张成本”

《中国经济周刊》2024 年同期采访一名 90 后摄影爱好者：他花近 4000 元购买 1970s 型号的宝丽来 SX-70；配套相纸每盒 8 张，价格 120 元以上。

- 《中国经济周刊》，2024-04-15：<https://paper.people.com.cn/zgjjzk/html/2024-04/15/nw.zgjjzk_20240415_1-06.htm>

证据等级：**B（同期媒体第一人称）**。

这意味着数码摄影已经把“单张边际成本”几乎压平二十年以后，一部分年轻人又主动购买：

- 有限张数；
- 不可无限重拍；
- 立即生成但无法像手机那样任意后期的实体相纸；
- 更高的单张成本；
- 旧设备的不稳定性。

可称为 **intentional friction / 主动摩擦**。

它不是倒退，也不能解释成“年轻人拒绝数字化”。相反，它只有在手机、云相册和无限拍摄已经成为背景基础设施后，才会把“有限、等待、实体”重新体验为一种有意义的差异。

### 9.2 2025—2026：摄影又从“器材兴趣”向旅行程序、社交表达和即时实体纪念扩散

2025 年中国青年报一项 1333 人青年样本调查中，87.6% 的受访者报告曾为了“出片”专程打卡；报道同时采访了会预约旅拍摄影师、会把照片作为旅行记忆和社交表达的人，也采访了认为过度追求出片会损失旅行体验的青年。

- 中国青年报客户端，2025-05-08：<https://news.youth.cn/gn/202505/t20250508_15988687.htm>

这个样本不能外推全国青年，但它说明拍照开始反过来组织真实行动：

```text
不是“到了一个地方顺便拍照”
而可能是
“因为希望得到某种照片 → 选择地点 / 衣服 / 时间 / 摄影师 / 路线”
```

可称为 **photo-directed mobility / 出片导向移动**。

到 2026 年，中国青年报又记录“人生四格”、拍报机、即时打印照片等玩法。数字影像已经无处不在以后，一部分年轻人仍愿意为一次现场、可拿走的实体照片保留仪式感。

- 中国青年报，2026-07-18：<https://news.youth.cn/sh/202607/t20260718_16770929.htm>

因此“防守型未来”不能自动等同于“兴趣全面收缩”。有些人在大目标上更谨慎，却仍会保护一小块明确可兑现、当下就能产生快乐和记忆的预算。

## 10. 海外对照：摄影网络社区的出现早于中文大众 Web，而且同样把技术、作品与市场叠在一起

1997 年的 Usenet `rec.photo.*` FAQ/guide 今天仍可读取，它列出的新闻组已经细分为：

- `rec.photo.misc`；
- `rec.photo.marketplace`；
- `rec.photo.darkroom`；
- `rec.photo.film+labs`；
- `rec.photo.equipment.35mm`；
- `rec.photo.technique.misc` 等。

- 1997-07-18 版本：<https://www.mat.uc.pt/~rps/photos/pointer.html>

证据等级：**A/B（同时代 Web 保存的 Usenet 资源指南）**。

这证明至少在 1990s 中期，海外摄影网络已经把：

```text
暗房技术
+ 胶片/冲洗
+ 器材
+ 技法
+ 二手市场
```

变成主题化、跨地域的信息空间。

Photo.net 则在 1993 年从个人主页起步，后来形成图片上传、评论、器材讨论和分类广告等社区功能；2007 年收购公告称其已有约 60 万注册用户和 250 万以上用户上传图片。

- 2007 同期收购报道：<https://photographybay.com/2007/10/23/namemedia-acquires-photonet/>

因此中国并不独有“摄影论坛把小众玩家聚成市场”的机制。可比较的共同变化是：

**本地摄影师/店家/杂志编辑掌握的稀缺知识，逐渐变成跨地域可搜索、可反驳、可积累的 peer knowledge。**

中国特有或至少需要本地化研究的部分，则包括具体摄影杂志体系、国产相机/胶卷产业、城市摄影市场、中文论坛平台谱系、网吧/家庭宽带普及时序和本地二手交易习惯。

## 11. 摄影比 Hi-Fi 更能暴露一种特殊的历史可见性偏差：爱好本身就是“制造史料”

Hi-Fi 玩家留下器材帖，摄影爱好者则会直接留下大量图像。因此摄影看起来可能比别的兴趣“历史证据特别多”。但这是假象的一部分。

### 11.1 image survival ≠ original survival

论坛缩略图可能仍在，原图可能已丢；外链图床可能死掉；重新压缩的 JPEG 可能没有原 EXIF。

### 11.2 visible photograph ≠ complete life

最容易留档的是：

- 好看的作品；
- 获奖照片；
- 精华帖；
- 长期坚持者。

最难留下的是：

- 拍糊的胶卷；
- 买相机两个月就放弃的人；
- 从不发论坛的普通家庭；
- 硬盘坏掉的一整段年份；
- 只存在 QQ 群/私聊的看片交流；
- 没钱冲出来的底片；
- 相册被搬家丢掉的家庭。

这可以称为 **successful-image bias / 成功影像偏差**。

### 11.3 数字 abundance 反而可能让未来研究者更难知道“哪些照片真正重要”

胶片时代一户人家只有几本相册时，精选机制往往由成本天然完成；手机时代几万张照片都可能留在云端。

于是未来历史学家可能面对：

```text
史料数量极大
但语境、筛选理由、观看频率和情感权重极难恢复
```

也就是 **archive abundance / meaning scarcity——档案丰裕、意义稀缺**。

## 12. 它改变了我们对“人怎么活着”的哪一点理解

摄影这个案例说明，兴趣生活不是从“穷的时候没有 → 富起来以后有”这么简单。

一项 hobby 可以连续经历：

```text
胶片：曝光稀缺、反馈慢、实体归档
→
数码：快门丰裕、即时反馈、电脑整理
→
论坛：全国同好知识、器材比较、二手可逆
→
手机：相机随身化、分享即时化
→
社交平台：照片开始反过来组织旅行和自我展示
→
复古摄影：一部分人主动买回有限张数、等待与实体感
```

最值得保留的结论不是“哪种摄影更真实”，而是：

> **技术每消灭一种摩擦，就可能暴露另一种新的稀缺。**
>
> 胶片时代稀缺的是快门、冲洗和反馈；数码时代稀缺的是筛选和存储；论坛时代稀缺的是注意力与可信经验；手机时代稀缺的是从海量照片里制造“值得留下的一张”；而当这一切都变得过于容易以后，一部分人甚至愿意重新花钱购买限制本身。

这使 hobby life world 成为 Life Horizons 的一个真正独立维度：人不只规划“我几年后成为什么”，也在持续规划“我还想保留什么样的周末、什么样的观看方式、什么样的记忆”。

## 13. 已知、可推断与未知

### 已知

- 1990s 中国胶片摄影基础设施和国产相机产业仍然活跃，1998 数码相机销量仍很小；
- 2001—2004 中文摄影 Web 已能把器材知识、作品、二手交易和跨城用户联系连接起来；
- 2008 同期第一人称明确记录 Internet 使一名摄影爱好者从读摄影书转向高频关注器材论坛与新品传闻；
- 2019 摄影论坛已经能容纳手机和多种相机共同作为摄影设备；
- 2020 居家限制能够改变摄影对象和活动半径而非自动终止 hobby；
- 2024—2026 存在年轻人主动购买老相机、胶片/即时相纸和实体照片体验的同期证据。

### 可合理推断

- 数码摄影把相当一部分成本从“每张胶卷/冲印”转移到设备、电脑、存储和整理；
- 摄影论坛增加了器材试错的可逆性和知识可搜索性；
- 手机更像给摄影增加一个常驻入口，而不是简单消灭所有独立相机使用；
- 在无限数字照片已成为默认背景以后，“有限、慢、实体”可以被重新消费为一种体验。

### 仍未知 / 下一轮应补

1. 1985—1998 普通城市/农村家庭相机拥有率、胶卷与冲印价格，需要更好的统计年鉴/商业调查；
2. 1990s 一名普通工薪摄影爱好者一年实际拍多少卷、花多少钱，当前缺高质量连续账本/日记；
3. 2000—2010 色影无忌/蜂鸟的历史 WARC、DOM、图片主机与 EXIF 解析行为尚未完成 M1 级验证；
4. 数码时代个人硬盘/光盘/刻录盘的照片丢失率很难从公开资料估计；
5. 2015—2019 需要更多“工作、婚育、搬家如何让摄影中断/转型”的同期第一人称，而不是只看器材论坛；
6. 2023—2026 胶片/CCD/拍立得复兴中的参与者，到底有多少会形成长期 hobby、多少只是短期潮流，目前不能从搜索热度直接推出。
