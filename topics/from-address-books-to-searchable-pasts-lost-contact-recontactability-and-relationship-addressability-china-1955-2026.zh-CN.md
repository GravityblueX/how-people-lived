# 从地址簿到“可检索的过去”：同学、旧友、失联与关系可寻址性（中国，1955–2026）

> 核心问题：一个普通人离开学校、换工作、搬城市、结婚改姓、换电话、换邮箱或十几年没有联络以后，旧关系还剩下多少“重新找到彼此”的可能？邮政地址、固定电话、纸质通讯录、校友会、ChinaRen、校内/人人、QQ/微信怎样把“过去认识的人”从记忆中的对象逐渐变成可检索、可重连、也可以主动删除的社会地址？

## 0. 去重：这不是“电话史”“电子邮件史”或“SNS 史”的另一份版本

本仓已经有：

- `telephone-household-reachability-number-identity-and-contact-state-china-1980-2026.zh-CN.md`：研究电话号码怎样从地点/家庭地址变成个人地址，再硬化成身份键；
- `electronic-mail-portable-address-webmail-formal-inbox-and-institutional-reachability-china-1986-2026.zh-CN.md`：研究 email 地址和高后果收件箱；
- `stranger-life-scripts-forums-peer-advice-and-alternative-life-course-visibility-china-1980-2026.zh-CN.md`：研究陌生人的人生路线怎样变得可见；
- `personal-homepages-self-publishing-and-platformed-public-identity-china-1980-2026.zh-CN.md`：研究公开自我与平台身份；
- 迁移、租房、找工作、同居/独居等专题已经讨论“离开原地点”本身。

这些专题多数研究：

> **一个通信地址怎样指向人。**

本专题补的是另一层：

> **当原通信地址已经失效时，过去共同经历过某段人生的人，能不能再次变成彼此可寻址的对象。**

因此研究单位不是某一种通信工具，而是 **relationship addressability / 关系可寻址性** 与 **recontactability / 重新联系可执行性**。

它关心的是一条关系跨几十年的状态变化：

```text
共同生活/学习/工作
→ 离开共同场所
→ 日常联系减少
→ 联系方式失效/关系休眠
→ 是否仍有可搜索锚点
→ 是否能重新确认“这就是那个人”
→ 能否发出消息
→ 对方是否仍使用该通道
→ 是否愿意回应
→ 关系是否真正恢复
→ 或者双方决定继续保持距离
```

所以必须固定：

```text
contact information exists ≠ person is reachable
person is reachable ≠ person is discoverable after losing the address
discoverable ≠ correctly identified
identified ≠ message seen
message seen ≠ reply
reply ≠ friendship restored
platform connection ≠ current relationship
```

## 1. 本轮新增的几个机制

### 1.1 relationship addressability：关系可寻址性

一个人可以清楚记得某位小学同学，却完全不知道她现在住哪里、姓什么、在哪工作。

“认识过”与“今天能找到”之间需要一套地址系统。

这种地址可以是：

- 家庭/宿舍地址；
- 单位地址；
- 固定电话；
- 纸质通讯录；
- 校友会掌握的联络方式；
- email；
- QQ 号；
- 学校 + 入学年份 + 班级；
- 实名/半实名 SNS 资料；
- 微信联系人或群组。

### 1.2 biographical-anchor indexing：生平锚点索引

Internet 以前，要找一个失去联系方式的人，常常必须知道她**现在在哪里**，或找到仍与她有联系的共同熟人。

校友录/SNS 出现后，可以倒过来：

```text
我不知道她现在住哪
但我知道：
学校 = X
入学年 = Y
班级/院系 = Z
```

这些已经结束的共同经历，变成一种长期检索键。

这叫 **biographical-anchor indexing / 生平锚点索引**：

> 人不再只能通过“当前地址”被找，也可以通过“过去共同走过哪一段人生”被找。

### 1.3 accidental loss-of-contact risk：偶然失联风险

关系结束与联系方式失效不是同一件事。

过去一段关系可能只是因为：

- 搬家；
- 单位调动；
- 电话换号；
- 邮件地址停用；
- 毕业后分散；
- 共同联系人断裂；

而进入休眠。

可检索校友录和社交图谱降低的是其中一部分 **accidental loss-of-contact risk**，不是自动提高感情质量。

### 1.4 recontactability as life-course optionality：重新联系也是人生 optionality

一个人在 25 岁离开学校时未必知道：

- 35 岁是否需要找回老同学；
- 40 岁是否回到旧行业；
- 50 岁是否参加同学会；
- 某次迁移、照护或危机时是否会重新需要旧关系。

如果旧关系仍可重新寻址，就保留了一种未来选择：

> **今天不联系，不等于以后永远无法联系。**

这是一种社会关系层面的 optionality。

### 1.5 contact persistence / relational persistence gap：联系方式持续与关系持续的缺口

数字平台第一次让一个很常见、但以前不容易观察的状态变得特别明显：

```text
联系人还在
群还在
账号还在
头像还在
聊天记录还在
```

却同时：

```text
多年无互动
不了解彼此现在生活
没有现实互助
甚至不愿继续联系
```

所以：

> **contact persistence can outlive relational persistence.**

### 1.6 social-graph overhang：社交图谱残留

当平台关系不再随着现实关系自然消失，用户会积累：

- 小学同学；
- 中学同学；
- 大学同学；
- 前同事；
- 一次活动认识的人；
- 已经停用账号的人；
- 单向删除关系。

这些记录构成 **social-graph overhang / 社交图谱残留**。

早期 Internet 的问题是“怎么把失联的人找回来”；成熟平台的另一个问题则变成：

> **哪些旧关系还值得继续占据自己的可达空间？**

### 1.7 boundary-maintenance labor：关系边界维护劳动

于是维护社会关系不再只有“记得更新地址”，还包括：

- 备注；
- 分组；
- 群消息免打扰；
- 退出群聊；
- 删除联系人；
- 区分工作号/私人号；
- 判断陌生“老同学”请求是真是假。

这不是说“现代人变冷漠”，而是关系可寻址性增强以后产生的一种新维护劳动。

## 2. 前互联网基线：离开共同地点，很容易同时离开共同通信网络

### 2.1 1978：不要把固定电话想成普通家庭的默认基础设施

国家统计局后来汇总的通信史数据记录：1978 年全国固定电话用户约 **192.5 万户**，当时全国人口约 9 亿；全国局用交换机容量约 406 万门。

Source:
- 国家统计局，《光辉的历程 宏伟的篇章》，2009（后期官方统计汇编）：https://www.stats.gov.cn/zt_18555/ztfx/qzxzgcl60zn/202303/t20230301_1920380.html
- 国家统计局，《改革开放30年报告之十三：邮电通信业在不断拓展中快速发展》：https://www.stats.gov.cn/zt_18555/ztfx/jnggkf30n/202303/t20230301_1920472.html

Evidence: **A/C boundary — 官方历史统计汇编；数字来自官方长期序列，不是 1978 当年新闻。**

这提醒我们：一个 1970s/early-1980s 的普通毕业生不能默认“互相留手机号/家里电话”。

可执行的关系维持更可能依赖：

- 家庭或单位邮寄地址；
- 单位总机；
- 少量家庭/公共电话；
- 班级通讯录；
- 校友会；
- 共同熟人。

### 2.2 纸质同学录/通讯录是“未来还能找到你”的人工索引

2014 年广西媒体征集旧同学录时，记录了多个后来回忆：

- 一名 1955 年初中毕业者保存同学录数十年，却称很多同学已经几十年没有联系；
- 一名 1971 年毕业者回忆，当年主要留下“通讯录”式联络方式；
- 一名 1986 年大学毕业者仍保存当年的同学录；
- 一名 1998 年中专毕业者所在学校已经统一印制带照片、基本资料和留言的毕业同学录。

Source:
- 广西新闻网/中新网，2014-04-28：https://www.chinanews.com.cn/edu/2014/04-28/6111540.shtml

Evidence: **C — 后来回忆 + 实物展示；适合证明纸质同学录长期存在及个人经验，不用于估算全国普及率。**

这里最重要的不是怀旧，而是一个状态差异：

```text
record retained ≠ address still current
```

纸可以活几十年，但纸上的住址、单位和电话未必活几十年。

### 2.3 邮政编码不是“人的 ID”

1978 年起中国在部分地区试行邮政编码，1980 年全国推行后曾中断，1986 年重新推广。2008 年的历史报道采访老邮政人员和居民，回忆更早时期主要依靠文字地址、熟悉投递区的邮递员和人工分拣。

Source:
- 《新京报》，2008-11-13，经新浪保存：https://news.sina.com.cn/c/2008-11-13/092116645846.shtml

Evidence: **C/B — 2008 年采访回顾 + 制度史。**

邮编提高的是**地点路由效率**，并没有解决：

> 人搬走以后，我怎样知道她的新地点？

所以前互联网的核心结构仍然是：

```text
person → last known place → forwarding / mutual contact / alumni organization → maybe person
```

而不是今天的：

```text
person name / school / old cohort → searchable platform → candidate profiles
```

## 3. 1999–2005：校友录第一次把“已经结束的共同生活”做成可搜索基础设施

### 3.1 1999–2001：ChinaRen 的同学录已经是明确产品

2001 年新浪科技在报道 ChinaRen 创始团队变化时回溯：ChinaRen 由陈一舟、周云帆、杨宁于 1999 年创办，其社区和同学录在大学生群体中已有较高知名度。

Source:
- 新浪科技，2001-03-04：https://tech.sina.com.cn/i/c/56262.shtml

Evidence: **B — 同时代行业报道。**

它能证明：最迟到 2001 年，面向学生/校友的在线同学录已经是中文 Web 的显著产品形态之一。

它不能证明：

- 全国大学生都在使用；
- 每个注册账号都是真实校友；
- 平台公布的用户规模都经过独立审计。

### 3.2 2005：真正改变的是“班级散了，但班级信息空间不一定散”

2005 年《解放日报》报道多个网上班级。

其中：

- 复旦大学新闻学院一个硕士班在同学分赴全国实习后，在 ChinaRen 建立同学录，班会/通知开始转移到线上；
- 一名武汉大学 1996 级毕业生在甘肃酒泉工作，报道引述他称，毕业五年来网上同学录让分散各地的同学仍保持联络。

Source:
- 《解放日报》，2005-03-18，经新浪保存：https://news.sina.com.cn/s/2005-03-18/09105394097s.shtml

Evidence: **B + contemporaneous first-person quotation。**

这条材料很重要，因为它不是“某网站有同学录按钮”，而是保存了行为整合：

```text
同一地点的班级
→ 实习/毕业后地理分散
→ 共同在线班级仍作为通知/留言/互动空间
```

Internet 在这里没有取消迁移，却降低了迁移造成的**班级通信断裂**。

### 3.3 2005：同学录与 IM 开始互通

搜狐 2005 年介绍搜Q 3.0 与 ChinaRen 校友录结合时，明确描述了“找同学”和“找班级”两个入口，并指出 ChinaRen 原有某些找同学功能带有手机绑定条件，而搜Q入口调整了相关限制。

Source:
- 搜狐，2005-03-01：https://news.sohu.com/20050301/n224481302.shtml

Evidence: **A/B boundary — 平台/产品同期材料；可证明平台如何描述功能，不把宣传效果当用户普及事实。**

这说明 recontactability 已经开始形成多层栈：

```text
school/class index
→ candidate person
→ account
→ IM presence/message
```

但仍要拆开：

```text
found in directory ≠ online now
online ≠ message seen
message seen ≠ willing to resume relationship
```

## 4. 2007–2010：扩张型未来里的一个重要承诺——“各奔东西以后还能找到彼此”

### 4.1 2007：ChinaRen 把班级动态、隐私和富媒体继续叠到旧同学录上

2007 年 ChinaRen 改版的同期平台材料称，2006 年起其页面从 table 布局转向 DIV+CSS，并大量采用 Ajax；2007 新版又增加班级动态、相册、资料隐私设置以及博客互通。

Source:
- 搜狐/ChinaRen 同期产品材料，2007-03-02：https://www.sohu.com/a/307988831_120136162

Evidence: **A（participant source）** 对“平台当时这样描述产品”成立。

注意：同页给出的注册用户、班级数量、日访问量属于平台自报，本专题**不将其当独立普及率证据**。

历史意义在于：

> 同学录开始从一张“在线通讯表”变成持续更新的班级状态流。

这也意味着 recontactability 开始依赖平台持续保存：

- 账号；
- 班级成员关系；
- 动态；
- 隐私状态；
- 外部博客/空间关系。

### 4.2 2008：学校自己也开始把“更新未来联系方式”制度化

同济大学校友总会 2008 年写给毕业生的公开信非常适合作为状态模型证据。学校要求毕业生：

- 在校友网注册；
- 查找自己的班级；
- 班级已经存在时申请加入，由班级管理员审核；
- 班级不存在时可以申请创建；
- 班级社区提供通讯录、留言、相册和管理；
- 毕业后及时更新自己的新联系方式；
- 班级管理员还可以把汇总通讯录通过传真或 email 提交校友总会。

Source:
- 同济大学校友总会，2008-07-01（信件落款 2008 年 6 月）：https://www.tongji.edu.cn/info/1032/1899.htm

Evidence: **A — 同时代学校官方流程。**

这里出现一个非常重要的新状态：

### **institutionalized recontactability / 重新联系的制度化**

学校不再只在毕业时给一张纸，而是试图维持一个长期更新的校友地址层。

同时，状态链不能偷懒：

```text
school page exists
≠ class exists
class exists
≠ user joined
join requested
≠ approved
approved
≠ contact data current
contact data current
≠ old classmate has permission to see it
visible
≠ person wants contact
```

### 4.3 2008：数字同学录没有立刻消灭纸质冗余

同年西南交通大学向 5212 名本科毕业生发放毕业纪念册，其中仍包含“同学录”和“通讯录”版块。

Source:
- 西南交通大学，2008-06-04：https://lixue.swjtu.edu.cn/info/1032/3592.htm

Evidence: **A — 同时代学校记录。**

这是一个必要反例：

> Web 校友录已经存在多年，纸质通讯录仍然值得学校统一制作。

因此不要写成：

```text
纸通讯录 → Internet 出现 → 纸消失
```

更接近现实的是：

```text
纸质冗余
+ 电话/SMS
+ email/QQ
+ Web 同学录
```

多条联系路径长期共存。

### 4.4 2008：校内网把“过去单位/学校”变成可搜索锚点

2008 年《IT时报》的同期报道记录，陈一舟向记者演示校内网的“找同事/同学”能力：通过筛选记者的工作单位和毕业院校，很快找到了其一名大学同班同学。

Source:
- 《IT时报》，2008-04-07，经中国诚通转载：https://www.cctgroup.com.cn/cctgroup/2008-04/08/article_2025052219401374993.html

Evidence: **B + participant demonstration。**

这不是对搜索成功率的系统测试，但能证明当时的产品想象：

```text
current phone/address unknown
+ old institution known
→ searchable candidate person
```

这就是 **biographical-anchor indexing** 的典型形态。

### 4.5 2008 第一人称反例：电话仍然打得通，关系却已经变了

《中国青年报》2008 年第一人称文章记录：作者与同班“师兄”毕业后分别去了北京和上海，联络逐渐减少；离开校园第三年，她仍以为感情不会因距离变淡，在需要帮助时直接打电话，却明显感到对方的互动方式已经与在校时不同。

Source:
- 中国青年报，2008-04-24：https://zqb.cyol.com/content/2008-04/24/content_2156881.htm

Evidence: **A/B — 同时代第一人称报刊文章；证明作者经验，不代表所有毕业生。**

这是本专题最重要的反例之一：

```text
phone number still works
≠ relationship state preserved
```

Internet 也无法修复这个缺口。

> **技术可以保存“还能找到”的可能，不会保存“我们还是当年的我们”。**

### 4.6 2008 的未来想象：毕业意味着去远方，但不再必然意味着永久失联

同济 2008 毕业信一边使用非常典型的扩张型未来语言——毕业生将去全国各地和海外、进入新的岗位和人生旅程——一边要求他们把新联系方式不断回写学校校友系统。

这形成一个很值得保留的同时代时间感：

```text
未来 = 地理扩张 / 职业展开
但过去的 cohort 不必因此完全断裂
```

它与今天“毕业后主动删掉很多同学”不是同一种未来语法，不能用今天的社交疲劳倒推 2008。

## 5. 从同学录到 SNS：旧关系从“班级页”变成个人社会图谱

### 5.1 班级是一个中介索引

典型早期校友录更像：

```text
学校
→ 入学年/年级
→ 班级
→ 成员
→ 通讯录 / 留言 / 相册
```

个人往往先属于班级，再由别人找到。

### 5.2 SNS 更接近个人中心的图谱

校内/人人等 SNS 则逐渐把：

- 学校；
- 年级；
- 工作单位；
- 好友；
- 个人动态；

同时挂到个人 profile。

因此“找同学”从：

```text
进入共同班级
```

逐渐变成：

```text
搜索/筛选个人
→ 加为好友
→ 直接进入个人关系图
```

这不是简单的页面升级，而是**关系索引模型变化**。

## 6. 2018–2019：拥堵型未来——“能找回来”逐渐变成“为什么还要一直留着”

### 6.1 2018 回顾性第一人称：人人网曾经让过去多个教育阶段重新连起来

2018 年人人网相关业务出售时，人民政协网的同期报道采访一名 2009 年大学毕业者。她回忆，自己从 2006 年开始使用校内网，后来曾在平台上找到失去联系的同学，看到小学、中学、高中、大学等不同阶段的旧关系重新出现在同一个平台。

Source:
- 人民政协网，2018-11-19：https://www.rmzxw.com.cn/c/2018-11-19/2220455.shtml

Evidence: **C/B — 2018 年对 2006–2009 使用经验的回顾性第一人称；适合研究记忆与功能，不用于精确重建当年页面。**

这里出现了一个变化：

> 同一个人过去不同阶段的 cohort，不再分散在几本纸通讯录或几个独立同学录里，而可以叠加到一个持续账号上。

### 6.2 2019 同时代第一人称：群还在，不等于同学关系还在

2019 年一篇第一人称文章写作者退出研究生同学微信群。她描述：多年后被拉进群，有旧同学打招呼、加好友，也有人从未互动；很多名字依然熟悉，却已经无话可说。

Source:
- 2019-07-26，经新浪财经头条保存：https://cj.sina.com.cn/articles/view/1829394383/6d0a57cf01900o91f

Evidence: **A/B — 当时的第一人称网络文章；只证明作者经验。**

这一次状态已经与 2005 网上班级几乎反转：

2005 的问题：

```text
大家散了，怎么避免班级也散？
```

2019 的问题可以变成：

```text
班级的数字容器没有散，但现实关系已经散了，是否还要留在里面？
```

因此拥堵型未来在关系层面表现为：

### **technical persistence > meaningful persistence**

平台能无限延长“联系人/群成员”状态，却不能替用户决定关系还值不值得维持。

## 7. 2020–2022：偶发型未来的自然实验——线上可达，并不足以保住共享场所产生的弱关系

本轮没有把中国疫情时期零散的“同学群”故事硬凑成全国结论，而选择一个可比较的海外研究。

2022 年 AERA Open 发表的美国大学生研究使用 2020 年 4 月调查和同年 9 月访谈，研究疫情早期社交网络变化。研究发现学生的人际网络总体连接数和角色多样性下降，尤其一些包含同事、同学和学术关系的网络模式消失或减弱。

Source:
- Smith et al., *Patterns of Undergraduate Student Interpersonal Interaction Network Change During the COVID-19 Pandemic*, AERA Open, 2022：https://doi.org/10.1177/23328584211073160

Evidence: **A — 同时代附近的同行评议研究，特定美国高校/学生样本；不是中国总体证据。**

它提供一个非常重要的跨国机制反例：

```text
everyone still has phones/accounts
+ online communication remains possible
≠ weak/contextual ties automatically persist
```

很多同学关系依赖的不是“对方是不是通讯录好友”，而是：

- 同一教室；
- 同一食堂；
- 同一实验室；
- 同一通勤路线；
- 偶然见面；
- 低成本小互动。

因此平台最容易保存**地址**，最难保存**共同情境**。

这说明：

> **shared-context continuity / 共同情境连续性** 是关系持续的另一种基础设施。

## 8. 2023–2026：防守型未来——从“尽量多留联系人”转向“选择哪些联系值得继续存在”

### 8.1 2024：平台第一次把“对方已经删了你”做成可计算的清理状态

2024 年多家科技媒体实测微信在联系人达到 10000 上限后出现清理逻辑，可以展示一批已单向删除/屏蔽关系，并辅助用户删除；测试材料还记录页面会使用添加时间/方式、最后联系、当前设备是否有聊天记录等信息辅助判断。

Sources:
- 搜狐科技经新浪保存，2024-10-24：https://finance.sina.com.cn/roll/2024-10-24/doc-inctriti2846011.shtml
- 相关后续报道引用腾讯客服解释，该功能用于在联系人达到上限时辅助用户腾出通讯录空间：https://www.thepaper.cn/newsDetail_forward_30174470

Evidence: **B — 同期媒体实测 + 客服说明。**

注意：10000 联系人的极端账号不是普通用户分布的代表。

真正有历史价值的是状态机本身：

```text
A still lists B
B has deleted/blocked A
→ asymmetric edge
→ platform detects/selects candidate
→ A may prune edge
```

数字社会关系因此不再只有：

```text
friend / not friend
```

而出现：

```text
mutual
one-way residue
inactive
rarely contacted
pruned
```

### 8.2 2025：“关系断舍离”成为一种可公开讨论的社交策略

2025 年《扬子晚报/紫牛新闻》围绕“删好友”采访/整理时，给出普通年轻人毕业后大规模清理同学、换工作后清理前同事，以及把工作号/私人号分开的案例和讨论。

Source:
- 紫牛新闻，2025-07-29：https://www.yzwb.net/news/wy/202507/t20250729_243177.html

Evidence: **B — 当期媒体重构/案例汇总；不能由这些例子推出“年轻人普遍如此”。**

它至少说明一种新的未来语法已经公开可说：

> 不是“我一定要永远保存所有旧关系”，而是“我可以主动决定哪些关系继续拥有即时进入我生活的入口”。

这就是 **selective recontactability / 选择性可重新联系**。

### 8.3 防守不等于“彻底断联”

防守型未来不是网络越小越好。

它更像：

```text
保留核心关系
+ 允许一部分 dormant ties 仍有重连可能
+ 对工作/临时关系设置边界
+ 删除失效/单向残留
+ 不让所有过去的人永久拥有同等实时可达权
```

因此关系 optionality 与边界之间存在张力：

```text
保留更多旧联系人
→ future recontact options ↑
→ notification / privacy / boundary maintenance ↑
```

## 9. 海外对照：这种变化不是中国特有，但平台形态和生命周期不同

### 9.1 美国 Classmates.com：1995 年就把学校变成“找回过去”的索引

CBS 2003 年报道 Classmates.com 时，创始人 Randy Conrads 回忆网站始于 1995 年，初衷是帮助人重新联系青年时期的旧友。报道还记录一个跨 50 年失联的家庭，最终通过学校旧同学网络重新建立联系。

Source:
- CBS News, 2003-05-05：https://www.cbsnews.com/news/in-search-of-the-past-05-05-2003/

Evidence: **B + participant interview / case report。**

CBS 同页引用的会员规模主要来自公司/报道口径，不作为本专题跨国普及率比较的硬数字。

共同机制很清楚：

```text
current address unknown
→ school cohort known
→ platform index
→ old peer as routing node
→ person found
```

这与 ChinaRen/校友录的 **biographical-anchor indexing** 高度相似。

### 9.2 英国 Friends Reunited：能把过去找回来，也会制造平台自己的“过期地址层”

2005 年 Guardian 报道 Friends Reunited 有约 1500 万注册用户，并以寻找旧校友为主要用途之一。

Source:
- The Guardian, 2005-12-07：https://www.theguardian.com/media/2005/dec/07/itv.citynews

Evidence: **B — 同时代高质量新闻；规模口径依赖公司披露。**

到 2016 年网站关闭时，创始人公开承认：大量注册者十多年前加入，联系方式已经过期；用户可能仍能在站内“看到这个人”，却联系不到。

Sources:
- Sky News, 2016-01-18：https://news.sky.com/story/friends-reunited-to-close-after-17-years-10135649
- The Guardian, 2016-01-18：https://www.theguardian.com/technology/2016/jan/18/friends-reunited-website-closes-after-15-years

Evidence: **B + participant closure statement。**

这提供了一个特别好的反例：

### **indexed ≠ reachable**

平台可以长期保存“某人曾经属于某所学校”的 profile，却无法自动保证：

- 她仍读这个 email；
- 她仍拥有这个电话；
- 她还记得密码；
- 她仍愿意被找到；
- 平台本身还能活着。

因此 recontactability 自己也有维护成本。

## 10. 一个更完整的历史变化：不是“人越来越联系紧密”，而是失联的原因改变了

可以暂时把长期变化写成：

### 阶段 A：地点/组织路由

```text
知道家庭/单位地址
→ 寄信/打单位电话
→ 由家庭/同事/邮政人员继续路由
```

典型失败：搬家、调动、地址过期。

### 阶段 B：个人联系方式

```text
固定/移动电话、email、QQ
→ 直接联系个人
```

典型失败：换号、账号停用、忘记通知。

### 阶段 C：生平锚点检索

```text
学校/年级/单位
→ 搜索平台
→ 找到候选账号
→ 重新建立联系
```

典型失败：资料虚假、同名、账号废弃、平台死亡。

### 阶段 D：持久社会图谱

```text
关系建立一次
→ 联系人/群长期保留
→ 低成本重新激活
```

典型失败不再只是“找不到”，也包括：

- 不想回应；
- 关系已经改变；
- 旧图谱过量；
- 边界需要重新清理。

所以历史不是：

```text
失联 → Internet → 永不失联
```

而是：

```text
物理失联风险下降
→ 可检索的 dormant ties 增加
→ 平台/账号过期成为新失联点
→ 技术连接持续时间开始长于真实关系
→ 用户需要主动维护边界
```

## 11. 这怎样改变“普通人有多少种活法”

### 11.1 迁移的社会不可逆性下降了一部分

如果离开家乡/学校意味着旧人际关系几乎无法恢复，那么迁移更接近一次强断裂。

如果：

- 旧同学可以再搜索；
- 校友会可以再路由；
- 老群仍存在；
- 账号仍可留言；

那么迁移在社会关系上增加了一些可逆性。

但只能写“一些”，不能写 Internet 消灭了迁移成本。

### 11.2 “今天不维护”与“永远失去”之间出现了中间状态

数字关系提供一种新的 holding state：

```text
dormant but recontactable
```

双方五年不说话，也可能仍有重新找到彼此的路径。

这是一种以前更昂贵的状态。

### 11.3 人生阶段不必各自封箱

小学、中学、大学、第一份工作、迁移城市等 cohort 以前可能各自装在不同纸本和记忆里。

持续账号让一个人的过去多个阶段叠在同一社会图谱中。

这扩大了：

- reunion；
- 求助；
- 信息交换；
- 工作/迁移时重新调用旧关系；

的可能。

但也同时扩大：

- 过去关系跨语境进入现在；
- 隐私暴露；
- unwanted recontact；
- social comparison；
- 边界维护。

### 11.4 真正增加的自由不是“永远联系所有人”

更准确的自由是：

> **一个人更有可能选择：哪些过去的人以后仍然可以重新找到我，哪些关系只需要留在过去。**

这是一种新的 **relationship optionality**。

|---|---|---|---|---|
| 2005–2012 扩张型未来 | ChinaRen、校友网、校内/人人、QQ、电话、email 并存 | 2005 网上班级；2008 同济校友网；2008 中青报第一人称 | 离开学校/城市以后仍能维持、重新找到旧关系 | 平台依赖、资料过期、关系不等于技术连接 |

这张表不是断言全社会按四段整齐切换，而是用于比较**当时公开可说的未来语法和基础设施压力**。

## 13. historical visibility：我们为什么会高估“失而复得”，低估“安静地淡掉”

这一题有非常强的保存偏差。

最容易留下报道的是：

- “找回失散 20 年老同学”；
- 大型同学会；
- 校友网站上线；
- SNS 找人成功；
- 公开退群/删好友争议。

最难留下的是：

- 每年只互祝一次生日；
- 联系慢慢减少，没有冲突；
- 电话还能打但大家都没有打；
- 群一直静音，没有人退；
- 同学关系变成偶尔点赞；
- 两个人都觉得不联系也没关系。

所以不能从 Web archive 得出：

> “Internet 让大家更念旧/更亲密。”

Archive 更容易保存**发生了动作的关系**，而不是大量没有事件的 dormant tie。

## 14. 与 `old-web-archaeology` 的接口

中文旧网部分真正需要考古的，不是“当年大家感情多好”，而是：

```text
学校索引
→ 班级索引
→ 班级创建
→ 申请加入
→ 管理员审核
→ 成员 profile

→ off-platform contact
```

当前已知的高价值 historical locator / artifact 包括：

- `class.chinaren.com`

## 15. 已知 / 合理推断 / 仍不知道

### What we know

1. 前互联网时代纸质同学录、通讯录、邮政和组织路由已经承担“毕业后还能联系”的功能。
2. 1978 年中国固定电话远未达到普通家庭默认拥有的程度。
3. 1999–2001 以后 ChinaRen 同学录已成为明确中文 Web 产品。
4. 2005 年同期媒体已记录地理分散的班级把通知和同学联络持续放在网上班级。
5. 2008 年学校官方校友系统已经明确设计“查班级—申请加入—管理员审核—更新联系方式”的长期状态链。
6. 2008 年第一人称材料同时证明：联系方式仍有效，不代表关系仍保持原状态。
7. 2019 年第一人称材料证明：数字班级容器可以比真实同学关系活得更久。
8. 2024 年微信的关系管理功能已经需要处理联系人上限、单向残留和低互动关系。
9. 美国 Classmates.com、英国 Friends Reunited 提供独立跨国对照：学校/cohort 作为重连索引并非中国特有。
10. Friends Reunited 的关闭证明：平台名录本身会老化，profile 存在不等于联系方式仍有效。

### What we can reasonably infer

1. Internet 降低了部分由迁移、换地址造成的偶然失联风险。
2. 学校/年级/工作单位等 biographical anchors 把“过去共同经历”变成长期检索键。
3. 关系可寻址性的提高，为迁移和多阶段人生增加了一些社会关系 optionality。
4. 持久社交图谱同时制造新的边界维护劳动。
5. 成熟平台的主要问题会从“找不到旧人”部分转向“旧人过多、状态过期、是否还想被找到”。

### What we do not yet know

1. 1999–2003 ChinaRen 最早班级创建/审核/搜索的原始 DOM、字段、charset 和 cookie/session 逻辑。
2. ChinaRen 历年真实活跃用户与注册用户差距。
3. 同一 cohort 中，究竟多少关系因为 Web 而避免永久失联，而不是本来就会通过电话/共同朋友恢复。
4. 各年龄/城乡/收入群体对校友录、QQ、SNS 的实际采用差异。
5. 2010s 从人人/ChinaRen 迁向 QQ/微信时，多少旧 social graph 真正迁移、多少被丢弃。
6. 2023–2026 普通用户中主动删联系人/退同学群的频率与原因分布。

## 16. 后见之明风险与反例

### 风险 A：把“能找到”写成“关系更好”

反例：2008 中国青年报第一人称材料。

### 风险 B：把“同学录用户多”写成“所有学生都依赖它”

平台自报规模不能替代独立 adoption 数据。

### 风险 C：把 SNS 视为第一个旧友重连基础设施

纸质通讯录、校友会、邮政、电话和共同熟人都更早存在。

### 风险 D：把今天的社交疲劳投射到 2008

2008 同济官方材料仍非常强烈地鼓励毕业生持续更新联系方式和加入校友网络；这是一种不同的未来想象。

### 风险 E：把“从不联系”自动理解成失败

有些关系自然休眠，双方并不需要恢复。

### 风险 F：把删好友浪漫化成绝对自主

删除也可能带来误伤、失去未来弱关系、工作/照护/迁移信息断裂。关系边界没有单一最优答案。

## 18. 一句话结论

> **Internet 并没有让旧关系永远不消失；它真正改变的是：过去的人生阶段越来越不必在离开那一天彻底封箱——一个人可以多年不联系，却仍保留再次找到彼此的可能。等这种可能积累得足够多，新的问题又出现了：哪些过去值得继续拥有进入现在生活的地址。**
