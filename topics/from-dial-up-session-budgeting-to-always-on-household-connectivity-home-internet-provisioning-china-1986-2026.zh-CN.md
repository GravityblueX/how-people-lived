# 从拨号会话到家庭网络：接入、端口、地址与日常在线性，中国 1986–2026

> 交叉研究切片：`how-people-lived` × `old-web-archaeology`
>
> 核心问题：一个国家“已经联网”、一座城市“有宽带”、一个小区广告里写着“光纤覆盖”，都还不能回答一个普通家庭今天晚上能不能真的上网。家庭互联网进入普通生活，需要把国际连通、公众接入、住宅线路、端口、资费、终端、家庭内部共享和真实应用一层层接起来。

## 0. 为什么这是一个新的普通生活问题

仓库已经研究了通信距离、旧 Web 平台、在线办事、租房、教育、就业、医疗、远程关系和各种数字 transaction，但尚未把**住房本身是否“可联网”**作为一种生活条件单独建模。

本笔记新增几个概念：

1. **household networkability / 家庭可联网性**：一个具体住所是否存在普通家庭实际可购买、可安装、可持续使用的互联网接入；
2. **access-session budgeting / 上网会话预算**：拨号时代，一次联网需要同时预算电话占线时间、网络费、电话费和下载/收信所需分钟数；
3. **technical always-on / economic always-on split / 技术常在线—经济常在线分裂**：线路技术可以“不必拨号、一直在线”，资费却仍可能按 40/100/200 小时计费；
4. **provisioning executability / 装机可执行性**：运营商宣传覆盖或接受申请，不等于楼里有空闲端口、铜线距离合适、物业允许施工、最终真的装通；
5. **address-bound connectivity / 地址绑定连接**：固定宽带能力属于“人 + 具体楼宇 + 运营商资源”的组合，搬家可能使原来的网络资格和套餐失效；
6. **scarcity relocation / 稀缺迁移**：从拨号时代的分钟数、电话线占用和 busy signal，迁移到宽带时代的端口、楼宇准入、共享带宽、合同、家庭 Wi-Fi 和多人并发；
7. **connectivity fallback stack / 联网后备栈**：固定宽带失效或没有安装时，手机流量、电视/IPTV、网吧、单位/学校网络、公共 Wi-Fi、亲友网络等能否维持学习、工作和通信。

需要固定几条边界：

- `国家全功能接入 Internet ≠ 普通家庭可以上网`；
- `科研电子邮件/专线联网 ≠ 大众 Internet`；
- `公众 Internet 服务开始提供 ≠ 普通家庭大规模采用`；
- `某村“通宽带” ≠ 每户都装了宽带`；
- `运营商网页显示业务存在 ≠ 一个地址可安装`；
- `申请受理 ≠ 端口可用 ≠ 安装完成 ≠ 实际稳定使用`；
- `技术上一直在线 ≠ 用户经济上敢一直在线`；
- `签约 100M/1000M ≠ 每个房间、每台设备、每个时段都得到该速率`；
- `互联网可以让工作地点移动 ≠ 所有职业、所有地点都获得同样的地理自由`。

## 1. 1986–1995：先有科研/邮件与全功能连接，再有面向社会的公众接入

中国互联网前史必须至少分成四层。

### 1.1 1986–1987：已经存在跨国数字通信，但还不能写成“普通中国人已经上 Internet”

CNNIC 后来的机构年表记录：

- 1986-08-25，中科院高能物理所人员通过卫星链路远程登录 CERN 机器并发送电子邮件；
- 1987-09-20，北京计算机应用技术研究所建成电子邮件节点并向德国发送邮件。

这些事实很重要，因为它们直接反驳“1994 年以前中国完全没有网络通信”。

但它们同样不能被升级成：

- 普通家庭可以拨号访问全球 Internet；
- 大学生普遍已经拥有 Internet 账号；
- 城市公众已经能通过 Web/BBS 形成大众在线生活。

正确写法是：

> **科研机构已经拥有跨国电子邮件、远程登录或其他联网能力；这种 institutional/research connectivity 与后来普通家庭的 public Internet access 是不同历史阶段。**

### Source / evidence grade

- B（机构后期整理，精确技术日期，但不是 1986/1987 当日原始日志）：CNNIC，《1986年～1993年互联网大事记》：<https://cnnic.cn/n4/2022/0401/c87-911.html>

### 1.2 1994-04-20：全功能接入是国家网络史节点，不是家庭普及日期

1994-04-20，NCFC 通过 64K 国际专线实现与 Internet 的全功能连接。

这一天应该保留，因为它回答的是：

`中国的 TCP/IP 网络能否全功能连接全球 Internet？`

它不回答：

`北京一个普通家庭今天能否给 ISP 打电话申请账号？`

更不回答：

`农村家庭是否拥有电脑、电话线与可负担的上网资费？`

### Sources

- B / institutional chronology：CERNET, *Evolution of Internet in China*（2001）：<https://www.cernet.edu.cn/english/cernet/introduction/200603/t20060323_4285.shtml>
- B / institutional retrospective：CNNIC 2024 回顾第一次统计报告时再次区分 1994 网络接入与后来的用户普及：<https://www2.cnnic.cn/n4/2024/0508/c208-10983.html>

### 1.3 1994–1995：大学与科研网络扩张，但仍不能把校园节点等同于社会家庭

1994 年 CERNET 试验网连接多个城市高校；1995 年 CERNET 主干和国际线路继续建设。后来的校史材料甚至回忆，一些高校早期可能整个学校共用很有限的账号或命令行邮件环境。

这说明：

`institution has network`

和：

`ordinary student has an independently usable Internet terminal/account`

仍有明显距离。

### 1.4 1995：公众 Internet 接入开始出现，是另一只“时钟”

CNNIC 1994–1996 年表记录，1995 年 1 月北京、上海两条国际专线开通后，电信系统开始通过电话网、DDN 和 X.25 等方式向社会提供 Internet 接入服务；同年 CHINANET 全国骨干建设继续推进。

因此中国大众 Internet 的时间线至少应写成：

`科研/邮件与专线前史`
→ `1994 全功能接入`
→ `1995 面向社会提供 Internet 接入`
→ `1996 前后全国公众网络进一步展开`
→ `家庭可及与大众化仍需再看电脑、电话、ISP、价格和地区分布`

### Source

- B / institutional chronology：CNNIC，《1994年～1996年互联网大事记》：<https://www3.cnnic.cn/n4/2022/0401/c87-912.html>

## 2. 1997–2001：拨号时代真正稀缺的是“可联网的分钟”

### 2.1 1997：绝大多数联网电脑仍通过拨号

CNNIC 第一次全国统计的后期机构回顾记录：截至 1997 年 10 月底，中国有上网计算机约 29.9 万台、上网用户约 62 万人；其中约 25 万台上网计算机属于拨号方式。

这时候“家庭上网”最值得重建的不是门户网站首页，而是一天的时间结构：

1. 电话线此刻有没有别人要用；
2. modem 能不能拨通 ISP；
3. 电话费怎样计；
4. ISP 网络使用费怎样计；
5. 邮件和网页最好先离线准备什么；
6. 下载是否会中途断线；
7. 为了省钱，哪些内容应该先想好再拨号。

### Source

- B / institutional retrospective：CNNIC 2024 对第一次报告的回顾：<https://www2.cnnic.cn/n4/2024/0508/c208-10983.html>

### 2.2 1999：上网成本不只是 ISP 月费，还包括电话线上的时间

1999-12-01 起，中国电信 163 拨号用户的上网通话费从每 3 分钟 0.18 元降到 0.09 元；169、263 等其他 ISP 当时并不都能享受同一优惠。

这里可以看到典型的 **access-session budgeting**：

> 连接互联网不是一个“家里已经有 Wi-Fi”的背景状态，而是一段会在电话账单上不断计时的行为。

同一时期，不同特服号/ISP 还可能有不同网络使用费，所以“上网一小时多少钱”常常不是一个单一价格。

### Sources

- B / 同时代：北京晚报，1999-11-30，《上网话费明起减半 优惠只限163》：<https://news.sina.com.cn/china/1999-11-30/36695.html>
- B / 同时代：光明网《生活时报》，2000-06-22，列举北京多种拨号资费和上网卡：<https://www.gmw.cn/01shsb/2000-06/22/GB/06%5E1382%5E0%5ESHSB1106.htm>

### 2.3 “先写邮件、后拨号”不是古怪技巧，而是成本结构塑造出来的日常技术

2019 年《北京日报》整理自己的 1990s–2001 同期版面时，重新引用了 2001 年“上网省钱招数”：比如先离线写好 email、先打开浏览器窗口，再拨号上线，以减少计费中的无效分钟。

这是一份后来整理的 C/B 混合材料，不能拿它精确复原某个家庭，但它说明一个重要的行为机制：

`按时间付费 + 电话线占用`
→ `把可离线完成的劳动尽量移到断线状态`
→ `联网成为有开始/结束边界的 session`

### Source

- C/B（2019 后期整理，引用报社 1996–2001 同期版面）：北京日报，《互联网初入京城》：<https://media.people.com.cn/n1/2019/1017/c40606-31404334.html>

## 3. 1999–2004：ADSL 的深层变化不只是“快”，而是 Internet 开始脱离电话会话

### 3.1 上海早期家庭宽带：价格仍高，采用仍是极小群体

上海电信后来的企业史回顾称，1999 年已有首批家庭 ADSL 用户；这一材料多年后形成，只能作为 C 级回忆来定位候选，不应代替同期部署统计。

更可靠的 2001 年同期新华社材料记录，截至当年 11 月：

- 上海电信因特网注册用户约 93 万；
- 主叫拨号上网用户约 92 万；
- 宽带用户约 8.3 万户；
- ISDN 用户约 21 万户。

即使在宽带建设领先的大城市，2001 年拨号仍远比家庭宽带普遍。

### Sources

- B / 同时代：新华社，2001-12-21，《上海构造智能化小区力推家庭上网》：<https://tech.sina.com.cn/i/c/2001-12-21/96846.shtml>
- C / 2024 回忆，用于定位早期家庭用户体验而非总体采用：<https://sh.people.com.cn/n2/2024/1213/c134768-41075012.html>

### 3.2 ADSL 把“电话是否空闲”和“Internet 是否在线”部分拆开

2001 年《人民日报》的技术说明非常关键：ADSL 在同一对铜线上分别传输语音与数据，不需要像 modem 那样占用电话交换机来拨号，并可保持在线；技术上，这让“打电话”和“上网”第一次更容易同时存在。

因此它改变的是家庭基础设施的耦合关系：

`一根电话线 = 语音或数据二选一`

逐渐变成：

`同一铜线可同时承担语音 + 数据`

这比“56K 变 512K”更直接地改变了家人的日常协调。

### 3.3 但北京 2001 年留下了一个重要反例：技术上一直在线，经济上仍按小时生活

北京 2001-07-28 开放 ADSL 申请时，产品仍是：

- 40 小时：99 元/月；
- 100 小时：199 元/月；
- 200 小时：380 元/月；
- 超时继续计费。

到 9 月 10 日，申请总数接近 2500 户。

所以不能写成：

`ADSL = 家庭立即进入 always-on Internet`

更准确的是：

> **ADSL 先让线路具备 technical always-on，资费制度再逐步决定普通人是否能把它当作 economic always-on。**

这就是 **technical always-on / economic always-on split**。

### Sources

- B / 同时代：《人民日报》2001-09-17，《北京宽带：为何没有热起来》及同版 ADSL 技术说明：<https://cn.govopendata.com/renminribao/2001/9/17/12/>
- B / 同时代：北京晨报，2001-08-06，记录 40/100/200 小时套餐与早期申请冷淡：<https://tech.sina.com.cn/i/c/2001-08-06/79011.shtml>

### 3.4 这会改变什么生活行为？

当连接不再需要每次拨号、也不再让家里电话持续占线时，家庭可以更容易出现：

- QQ/邮件长时间保持可达；
- 较大的软件、图片、音乐文件在后台下载；
- 两次短暂上线之间不必反复决定“值不值得拨号”；
- 互联网从一个主动安排的活动，逐渐转成屋里持续存在的基础设施。

但上述“行为正常化”的速度仍必须与价格、电脑拥有、城市/农村和具体楼宇的接入能力分开，不能从 ADSL 技术说明直接外推全国日常。

## 4. 2004–2006：宽带自己也长出 Web 管理层——“能上网”开始被账户、套餐和线上营业厅管理

2004–2006 年的北京材料已经可以定位两个重要 host：

- `www.bbn.com.cn` — “北京宽带网 / 宽带北京”；
- `www.bjtelecom.com.cn` — 北京网通/通信网上营业厅相关入口。

2006 年同期材料明确记录：北京网通 ADSL 用户可以用 ADSL 用户名和密码登录网上营业厅/宽带北京，自助申请变更使用时长和速率；申请从次月生效，以当月最后一次变更为准。

这里出现了一个新的家庭后台工作：

`线路已经装好`
≠
`连接条件从此不需要维护`

用户还要管理：

- ADSL 账号和密码；
- 套餐时长；
- 速率档位；
- 资费变更生效日期；
- 后来可能还有绑定电话、融合套餐和合同期。

互联网基础设施开始用 Web 来管理 Internet 自己。

### Sources

- B / 同时代：人民邮电报，2006-05-17，《ADSL网上自助改时长简化大客户办理手续》：<https://tech.sina.com.cn/t/2006-05-17/1755942442.shtml>
- B / 同时代：北京晚报，2006-05-17，记录 `www.bjtelecom.com.cn`、`www.bbn.com.cn` 和账号密码流程：<https://tech.sina.com.cn/t/2006-05-17/1712942299.shtml>

### 旧网交叉意义

对 `old-web-archaeology` 来说，这类页面不是普通“门户首页”。它们至少包含：

`public service description`
→ `authenticated account`
→ `service parameter change`
→ `backend provisioning`
→ `next-month effective state`

今天即使只留下一个“网上营业厅”按钮，也不能证明当年的登录、POST、身份校验和后端变更仍可复原。

## 5. 2008–2010“扩张型未来”：家庭上网已经非常常见，但“全国有宽带”仍不等于“我这间房能装”

### 5.1 宽带开始成为主流上网方式，家庭也成为主流地点之一

CNNIC 第 22 次报告显示，截至 2008 年 6 月：

- 中国网民 2.53 亿；
- 网民中 84.7% 使用宽带接入；
- 74.1% 的网民在家上网；
- 39.2% 仍在网吧上网；
- 家庭上网计算机约 8470 万台；
- 在家上网网民月均家庭接入费用约 77 元。

这已经是大众化阶段，但它恰好说明不能把“家里上网”与“唯一在家上网”混为一谈：同一个人可以同时在家、学校、单位、网吧和手机上网。

### Source

- A/B（CNNIC 当期调查报告）：《第22次中国互联网络发展状况调查统计报告》，2008-07-19：<https://www3.cnnic.cn/n4/2022/0401/c88-813.html>

### 5.2 “乡乡能上网”也不是“农村每户都有宽带”

CNNIC 2008–2009 农村调查报告记录：

- 98% 乡镇能上网；
- 95% 乡镇通宽带；
- 89% 行政村能上网；
- 但城镇居民互联网普及率为 35.2%，农村仅 11.7%；
- 农村网民中，在网吧上网者比例仍为 54.2%。

因此必须固定：

`village coverage ≠ household subscription ≠ individual use`

它们分别属于基础设施、家庭购买和个人行为三只不同的时钟。

### Source

- A/B（CNNIC 当期调查）：《2008-2009 中国农村互联网发展调查报告》：<https://www2.cnnic.cn/n4/2022/0401/c117-827.html>

### 5.3 2008 年广州第一人称：钱已经付了，端口却可以仍然不存在

2008 年《南方都市报》报道，广州棠东经营公司的陈先生租下一层办公室，月租约 1.3 万元，申请两条 2M 宽带并被预扣 5200 多元包年费用，三天后申请却被退回：当地 ADSL 接入口已经满，暂无可用端口。

最后运营商尝试从更远位置牵线，但因为铜线距离较长，只能先按 512K 提供，并提示可能不稳定。

运营商当时描述的内部流程本身就值得保存：

`用户申请`
→ `客户资料`
→ `资源系统匹配`
→ `有资源才生成工单`
→ `装机人员执行`

所以历史研究必须写成：

> **“运营商在广州提供 2M ADSL”不等于“广州任意地址都可报装 2M ADSL”。**

### Source

- B / 同时代：南方报业网转载，2008-07-08，《宽带接入频报端满 运营商“圈地”现痼疾》：<https://net.zol.com.cn/98/987730.html>

### 5.4 固定宽带是地址资产：搬到马路对面也可能要换运营商

同一篇报道还记录一名居民原本想在现住宅装宽带，但三个月后将搬到马路对面；当前楼只能装一个运营商，新楼只能装另一个，宽带无法随人直接迁移，于是他临时选择附近网吧。

这就是 **address-bound connectivity**：

`我有电脑 + 我付得起网费`

仍不足以产生：

`我在新住所还能无缝保持家庭 Internet`

搬家因此不只是换一个门牌号，也可能意味着：

- 退旧线；
- 换运营商；
- 换账号/套餐；
- 等端口；
- 重新施工；
- 在空档期用网吧或移动网络过渡。

### 5.5 北京郊区同年再次证明：城市有网络，具体线路资源仍可以耗尽

2008 年底，北京昌平、朝阳部分偏远地区居民向媒体反映多年无法安装固话和宽带；当地电话局解释为线路/端口全部使用，需要新增机房、电杆和电缆，而扩容又受场地与施工协调影响。

这使“最后一公里”真正进入普通生活：

> 国家骨干网、城市城域网乃至运营商广告都已经存在，家庭最后几十米/几百米的线路仍可以决定一个人是否联网。

### Source

- B / 同时代：京华时报，2008-12-29：<https://www.chinanews.com.cn/it/txxw/news/2008/12-29/1506181.shtml>

### 5.6 家里已有一条宽带以后，“多少人/多少设备可以共享”又成为下一层制度接口

2008 年广东出现针对部分“一拖N”共享的限制和争议。运营商说明，普通家庭少量多机使用与出租屋转售/企业大量共享应区分，但同期合同与技术控制确实把“线路属于谁、允许几台设备同时使用”变成家庭网络设计的一部分。

这说明 Internet 大众化后的新问题不是简单“有没有网络”，而是：

`一条家庭线路究竟能支持多少共居者、设备和用途？`

## 6. 2015–2019“拥堵型未来”：网络从稀缺用品变成默认基础设施，摩擦转向质量、运营商、合同与家庭内部

### 6.1 光纤与百兆快速变成新常态

工信部 2018 年统计显示：

- 年底固定互联网宽带接入用户约 4.07 亿；
- FTTH/O 用户约 3.68 亿，占 90.4%；
- 100Mbps 及以上用户约 2.86 亿，占 70.3%。

这一阶段家庭宽带的历史问题已经不能继续写成“有没有 ADSL”。更多家庭开始默认 Internet 像电、水一样应该持续存在。

### Source

- A：工信部，《2018年通信业统计公报解读》：<https://www.miit.gov.cn/zwgk/zcjd/art/2020/art_2b69d6d5049547efb304ac99137ed372.html>

### 6.2 价格下降以后，选择反而可能变成新的家庭行政劳动

2019 年北京居民余女士的同期第一人称非常直观：她 2015 年办理的 20M 宽带一年 1480 元；到 2019 年，同一市场已经出现 100M 三年 1280 元的价格。

这不是简单“更便宜了”。同一时期宽带越来越与手机套餐、合约期限、运营商留存绑定：

`选一个 Internet 接入`

逐渐变成：

`比较速率 + 合约期 + 手机套餐 + 楼宇可装运营商 + 是否方便搬家/退订`

### 6.3 “50M 已安装”仍不等于“直播课能稳定看”

2018 年新华社调查里，上海一名居民家中已经安装 50M 光纤，但外孙看直播网课仍经常卡顿，多次报修没有解决；文章同时调查小区宽带独占、实际速度与承诺速度等问题。

所以成熟阶段又增加一个边界：

`subscription rate ≠ delivered household experience`

签约速率只是运营商边界参数；家庭真实体验还受：

- 楼内网络；
- 共享链路；
- 家庭路由器/Wi-Fi；
- 终端；
- 上游内容平台；
- 并发用户；
- 故障与维修

共同影响。

## 7. 2020–2022“偶发型未来”：原本可选的家庭网络，突然可能变成学校和工作的执行前提

### 7.1 一个非常强的反例：家庭可以主动“不装宽带”

2020 年云南一名高二学生家长杨雨写信称，平时担心孩子上网玩游戏，所以家里**没有安装宽带**；学校转为网课后，孩子只能用手机上课，连续数日后家长因长时间屏幕学习而焦虑。

这个材料非常重要，因为它说明 2019 年以前：

`家庭有条件安装宽带`

仍不必然等于：

`家庭愿意把持续 Internet 引入家中`

父母可以把“不装宽带”当作管理家庭边界的一种选择。

疫情中的线上教学却突然把这项选择重新定价：

`不装宽带 = 少一个娱乐入口`

可能转成：

`不装宽带 = 学校基础设施缺一层`

### Source

- B / 同时代第一人称：云南网，2020-03-10：<https://m.kunming.cn/news/c/2020-03-10/12868608.shtml>

### 7.2 危机真正暴露的是 connectivity fallback stack

黑龙江 2020 年公开的网上开学保障不是只押注家庭光纤，而是明确保留三条路线：

1. 光纤宽带接云课堂；
2. 有线/无线电视；
3. 移动 4G/5G 接入。

四川也同时保留有线电视、IPTV/网络电视和网络平台，并明确要求对没有数字电视或宽带不畅的家庭提供个性化辅导。

这比“全国都改成网课”更准确地描述了普通生活的韧性：

> **真正可靠的数字生活不是只有一条最先进的连接，而是当主入口失败时仍有第二、第三条可执行路线。**

- A/B / 同期政府发布会：黑龙江省通信管理局答疑，2020-03-02：<https://hlj.people.com.cn/n2/2020/0302/c220024-33843963.html>
- A/B / 同期教育安排：四川，2020-03-06：<https://sn.people.com.cn/n2/2020/0306/c393584-33856125.html>

### 7.3 “全国网络够快”与“所有孩子此刻可稳定在线”仍是不同命题

同一时期网络能力可以支撑数亿人上课，但少量家庭仍会遇到：

- 没有固定宽带；
- 手机流量不足；
- 室内信号弱；
- 多人同时在线；
- 教学平台拥塞；
- 设备只有一部手机。

因此危机没有证明“数字鸿沟消失”，而是把家庭网络从消费设施升级成教育/劳动 continuity infrastructure，同时把原来隐藏的末端差异暴露得更清楚。

## 8. 2023–2026“防守型未来”：家庭连接高度普及以后，网络开始参与“我可以住在哪里”的选择

### 8.1 数字游民是一条真实但窄的 life path，不能写成整个青年群体的未来

2023 年 28 岁的向玲娇在同期采访中说，她从深圳到成都、重庆、杭州、上海、长春等地移动，同时把工作地点放在咖啡店、酒店、飞机和高铁上。

2025 年，做自媒体的陈扬从上海回到长沙，常在湖边咖啡馆处理数小时工作。

这些材料证明：

> 对一部分可以远程交付的职业，Internet 已经把“工作所在城市”和“公司办公室所在城市”部分解绑。

但绝不能推出：

- 所有白领都能数字游民；
- 制造、照护、零售、实验、现场服务等工作已经脱离地点；
- 有 5G/光纤的城市之间生活机会完全等价。

真正的状态是：

`职业任务可远程`
+ `稳定网络`
+ `设备`
+ `住房/第三空间`
+ `收入与社会保障可持续`

共同决定这种路线是否可执行。

### 8.2 到 2026，固定宽带已经是大规模家庭基础设施，但“普及”仍不能替代具体地址判断

工信部最新统计显示，截至 2026 年 7 月底：

- 固定互联网宽带接入用户约 7.02 亿；
- 100Mbps 及以上用户约 6.71 亿，占 95.6%；
- 1000Mbps 及以上用户约 2.60 亿，占 37.1%；
- FTTH/O 接入端口占全部宽带接入端口约 96.7%。

2025 年底家庭宽带接入用户已达 5.83 亿户，家庭宽带普及率为每百户 117.9 部，户均签约带宽 553.4Mbps。

这些数字说明固定宽带已经进入成熟基础设施阶段，但“每百户超过 100 部”尤其提醒我们不要把“用户/接入账户数”机械解释成“117.9% 家庭各自拥有一条”；账户、家庭和住宅并不是天然一一对应。

### 8.3 2026 的新问题已经更像“家庭内部最后十米”

当 FTTH、千兆端口和移动网络都很普遍以后，下一层生活问题越来越可能是：

- 路由器放在哪里；
- 隔墙后是否还稳定；
- 一家几个人同时视频/游戏/远程工作；
- 哪个房间适合作为工作和学习空间；
- 装修时是否预埋网线；
- 搬家时融合套餐、光猫和账户如何迁移；
- 固网故障时手机热点是否足以维持工作。

这也是从“Internet 是否存在”到“住宅是否真正具有可用数字基础设施”的最后一步。

本轮尚未找到足够好的全国代表性家庭内部 Wi-Fi/FTTR 使用行为调查，因此这里只把它列为下一阶段问题，不把 2026 的 FTTR 用户增长直接解释成某种统一生活方式。

## 9. 海外对照一：1988 法国 Minitel 提醒我们，家庭联网生活并不只从 Web/Internet 开始

1988 年法国《世界报》根据 France Télécom 年度数据报道：1987 年底法国已有约 337.3 万台 Minitel，相当于约 14% 电话订户；15 岁以上人口中约 20% 在家或工作场所可以接触 Minitel，平均使用约 93 分钟/月。

- 家庭已有网络终端；
- 使用与电话网络、计费和服务目录绑定；
- 查目录、信息、留言和其他远程服务可以进入日常；
- “家中网络服务”并不必然以开放 Internet/Web 的技术路径出现。

## 10. 海外对照二：1996–1997 AOL 说明“包月”会把稀缺从钱转移到容量

AOL 1996 年 12 月把服务切换到每月 19.95 美元的不限时方案后，用户使用行为迅速变化。

1997 年 1 月同期报道记录：

- 用户因为不再按小时付费而更长时间在线；
- AOL 同时在线容量一度只能支持约 26 万用户；
- 用户频繁遭遇 busy signal；
- 平均每日使用时长从 1996 年 9 月约 14 分钟升到 1997 年 1 月约 32 分钟；
- 一些没有本地接入号码的地区仍需长途拨号或使用有附加费的 800 号码。

这与中国从拨号计时到宽带包月的变化形成非常好的机制对照：

`按分钟/小时计费`
→ 用户主动缩短 session

`固定包月`
→ 在线时长迅速上升
→ 旧网络容量不足
→ 稀缺从个人账单迁移到 busy signal / access port / capacity

所以 **flat rate does not abolish scarcity; it relocates scarcity**。

## 11. 跨时期比较：Internet 到底怎样进入普通人的一天

### 11.1 1980s–mid-1990s：机构网络先于家庭网络

生活问题：

> 我所在的学校/研究机构是否有一条稀缺的外部通信路线？

不能写成全国公众上网。

### 11.2 late-1990s：Internet 是一段需要安排的会话

生活问题：

> 现在拨号值不值得？电话会占多久？一分钟多少钱？邮件能不能先离线写？

Internet 有明显“开”和“关”。

### 11.3 early-2000s：技术上开始常在线，价格和楼宇条件仍决定是否真的常在线

生活问题：

> 我家铜线能装吗？一次性费用多少？包多少小时？装好后电话还能同时用吗？

### 11.4 2005–2012：家庭 Internet 成为大众基础设施，但具体地址仍有端口与运营商差异

生活问题：

> 这个小区到底能装哪家？端口还有没有？搬到另一栋楼能不能迁？全家几台电脑能不能一起用？

### 11.5 2015–2019：默认在线，摩擦转向质量、套餐和合同

生活问题：

> 我买的是多少 M？实际能跑多少？手机和固网怎样捆绑？租房一年却要不要签两三年合约？

### 11.6 2020–2022：连接成为 continuity infrastructure

生活问题：

> 学校和公司今天突然搬到线上，家里有没有足够的线路、终端和后备方案？

### 11.7 2023–2026：连接开始决定“地点能否被重新选择”

生活问题：

> 如果工作本身可远程，我能不能换城市、回家乡、去第三空间工作，而不让收入链断掉？

这条路线只适用于部分职业，不能变成整个时代的青年人格描述。

## 12. 这改变了我们对“普通人怎么活”的哪一点理解

“Internet 普及”不应该只画一条网民数曲线。

对一个普通人而言，真正决定生活的是一组更细的状态：

`国家/城市网络存在`
→ `公众服务存在`
→ `住所被覆盖`
→ `楼宇允许该运营商进入`
→ `有空闲端口/合格线路`
→ `家庭付得起安装和月费`
→ `申请成功`
→ `施工完成`
→ `账号可用`
→ `家中设备接得上`
→ `多人可以共同使用`
→ `速度足以执行真实任务`
→ `搬家/故障时还有 fallback`

这条链一旦稳定，Internet 才会从“我要去上网”变成“我住的地方默认在线”。

而这种变化会反过来改变：

- 与远方家人的联络频率；
- 下载、音乐、影视和游戏的时间结构；
- 找工作、租房、买东西的搜索习惯；
- 学校和单位敢不敢把任务默认放到线上；
- 独居者和异地家庭能否维持日常协调；
- 一部分工作能否脱离固定办公室；
- 搬家时“网络能否无缝继续”是否成为新的住房条件。

所以家庭网络不是娱乐史的边角料，而是现代生命路线的执行基础之一。

## 13. Evidence strength / 反例 / 后见之明风险

### 强证据

- CNNIC 同期统计对 2008 家庭上网地点、宽带使用和城乡分布的量化；
- 1999–2001 同期资费材料；
- 2001 ADSL 技术与北京产品计费材料；
- 2006 北京网通网上营业厅具体账号/变更流程；
- 2008 广州“申请后因端口满被退回”的具体 provisioning 链；
- 2018–2019 光纤、百兆与家庭价格的同期材料；
- 2020 家庭未装宽带与网课 fallback 的同期第一人称/官方渠道说明；
- 2026 工信部最新固定宽带统计。

### 反例

1. 1987 有国际电子邮件，不等于大众 Internet 已经存在；
2. 1994 全功能接入，不等于普通家庭同年即可联网；
3. 2001 ADSL 技术可一直在线，北京产品却仍按小时分档；
4. 2008 中国宽带网民已经占绝大多数，具体楼宇却仍可能端口已满；
5. “乡镇通宽带/行政村能上网”与农村居民实际普及率仍有巨大距离；
6. 2018 已装 50M 光纤，直播课仍可能卡顿；
7. 2020 有些城市家庭在危机前会主动选择不装宽带；
8. 2026 千兆网络大规模存在，不等于所有工作都获得地理自由。

### 后见之明风险

- 不要把今天的“家里默认有 Wi-Fi”投射到 1998；
- 不要把拨号用户写成只是“网速慢”，他们还承担电话占线和按时计费；
- 不要把 ADSL 的 always-on 技术特性直接翻译成用户可以无限时使用；
- 不要把“光纤到村”翻译成“每户 FTTH”；
- 不要把运营商营销中的“光纤/百兆”自动当成端到端实测；
- 不要把 2020 危机造成的突然需求写成此前家庭都已经把宽带视为必需品；
- 不要把数字游民当成 2020s 青年的代表性标准路线。

## 15. 一句话结论

> **普通人真正获得的不是抽象的“互联网”，而是一种住宅能力：从每次拨号都要计算电话费和分钟，到房子本身默认持续在线；只有当覆盖、端口、价格、施工、账号、家庭内部网络和故障后备都能执行时，Internet 才会真正进入“我今天怎样上学、工作、联系家人，以及我敢不敢搬到另一座城市”的生活底层。**
