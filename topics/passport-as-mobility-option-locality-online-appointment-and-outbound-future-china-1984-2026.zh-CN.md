# 从“先证明为什么要出国”到“先把护照准备好”：普通护照、出境期权与国际流动的可执行性（中国，1984—2026）

> 研究切口：普通人什么时候开始能够把“未来也许会出国”保存成一个随时可以继续推进的制度选项？
>
> 本文研究的不是中国出境旅游史，也不是签证史，而是普通护照怎样从一条需要单位、邀请、证明和户籍地审批共同启动的目的性事务，逐渐变成一种可以提前持有、跨城市办理、在线维护的国际流动基础设施。

## 一句话结论

**护照普及真正改变的，不只是“出国手续少了”，而是一个人可以在目的地、工作、留学、探亲甚至旅行计划尚未完全确定时，先保存一项未来的跨国移动能力。**

但这项能力始终只是整条路线中的一层：

```text
想去国外
  ≠ 知道有哪些路线
  ≠ 有资格申领护照
  ≠ 已提交申请
  ≠ 已被受理
  ≠ 已采集/核验身份与生物信息
  ≠ 护照已签发
  ≠ 护照已经领取/送达
  ≠ 获得目的地签证或其他入境许可
  ≠ 买得到并负担得起交通
  ≠ 中国边检允许出境
  ≠ 目的地允许入境
  ≠ 实际完成旅行、学习、工作、探亲或迁移
```

所以全文坚持：

**passport availability ≠ international mobility outcome。**

## 1. 为什么这是一个新的 life-horizons 问题

仓库已有迁移、返程、住房、就业、教育、婚姻、居住记录、社保可携带等专题，主要回答一个人在国内怎样换城市、换岗位、维持家庭或制度身份。

但“海外”不是简单把国内迁移距离再拉长。它额外需要一套可被国家识别、被他国接受、能够跨边境使用的身份证明链。

这使普通护照成为一种很特殊的 life-course infrastructure：

- 它不是工作本身，却可能决定一份海外工作能否及时接受；
- 它不是留学录取，却可能决定录取以后能不能继续申请签证；
- 它不是探亲，却决定远方亲属突然需要照护时是否还要先补一轮证件；
- 它不是旅行，却能让一个临时出现的旅行机会不必从“先办证”开始；
- 它不是迁移决定，却可以让“要不要走”在更晚的时间点再决定。

本文把这种作用称为：

> **international-mobility option document / 国际流动期权证件**

这里的“期权”不是金融意义上的资产价值，而是指：**一个有效护照把某些未来路线从“先解决基础身份文件才能考虑”推进到了“目的出现后可以继续下一步”。**

## 2. Internet 以前：真正昂贵的是“为什么允许你走”

### 2.1 1980 年代的申请链不只是填表

2008 年《京华时报》回顾护照制度改革时，保存了多名早期申请者和窗口工作人员的回忆。由于这些 1980—1990 年代个人经历是在 2008 年接受采访时回述，本文将其标为 **C：回顾性第一人称**，不冒充 1989 年同期日记。

其中一名 1989 年申请人徐磊回忆，他第一次去领申请表时遇到百米长队，因为表格限量，连续三天才拿到；随后还要处理单位证明、境外邀请、经济担保、公证、翻译和多个基层机构的盖章，最后约两个月才取得护照。窗口工作人员则回忆，当时很多申请者并不清楚材料要求，缺材料意味着下一次再来。

来源：

- 京华时报，2008-11-04，经新浪保存：<https://news.sina.com.cn/c/2008-11-04/165316586981.shtml>

这个材料的重要之处不是“过去办事很麻烦”这么泛，而是它把当时的出境能力拆成：

```text
有出国目的
→ 获得邀请/资格
→ 单位允许
→ 居委会/街道/派出所等环节认可
→ 准备公证与其他目的证明
→ 取得并正确填写表格
→ 公安机关受理/审批
→ 等待结果
→ 领取护照
```

因此，当时的普通护照更接近一种**目的绑定型许可链**，而不是今天意义上“我先有一本护照，需要时再决定去哪里”。

### 2.2 1984 年以后不能写成“一夜之间按需出国”

同一 2008 年回顾材料引用 1984 年公安部关于放宽因私出国审批条件的政策变化，强调因私出国开始被明确视为正当权益，同时也保留了当时“该受理不受理、该批不批、审批慢”等现实问题的描述。

所以不能用后来的结果反推：

> 1984 政策放宽 = 普通人已经拥有今天式的护照申领体验。

更准确的是：

> **right recognition can precede transaction simplification / 权利承认可以早于事务简化。**

法律和政策可以先改变“原则上能不能申请”，窗口、证明、时限、地方差异和信息透明度随后才逐步改变“普通人能不能顺利执行”。

### 2.3 1994—1998：时限本身就是未来基础设施

2008 年受访者回忆，1998 年再次办理时，材料和审查已经比 1989 年减少，而且最让他安心的是：办理有明确期限，申请提交以后不再处于无限期不确定状态。

这提示 Life Horizons 一个此前容易忽略的变量：

> **administrative time boundedness / 行政等待的有界性**

一个人计划海外学习、商务或探亲，不只需要“最终大概率会批”，还需要知道：

- 最迟什么时候会知道结果；
- 机票、入学、报到或会议日期能不能与办证日历对齐；
- 如果没批，是否还有申诉或调整路线的时间。

未来不确定性的一部分，其实来自窗口没有明确结束时间。

## 3. 2002—2007：“按需申领”让护照开始脱离单次目的

### 3.1 上海 2002：取消邀请函和单位同意的意义

2002 年 8 月新华社同期报道，上海自当年 9 月 1 日进一步实行按需申领普通护照，普通居民主要凭身份证、户口簿申请，不再要求境外邀请函以及原有的单位、派出所等目的性证明链。

同期来源：

- 新华社，2002-08-29，经新浪保存：<https://news.sina.com.cn/c/2002-08-29/1826697371.html>

2004 年新华社又报道，2001 年以后按需申领在大中城市推进，到 2004 年初已有 24 个省级地区的 101 个城市实行相关措施。

- 新华社，2004-01-02，经新浪保存：<https://news.sina.com.cn/c/2004-01-02/23281491295s.shtml>

这里最重要的结构变化不是材料少了几张，而是：

```text
旧：先证明“我为什么现在要出国” → 才有资格启动护照链
新：先证明“我是这个申请人” → 普通护照可以先成为个人持有的长期证件
```

这就是本文所谓 **approval-to-option shift / 从目的审批到未来选项保存**。

### 3.2 不能把城市试点写成全国普通家庭已经同步拥有

2004 年已有 101 城市实施，恰恰说明它当时还不是全国均质状态。

因此至少要继续区分：

1. 法规或中央政策允许；
2. 某城市已实施按需申领；
3. 县级或更基层窗口实际可办理；
4. 普通家庭知道规则；
5. 家庭有钱、有时间、有目的继续走签证和交通路线；
6. 最终真的出境。

“按需申领护照”不能被当成“2002 年以后中国人普遍可以轻易去国外”。

### 3.3 2006《护照法》：空间和时间开始被写进证件权利

2006 年通过、2007 年实施的《中华人民共和国护照法》把普通护照签发机构、办理时限等进一步法律化。后续行政规范仍然保留申请人向户籍所在地县级以上出入境管理机构本人提出申请的结构。

法律/规章来源：

- 司法部普通护照签发管理相关规章：<https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/200804/t20080402_144481.html>

这形成一个后来持续十多年的矛盾：

> **人的工作和生活已经跨城市移动，基础国际旅行证件的申请权限仍可能锁在户籍地。**

本文称为：

> **mobility-document locality lock / 流动证件地域锁定**

## 4. 2005—2012 的“扩张型未来”：先把证件准备好

### 4.1 2008 的当下体验已经和 1989 完全不同

2008 年《京华时报》现场描述北京居民当时办理普通护照：填表、提交证件、缴费，约一周取证；同篇回顾还记载，北京各区县已设置办理点。

这是 **B：同期媒体观察 + C：历史回顾混合材料**。对 2008 年窗口状态可当同期材料，对 1980—1990 年代个人经历必须按回顾材料使用。

这种变化使一个重要的未来行为成为可能：

> **credential-before-destination / 目的地之前先准备证件。**

一个年轻人不必等到“学校已经录取、公司已经确定派我、亲戚已经催我、旅行团已经订好”才开始最基础的护照事务。

### 4.2 扩张型未来不等于人人想移民

这里要主动防止后见之明。

2005—2012 年普通护照更容易获得，可以同时支撑：

- 出境旅游；
- 留学；
- 工作和商务；
- 探亲；
- 短期培训；
- 以后可能发生但尚未确定的机会。

因此，**持有护照本身不能被解释为“想移民”“想离开中国”或某种政治态度。**

更稳妥的时代描述是：

> 海外从少数人的一次性审批项目，逐渐进入更多普通人的可想象生活菜单；而护照是这个菜单里最基础、最可提前准备的一层。

## 5. 2012—2015：Web 减少排队，同时生物识别重新要求身体在场

### 5.1 2012 电子普通护照：更数字，也更身体化

2012 年 5 月 15 日，中国正式启用电子普通护照。同期报道明确说明，16 周岁以上申请人在申请时需要现场采集指纹；新版护照芯片保存基本身份资料、照片等信息。

同期来源：

- 2012-05-16，新疆首本电子普通护照报道：<https://news.sina.com.cn/c/2012-05-16/014024421282.shtml>
- 2012-05-04，上海启用通知，经中国互联网协会保存：<https://www.isc.org.cn/article/20288.html>

这里出现一个很重要的非线性：

```text
Web / 数据库 → 可以减少窗口等待和重复录入
电子护照 / 指纹 → 又让某个身份核验阶段必须由身体亲自出现
```

所以“数字化”不必然等于“远程化”。

本文称为：

> **digital convenience / bodily verification coupling / 数字便利—身体核验耦合**

### 5.2 北京 2013：网上“申请”实际上首先是预申请 + 预约

2013 年 6 月起，北京户籍居民可以通过北京市公安局网站的“出入境管理办事大厅”在线填写资料、接受后台信息比对并预约办理时间和地点。同期报道给出的历史 locator 是：

- `www.bjgaj.gov.cn`

并明确说明：后台基本信息比对最快可在约 10 秒内返回，但申请人此后仍要本人到现场办理；电子护照还涉及照片、指纹等身体核验。

同期来源：

- 北京日报，2013-05-28：<https://news.sina.com.cn/c/2013-05-28/025927240568.shtml>
- 新京报，2013-05-28，经人民网保存：<https://www.people.com.cn/24hour/n/2013/0528/c25408-21636069.html>
- 京华时报，2013-05-28，经人民网保存：<https://politics.people.com.cn/n/2013/0528/c1001-21634859.html>

因此 old-Web 里绝不能把“网上申请护照”缩写成“网上办护照”。真实状态更像：

```text
网页可访问
→ 在线填资料
→ 后台身份/资格初核
→ 初核通过
→ 选现场时段
→ 预约保存
→ 本人到场
→ 采集照片/指纹
→ 正式受理
→ 审核/制证
→ 领取或寄送
```

### 5.3 一次失败也很重要：预约不等于受理

2013 年北京扩大预约受理点后，同期报道显示，一部分已经预约的人最终没有在对应窗口形成正式受理，原因包括本人改变出行计划、申报信息不准确等。

这提醒研究者：

> **appointment count ≠ accepted case count ≠ passport issued count ≠ trip count。**

旧 Web 最容易留下预约入口和成功页，而普通人“填完以后没去”“计划取消”“材料不对”的负状态最容易消失。

### 5.4 上海 2013：政府网站是前台，跨部门后台是另一层

上海市公安局 2013 年政府信息公开年度报告记录，公安网站 `www.police.sh.cn` 持续运行网上办事大厅，并改版出入境电子政务平台，推出出入境证件自助预约等服务。

A 级机构来源：

- 上海市公安局 2013 年政府信息公开工作年度报告：<https://www.shanghai.gov.cn/nw31917/20200820/0001-31917_38323.html>

但现代上海政府网站保存下来的年度报告，不能被当成 2013 年事务应用本身的历史 capture。

## 6. 2015—2019 的“拥堵型未来”：证件终于追上已经移动的人

### 6.1 2019 全国通办：减少的是一趟“为办移动证件而反向移动”的旅程

2019 年 4 月 1 日起，内地居民申领普通护照等出入境证件实行“全国通办”，可以在全国任一出入境管理窗口提出申请，不再受原来的户籍地/居住地办理限制。

A 级来源：

- 国家移民管理局，2019-03-26：<https://www.nia.gov.cn/n741440/n741577/c1015032/content.html>

这项改革的 life-course 意义非常具体：

> 以前，一个已经在杭州、上海、北京工作十年的成年人，为了获得一本用于下一次移动的证件，可能先得请假、坐车回户籍地。

于是出现一种悖论：

> **为了获得国际移动能力，先必须进行一次不必要的国内返乡移动。**

全国通办首先拆掉的就是这段事务性回程。

### 6.2 2019 同期第一人称：杭州工作十多年后，终于可以在生活地办

2019 年 4 月 1 日，杭州“全国通办”首日，江西抚州户籍的雷女士已经在杭州工作十多年，此前从未出国。她计划“五一”和朋友去泰国，当天只带身份证，在工作单位附近的出入境大厅约 5 分钟完成申请。

B：同期人物报道：

- 浙江法制报/平安杭州网，2019-04-02：<https://www.pahz.gov.cn/quxiandongtai/201904/t20190402_9811830.shtml>

这个案例把**内部迁移**和**国际移动**第一次接得很清楚：

```text
户籍地：江西
长期工作生活地：杭州
计划中的短期海外目的地：泰国
```

过去三套地理位置会迫使她先回第一处，再从第二处生活、最后去第三处；2019 年以后，最基础的护照事务可以在第二处直接完成。

### 6.3 “突然需要出国”的担忧：有效证件是一种时间缓冲

2019 年北京同期报道中，一名异地工作者谈到自己出差较多，担心如果临时需要出国时护照突然出现问题；过去即使户籍地与北京之间高铁只需半小时，办证也会吞掉几乎一整天。

这类材料提示另一种“拥堵型未来”：

> 工作日历已经塞满时，最珍贵的不只是钱，而是**不要让一个突发机会再额外占掉一整天事务时间**。

因此可以把有效护照理解成一种：

> **administrative readiness buffer / 行政准备缓冲**

它并不是“逃跑准备”，而是把未来未知的商务、旅行、探亲等机会从“先请假回去办基础证件”推进到下一层。

## 7. 2020—2022 的“偶发型未来”：同一本证件路线可以按目的突然收窄

2021 年上半年，全国普通护照签发 33.5 万本，约为 2019 年同期的 2%。国家移民管理局当时明确执行“非必要非紧急”出境事由暂不签发普通护照等证件，但同时强调对真实的留学、就业、商务等必要需求继续及时受理签发。

同期来源：

- 人民网，2021-07-30：<https://society.people.com.cn/n1/2021/0730/c1008-32176416.html>
- 新华社，2021-07-30：<https://www.xinhuanet.com/2021-07/30/c_1127714411.htm>

所以不能写：

> “疫情期间中国停止办护照。”

更准确的是：

> **purpose-classified mobility contingency / 按出境目的分类的流动偶发性。**

同一个人、同一种普通护照，在不同出境目的下，事务路线的可执行性可能不同。

这让“偶发型未来”多出一个很强的机制：

```text
昨天还认为“今年想旅游就办护照”是普通事务
→ 公共卫生冲击
→ 旅游类目的被显著收紧
→ 留学 / 就业 / 商务等必要路线仍保留
```

不是“所有未来都关了”，而是**未来被重新分类，只有部分目的继续保持制度优先级。**

## 8. 2023—2026：路线恢复以后，开始维护“证件随时可用”

### 8.1 2023-01-08：出境旅游、访友普通护照申请重新恢复

国家移民管理局 2022 年 12 月 27 日公告，从 2023 年 1 月 8 日起有序恢复受理审批中国公民因出国旅游、访友申请普通护照。

A 级来源：

- 国家移民管理局，2022-12-27：<https://www.nia.gov.cn/n794014/n1050181/n1050489/c1548474/content.html>

这一时间点特别适合防止后见之明：

> 2022 年 12 月的人不能把 2023 年 1 月以后的恢复当成已经确定的长期常态；反过来，2023 年恢复以后的人也不能把 2021 年的限制回忆成“本来就只是很快会过去的一小段”。

### 8.2 路线重新打开，不代表过去三年的关系时间自动补回来

2023 年 1 月上海恢复相关业务后，同期报道中有人更新护照，是为了春节去韩国看多年未见的亲属。

这类材料说明：

> 证件服务恢复只是把未来路线重新打开；已经错过的探亲时间并不会被技术自动补偿。

本文称为：

> **reopened option / unrecoverable elapsed time gap / 选项重开—已流逝时间缺口**

### 8.3 2024：第一次出现真正意义上的“人在家里换护照”

2024 年 5 月 6 日起，国家移民管理局在北京、上海、成都等 20 个城市试点普通护照等证件换发补发“全程网办”。成都首日，赵女士计划暑假带家人出国旅游，但抽不出时间去窗口，于是在手机上约 5 分钟提交并成功受理。

B：同期人物材料：

- 人民网四川，2024-05-08：<https://sc.people.com.cn/n2/2024/0508/c345509-40836145.html>

这个节点很容易被写成“护照终于可以完全网上办”，但必须加限定：

- 它首先是**换发/补发**；
- 不是所有第一次申领者；
- 需要满足试点城市、年龄、户籍和既有身份记录等条件；
- 国家已经保存过的可信身份和指纹记录，成为减少下一次身体到场的基础。

因此出现一个新的制度资产：

> **prior identity record as friction-reduction asset / 既有身份记录成为减摩擦资产。**

### 8.4 2025—2026：50 城试点仍不是全国所有人的“零跑腿”

2025 年 11 月 20 日，全程网办换发补发试点从 20 城扩大到 50 城。

截至 2026 年 8 月公开规则，符合条件者通常包括：

- 50 个试点城市 16 周岁以上户籍居民；
- 不包括特定登记备案人员和现役军人；
- 曾申领普通护照且证件仍在有效期；
- 属于有效期不足六个月、损毁、遗失、被盗、签证页用完等换补发情形；
- 过去办理中已经留存本人指纹；
- 在线申请时本人实时定位在中国境内。

当前官方说明：

- 深圳市人民政府口岸办公室，2026-08-06：<https://ka.sz.gov.cn/gzcy/ywzsk/tgzy/content/post_12925109.html>
- 国家移民管理局政务服务平台 2025 扩围公告：<https://s.nia.gov.cn/mps/tztg/202511/t20251110_1009.html>

所以必须坚持：

> **full-online renewal exists ≠ first passport is full-online ≠ everyone is eligible ≠ physical service disappeared。**

## 9. 四种时代未来感：护照这一格怎样变化

| 时期 | 典型机制 | 不应偷换成 |
|---|---|---|
| 2005–2012 扩张型未来 | “先把基础证件办好，未来旅行/留学/商务机会来了再继续” | 人人都想移民、人人负担得起出国 |
| 2015–2019 拥堵型未来 | 已在异地工作的成年人不愿再为基础证件浪费一整天甚至回户籍地；维护证件有效性成为时间管理 | 年轻人普遍悲观或“随时准备逃走” |
| 2020–2022 偶发型未来 | 公共卫生冲击使普通旅游类办证路线突然显著收窄，而留学/就业/商务等必要路线继续存在 | “所有护照停办” |
| 2023–2026 防守型未来 | 恢复路线后，更重视证件随时可用、换补发少占工作日；全程网办为已有身份记录者提供行政缓冲 | 持有/更新护照就是迁移意图 |

这一专题因此修正一个很容易被过度心理化的判断：

> **“防守型未来”不只是在想最坏情况，也可能只是降低下一次不确定事件发生时的行政启动成本。**

## 10. 海外对照：Internet 不是“远程护照事务”的起点

### 10.1 美国 1950s–1960s：后台网络先数字化

美国国会 1969 年记录 Passport Office 技术演进时提到：

- 1955 年以前护照长期通过挂号邮件寄给申请人，随后转为普通邮件；
- 1956 年开始在护照办公室与外地机构之间使用 wire transmission 加速 clearance；
- 1967 年部署与计算机化兼容的 teletypewriter 网络；
- 到 1969 年，10 个 passport agencies 与华盛顿系统连接，部分 clearance 可由 IBM 360 系统迅速返回。

A：美国国会同期记录：

- Congressional Record, 1969-11-04, GovInfo PDF：<https://www.govinfo.gov/content/pkg/GPO-CRECB-1969-pt24/pdf/GPO-CRECB-1969-pt24-5-3.pdf>

这说明：

> **back-office networking before public Internet / 公共互联网以前就存在后台联网。**

申请人可能仍在窗口、法院或邮局递交材料，真正被“电子化”的首先是政府机构内部的查询和审查。

这与中国后来很多政务 Web 很像：

> 前台身体仍然到场，后台事务已经在网络里跑。

### 10.2 美国 1980s：邮寄续照比 Web 早几十年

1981、1983 年美国同期报道已经区分：曾持有护照者在符合条件时可以邮寄办理，而首次申请或某些年龄人群仍需本人到场。

同期档案：

- UPI, 1981：<https://www.upi.com/Archives/1981/01/13/If-you-are-planning-a-trip-outside-the-United/5705348210000/>
- UPI, 1983：<https://www.upi.com/Archives/1983/02/10/Americans-traveling-outside-the-United-States-should-apply-for/7937413701200/>

这与中国 2024 以后“已有护照 + 已留指纹的人先获得全程网办换补发”之间存在一个跨时代共同机制：

> **当制度已经拥有可信的旧身份记录时，续期/换发通常比第一次建立身份更容易远程化。**

因此不能把 `remote credential maintenance` 写成 Internet 独有现象。

## 11. 哪些是中国特有，哪些是现代生命历程的共同变化

### 更具有中国制度路径特征的部分

- 普通护照申请长期与户籍所在地办理权绑定；
- 国内迁移已经高度常态化以后，国际旅行证件的本地办理仍晚一步追赶；
- 2002—2005 大中城市“按需申领”先于全国均质化；
- 2019 “全国通办”对长期异地工作者直接取消一段回户籍地事务旅程；
- 2020—2022 按出境必要性分类的护照签发收紧特别显著。

### 更普遍的现代共同机制

- 第一次建立法定旅行身份通常比续期更强调身体核验；
- 后台网络化可能远早于普通人看到 Web 页面；
- 邮寄、电话、线下窗口、Web、App 可以长期并存；
- 有效证件把未来的跨境路线从“先建身份”推进为“继续申请许可”；
- 身份记录积累越完整，后续事务越容易远程化；
- 政府数据库里的一次状态变化，不等于现实中的一次旅行。

## 13. 主动保留的反例

### 反例 1：有护照但从未出国

2019 杭州案例本人已经长期在大城市工作，却此前从未出国。护照制度越来越方便，并不意味着每个人都已经进入跨国生活。

### 反例 2：网上预约后可以取消、不去或因信息错误未受理

因此不能从系统里的预约记录推导实际办证，更不能推导实际旅行。

### 反例 3：电子化有时增加一次必须本人完成的数据采集

2012 电子护照的指纹采集正说明“数字化 = 去现场化”是错误线性模型。

### 反例 4：2021 不是“全部停办”

留学、就业、商务等必要事由仍然可以经审核办理。

### 反例 5：2024 以后“全程网办”仍是有限集合

它主要先覆盖已有护照、已有指纹记录、符合换补发条件、且属于试点范围的人。

### 反例 6：护照有效不代表其他边境条件成立

签证、目的地入境规则、机票成本、工作/学校许可、边境政策仍可独立阻断路线。

## 14. 后见之明风险

1. **不要把 1980 年代写成“完全不能因私出国”。** 政策和实际执行在变化，留学、探亲等路线已经存在，只是事务成本和审批性质与后来不同。
2. **不要把 2002 上海试点写成全国同步。** 城市扩散有明确时间差。
3. **不要把 2008 年的出境增长解释成每个普通家庭都具备海外消费能力。**
4. **不要把 2013 的“网上申请”写成“网上签发”。** 很多环节仍在线下。
5. **不要用今天的移动 App 体验倒推旧 PC 政务网站。** 浏览器、session、表单、后台接口和错误页必须另证。
6. **不要把 2021 简化成“护照停办”。** 要保留目的分类。
7. **不要把 2023—2026 更新护照解释成“移民意愿”。** 同样可能是旅游、探亲、商务、学习或单纯维持证件可用。
8. **不要让“扩张 / 拥堵 / 偶发 / 防守”成为人格标签。** 它们只是解释环境中风险与时间安排如何变化的分析工具。

## 15. 仍未确定

- 1980s–1990s 不同地区普通因私护照实际申请时间的系统性地区差异；
- 2002—2005 按需申领从大中城市向县域扩展的精确分布；
- 2007—2010 年年轻人“先办护照再决定去哪”的同期第一人称样本仍偏少；
- 2012—2015 北京、上海在线预申请的实际使用率与线下 walk-in 占比；
- 2013 北京、上海历史事务网站的可重放 capture；
- 非户籍人口在线预申请中，后台社保/户籍校验失败的结构性比例；
- 2024—2026 全程网办用户与仍需线下首次申领用户之间的社会分布。

这些未知不得由政策文本自动补齐。

## 16. 对核心矩阵的新增

| 矩阵项 | 本专题新增 |
|---|---|
| 教育 | 留学路线需要护照作为录取之后、签证之前的基础状态 |
| 就业 | 海外工作、商务出差需要证件 readiness；异地上班者曾要回户籍地办 |
| 住房 | 本身不是核心，但长期生活地与户籍地不一致直接影响旧办理路线 |
| 婚姻家庭 | 探亲、跨国家庭团聚受到证件和边境时间约束 |
| 迁移 | 新增“国际移动期权”与“为办移动证件而反向返乡”的悖论 |
| 照护 | 海外亲属突然需要探望时，有效证件影响响应启动时间 |
| 非正规劳动 | 不是主轴；不能把商务/就业护照统计自动等同正规就业 |
| 长期中断 | 疫情期间按目的分类收窄路线，计划可被外部冲击暂停 |
| 证件与记录 | 核心：身份、户籍、指纹、旧护照记录逐步成为后续事务基础设施 |
| 通信方式 | 邮寄、电话、政府内网、Web、App 长期叠加 |
| 互联网平台 | 在线预申请、预约、进度查询、全程网办依次接管不同阶段 |
| 信息获取 | 信息公开减少“到窗口才知道缺什么”的成本 |
| 社交关系 | 海外探亲和跨国联系需要现实身体路线才能最终兑现 |
| 未来预期 | 有效护照使未知海外机会可以更晚决定，不必从最基础证件开始 |
| 线上/线下身份 | 网上账号/表单必须与身份证、户籍、指纹和本人身体重新对齐 |
| 平台消失与记忆保存 | 预约网页可能保存，真实受理/取消/失败和后台比对状态更易消失 |

## 17. 它改变了“人怎么活着”的哪一点理解

过去我们容易把“出国”当成一个很大的决定：留学、移民、远行、商务、探亲。

但真正构成这些宏大路线的，首先常常是一件很小的事：

> **你手里有没有一本还有效的护照。**

1989 年，一个人可能要先证明自己为什么要走、让多个机构盖章，再等两个月；2003 年，越来越多城市开始允许先凭身份申领；2013 年，网页先替申请人占一个未来窗口，但指纹仍要本人去按；2019 年，已经在另一座城市生活十年的人终于不必为了取得国际移动证件先回老家；2024 年以后，一部分曾经建立过生物身份记录的人甚至可以在家里完成换发。

因此，几十年的变化不只是“审批越来越方便”。

更深的一层是：

> **跨国生活从必须先把目的解释清楚，逐渐变成可以先保存移动能力、把人生决定推迟到信息更多的那一天。**

这正是普通人“有多少种活法”里很少被单独计算的一种自由度：不是已经选择另一种生活，而是**不必太早把另一种生活彻底排除。**
