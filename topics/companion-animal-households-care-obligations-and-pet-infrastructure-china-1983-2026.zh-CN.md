# 伴侣动物家庭：非亲属照护、居住约束与宠物基础设施（中国，1983–2026）

## 研究问题

这篇 note 不是宠物产业史，也不把“养猫养狗”当作青年消费趣闻。它补的是生命历程矩阵里一个此前缺少的状态：**一个人可以独居、无孩、未婚，却仍然承担每天不能中断的家内照护责任。**

因此需要把几组经常被混在一起的概念拆开：

- `一人户 ≠ 无照护责任`；
- `无孩 ≠ care-free`；
- `宠物被主人称作家人 ≠ 法律上的亲属关系`；
- `宠物提供陪伴 ≠ 宠物“替代”婚姻或生育`；
- `网上看到可领养动物 ≠ 已经完成安全、稳定的领养`；
- `主人仍然在意宠物 ≠ 主人此刻能够亲自完成喂养、就医、遛放或接回`。

本文把猫犬等伴侣动物视为一种 **non-kin dependent / 非亲属依赖照护对象**。这个术语只描述生活组织结构，不把动物等同于儿童，也不把不同照护关系的强度、法律权利和伦理责任混为一谈。

核心问题是：当一个人的家庭里出现这样一个必须持续喂养、清洁、医疗、安置和看护的生命时，她的住房、通勤、旅行、返乡、迁移、预算、社交和紧急预案会发生什么变化？互联网又在哪些环节真正改变了可执行性？

## 1. 前互联网基线：宠物关系不是 Internet 发明的，城市制度早已能决定它能否存在

1983 年北京市政府发布《北京市养犬暂行管理办法》。文件把城区、近郊区、远郊城镇居民聚居区等划为禁止养犬区，并要求获准犬只登记、检疫、免疫；犬只转户、死亡、丢失还需要在规定时间内办理记录变更。附件同时记录，当时崇文区居民养犬已经达到数百只，并进行了集中处置。

来源：北京市人民政府，1983-09-16，A 级官方同时代制度材料：
<https://www.beijing.gov.cn/zhengce/zfwj/zfwj/szfwj/201905/t20190523_71005.html>

这条材料的意义不是证明“1980 年代北京普通家庭普遍养宠物”，恰恰相反，它证明：

1. 伴侣动物/家犬关系在大众互联网以前就已经存在；
2. 这种生活方式的可执行性很早就受到城市空间、公共卫生、登记和户外活动规则限制；
3. 所以宠物生活史不能从宠物网站、微博或“小红书养宠”开始算起。

1986 年修订办法仍把大片城市空间设为禁养区，并要求准养犬登记、年度复核、免疫牌和拴养/圈养。这里的历史变量首先是 **permission to keep / 能不能养**，之后才有 Internet 时代的 **how to care / 怎样养**。

来源：北京市人民政府，1986-01-24，A：
<https://www.beijing.gov.cn/zhengce/zfwj/zfwj/szfwj/201905/t20190523_71228.html>

### 前互联网阶段暂不能写得更确定的部分

本轮没有取得足够同时代生活史去量化 1980s–1990s 普通城市家庭怎样通过花鸟市场、兽医站、邻里、报刊分类广告、电话和协会完成宠物获得、走失寻找、寄养和医疗。**“没有找到完整链条”不能写成“当时没有这些链条”。** 以后若继续前推，应优先找报刊广告、地方志、兽医站史料、花鸟市场档案和普通家庭日记，而不是用今天的宠物产业回忆倒推。

## 2. Internet 真正新增的第一层：动物与潜在照护者开始变得可搜索

### 2.1 2004–2007：领养对象被压成可远程传播的资料包

新浪生活今天仍能访问一篇标注为 2004-09-03 的宠物送养页：送养者因长期出差，需要为两只幼猫找新家，页面包含性别、年龄、习惯、城市和领养条件等信息。2007-11-29，新浪宠物“领养中心”又保存了一篇网友为满月小狗找领养的页面。

来源（同源 live legacy page；能证明今天仍保存带历史日期的内容，但**不是**已验证 Wayback memento）：

- <https://bj.sina.com.cn/art/2004-09-03/53479.shtml>
- <https://pet.sina.com.cn/2007-11-29/1732155778.shtml>

这代表一个很小但重要的结构变化：过去“谁家有只猫要送”高度依赖附近熟人、纸质告示、电话和本地机构；网页可以把动物转成：

`照片/外貌 + 年龄 + 性别 + 健康/习惯 + 所在城市 + 领养条件 + 联系入口`

也就是 **animal addressability / 动物可寻址性**。

但这只解决“发现”，没有解决“交付”。

### 2.2 2009：在线可发现性同时扩大了错误匹配的风险

2009 年《天府早报》报道成都一起流浪猫领养事件。原照护者因为已经收留多只猫，无力继续照顾，于是在网上发帖寻找领养者；一名男子通过 QQ 联系，自述掌握绝育、驱虫和科学养猫知识，也同意试养与回访。实际交付后，原照护者发现动物遭受严重伤害，后来又通过论坛、搜索 QQ 号和猫友协作追回。

来源：2009-04-13，四川在线-天府早报经搜狐保存，B 级同期媒体，内含同时性自述：
<https://news.sohu.com/20090413/n263349275.shtml>

这一案例不应被猎奇化。它在方法上证明的是：

`网络自我描述 ≠ 真实照护能力 ≠ 安全领养人`

以及：

`在线匹配 → QQ 沟通 → 线下见面 → 动物交付 → 回访 → 异常发现 → 社群协助追回`

领养不是一次点击，而是一条带有身份、信任和后续监督的链。

### 2.3 2010：页面流量与可执行领养之间存在巨大落差

2010 年《新京报》报道，一名志愿者为了给三只流浪狗找家庭，在网站发帖，也在线下社区贴广告。新浪宠物频道的一篇相关博客不到一周有两万多点击，但真正联系领养的不超过 20 人，而且其中一些人在外地。

来源：2010-04-10，新京报经新浪保存，B：
<https://news.sina.com.cn/o/2010-04-10/011717348865s.shtml>

这给出一个很干净的 **visibility / executability gap**：

`20,000 page views ≠ 20,000 potential homes ≠ local compatible adopter ≠ completed adoption`

所以 2005–2012 的“扩张型未来”不能只写成“互联网让选择爆炸”。更准确的是：**候选集合和发现半径大幅扩张，但住房、距离、登记、照护经验、信任与线下交接仍然决定真实结果。**

## 3. 宠物把“一人生活”改成“有人等你回家”：2015–2019 的照护负担与家的生成

2019 年《南方都市报》一篇返乡手记保存了很强的第一人称。作者在深圳捡到一只年老流浪狗，先把寻狗启事发到遛狗群和微博，没有找到原主人，后来自己照顾。她说，有了狗以后，饭点要赶回家喂饭、收工要回去陪狗，原本的“出租屋”逐渐有了“家”的感觉。春节回乡前，她从前一个月就开始为寄养焦虑；现实选项包括留在深圳、开车带狗回家、托朋友、宠物店寄养，而老犬又不适合长途移动。

来源：2019-02-09，南方都市报，B，第一人称：
<https://www.sohu.com/a/293786971_161795>

这条材料非常重要，因为它同时出现了两个方向相反的机制：

- **home-making effect / 家的生成**：一只依赖你的动物可以让临时租住空间产生持续的日常节律和归属；
- **mobility liability / 移动负担**：同一个关系又让返乡、加班、旅行、搬迁不再只需要安排自己。

因此：

`living alone ≠ having nobody waiting at home`

也等于：

`human household size = 1 ≠ care obligation = 0`。

同年《中国青年报》记录了另一组更明确的时间成本。北漂青年赵小森养两只猫，因为疫苗时间不同，一年需要多次往返宠物医院；宠物不能直接按人的普通通勤方式移动，他把问题概括为交通和时间成本太高，于是开始使用预约上门的宠物医疗服务。报道还记录了大学毕业后租房独居的刘畅，通过微博陆续领养猫狗，并把大量收入投入宠物生活。

来源：2019-04-09，《中国青年报》，B，含同期第一人称：
<https://zqb.cyol.com/html/2019-04/09/nw.D110000zgqnb_20190409_1-11.htm>

这使“拥堵型未来”多出一个过去矩阵没有独立处理的机制：**care-route compression / 照护路线压缩**。当工作、通勤已经很满时，年轻人不是不承担照护，而是开始购买“上门医疗、寄养、配送、预约”等服务，把原来需要本人移动的照护任务压回住宅。

### 不做的因果跳跃

同期媒体经常把“空巢青年”“单身”“丁克”和宠物消费放在同一段里。这些材料最多证明它们在当时的公共话语中被相互联系，不能证明：

`养宠 → 不婚 / 不育`

或：

`不婚 / 不育 → 必然养宠`。

宠物可能是陪伴、兴趣、责任、偶然救助、共同伴侣关系的一部分。研究必须保留多种路径。

## 4. 2020–2022：主人存在，但照护链断了——宠物作为危机连续性压力测试

2020 年初，人员无法返城、社区出入受限后，一批宠物被单独留在住宅。昆明同期报道记录志愿者上门添粮、换水，并通过手机直播让无法回家的主人看到宠物。

来源：2020-02-20，《昆明日报》经人民网保存，B：
<https://yn.people.com.cn/n2/2020/0220/c372456-33811522.html>

这一阶段不能简化成“疫情带火宠物经济”。真正新的生活史状态是：

`owner emotionally attached = true`

但同时：

`owner physically reachable = false`

于是宠物是否能继续活得稳定，取决于一整条 fallback stack：

`住宅能否进入 → 钥匙/授权能否交给别人 → 本地志愿者/朋友是否存在 → 粮水是否可获得 → 动物是否接受陌生照护者 → 异常时能否送医 → 主人能否远程确认状态`

这可以称为 **companion-animal care continuity / 伴侣动物照护连续性**。

它与儿童、老人、病患照护并不等价，但它让我们看到一个共同结构：危机时真正暴露的不是“有没有感情”，而是**有没有替代照护者和可执行授权**。

海外有一个很有用的对照。2005 年 Katrina 之后，PETCO 在新奥尔良地区门店设置无线 Internet kiosk，让本地居民访问 Petfinder 的 Animal Emergency Response Network，搜索灾后失散动物；公告明确说，当地有线通信不可靠，因此要提供替代接入。也就是说，早在社交媒体以前，网络数据库 + 临时公共终端就已经被用于“主人不在动物身边时重新建立关系地址”。

来源：PETCO 2005-10-11 企业同期公告，A（可证明企业当时部署/宣称的服务，不自动证明每次重联成功）：
<https://corporate.petco.com/2005-10-11-PETCO-Installs-Wireless-Kiosks-in-New-Orleans-Area-Stores-to-Aid-Pet-Searches>

这个对照说明“灾害使宠物照护链断裂、数字系统帮助重新匹配主人和动物”不是中国特有；中国 2020 年更突出的是住宅门禁、跨城流动与即时通信/直播被组合成新的临时照护链。

## 5. 2023–2026：防守型未来里的“宠物 fallback portfolio”

2023 年春节，新京报/中新网报道一名在北京工作的宠物主人，因为猫而选择开车回河北老家；同期宠物寄养、上门喂养和自动设备一起成为假期安排的候选方案。

来源：2023-02-03，新京报经中新网，B：
<https://www.chinanews.com.cn/cj/2023/02-03/9946444.shtml>

这与 2019 年“宠物寄养焦虑”相比，变化不是焦虑消失了，而是 **fallback portfolio / 后备组合** 变得更丰富：

- 带宠物同行；
- 朋友/同事临时照护；
- 商业寄养；
- 上门喂养；
- 自动喂食/饮水/监控；
- 必要时改变交通方式或放弃一部分行程。

2025 年《中国青年报》又记录了“上门喂猫遛狗”作为假期兼职：有人在春节值班、无法返乡，就利用空闲为其他人的留守宠物提供喂食、清洁、观察和陪玩。这说明同一个照护缺口已经产生了新的 **informal / flexible labor path**。

来源：2025-02-16，《中国青年报》经中新网：
<https://www.chinanews.com/sh/2025/02-16/10369475.shtml>

所以宠物并不只改变消费者生活，也能创造一种围绕他人家庭照护缺口的兼职劳动。

到 2026 年，自动化继续往前推进。《中国青年报》记录年轻宠物主人使用智能项圈、自动猫砂盆、智能喂食器等设备，同时也出现由监测数据引起的新焦虑：设备把睡眠、活动等指标持续推到手机上，主人不一定因此更放心。

来源：2026-01-16，《中国青年报》经人民网/央广网保存：
<https://health.people.com.cn/n1/2026/0116/c14739-40646509.html>

这里应固定两条边界：

`care automation ≠ care transfer`

以及：

`more telemetry ≠ more reassurance`。

防守型未来在宠物照护上的准确含义，不是“大家更舍得花钱”，而是越来越多人试图把一个持续存在的家内依赖关系做成**不会因为加班、返乡、临时出差、疫情、搬家而立刻失效的冗余系统**。

## 6. 海外比较：Internet 改变的是发现半径与匹配结构，不是把“领养”变成一个纯线上动作

Petfinder 1996 年上线，是一个很好的海外比较。2004 年休斯敦地区的同期报道已经明确描述：动物照片与描述上传数据库后，远处的潜在领养者可以在家搜索；但真正的领养仍由各 shelter / rescue group 按自己的规则完成。

来源：Houston Chronicle, 2004-01-06，B：
<https://www.chron.com/neighborhood/article/Houston-area-pets-find-homes-via-the-Internet-9797047.php>

因此跨国共同结构是：

`searchable listing → contact institution/person → screening → physical animal → transfer`。

中国 2004–2010 的新浪送养页、论坛与 QQ 已经出现相似的“发现层”，但组织化 shelter database、身份核验、回访与统一状态管理并不等量成熟。不能把“有一篇网页”写成“已经形成同样的制度能力”。

## 7. 对 Life Horizons 矩阵的新增状态

本轮建议把以下机制作为后续矩阵的可复用字段：

### 7.1 non-kin dependent care / 非亲属依赖照护

一个成年人可能没有孩子、没有同住亲属，却仍然每天承担固定照护任务。

### 7.2 pet-compatible housing / 宠物兼容住房

`有房可租 ≠ 允许养宠 ≠ 空间/邻里/公共区域适合长期养宠`。

本轮还没有系统补齐租赁合同中的宠物条款，属于下一层缺口，不能凭常识补写。

### 7.3 mobility-with-dependent constraint / 携带依赖者的移动约束

返乡、出差、旅游、迁居不再是“买到一张票就可以走”，而需要额外回答宠物是否能同行、谁来照顾、怎样运输。

### 7.4 care fallback diversity / 照护后备多样性

同一主人可以同时维护朋友、寄养、上门服务、自动设备等多条后备链。**有 fallback 与 fallback 可靠不是一回事。**

### 7.5 pet-mediated home-making / 宠物介导的“家”

出租屋可以因为稳定照护节律和等待关系变成主观意义上的“家”。这是同时代第一人称能支持的经验，不应被升级成所有养宠者的一般规律。

### 7.6 platform-mediated adoption risk / 平台化领养风险

扩大匹配半径同时扩大了错误匹配、虚假自我描述和跨城不可执行的可能性，因此筛选、回访和线下核验不是“旧式摩擦”，而是照护安全层。

### 7.7 care-platform labor / 照护平台劳动

寄养、上门喂养、上门医疗等把私人家庭里的宠物照护缺口转成新的服务劳动与零工路径。

## 8. 反例与后见之明风险

1. **不能把宠物写成孩子的替代品。** “猫儿子”“毛孩子”是部分受访者的关系语言，不等于法律、经济和生命历程上与育儿同构。
2. **不能把年轻养宠增长直接解释成孤独。** 可能还有家庭传统、兴趣、救助、伴侣共同选择、收入变化、城市动物文化等原因。
3. **不能把宠物市场规模当宠物家庭比例。** 消费额、犬猫数量、用户数的分母不同，行业白皮书尤其需要保留调查方法与商业来源风险。
4. **不能把在线领养页的存活当成动物状态存活。** 2004/2007 页面今天还在线，不代表对应动物今天仍可领养，也不代表页面二十年间从未下线或变形。
5. **不能从成功故事估计成功率。** 找到新家、灾后重联、救助成功更容易被报道；无人回复、领养失败、退养、页面无人更新更容易消失。
6. **不重新公开旧联系方式。** 旧送养页含邮箱/电话等个人联络信息时，只保留支持研究结论所需的最小信息。

## 9. 当前尚不确定 / 下一步

- 1980s–1990s 中国普通城市家庭获得、寄养、寻失宠物的具体非互联网信息链仍缺强生活史；
- 2004–2010 中文宠物领养/寻宠页面尚未获得并实际验证 Wayback/WARC transaction capture；
- 宠物友好住房、航空/铁路、酒店、商业空间怎样改变迁移与旅行，需要另做制度/服务地图，不能在本篇凭印象扩写；
- 宠物死亡、数字纪念与账号遗产应与现有 digital-afterlife 专题交叉，而不在这里重复；
- 需要寻找失败样本：长时间无人领养、跨城无法交付、寄养服务失约、自动设备故障、临时照护链中断。

## 10. 这一轮改变了什么

此前的 life-course 矩阵很容易把“照护”默认成儿童、老人、伴侣、病患等人类关系，把“独居/无孩”默认理解成相对少的家内依赖责任。本轮新增一个必须单列的状态：

> **一个人可以是唯一的人类住户，却不是家里唯一需要被安排时间、空间、金钱和应急后备的生命。**

这使住房、迁移、返乡、加班、旅行和“未来是否自由”的判断都需要多问一句：家里是否还有一个无法自己订票、开门、买粮、去医院，却会持续等待照护的成员。

Internet 的关键变化也不是“年轻人开始喜欢宠物”，而是把领养、寻宠、养护知识、寄养、上门医疗、临时照护和灾害重联逐步做成可搜索、可协调的基础设施。它扩大了可以建立这种关系的半径，同时也把筛选、回访、服务可靠性和平台状态维护变成新的生活劳动。
